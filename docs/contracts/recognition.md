# 共用页识别

题库、资源和备课使用同一个机器页结果。HTTP/schema 以 [materials.openapi.yaml](../../apps/api/src/contracts/materials.openapi.yaml) 为准；来源、文件与任务沿用 [materials.md](materials.md)。模块只负责采用、校对及自己的业务结构，不各自启动 OCR 服务。

## 入口与状态

- `GET /api/workbench/files/:id/recognition?renditionFileId=...` 返回配置是否可用、固定来源和各页状态；GET 不受理识别。
- `POST` 同一路径，正文 `{renditionFileId,pages}`，带现有请求保护和幂等键，返回持久受理的 `recognition` Job。
- `GET /api/workbench/files/:id/recognition/pages/:page?renditionFileId=...` 读取这一份来源的机器结果。省略 rendition 只读当前预览；消费者应传入画面中固定的 rendition。
- 取消与重试使用现有 Job 接口。`unitId` 为 `page:N`；空重试集合代表原请求全部未完成页。已成功页保持不变。引擎修订变化后拒绝重试旧 Job，需要明确重新发起识别。重启将运行中页标为 interrupted，不自动重发。

原件、rendition、页图均为同账户受管文件，且必须出现在已生成的固定预览映射中。尚无预览返回 `preview-required`；引擎不可用且需要新识别时返回 `recognition-unavailable`。前端保留原件和输入，显示可重试状态。其他账户的文件及结果返回 404。

成功页按账户、页图字节摘要和引擎/转换修订复用。同像素的另一份上传可以复用结果，但返回 `location` 必须绑定本次请求原件、rendition 和绝对页号。模型输出的空页号、相对序号不能覆盖这个映射。活跃请求覆盖全部所选页时返回同一 Job；仍有其他页正在处理时返回 `job-running`，不静默改变选择。

未配置引擎时，既有成功结果仍可读取。取消期间已经完整返回的原始结果和图片作为该 Job 的证据保存，不发布为 ready 或重开任务；请求记录绑定迟到产物，后续重试不能擦除这份绑定。

未能确认本地识别进程停止时，页和 Job 标记失败并提示清理未确认，不报告取消完成。临时证据保留；下一次明确识别请求先尝试停止旧进程范围，成功后才启动新模型。

本地运行临时目录由实例显式传入 `createRecognizer({home,workDirectory})`，与共用模型目录分离。`run` 接收可信的 `accountKey`，在创建页目录、写入原页前原子保存账户、本实例真实路径与本次 scope 归属；归属记录置于页目录之外，确认页目录已移除后才删除。账户删除先取消并等待该账户的任务，再调用 `recognition.cleanupAccount(accountKey)`；该接口等待本实例识别写回结束，确认对应 scope 已停止后才清理该账户的临时原页。权限、停止或归属核对失败时保留现场并拒绝报告清理完成，创建或删除中断后仍可按持久记录重试。其他账户、其他实例和旧模型目录中没有归属的现场不在清理范围内。引擎未配置或环境不可用时，已配置实例工作目录的清理端口仍可调用，`available:false` 不影响旧机器结果读取。

## 机器页结果

`ready` 表示完整结果、文稿和引用的文件可以读取，不表示教师已经校对，也不表示识别准确率为 100%。结果包含：

- `resultId`、输入摘要、引擎修订及本次来源 `location`。
- `rawFileId` 指向原始识别 JSON；原始版面字段保留，不被机械转换覆盖。`content_check` 附加独立 CPU 识别原始结果、规则修订和内容疑点，不替换主识别正文。
- `document` 是 Document v2，包含文字、数学、表格和受管图片；`text` 是可搜索的全文投影。
- `blocks` 保留模型块的数组顺序和原始字段，补充块级 Document、文字、归一化区域及附件引用。空 order 不触发重新排序。
- `assetFileIds` 保留全部派生及原始图片，包括 HTML 表格内的图片；`originalAssetFileIds` 单列原始资产。文稿引用派生 PNG，不能用资产总数计算文稿的图数。
- `derivations` 保存每张图的原坐标、polygon、派生矩形及裁图疑点。原页矩形保留原像素；缺少表格单元格边界时，保守扩边可能带入表格线，必须保留疑点。
- `issues` 汇集格式恢复、未解析数学、结构缺口、裁图及局部内容疑点。`ocr-text-conflict` 表示同一段存在不同识别结果；`ocr-source-gap` 表示原图该行有待核对的较大留白。两者携带归一化 `box`、`blockId` 和静态 `detail`，不宣称缺失了某个确定字符。缺失被引用的图片或不可读取的内容导致失败，不能伪装为空页成功。

机械转换只表达模型实际返回的内容。不得添加答案、重画原图、纠正数学结论或用固定题号规则修补样本。原始图块与从原页像素派生的裁图分别记录；派生不得使用旧 polygon 掩膜截掉图形。

普通正文中的大写几何点名加整数下标可恢复为数学 run；上下文明确的字面换行可恢复为同一单元格内的段落。恢复保留 `math-recovered` / `text-lines-recovered` 校对提示和原 block 定位，原始 JSON 与块内容不变。代码、链接、路径、引用中的字面表达及无法确定的数学记法保持原文和疑点。该规则不修补任意 LaTeX，也不推断题目边界。

内容复核在主识别释放后串行运行 PP-OCRv5 mobile CPU 管线，复核失败使本页失败并允许明确重试，不发布缺少复核阶段的新结果。正文冲突要求复核行的汉字序列在主识别块中完整且唯一对应，再比较相邻汉字间的普通内容；重复题干或不完整对应不强行选择首次出现的题目。复杂数学不以删除运算符的方式凑成一致。留白候选来自行间或公开词位置中的间距，并核对原图像素，排除可见公式、答题横线及重复对齐列。词位置是由解码位置估计的区域，不是逐字精确轮廓；布局分数和整行识别分数不作为文字正确概率。

没有疑点不代表内容正确：两路共同补全或省略、复杂公式、无法对应的片段可能漏报；刻意较大的词间空白与缺字可能无法区分。提示只要求对照原稿，不自动改写正文或猜测缺字。原件、两路机器结果与教师校对稿分别保留。

## 模块接缝

服务端依赖 `recognition` 提供 `get`、`readPage`、`readResult`、`request` 和 `ensurePage`。`readResult(principal,resultId,source)` 同时核对已完成结果和来源。题库 extraction Job 在自己的执行内调用 `ensurePage(principal,{fileId,renditionFileId,page},{signal,retry})`，不能把子任务排入同一串行执行器再等待。已有失败页默认只读，显式重试才重新执行。

资源查询把原生文字与已完成 OCR 结果合并，原生 PDF 文字层保持其原有坐标。识别正文不冒充精确文字层。备课采用前允许整页校对，保存来源及机器/采用快照；后续编辑不覆盖机器结果。题库独立负责题号、答案、题图和跨页关联。

三个消费者显示具体内容疑点，并可查看对应原页区域。题库使用 `uncertain-text` 和可选静态 `detail` 表达局部内容疑点；疑点只关联可唯一确定的题目。同一识别块含多题时，按保留的正文范围关联；无法唯一确定时留为带原页位置的未分配片段，不给整页所有题添加同一个提示。局部校对与原稿对照后可保存、刷新继续，其他已核对题目可以先入库。

备课可从整页机器文稿中显式选择配图，再沿 File 预览及固定第 1 页识别，校对后独立采用为教学环节。`AdoptLessonPage.recognizedImage` 只提交配图文件、衍生件和结果 ID；原顶层字段仍绑定父资料原页。采用事务只读父子 ready 结果，所选图片须同时出现在父机器文稿的递归 image 引用和 `assetFileIds` 中，原始备用附件、其他页图片不能代替。`pageSource` 保留父页机器稿、原页与原始结果，子 `recognizedImage` 保留配图机器稿及其文件；根 `adoptedDocument` 是教师校对的子文稿。复制、保存历史和导出保留两层来源，不将裁图第 1 页冒充原资料页码。

部署备份保存识别表与受管原始结果/图片并核验账户关系；备课当前环节的 `pageSource`、历史快照和题库提取任务都校验文件归属。个人资料包保留识别元数据及附件，补充元数据中的 `questionRecognitionEvidence` 记录题库任务取消后的完整迟到产物及固定来源，不导出其内部执行进度。个人包仍是可读导出，不提供覆盖账户式还原。

## 路线与验证

当前使用 PaddleOCR-VL 的完整本地管线，版面定位、内容识别和排序一起执行；保留现有 File、Job、Document、Location 与原生 Word/PDF 路径。固定模型、依赖和实际运行参数只在[运行指南](../SETUP.md#本地页识别工具)及其源码入口维护。资源、备课与题库复用同一识别服务，不各建模型进程、独立缓存或常驻服务。

页块解析不等于教学语义：题库负责题目/答案/配图与跨页归属；备课负责校对采用，资源负责阅读和检索。原始机器结果、机械转换与人工采用分别保存、分别判断，不能以人工修正后的产物代签模型准确率。

识别变更依次验证运行与停止恢复、原页对照的原始质量、Document/真实裁图转换、三个模块的保存与使用。先确认共用层，再验消费者；固定产物回放只证明消费，模型或参数改变后必须重新验证真实原页。固定输入在[样本索引](../acceptance/samples.md#固定输入与回放)，完整要求在[提取判据](../acceptance/mvp-matrix.md#extraction)，当前结果在[项目状态](../plans/run-state.md)。

若同类核心失败持续出现，可据固定输入和新证据替换路线，无须维护既有方案；公开评测和 Markdown 流畅度不能替代产品实测。需要重新选型时可追溯冻结调查 `59763ca2c38ef98b03045d785d1c49bcef913c4b:docs/research/c21-open-source-reuse.md`，按当次实际需要重新核验上游事实；旧调查不提供新的费用、模型或环境操作授权。
