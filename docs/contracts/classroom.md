# 班级后端契约

实现或消费班级接口时读本页。产品行为见[班级](../features/classroom.md)，精确字段以 [classroom.openapi.json](../../apps/api/src/contracts/classroom.openapi.json) 为准，验证入口见[班级验收](../acceptance/classroom.md)。模块 ID 为 `classroom`；退役 ID `classes` 不复用。

## 入口与公共边界

HTTP 前缀 `/api/modules/classroom`。可信身份、页面绑定、Origin/保护头、Idempotency-Key、版本冲突和 Problem 采用[公共保存契约](workbench.md)。读取无副作用；同账户以外对象和文件返回 404，参数错误 422，版本或状态冲突 409。创建返回 201，更新返回 200。

| 资源或操作 | 用途 |
| --- | --- |
| `classes`、`students`、`records` | 名单、资料与自由记录的查询、创建和更新 |
| `PUT classes/:id/seating` | 完整座位布局及基线版本 |
| `exams` | 原卷、稳定计分题、满分、日期及标签 |
| `tags`、`POST tags/:id/merge` | 标签查询、创建、改名及原子合并 |
| `imports`、`POST imports/:id/confirmation` | 成绩表读取、映射与校对草稿、确认成绩 |
| `results` | 已确认成绩的查询和版本化修正 |
| `PUT <集合>/:id/deletion` | 支持对象的软删除或恢复 |
| `GET students/:id/statistics`、`classes/:id/statistics` | 学生及班级的逐场序列 |
| `GET exams/:id/comparison` | 同场指定班级的对照 |

列表按明确过滤返回全部匹配 `items`，没有隐藏分页。未知或重复查询参数、重复 UUID 筛选值拒绝。日期使用真实日历日 `YYYY-MM-DD`；分数最多两位小数，计算使用整数百分之一分避免同分误差。范围、正文和数组上限查机器 schema，不由 UI 自行放宽。

班级工厂的顶层 operations、只读 port、可信参数、Excel 异步准备和幂等提交，以及持久化/维护入口见 [班级技术入口](../subsystems/classroom.md)。SQL 和仓储归模块；业务交换保证由本页维护。

## 资料、关系与版本

所有对象有稳定 ID、版本、创建/更新时间与删除状态。学生属于当前班级；同班活动学生的非空学号唯一，姓名可以相同。换班时移除旧座位并更新旧班级版本，学生记录仍绑定学生 ID。成绩保留考试时的班级及学生姓名/学号快照，后续改名、换班和删除不会改写既往事实。

题目 ID 在考试内稳定，新增题由服务端生成 ID；有实际成绩的题不能直接移除。修改总满分或题目满分时检查已保存分数，越界整笔拒绝。新增题在旧成绩中属于缺失。题目分组只是标题，不计第二份分数。

标签名称经 trim、Unicode NFKC 和连续空白合并后检查重复。合并同时核对源/目标版本，更新活动及删除考试中的标签并去重，增加受影响考试版本；旧标签保留合并目标用于解释来源，不能再作为有效题目标签。连续合并时，同事务将既有指向源标签的条目改指向最终目标并增加版本，始终保持单跳；没有递归别名解析或自动复活。

## Excel 输入与确认

接收标准 `.xlsx` 和 Excel 97-2003 `.xls`；按实际字节判别，拒绝加密文件及伪装的 HTML/XML。单原件最多 10 MiB、ZIP 实际展开最多 64 MiB、最多 20 个工作表、每表 2000 行及 256 列，总计最多 100000 个单元格；超限明确拒绝，不截断录入。SheetJS 固定依赖由锁文件安装；读取器及可重建样例在 `workbook.js` 与 `test/fixtures/classroom/`。

读取结果保留工作表、行列、显示文本、合并区域和公式信息。公式仅使用已有有限数值缓存，不执行公式；缓存缺失/非法及错误单元格保留为待校对问题。空白为缺失，数值 0 保持为 0，百分比、日期、布尔和非数字文字不能直接变成成绩。学号使用显示文本保留已有前导零，不补猜 Excel 已丢失的零。

创建导入指定考试、班级及源 File ID，得到未映射草稿。映射包含工作表、表头、数据行范围、姓名/学号/总分/缺考列、题目列和显式忽略行；行列从 1 起，工作表序号从 0 起。PUT 的 `rows:null` 由服务器按映射生成候选，完整 rows 数组表示人工校对；改变映射须重新校对，传 `rows:null` 重新生成候选。原表及坐标保留供对照。

有学号时精确匹配本班唯一活动学生；没有学号时仅在完全同名且唯一时给出候选。姓名/学号矛盾、重名、未匹配或重复匹配均须明确处理。导入不新建学生，不接受客户端编造的学生快照。老师可明确忽略原行，不能遗漏原行而静默丢弃数据。

校对可以保留问题草稿，确认时重新检查全部错误与基线。阻断错误拒绝整笔确认；警告允许保存。仅映射使用的错误单元格阻断，人工修正后不再被源错误永久拦住。`reviewedSourceRows` 由服务端记录显式提交校对的行；自动候选不带复核资格，重设映射清空标记。人工提交仍完整检查分数、状态及学生匹配，不能借复核绕过业务错误。未出现在表内的班级学生记为 `unrecorded`，缺考为 `absent`，实际参加为 `present`；缺考和未记录不携带分数。

确认检查考试、班级、学生及现有成绩版本，原子写入一份 `(examId,classId)` 成绩、导入确认状态和幂等回执。新导入按当前基线替换活动名单成绩，保留既有结果中已换班或删除学生的历史行及快照，不追加重复成绩；已删除成绩须先恢复。确认后改映射或源表需新草稿，个别成绩通过 Result PUT 修正并保留原来源。历史行不能无声删掉，纠错须明确为未记录；不可把任意外班学生加进成绩。

每场总分仍来自表格或人工校对。仅当逐题完整且满分覆盖整卷时判定总分差异，返回 `totalMismatch` 警告；逐题缺失只报告覆盖不足。不会用题分之和覆盖总分，也不会把差额分摊到题目。

## 原卷与固定定位

Exam 的 source 按阅读顺序保存原 File ID 和可选固定 rendition；接受 Word、PDF、PNG/JPEG/WebP。下载、预览、转换及裁图使用[材料接口](materials.md)。题目 location 引用该考试 source 中的固定 rendition 和真实页号；页从 1 起，box 为显示方向左上角归一化的 x/y/width/height，必须位于页内，null 表示整页。

跨页题可有多个 location。保存和恢复均核对原件、派生文件、页映射及账户归属；预览更新不替换旧定位。没有可用预览时允许保留未定位题及原件，不声称题目已识别。换原卷必须在同次考试更新中重新校验全部定位。

## 统计口径

查询只使用未删除考试和成绩。学生更名、换班、软删除不抹去成绩；历史班级参考来自结果所属班级。每场保留考试名、日期、学科、满分、题目及相关版本，筛选无结果返回空序列。

| 指标 | 分子、分母与缺失处理 |
| --- | --- |
| 总成绩、均值、中位数、最高/最低 | 仅 `present` 且总分为数值者参与，0 分参与；另列缺考、未记录及总分缺失人数 |
| 得分率与排名 | 总分 / 本场满分；同分排名 1/1/3，同时返回排名人数，不把人数改变解读为能力变化 |
| 单题 | 已知分数之和 / 已知人数乘题目满分；同时返回可观察人数、已知及缺失人数，无已知时 rate=null |
| 标签 | 命中题目的已知得分和 / 这些已知得分对应满分和；返回全部可能满分、已知/缺失格数，多个标签按题目 OR 并集 |
| 分布 | 总分得分率十档 `[0,.1)` 至 `[.9,1]`，满分入末档，缺失与缺考不入零分档；附学生 ID |
| 同场比较 | 同一 examId 下各班使用同口径；没有成绩明确 `no-result`，不伪造零均分 |

跨考以逐场 points 呈现，日期和考试可过滤；未考到选定标签为 `not-assessed`，考到但全缺分为 `missing-scores`，两者都不填零。单标签报表可能共享题目，不可把各标签结果相加当作整体。response 的 `dataVersions` 标明参与的考试、成绩与标签版本；不存派生统计或 AI 结论。

## 删除、导出与恢复

软删除保留对象及关系。删除班级不改写孩子，恢复父级不复活独立删除对象；删除学生移除当前座位但保留历史成绩，恢复不抢占座位；删除考试或成绩使其退出统计。确认导入属于保留来源，不能单独删除。

个人包包含七类 `classroom-*` 对象和源文件、固定预览、关系。部署恢复校验 schema、同账户对象引用、唯一成绩、分数范围与固定文件定位；历史换班、父级软删除属于合法状态。具名旧备份追加新模块空表后执行现行完整校验，不迁移退役旧班级数据。公共恢复及删号仍按[数据管理与恢复](../features/data.md)执行。
