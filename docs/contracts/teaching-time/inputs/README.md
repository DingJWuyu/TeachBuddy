# 固定输入

只读副本清单为 [manifest.json](manifest.json)，每项含来源完整 SHA、原路径、本地路径和 Git blob。T50 原包放在其原文档路径；M40 schema 及其递归外引放在 `m40/`，保持原相对目录并逐字节复制，不覆盖本分支认证、材料或数学提供方。

消费本批新版从[教学记录与数学作品契约](../../teaching-time.md#数学作品关联)进入。副本中的候选状态和原文导航不重新解释为本次状态；未复制的提供方文档/证据按 manifest 的 SHA 用 `git show <SHA>:<原路径>` 读取。这里只封存可解析 schema 所需闭包与直接扩展，不复制提供方全部实验制品。

manifest 中 `local` 位于 `inputs/m40/` 的五项是本树固定副本，其余条目定位原 T50 commit 内的路径；不能把它们当作当前文档导航。

旧 T50 schema、用例及样本保持独立；新版外引 M40 的数学分支并在自身完整 OpenAPI 中保留原 T50 定义。需要修正提供方时由原拥有者发布新版及独立冻结，消费者不编辑本目录中的副本。
