# 数据管理与恢复

这一页讲老师的资料怎样带走、误删后怎样找回、删除账户时清掉什么，以及维护者怎样把整个工作台还原到某个时间点。三件事互不替代：

- **个人资料包**把老师自己的资料下载下来阅读和取回，不能导入回来覆盖账户。
- **误删恢复**在各模块自己的归档里进行，恢复的是原来那个对象。
- **维护备份还原**由维护者停服后执行，把整个工作台连同所有账户退回备份那一刻。

保存、草稿和冲突的共同规则见[工作台](workbench.md)。

## 个人资料包

- 在设置里点"导出数据"生成资料包。导出记录列出每次的时间和状态（等待生成、正在生成、可下载、生成失败、已中断），可下载的才能下载。
- 内容固定在点下导出的那一刻，包括已归档的内容：题目和来源快照、原稿和校对稿，资源和保留的每个文件版本，数学作品每个历史版本的源码和导出文件，班级、学生、记录、考试、成绩和导入证据，日程和通知，偏好和导航布局，助理对话和工具结果。原题后来被彻底删除，包里仍有当时的快照。
- 解压后打开 index.html 就能离线阅读，能找到对应的原文件、源码和关联。外部 HTML 只提供下载，不在阅读页里运行。
- 不含密码等账户秘密、登录会话、验证码、模型内部记录和没上传的设备草稿。老师写的文字原样保留，不会为过滤敏感内容而删改。
- 原文件缺失或磁盘不够时显示"生成失败"，不会给出缺附件的包；服务重启打断的显示"已中断"。两种情况业务资料都不受影响，重新导出即可。
- 导出记录可以逐条删除：正在生成的先停下，正在进行的下载中断，服务器上的包和记录一起删掉。教学资料和已下载的副本不受影响。
- 生成或删除的结果暂时无法确认时，按工作台的保存规则保留原请求，可以查看并重试确认；关弹窗、离开设置或刷新后它仍在，确认之前不能发起新的导出或删除。
- 取回内容靠重新上传原文件、把数学 HTML 导入数学工坊、或复制正文和公式；取回的是新对象，不恢复原来的编号和关联。资料包和维护备份不能互相代替。

## 误删恢复

- 题目、资源和数学作品从各自的归档恢复，编号、来源、文件和历史版本都还在；彻底删除后不能恢复。规则见[题库](questions.md)、[资源库](resources.md)、[数学工坊](math.md)。
- 日程没有回收站，删了就不能恢复，见[日程](schedule.md)。
- 班级、学生、记录和考试删除后可以恢复，见[班级](classroom.md)。
- 删除收录材料不会删除已入库的题目。
- 设置里没有跨模块的"最近删除"，隐藏导航模块也不会删除资料。

## 删除账户时清理什么

确认和核实过程见[账户与身份](identity.md)。

- 清理这个账户的全部资料：各模块正在用的和已归档的内容及关联、原稿、附件、导出文件、识别结果、偏好、助理对话和登录资料，包括暂时不在模块目录里的模块。其他账户不受影响。
- 先撤销所有登录，等助理、后台任务、导出和识别都停下，再清文件和记录；全部完成才报告成功。
- 服务器确认后，浏览器清掉这台设备上该账户的草稿、待上传文件和助理缓存；失败可以单独重试，其他账户的设备资料保留。
- 已下载的副本、外部资料和维护备份不受影响。用删号之前的备份还原，可能把这个账户带回来。

## 维护备份和还原

这是维护者的操作，不在设置里。命令和参数以维护命令的 `--help` 为准，运行准备见[运行指南](../SETUP.md)。

- 只在停服后备份：服务、后台进程和自动重启都停掉，服务还在运行时备份会失败。备份包括完整的数据库和全部受管文件，配置另行保管。账户删除没完成时不能备份。
- 还原写到一个新目录，原数据和备份都不改。先准备：核对完整性、版本和迁移，撤销备份里的全部登录；再由维护者启用，之后才能开放。任何核对不过都停下，原数据不动。
- 这是时间点还原：备份后的新账户、新密码和新资料不会合并回来。还原后又有新写入再切回旧库，就是又一次时间点还原，由维护者明确选择。
- 还原后资料以原来的编号、源码和关联回来；旧登录全部失效，老师用备份时的密码重新登录同一账户。资料包不在备份里，之前的导出记录显示"已中断"。
- 工作台会提示"工作台已从备份恢复"。这台设备上旧的草稿和待确认请求保留但隔离，不自动重新执行，老师对照当前资料后再明确保存。助理在还原前结果不确定的操作保持未确认，不会再执行一次。普通重启不触发这些。
- 较旧版本的备份可以还原，其中已退役的备课和旧班级教学数据会被移除，不会重新开放；无法识别的版本直接拒绝。

## 故意不做的

- 没有整包导入、按原编号恢复关联或账户迁移；原编号还原只由维护备份承担。
- 设置里没有最近删除汇总、设备草稿管理、恢复隔离记录或备份说明。
- 不做运行中的在线备份，没有跨库合并或跨账户重映射。
- 删除条目不等于释放磁盘空间，没有文件自动回收或过期清理。
- 删除账户不追查已下载的副本、外部资料或维护备份。
