# 资源库

资源库保存老师真实在用的 PPT、模板、图片、文档和外部工具做出的成品，方便积累配色、版式和素材，随时找出来预览、下载或复制文字。题目编辑在[题库](questions.md)，作品制作在数学工坊，实体书籍不在范围内。

资料条目的名称、文件夹、标签和备注与它当前的文件分开：换文件不改条目，改备注也不动文件。界面以[设计输入](../design-system/README.md)和完整应用原型为准。

## 上传

- 上传即收录：名称默认是文件名，显示"文件已保存"后留在列表里，不用再点保存。可以一次选多个文件，按选择顺序收进当前文件夹并显示进度。
- 选择时先检查单个文件不超过 100 MB、文件名不超过 200 字。
- 上传队列和没确认的请求记在这台设备上，刷新后接着传，已保存的不会重复创建。结果不确定时请老师重新选择原文件核对；明确失败的可以跳过，继续剩下的。
- 同样字节的文件已经在本账户里（包括归档）时，先提示"发现重复资料"，老师选择跳过或另存。判断看文件内容，不看文件名。

## 浏览和整理

- 列表可以切换缩略图和列表视图，缩略图取第一页或原图，预览完成后自动出现。可以按格式、文件夹（含子文件夹）和标签组合筛选。
- 文件夹就是分类，可以移动、改名和删除。删除文件夹会连同子文件夹一起删掉，里面的资料移到未分组，资料本身不删。
- 标签由资源库自己管理，名称、顺序和八种颜色随账户保存，换设备也一样。浏览栏的标签用来筛选，资料信息里的标签用来标记当前资料。
- 资料信息里可以改名、选文件夹和标签、写备注，也可以就地新建文件夹或标签，点"保存修改"才生效。没保存的修改在收起信息栏和刷新后保留；期间删掉的文件夹或标签会从草稿里去掉，其他修改不动。
- "选择资料"后可以批量移动到文件夹、追加标签、归档或恢复，每次最多 100 份。整批要么全部生效，要么全部不生效；移动不改其他信息，加标签保留原有标签。
- 返回列表时恢复原来的文件夹、筛选、选择和滚动位置。

## 预览和复制文字

- PDF 和图片直接看，Word 显示固定转换后的页面，PPT 显示静态幻灯片。多页文件才显示翻页和页码跳转，缩放和阅读位置按文件和页保留。
- HTML 只以安全的纯文本显示或下载，不执行其中的脚本，交互展示请用数学工坊。
- 转换不完整时显示"预览需核对"并标出缺页或公式对象风险。转换失败时说明原件已保存，并提供重试和补充 PDF 入口；格式本身不能在线预览时请老师下载后用对应软件打开，不显示无效的重试。
- 旧版 .doc 常丢公式对象，必须给出实际转换页和补充 PDF/图片的入口。老师可以上传用 Office 导出的 PDF，逐页核对后采用为这一版文件的补充预览；换了新文件后不沿用旧的补充预览。
- 一份资料预览失败只影响它自己；Office 工具没装时，PDF、图片和 HTML 预览不受影响。
- 有文字的页面可以拖选复制，也可以"复制本页文字"。"查找本页"在当前页里按字面查找，Enter 和 Shift+Enter 在命中之间切换，Escape 关闭；不跨页、不支持正则。复制出来是纯文本，复杂公式、表格和多栏顺序需要对照原件。

## 识别扫描页

- 扫描页没有文字时会明确说明。老师点"识别本页"或"识别剩余页"才开始识别，打开资料、查看状态和搜索都不会自动触发。
- 多页识别显示完成数量，可以停止后续页，已完成的页保留，失败或中断的页由老师决定是否重试。刷新不会重复创建识别任务。
- 识别结果只读，标明尚未校对，公式、表格和图片按排版显示；"复制本页识别文字"复制包含公式源码的原文。识别为空只说明没认出文字，不断言原页空白。
- 识别结果绑定当前文件和那一版预览，翻页、换文件和刷新后读的都是对应页。疑点会说明原因，并可以在原页上标出位置。
- 识别服务不可用时，原件和已有识别结果照常可看，新识别按钮禁用。

## 搜索

- 搜索覆盖名称、原文件名、备注和当前文件的正文：带文字的 PDF、已转换的 Word 和 PPT、纯文本，以及已完成的识别结果。采用了补充 PDF 时以补充 PDF 为准；换文件或恢复历史后只搜当前文件，旧内容不混进来。
- 正文命中显示摘录和第一处命中的页码，打开后定位到该页。中英文不区分大小写，连续空白视为一个，中文跨行也能连上。
- 第一次搜索时逐步读取正文，界面说明还剩多少份没读完并自动补充结果。没有可读文字、还在等预览、读取失败和没有匹配分别说明，读取失败的可以重试。断网时停止等待，提供"继续检索"。
- 打开命中时会重新核对资料当前的文件；文件已经换了就提示重新搜索，不会把旧页码套到新文件上。
- 归档列表单独搜索，文件夹、标签和格式筛选照样有效。

## 文件历史、归档和删除

- "更新文件"先确认新旧文件名，新文件保存成功后才替换，名称、文件夹、标签和备注不变；失败时保留原文件。预览没完成不妨碍原件保存，状态一直可见。
- "文件历史版本"按新到旧列出，每一版都能下载核对。恢复旧版前再次确认，成功后作为一个新版本采用旧文件和它的补充预览，其他信息不变。只改备注或分类不产生文件历史；历史从这个功能启用时的文件开始记录。
- 归档后回到原列表，浏览条件不变。归档资料可以查看、下载和恢复，恢复后才能切换当前文件。
- 彻底删除只对归档资料开放，二次确认后永久移除，刷新和搜索都不会再出现，文件历史也一起移除。
- 保存失败、结果不确定或版本冲突时按[工作台](workbench.md)的保存规则提示，草稿不丢。从旧链接打开已删除的资料时显示"未找到资料"；读取失败则显示错误并可重试，不当成资料不存在。

## 故意不做的

- 不做语义搜索，不跨页查找，不用正则。
- 不执行上传的 HTML 或 Office 里的脚本和宏。
- 不自动合并重复资料，重复与否由老师决定。
- 没有并行于文件夹的第二套分类树，也不和题库共用标签。
- 不推测重建功能启用之前的文件历史。
- 彻底删除只移除资料条目，已保存的文件字节继续保留，暂时没有回收磁盘空间的入口。
