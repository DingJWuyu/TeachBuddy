# 数学工坊

数学工坊帮老师在一个作品里做好一堂课的数学内容：可编辑的公式、一个完整的数学构造（函数、平面或立体图形）、参数和教学步骤。作品可以试演、全屏上课、导出成图片或离线课堂演示，之后随时接着改。主要靠右侧的数学助理用自然语言制作，也可以直接手动做。

构造和绘图由项目自带的本地 GeoGebra 完成，不依赖 GeoGebra 官方服务，画面保留其署名。界面以[设计输入](../design-system/README.md)为准。

## 首页

- 首页可以新建、搜索作品，切换缩略图和列表。按类型浏览、导入和已归档作品在右侧栏。
- 在首页描述想做的内容并"开始制作"：助理已连接就进入新作品并直接执行这次请求；未连接就展开连接引导，输入保留。
- 没有任何内容就离开，不会留下空作品。连续改搜索或切换已归档时，只显示当前条件的结果。

## 制作

- 公式按顺序排在上方，单击即编辑，Enter 确认；需要时展开"公式源码"编辑或复制 LaTeX。纯公式作品不显示空画布。
- 公式下面是数学画布和步骤轨道。可以连续"输入算式"，也可以用点、线、圆、多边形和立体工具直接画。"平面""三维""双视图"切换同一个构造的视图。
- 画布、内容列表和右侧属性栏共享同一个选择，细小的对象可以从列表选中。打开 AI 辅助栏会盖住属性栏，关掉后现场还在。
- 滑杆参数用数值框和滑杆一起调。改名、删除对象或改参数范围时，步骤、播放和轨迹里的引用跟着更新，会影响步骤的改动先确认。
- 作品在深浅主题下都画在白纸上，数学对象的颜色不变。

## 步骤、试演和上课

- 参数可以单次、循环或往返播放，按步长取值、不超出范围；点可以留轨迹。
- 每一步记下参数取值、可见的对象和公式、视图和一段说明。切到一步总是从完整构造重新套用，前一步的探索不会带过来。
- "试演"里拖动、播放和切换步骤都不改作品，"设为开场"才把当前状态存为开场。某个取值下对象无定义时隐藏并提示"此取值下无定义"，不拿旧结果冒充。
- 独立公式是文稿，不随参数求值；要跟着变的标注用图形对象做。
- 课堂展示进入浏览器全屏，只留参数、步骤、播放、重置和退出；退出回到编辑内容。浏览器不支持全屏时在窗口内展示。

## 保存和历史

- 修改自动保存到服务器，状态分正在保存、已保存、保存失败和结果待确认，失败可以重试；结果不确定时先确认上一次，不会多建作品。
- 公式、构造、参数、步骤和视图共用一份撤销历史，AI 的一次修改算一步。
- 没点"加入作品"的公式和算式只留在这台设备上，刷新后还在；离开工坊时先确认是否放弃。
- 等待 AI 时手动改了内容，旧回复不会覆盖它；AI 修改失败或取消，恢复到修改之前，期间的手动修改也保留。
- 每次保存留下一个可预览的历史版本。恢复会替换当前内容（有未保存修改时先确认），再保存成为新版本，旧历史不变。
- 和别的设备冲突时，可以以服务器版本为基础保留当前内容、另存为新作品，或读取服务器版本。其余按[工作台](workbench.md)的保存规则。
- 公式或算式写错、图形无定义时作品照样保存，但显示渲染失败、只能下载源码，不拿旧图冒充；改好再保存即可。

## 数学助理

- 助理使用老师自己登录的免费 DeepSeek 网页账号，需要装一次浏览器扩展，首批支持桌面 Chrome 和 Edge。扩展未上架时如实说明，不放占位链接。
- 连接入口在输入区底部的模型选择器里，只显示当下需要的安装、登录或连接一步。连接状态只算当前浏览器。装好或更新扩展后重新检测，作品和未发送的输入保留，不会自动重发。
- Enter 发送，Shift+Enter 换行，输入法选词不会误发送。
- 每次只发送当前作品的公式、对象、参数、样式、视图和步骤，不带其他模块的数据。助理只能返回有限的数学操作，由编辑器检查后执行；"执行成功"和"已保存"分开显示。
- 离开作品停止请求，临时关掉辅助栏保留对话。DeepSeek 网页改版、断开或登录失效时明确报错。

## 导入和外部网页

- 可以导入制作源 JSON（最大 1 MiB），检查后存为新作品，原文件不变。
- 可以导入本地 HTML 网页，首次不自动运行。预览在隔离框里运行，拿不到登录状态和工作台数据，关闭或切换即销毁；需要外网资源时提示预览可能不完整。
- 网页里的标题、滑杆范围等通过"编辑源码"修改，预览确认后存为新版本；改作品名只改目录名称。工坊不会猜网页里的滑杆是哪个参数。
- 坏掉、非 UTF-8 或超过 1 MiB 的网页也能保存和取回原件，但不能编辑或运行。
- 导出分"取回原文件""下载当前源码"和"下载隔离演示"。隔离演示标注"离线效果待检查"。前两种下载会提示：直接打开原始 HTML 会运行其中的代码。原件永远不会被修改版覆盖。

## 归档和旧作品

- 归档的作品可以恢复或彻底删除。彻底删除先确认，删掉作品和全部历史；已下载的文件不受影响。
- 以前的公式、平面、立体、动态、GeoGebra 和网页作品都能在新版界面里打开、修改和导出。

## 导出

下载总是用一个已保存的版本，有未保存修改时先保存。

| 成果 | 说明 |
| --- | --- |
| 整份作品 PNG | 保存的开场 |
| 公式 PNG / SVG | 单条公式，可透明底 |
| 数学视图 PNG / SVG | 平面可导出矢量 SVG；三维和双视图只有白底 PNG |
| 制作源 JSON | 完整作品，可再导入 |
| `.ggb` | 只有图形构造，不含公式和步骤 |
| 课堂演示 ZIP | 解压后打开 `index.html`，不需要登录、网络或服务器 |

课堂演示里的修改只影响这次展示，重新打开回到开场。

## 故意不做的

- 没有另一套"本设备草稿"管理，首页只显示作品；撤销不跨刷新，AI 对话只存在本设备。
- 不接付费模型 API，不读取 DeepSeek 的账号或 Cookie。
- 外部网页不自动联网下载依赖、不替老师修补脚本，也不为了让它运行而放开隔离。隔离挡得住读取老师数据，但挡不住恶意脚本卡死预览。
- 不自动把旧作品迁到新格式。
- 不拆成独立应用，也不扩成全站 AI 开发；旧的班级联动已退役。
