# TeachBuddy 产品说明

TeachBuddy 是一位高中数学教师的个人教学工作空间：收题、管资料、做数学图形和演示、排日程、记住班里的学生，并让 AI 助理按同样的规则帮忙完成这些事。

交付的标准是真实可用：前后端真实运行，内容持久保存，各模块之间能互相引用。点击原型、内存样例、写死的 AI 回复都不算数，必须能保存、重新找到、接着用。

## 分区

产品分成八个分区，另有一页共享的数据管理。每页写老师能做什么、规则是什么，以及故意不做的事。界面和交互以[设计输入](../design-system/README.md)和完整应用原型为准。

| 分区 | 一句话 |
| --- | --- |
| [账户与身份](identity.md) | 注册、登录、找回密码、退出和注销账户。 |
| [工作台与设置](workbench.md) | 外壳、导航、辅助栏、页面往返、外观和语言偏好、设置、帮助与更新页；以及所有分区共用的保存规则。 |
| [题库](questions.md) | 从图片、PDF、Word 或文字自动拆出多道题，局部校对；自建、直接改或复制改编；分类、标签、笔记和检索。 |
| [资源库](resources.md) | 保存课件、模板、图片和文档；分类、标签、备注和检索；真实预览和下载；换文件时保留条目信息。 |
| [数学工坊](math.md) | 在同一个作品里做公式、图形和教学步骤；动态演示、二次修改、导出，以及不用登录的离线演示。 |
| [班级](classroom.md) | 记住班里的每个学生和这个班经历的教学：学生资料、自由记录、正式考试成绩和整体回顾。 |
| [日程](schedule.md) | 日期视图、安排、事项、重复、提醒和时区。 |
| [AI 助理](agent.md) | 首页和各页面侧栏里的同一个助理，按手工操作的同一套规则查找、整理、创建和修改内容，结果可以核实。 |
| [数据管理与恢复](data.md) | 个人资料导出、误删恢复和整机备份还原，三者是不同的操作。 |

题库、资源库、数学工坊、日程和班级是注册进模块目录的五个功能模块（见 [ADR 0001](../adr/0001-use-a-single-static-module-catalog.md)）；账户、工作台和 AI 助理由应用直接组合。公共文件、识别、文稿编辑、保存和后台任务是共享底座，不算第九个分区。

## 跨分区的共同约定

- **账户和持久化**：刷新、退出重登、换设备都能读到同一账户已保存的资料、文件和对话，账户之间互相隔离。没上传的草稿只留在本设备。
- **现场**：切模块、查看关联来源、打开辅助栏、对照再返回时，草稿、选择、筛选、滚动和布局都保留。保存失败要如实显示，不能把"页面还挂着"当成已经保存。
- **外部 AI**：帮老师少搬运上下文。可以预览后复制并打开普通链接，产物通过粘贴或上传带回来。数学工坊另有浏览器扩展协作。
- **访问和体验**：通过网址使用，以电脑上的完整体验为主，平板能完成基本操作。工作台整体不要求离线，只有数学演示要在约定的浏览器里离线可用。视觉、紧凑的布局、渐进的动效和各区独立滚动都是交付条件。

## 范围边界

- 学期为班级和日程提供语境；题库、作品和长期资料跨学期积累。
- 小测验和日常作业不作为成绩输入。
- 导航里隐藏模块不删除资料；导航的垃圾桶也不等于误删恢复。
- 自动整理要完成主要录入，错误能定位和局部修正；老师整题重录不能算自动提取达标。Word 里的文字和公式要能继续编辑，截图不算。
- PPT 由老师用自己的工具和版式手工做，工作台提供材料、思路和数学素材。
- 真实环境不足或实验失败，不自动缩减产品目标。

## 故意不做的

- 学生端、家长端、组织管理、学校排课、出勤、独立的课程标准或实体书管理。
- 自动生成整套 PPT、自动登录任意网站抓题、任意外部 AI 网站的自动化或跨平台会话互通。
- 本地 Office 自动同步、HTML 直接嵌入 PPT、任意导入的 HTML 自动变成可结构化编辑、任意 SVG 在 Office 里继续编辑。
- 保证兼容所有课堂设备。
