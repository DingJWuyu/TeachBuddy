# 工作台功能模块设计

[返回主 README](../README.md) · [产品范围](PRODUCT_SCOPE.md) · [路线图](ROADMAP.md)

本文记录功能模块设计共识及 2026-09-21 首轮体验后的调整，作为真实 MVP 的行为与页面设计依据。功能范围以 PRODUCT_SCOPE.md 为准；本文说明页面布局、工作过程和模块连接，具体交互可在已确认原则下继续收敛。

产品实现与视觉验证同时遵守[设计对齐与验证方法](rules/design-and-verification.md)。

这些是产品设计结论，不代表完整业务实现或视觉验收。首轮交互稿已合入仓库的 `prototype/src/workbench/`，实际覆盖与限制见[模块原型行为](../prototype/behavior/modules.md)，仓库状态统一见 [README](../README.md#当前状态)。后续按路线图在真实应用中逐条细化这里的行为、失败恢复与跨模块联系，并连接接口用例和实际验收结果；不要求先重新制作整套原型。

## 1. 整体结构

### 入口与职责

| 入口 | 打开内容 | 设计结论 |
| --- | --- | --- |
| 顶部首页 | Agent 完整工作区 | 首页用于与 Agent 工作，无需另设传统统计与导航 dashboard |
| 顶部日程 | 完整日程页面 | 将原来的日历改为日程，承载课程、日期范围、时间段和待办；侧栏不再重复设置日程入口 |
| 左侧模块导航 | 题库、备课、数学工坊、资源库、班级教学 | 五个业务模块，既有原型中的其他模块名称不构成功能要求 |
| 左侧底部固定 AI 入口 | 当前页面的 AI 助理 | 在首页聚焦 Agent 输入区，在工作页面中展开右侧助理；侧栏收起时仍保留入口 |

Agent 完整页面与侧栏是同一个助理的两种呈现方式。切换形态时延续对话与引用内容，返回业务页面时保留操作位置。MVP 已确定采用 pi agent 作为核心运行时，能实际操作六个模块；模型接入、工具契约和具体操作控制由后续设计确定，不将此能力推迟到 MVP 之后。

用户明确喜欢 Codex Desktop 的布局关系，作为工作台布局参照：左侧负责稳定的全局入口，中间承担当前工作，右侧提供辅助内容与 AI。视觉样式继续沿用现有原型的白色、深色选中态、少量紫色强调、细边框和紧凑控件。

### 右侧辅助栏

- 桌面端展开辅助栏时，占据右侧空间，主工作区随之调整宽度，保持两边可以同时操作。
- 五个业务页面及日程均沿用同一右栏，在当前页面工具与 AI 之间切换，不额外叠加一列。
- 右栏切换内容时，分类、筛选、展开位置、对话和输入草稿都保留。关闭右栏后，主工作区获得更多宽度。
- 当前分类、班级或课题在对应内容区域仍可见，避免右栏切到 AI 后丢失当前工作对象；不为这一信息额外增加横跨多个区域的顶部栏。
- 普通浏览、切换题目或调整日期范围不抢走已经打开的 AI。明确开始编辑，例如在网格拖出时间段，才切换到相应工具；AI 对话和草稿继续保留。
- 原始材料与识别结果、原题与改编题等需要同时比较的内容，在中央区域并列展示，不与 AI 争用同一辅助栏。

| 页面 | 中央主工作区 | 右侧工具，与 AI 共用 |
| --- | --- | --- |
| 题库 | 找题列表与当前题目；收录或改编时左右对照 | 自定义分类与标签 |
| 备课 | 可编辑文稿、环节和就地取材界面 | 我的备课与本课大纲 |
| 数学工坊 | 当前作品及预览 | 作品切换；制作工具等待 skill 验证 |
| 资源库 | 缩略图、列表与展开的资源预览 | 自定义资源分类 |
| 班级教学 | 当前班级实际进度与记录 | 班级切换和相关备课 |
| 日程 | 任意连续日期的时间网格 | 月份、日期范围、安排与事项编辑 |

### 所有现场都保留

保留现场是全工作台共同原则，覆盖所有模块与组件，不是某个页面的特殊待遇。

需要保留的内容包括：当前工作对象、日期范围与时间段、搜索与筛选、选题与批量选择、各区域滚动位置、编辑草稿、目录展开状态、面板开合、用户调整的布局，以及 AI 对话、引用和输入草稿。

切换页面、打开或关闭辅助栏、进入取材界面、对照或编辑后返回，都应恢复相应现场。切换模块时已展开的 AI 继续保持，并延续对话。真实内容与 Agent 对话持久保存，刷新、重新登录和换设备后仍可访问；草稿与界面现场的保存恢复策略由后续契约具体定义。保存失败需明确反馈，页面内保持挂载的表现不能代替持久化验证。

### 滚动与空间

- 工作台外壳与主要工具栏保持稳定，长内容在所属组件区域内滚动。
- 多个工作区域各自滚动，滚动当前区域不应带动整页或其他区域。
- 不把每个小卡片都做成独立滚动容器，优先以完整的列表、文稿、预览、时间网格、助理对话为滚动单位。
- 页面均需考虑辅助栏关闭和展开两种布局；窄屏下如何收起、切换或展开区域，后续在真实尺寸中验证。
- 题目、公式和图形以阅读需要确定字号与留白，控件密度沿用现有原型基线。
- 独立工作区域用间隙分隔并露出背景，各自承担明确工作；避免再用一个大框把所有区域包起来，也不把每个内容小块都做成卡片。
- 按钮靠近所作用的内容。减少无必要的横跨区域顶部、重复标题和页面介绍小字，必要的字段含义、操作后果与错误反馈保留。
- 以电脑浏览器的完整体验为主，适配平板浏览和基本操作。

### 支持页面

设置、帮助和更新日志采用与内容相称的独立布局，不套用业务工作区大框和工具/AI 分栏。设置按个人偏好等内容分组，帮助按使用流程组织目录和正文，更新日志围绕真实发布内容组织；筛选等控件按实际需要决定。

这些页面同样遵循外壳稳定和区域内滚动，长设置内容或文章正文可作为一个完整滚动区域，无需把每组内容拆成小滚动框。沿用 EMStudio 参考的留白、细线和紧凑控件，截图中的计费、套餐等内容不进入范围。

## 2. 日程

日程是顶部进入的完整页面。参考用户提供的日历截图，左侧为主要时间网格，右侧为月份选择与安排编辑区域。

### 两种时间选择

1. **可见日期范围**：选择任意连续日期或天数，显示这一段时间的安排，不限制为固定自然周。右侧月份日历与网格日期范围对应。
2. **具体时间段**：在左侧网格中按住鼠标拖动，选择某一天内的时间段；右侧下方随之显示该时间段的安排与待办编辑内容。点击已有安排也可进入对应内容。

时间网格内部滚动。日期较多时，应保持日期列可读，可以在网格区域内横向浏览；具体可见天数控制与窄屏手势后续验证。

### 时间段与事项

- 一段时间内可以记录多件事项，并安排全局优先级与段内顺序。
- 支持尚未安排时间的事项，具体入口后续放入日程页面设计。
- 事项是轻量记录，不引入任务进度、逾期、自动顺延或完成状态维护。
- 提醒由老师自行设置，按时间段结束前或结束后的间隔触发，仅进入工作台顶部通知栏。
- 空白状态表达这段时间尚无安排，不使用参考截图中的“全部完成”等带完成状态含义的文案。
- 课程可关联班级与备课，按周重复并设置结束日期；只调整某一次课程时，其他安排保持原样。
- 工作台关闭时到点的提醒，下次进入仍可看到原定提醒时间，点击可返回对应安排，不连续弹出补发提醒。

无具体时间段选中时，展示所选日期范围的安排；选中后编辑该段，清除选择后返回范围概览。月份、事项与 AI 共用右栏。仅改变日期范围时保持 AI，拖选新时间段或明确打开已有安排时切到日程工具。

## 3. 题库

### 浏览题目

中央区域包含找题与当前题目两个独立面板，面板之间有可见间隙。初步比例约为 35% 与 65%，用于表达空间关系，不是固定像素规格；宽度可调整。

- 找题区提供搜索、筛选和题目列表。每条题目露出有辨识度的题干、公式或配图，不能仅靠文件名式标题认题。
- 当前题目区完整展示选中题目，两边独立滚动。连续切换题目时，找题区的搜索、筛选和浏览位置保持。
- 题型与标签完全由老师自定义，不预设知识点、解法、难度等分类体系。
- 分类与标签筛选位于右侧辅助栏，与 AI 共用；题目列表与完整题目留在中央主工作区。
- 收录、自建题目的入口归入找题与管理区域，不再额外设置横跨两个面板的顶部工具栏。

当前题目的编辑、复制修改、查看原始材料、加入备课等操作放在题目面板内，按使用场景安排显隐，不要求始终铺满一排按钮。正文连续呈现题目主体、可展开的答案解析、个人教学笔记，以及紧凑的来源与整理信息。

题目本身与老师的教学笔记分别保存和呈现，取用题目时可以只使用题目内容。各字段按材料实际情况填写，不要求所有题目都有答案解析。

### 收录与原稿对照

点击收录后，主工作区进入对照状态：左侧原始材料，右侧整理后的题目，初始空间大致均分，可调整宽度。

- 原稿按材料需要支持翻页、缩放、选择区域等操作。
- 图片、PDF、Word 和粘贴文字的自动提取、拆题和整理是 MVP 必须具备的能力。一份材料中包含多道题时，整理为独立条目，保留公式、配图和原材料已有的答案解析；提取后的文字与公式可编辑。
- 点击整理后的题目，能够定位相应原始位置，帮助老师检查公式、配图和拆分结果。
- 有疑问的识别内容在对应位置提示，原稿与出处保留。不能完整提取时仍可先收下材料，不要求老师先填完分类表单。
- 已收藏的题目也能通过查看原始材料进入同样的对照状态；退出后恢复浏览现场。

不同来源的具体导入方式、准确性和定位能力需用真实材料验证。网页与实体材料通过截图、文件、拍照或文字进入；任意网站自动登录抓题不作为 MVP 要求。

### 编辑、自建与改编

- 自建题目进入题目编辑流程，保存后同样可检索、整理与复用。
- 编辑直接修改当前题目，在当前区域进入编辑状态并尽量保留阅读位置。
- 复制修改创建有关联的副本，再编辑副本；原题与副本各自可找到，也能互相跳转。
- 比较原题与副本时，中央主工作区左右呈现两道题，题目列表暂时让出空间。可以比较题干、配图与解法。

### 用于备课

从题库选择一题或多题，点击加入备课，就地选择目标，完成后继续留在题库找题。提供前往该备课的入口，由老师决定是否跳转。

题目可以关联多份备课并回看使用场景。题库笔记描述长期适用的教学观察，某节课的讲解顺序、提问方法等备注属于那份备课。

## 4. 备课

### 真实工作与材料

备课围绕教学目标、学生已有基础、教学顺序、提问与练习、材料准备，以及判断学生是否学会来组织。对当前实习数学教师，还应容纳指导意见、试讲调整和课后体会；具体学校要求不能假定为统一格式。

教学设计中可以包含图象观察、概念形成、例题、独立练习等内容。强基班背景提示应容纳概念辨析、论证、不同解法与备用追问，具体难度和教学深度由老师决定。参考：[高中函数性质教学设计案例](https://statics.scnu.edu.cn/pics/maths/2021/0218/1613615129109322.pdf)、[数学专业教育实习安排](https://stxy.jsu.edu.cn/bkjy/jxhd/68fe37b7fc3440839038da6305d4c02e.htm)。

教案供老师组织教学及按需要交给指导教师审阅，导学案或讲义供学生使用，PPT 与演示用于展示，练习作业用于学习与反馈。这些材料不要求每节课做齐，也不要求老师按固定表单填写全部内容。

### 备课文稿与导航

主工作区以一份持续可编辑的备课文稿为中心。课题与常用操作固定，文稿独立滚动。教学目标和学生基础等信息可放在开头并收起，主体留给教学过程。

- 教学环节由老师自行命名、增删、排序，可先写粗略思路，再逐步整理。
- 环节中可以包含文字、题目、图形、演示和本课备注。材料直接出现在使用它的环节。
- 导航包含我的备课与本课大纲，支持按自定课题或专题组织、切换备课，以及定位和调整当前课的教学环节。
- 我的备课目录与本课大纲位于右侧辅助栏，与 AI 切换，替代早期文稿左侧导航的方案。

### 取材与返回

1. 在某环节选择插入题目，主工作区临时进入题库选择界面，明确显示正在为哪份备课、哪个环节选题。
2. 沿用找题与完整预览布局，可以多选，切换浏览时保留已选题目。
3. 确认后返回原文稿位置，按选定顺序插入题目。题干配图就地展示，答案解析可展开，讲解备注属于本课。

已有数学作品和资源可以通过类似的选择过程插入。需要新制作数学作品时，从当前环节进入数学工坊并保留使用目标，完成后提供插入该备课与返回的动作。

### 本课材料

提供本课材料总览，能找到整课关联的 PPT、教案、参考资料，也能查看各环节已使用的题目与演示，并保留还没有安排具体环节的备用材料。

支持先编排教学顺序再取材，也支持先收下材料再安排教学。通过关联复用内容，避免为了归档重复保存。老师继续在熟悉的工具中手工制作 PPT，工作台提供可查阅的题目、讲解思路和素材。

### 成果输出

MVP 支持教案与教学提纲、导学案与讲义、练习材料三类成果。老师可以手动编写，或让 Agent 根据已有内容生成初稿再修改，结构可以自定义。

三类成果均能输出可继续编辑的 Word 与用于打印分发的 PDF；Word 中的文字和公式保持可编辑。输出时能选择是否包含答案解析和教学备注，形成教师用与学生用材料。具体编辑器、排版及文件衔接方式由后续契约确定。

## 5. 数学工坊

共同框架以当前作品为中心，名称与相关操作就近放置，右侧工具提供作品切换及按需出现的制作工具；从备课进入时保留课题与返回入口。作品列表不必始终占据画布空间，AI 沿用全局辅助方式。

公式、静态图形和动态演示的真实制作、修改、导出和课堂使用均进入 MVP，Agent 也能实际参与制作与修改。实际制作方式需考察合适的 skill 与工具后决定；参数区、步骤编辑器和工具摆放不预先锁定成统一编辑器。

- 先以真实教学任务验证接收要求、制作、修改、预览、复用和课堂运行的完整过程，再决定内部布局。
- 支持接纳已有的外部 AI HTML，保存与预览；可调整的参数取决于作品实际提供的能力，不能假定任意 HTML 都自动拥有统一参数编辑面板。
- 交互 HTML、动画视频、可编辑图形的操作方式不同。考察这些差异用于选择制作路径，不因此增加视频制作等独立功能方向；视频不能代替已要求的自由交互能力。
- 编辑与课堂展示需要不同的空间安排。展示时聚焦数学画面与必要控制，分步讲解和自由探索是需求方向，具体实现待验证。
- 公式保留可编辑内容，可导出透明背景图片；函数图像、常见平面与空间几何示意图支持标注和样式调整，并能导出 PNG、SVG。
- 作品保留可继续修改的制作内容。动态演示可下载，在约定支持的浏览器中离线打开，展示无需登录工作台；支持环境和依赖需真实验证。

不承诺任意教室设备兼容、HTML 可直接嵌入 PPT 或任意文件可继续编辑。

## 6. 资源库

### 右侧分类与 AI 共用

左侧保留全局模块导航，中央浏览与操作资源，右侧辅助栏显示老师自定义的分类或文件夹，并可切换为 AI。先前提出的左侧资源分类方案已被这一安排替代。

主区域顶部显示当前分类路径及搜索、筛选和常用操作，资源内容内部滚动。即使右栏显示 AI，老师仍能看清当前所在分类，必要时返回上级。

### 浏览与预览

- 提供缩略图和列表两种方式，分别支持按课件封面、图片外观或文档名称辨认材料。
- 预览按需打开；认真查看 PPT、多页文档时，可展开到整个主工作区，关闭后恢复资源浏览现场。
- 查看资源时，能找到备注、标签、关联备课和加入备课入口。常用 PPT、Word、PDF 和图片必须提供真实内容预览与下载，不能用文件类型封面代替实际预览；预览结果按格式验证。

### 收录、更新与复用

收录不要求先完成归类。从备课中加入的文件保留相应关联，之后可从课程用途找回材料。

支持更新已有资源的文件，保留资源条目的名称、分类、标签、备注和关联，适应老师在外部工具中修改 PPT、Word 后上传更新的习惯。已引用材料如何采用更新内容由后续契约确定，不能推定为本地文件自动同步。

题目的专门编辑属于题库，数学作品的专门制作属于数学工坊，资源库承担已有电子材料的整理与取用。

## 7. 班级教学

支持创建和管理自己的班级。中央显示当前班级的教学记录，右侧辅助栏提供班级切换、相关备课入口，并与 AI 共用。当前班级在记录区域中持续可辨认。

中央上方紧凑呈现最近实际教到哪里，下方按日期呈现可连续阅读的教学记录，内容在区域内部滚动。

一条记录可以包含实际教学位置、尚未讲完的内容、学生共性问题、后续教学想法，以及相关备课、题目或演示。各项均按需要填写，允许只记一句话后直接保存，再补充关联。

例如：“例 2 没讲，定义中的任意性还需要强调。”无需为了留下这句话完成整套表单。

同一份备课可以用于不同班级，每个班的实际教学记录分别保存。备课中可回看关联的教学记录，记录中也可打开当时的备课或题目。日程记录了上课时间不表示实际完成对应内容。

本轮只围绕班级教学位置和共性反馈，不加入学生个人成绩或薄弱点追踪。

## 8. 真实 MVP 的行为验证重点

以下过程需接通真实前后端，并使用实际材料、文件与持久数据验证：

1. 从一份多题材料收录，检查原稿定位、整理结果、修改和返回浏览的位置。
2. 保留原题复制改编，对照题干和解法，再将选定题目用于某个备课环节。
3. 在备课中途选题、取素材、进入数学工坊并带回作品，核对当前课题、目标环节和草稿都保留。
4. 在资源库切换分类与 AI，检查当前分类仍可见、筛选继续生效、对话和各区域位置保留。
5. 选择任意日期范围，拖出时间段、记录多件事项、设置优先级与自选提醒，再从通知返回。
6. 课后记下某班实际进度和共性问题，在对应备课中回看，保持计划与实际记录的区别。
7. 输出可继续编辑的 Word 和可打印的 PDF，检查公式与配图，以及学生材料中的答案解析、教学备注选择。
8. 预览真实 Office 文件并上传更新，核对原条目与关联保留；下载数学作品，在约定浏览器中离线展示。
9. 设置重复课程，单独调整某次安排；关闭工作台后再进入，验证到点提醒仍可找到。
10. 让 Agent 实际串联题库、备课、数学作品或日程，检查页面与保存结果一致，手动和 Agent 操作遵守同一规则。
11. 刷新、重新登录与换设备访问真实内容，验证保存失败反馈、个人资料导出、备份恢复和误删恢复。
12. 走查设置、帮助、更新日志的内容与独立布局，以及电脑完整使用和平板基本操作。

后续需确定具体行为契约、文件与引用内容的更新规则、现场恢复策略、pi runtime 适配、数学工坊 skill 与工具、编辑与输出方案及支持环境。这些实现选择不改变已确认的 MVP 范围。

首轮原型已演示提醒点击后标记已读并回到安排，取消已读划线；关闭工作台后的提醒补记尚未接入。这类原型记录只能说明当前状态，不能代替上述验收证据。

用户已完成范围决策，后续行为细节、页面和技术方案由 Agent 在范围内自行落实。pi agent 是已确定的运行时方向，实施顺序与关键能力验证见[路线图](ROADMAP.md)；暂不增加新的业务模块。
