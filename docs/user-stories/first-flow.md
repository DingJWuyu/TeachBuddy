# First-flow 用户行为

状态：B11/v1 候选，待独立冻结。范围依据：[题库与备课](../PRODUCT_SCOPE.md#1-题库)、[共同现场原则](../WORKBENCH_DESIGN.md#所有现场都保留)。设计源为 `59a14e95bab667e0a01b8d62f6e87e018ddb1c5f`；B10 补充输入为 `8e9b230c56c7384521b122a7a80b6b07e18c852c`。本包的行为、契约与场景作为一个候选整体审查。

| 故事 | 老师的目标 | 验证场景 |
| --- | --- | --- |
| FF-1 | 作为数学老师，我希望自建或粘贴一道题并继续编辑文字、公式，以便把手边题目真正收进个人题库。 | WB-001、002、014 |
| FF-2 | 作为备课老师，我希望直接修正题目，或保留原题复制改编并对照，以便分别保留修订结果和教学变式。 | WB-003、004 |
| FF-3 | 作为备课老师，我希望自行组织环节、顺序和本课备注，再从环节选题，以便按照自己的讲解过程备课。 | WB-005、006、007 |
| FF-4 | 作为老师，我希望复用题目时保留备课中已经采用的内容，并自主接受题库更新，以免临上课材料突然改变。 | WB-008、009 |
| FF-5 | 作为老师，我希望取材、切页和刷新后接着工作，遇到保存失败能找回输入，以免误以为内容已保存。 | WB-010、011、012、013、015 |
| FF-6 | 作为老师，我希望误删后恢复题目和备课，而且其他账户读不到我的资料，以便放心积累。 | WB-009、016、017 |

本批覆盖单题手动录入、手动粘贴整理、可编辑数学文字、标记/笔记/搜索、自定备课环节、题目引用、软删除恢复及现场。自动拆题、图片/文件、题型与标签管理、Office 输出、其他模块、真实 Agent 与完整认证仍属 MVP，分别由 R30、C20-C26、A10/A11 及对应后续节点交付。本批 UI 只呈现可执行动作；手动粘贴不能标成自动提取。

具体状态与返回由 [UX](../ux/first-flow.md) 拥有；数据与错误语义由 [工作台契约](../contracts/workbench.md) 拥有；可复现预期由 [BDD](../acceptance/first-flow.feature) 拥有。原型的 modules、shell、navigation 行为仅为交互参考，原型 Mixed/Draft 状态没有转换成本包的验收结论。
