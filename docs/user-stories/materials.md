# Materials 用户故事

材料设计已冻结，当前状态与固定来源见[输入索引](../plans/run-inputs.md)。本页说明目标行为，不声明全部产品能力完成。范围依据 [题库](../PRODUCT_SCOPE.md#1-题库)、[备课](../PRODUCT_SCOPE.md#2-备课)、[资源库](../PRODUCT_SCOPE.md#4-资源库)及[基础交付](../PRODUCT_SCOPE.md#基础交付要求)。

本批行为由 [UX](../ux/materials.md)拥有，字段与交换从[契约入口](../contracts/workbench/materials.md)进入，实验判断与实现所有权见[架构](../arch/materials.md)，可观察验收见 [BDD](../acceptance/materials.feature)。本批没有新的领域词义，沿用根 CONTEXT 的题目、原始材料、教学资源、教学环节和模块公共端口。

| 故事 | 用户目标与价值 | 场景 |
| --- | --- | --- |
| MS-01 | 作为数学教师，我希望一次交入图片、PDF、Word 或文字后自动得到独立题目，以便主要精力用于校对而非重录。 | WB-M001、M002、M003、M004 |
| MS-02 | 作为数学教师，我希望点一道题就看到原页和相关区域，修改文字、公式、配图、选项和小问，以便有依据地修正拆分和识别错误。 | WB-M005、M006、M007 |
| MS-03 | 作为数学教师，我希望失败或不完整的材料仍被保存，能只重试遗漏部分，以便暂时离开或服务重启后继续收题。 | WB-M004、M008、M009 |
| MS-04 | 作为数学教师，我希望自行维护题型、标签、个人标记与长期笔记，并选择直接修改或复制改编，以便题库符合我的分类习惯且保留原题联系。 | WB-M010、M011、M012 |
| MS-05 | 作为数学教师，我希望按自己的文件夹和标签保存、查找及实际预览资料，以便找到已有课件和版式再使用。 | WB-M013、M014、M015 |
| MS-06 | 作为数学教师，我希望上传外部编辑后的新文件仍保留资源条目和关联，并明确决定备课何时采用新版，以便过去的备课和原稿不被悄悄改掉。 | WB-M016、M017 |
| MS-07 | 作为数学教师，我希望在任意教学环节取题或取文件，先放入本课材料再安排，以便逐步形成适合自己的教学顺序。 | WB-M018、M019 |
| MS-08 | 作为数学教师，我希望从已保存的备课分别得到教案/提纲、导学案/讲义、练习的可编辑 Word 和打印 PDF，并选择答案和教师注记，以便用于审阅、教学和分发。 | WB-M020、M021、M022、M023 |
| MS-09 | 作为数学教师，我希望把题目文字、公式源和配图带到自己制作的 PPT，以便沿用已有配色、版式和制作习惯。 | WB-M024 |
| MS-10 | 作为数学教师，我希望保存结果、失败原因和工作现场可信，原文件、引用及删除恢复能经受刷新和重启，以便放心积累教学材料。 | WB-M025、M026、M027、M028 |

前置首条流程的 WB-001 至 WB-019 继续适用，特别是直接修改/复制、固定引用快照、幂等请求、未知结果和账户分区。材料版的新增行为不得降低这些断言。后续数学作品专属编辑和引用类型归 M40，真实 Agent 调用归 C25；本批提供它们能够消费的现有公共端口，不承诺整套 PPT 生成。
