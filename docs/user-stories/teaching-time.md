# Teaching-time 用户行为

本页定义已冻结的教学时间行为；实现与具名验收见[教学入口](../modules/teaching-time.md)。故事、UX、契约与场景保持同版。范围来自 [班级教学](../PRODUCT_SCOPE.md#5-班级教学)、[日程](../PRODUCT_SCOPE.md#6-日程)及[保留现场](../WORKBENCH_DESIGN.md#所有现场都保留)。

| 故事 | 用户目标与可观察结果 | 场景 |
| --- | --- | --- |
| TT1 | 作为教师，我希望给某班只记一句“例 2 没讲，任意性还需强调”，以便课后随手留下事实；日期默认今天，位置、未讲内容、共性问题和下次备注可以以后再补。 | WB-T001、002 |
| TT2 | 作为教师，我希望在记录中打开备课、题目或作品，也能在材料中回看班级反馈，以便下一次备课利用实际经验；同一备课用于两班，记录各自独立。 | WB-T003、004、020 |
| TT3 | 作为教师，我希望先记下事情，再按需要放进一个时间段，以便不为琐事逐件分配时长；优先级与段内先后顺序分别调整。 | WB-T006、007 |
| TT4 | 作为教师，我希望从顶部打开日程，看任意连续日期，拖选时间再编辑，以便按实际教学节奏安排；查看其他日期时继续保留 AI 对话。 | WB-T005、008 |
| TT5 | 作为教师，我希望每周课程可重复到指定日期，调课时只改某一次，以便其他周保持原样；安排了课程也不意味着实际讲完。 | WB-T009、010、011 |
| TT6 | 作为教师，我希望只在自己设置的结束前后收到站内提醒，以便按自己的安排处理；关闭工作台后回来仍看得到原定提醒时间，点开就回到那一段。 | WB-T012 至 016 |
| TT7 | 作为教师，我希望刷新、切换页面和保存失败后仍能接续输入，并能找回误删内容，以免为维护工具增加负担。 | WB-T017 至 019 |

本批行为用语沿用 [领域词表](../../CONTEXT.md#教学内容)。班级记录是实际反馈，日程是计划，通知已读只表示看过。没有任务完成字段、逾期、催办、自动顺延或学生个人档案。

普通记事和班级随记完整可用，不等待数学或资源提供方。作品双向关联仍属 MVP，其行为由[数学扩展](../contracts/teaching-time-math.md)定义；完整验收必须消费真实作品提供方。资源直接关联不在本批新增，关联备课后可通过备课访问其资料。
