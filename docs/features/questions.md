# 题库：录入、编辑与复用

题目支持图片、PDF、Word、文字四入口，也可从零自建。题面、答案、长期笔记独立；题型和标签完全由老师定义。保存后可检索、改编、用于备课和关联班级反馈。网站来源通过文件、截图或文字进入，不自动登录网站抓题。

## 实现与剩余能力

手工编辑、复制改编、分类、笔记、原稿对照及备课取用已接入。文字/DOCX 原生拆题、文字层 PDF 有固定样本结果；图片、扫描 PDF 没有生产视觉 provider，复杂多栏、无题号、跨页及旧 DOC 数学对象仍有限制。完整自动整理继续属于产品目标，质量标准与待许可路线见[自动提取](../research/c21-open-source-reuse.md)。

旧 DOC 只能如实显示 `limited / legacy-object-loss`；人工裁图和改字能保存不等于公式已自动还原。DOCX 的段落原文视图不是 Word 原分页。转换环境的即时状态只见[运行台账](../plans/run-state.md)。

## 浏览、自建和保存

中央找题与当前题目分区，约 35%/65% 可调；两区独立滚动，列表用题干、公式、配图辨认题目。分类在共享工具栏；搜索、选中、滚动不因连续切题丢失。编辑、改编、原稿、取材操作就近放在当前题目区域。

自建先形成设备草稿，首个保存才创建服务器 ID；无有效内容的空稿可直接退出。题型、标签、答案、笔记均非必填，题面要有有效内容。编辑修改原 ID；复制改编以所选版本为基础，首个保存创建新 ID，保留原题快照和双向联系，笔记清空、标记关闭、分类沿用。原题后续改动或软删除不改变副本来源快照。明确放弃非空稿才丢弃输入。

共享保存反馈和恢复规则见[工作台保存契约](../contracts/workbench.md#写入冲突与未知结果)。特别是保存中的新输入不能被旧响应覆盖；未确认时保留原键、原请求及后续草稿；分类删改造成题目升版时也要保住未提交笔记。未保存输入不能作为已保存题目传给消费者。

**待裁决差异：** 材料设计的默认搜索排除答案；当前 `materials-service.js` 的 `filtered` 实现及 MANUAL-QUESTIONS 作者结果包含答案。两者尚无明确统一决定。保存任务不应顺带改变搜索语义；搜索任务须先明确这一差异。

## U-M1 收录、等待与再次进入

题库找题面板内的“收录”提供图片（可多选并排序）、PDF、Word、粘贴文字四入口；自建仍是独立动作。收录不先要求题型或标签。先保存原始材料和可选出处，再自动开始拆题。上传字节进度与“原稿已保存”“正在整理”“已整理 3 页，还有 1 页待处理”分别呈现，不能把接收请求显示为已收录题目。

原始材料保存后进入中央对照区。右侧题目草稿逐批出现，每题默认待校对，机器的高置信度不代表老师确认。处理中的草稿可看；等当前运行结束或停止后编辑，避免后台替换正在修改的内容。工具栏显示已入库数量与待处理数量，题库列表有“待整理材料”入口，重新打开沿用同一材料和已保存校对结果。

```text
全局导航   原始材料                         题目草稿                      工具 / AI
           文件名  页码  缩放  选区         3/6 题  待校对  保存校对
           [原页，当前题相关框]             [题干、选项、小问、配图]
           [独立滚动]                       [答案解析] [定位疑点]
                                             拆开 / 合并 / 忽略 / 确认收录
```

一次收录多张图片按老师确认的顺序编号；原图字节不旋转重写，识别用的纠偏图映射回原图坐标。PDF 页码从 1 开始，以整份 PDF 为准。只选第 7-8 页时仍显示 7、8，不显示模型局部序号 1、2。Word 优先显示固定转换版本的页面，同时提供原始段落定位；没有可靠分页时明确显示“段落 N”，不把显式分页符数冒充真实页数。文字原稿逐字保留，用字符范围高亮。

关闭、切模块、AI 切换和刷新后，从待整理材料恢复原稿页、缩放、草稿选择和已保存结果；未上传的文件字节不会跨设备恢复，显示重新选择同一文件的动作。已保存材料跨设备可用。停止后显示“正在停止”，重开仍可见；它只停止后续处理，已保存原稿/成功单元保留；已运行请求可能稍后结束，停止后不得自动覆盖草稿。丢失创建响应时先确认原请求，避免建立第二份收录。

## U-M2 校对和局部失败

选题时定位该题的所有原稿位置，包括题面、分散的答案和跨页续题；点击疑点跳到对应块和原稿区域。左右阅读区各自滚动，不永久强制联动。老师可重框定位、裁图、调整配图与题的归属，在右边改文字与公式、移动段落、增删选项/小问。公式以可编辑源和即时排版同处呈现；渲染错误保留输入并标出位置。

拆分把一个草稿变成两个独立草稿，合并把选定草稿按选择顺序组成一题；均在同一校对保存中提交完整结果和定位，旧草稿被显式移除。已入库的草稿不能再次拆分或改变映射，转入题库编辑；其余草稿仍可继续。忽略可辨识的页眉、教师活动等片段不删除原稿；未分配片段有独立列表，可归入题干、答案、笔记或忽略。教师活动默认留在未分配内容，不自动混入题干。

缺字、遮挡、丢图、公式转换失败、截断响应分别定位。未看到答案时保持“未提供答案”；只读到部分答案为“答案待核对”，不能当成不存在或模型补做。只有题干可读、必需图已绑定、公式可编辑、所有阻断疑点已由老师解决，才能“确认收录”。允许一次收录已校对的部分题，其余继续保存；成功响应包含新题 ID，可直接查看或加入备课。手工补充是局部恢复动作，不能成为四入口自动整理的正常主流程。

请求空正文、非完整 JSON、页数遗漏或超时不会显示“全部完成”。有完整可独立验证的题片段时保留为待核对候选，外层截断使整批为部分失败。每次重试只覆盖选定失败单元，已校对或已入库内容不被替换；新增候选供显式选择。新照片作为补充原稿加入原材料，旧遮挡图仍保留。重试有新任务 ID，网络请求结果未知时先重放确认原任务。

## U-M3 题库与分类

找题与当前题目分区沿用约 35%/65% 可调布局；列表显示题干/公式/图的辨识片段。搜索标题、题干、公式源、长期笔记，自定义题型（单选）、标签（多选且全部匹配）、标记与删除状态可组合筛选。答案与原稿不混入默认搜索。

右侧分类工具初始没有预置题型或标签。“管理”内新建、改名、删除均就近完成；同类名称去首尾空白后不区分大小写唯一。改名保留关联；删除先显示影响题数，确认后移除关联，题目仍在，题型变为未分类。删除后以同名重建获得新身份，不自动恢复旧关联。自动整理只建议已有分类，老师确认后采用，不自动创建标签体系。

编辑直接改当前题；复制改编以当前采用版本初始化独立副本，长期笔记清空、标记关闭，分类初始沿用。原题与改编题双向可达，原题删除后仍能看采用时的内容及原始材料。校对定位可修正，但原文件和原始文字不可修改。引用方始终保留采用时快照。

## 用于备课、教学与 PPT

单题或多题加入备课时就地选择目标，成功后留在题库，提供“前往备课”。有未保存修改时显式“保存并加入备课”，引用采用真实保存版本；长期笔记不进入引用，某课备注归备课。原题/改编对照在中央并排，退出恢复浏览现场。

班级关联使用 [材料与教学接缝](../contracts/materials-teaching-alignment.md)，从来源返回原记录并保留草稿，当前题目反馈随题目切换。PPT 素材支持复制题面文字与 LaTeX 源、下载透明题面 PNG 分片和单幅配图；具体像素/分片与权限在[材料契约](../contracts/workbench/materials.md#引用和输出)，不承诺自动制作整套 PPT。

## 接口、代码与判断结果

- 普通题目保存先读[共享契约](../contracts/workbench.md)的身份、内容、引用及写入节；丰富题目、分类和校对再读[材料契约](../contracts/workbench/materials.md#内容)。字段只读对应 OpenAPI 操作，不需要 Agent、数学制作或完整 DAG。
- 页面 `apps/web/src/features/questions/MaterialsQuestionsPage.jsx`；请求 `materials-api.js`；上传恢复 `uploadRecovery.js`；原稿 `OriginalPane.jsx`。
- API `apps/api/src/modules/questions/materials-service.js`、`materials-router.js`、`extraction*.js`、`native-word.js`；共享编辑器 `apps/web/src/features/workbench/materials/DocumentEditor.jsx`。
- 浏览器 `apps/web/e2e/manual-questions.config.mjs`；HTTP `apps/api/test/first-flow-questions.test.js`、`materials-questions*.test.js`；保存基例 [WB-003/004/011-018](../acceptance/first-flow.feature)，材料基例 [WB-M001-012/025-028](../acceptance/materials.feature)。

保存行为变更至少走自建、直接修改、复制改编、刷新重开；再覆盖本次影响的断线未确认、版本冲突、保存中继续输入、分类变更、身份切换和保存后取用。确认原 ID/来源快照/独立笔记正确，不能仅凭 toast 判断。当前具名证明范围在[能力证据](../plans/run-inputs.md)。
