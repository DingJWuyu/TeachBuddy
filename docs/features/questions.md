# 题库：录入、编辑与复用

题目支持图片、PDF、Word、文字四入口，也可从零自建。题面、答案、长期笔记独立；题型和标签完全由老师定义。保存后可检索、改编和关联班级反馈。网站来源通过文件、截图或文字进入，不自动登录网站抓题。

## 录入路径与边界

文字/DOCX 沿原生拆题；旧 DOC 先由 LibreOffice 固定为 DOCX 转换稿，再读取现存公式、文字和配图。Word 保留段内换行，校对页可切换分页预览与段落视图，段落定位不冒充原分页。原件缺失的对象不补造，旧 DOC 仍保留对象风险提示。文字 PDF 使用 Xpdf 保留阅读顺序，支持常规双栏及页首明确题号的续题，依赖安装见[运行指南](../SETUP.md#题库文字-pdf)。图片和无文字层的 PDF 使用[共用页识别](../contracts/recognition.md)。

常规单栏 PDF 的配图须与同页唯一题号对应。存在 Figure 结构时，依据成员身份和完整唯一文字匹配去除重复标注，裁图保留笔画及完整成员文字；不使用结构中的描述文字代替题面。没有结构或结构读取失败时，仅采用完全落于未扩边笔画框内的完整唯一匹配；图边文字、跨题或多栏歧义保留可编辑内容并待核对。原生阅读器把图内标注与正文合为一行时，无法证明整行归属就保留整行。裁图留白避开正文；确实无法避开时最多完整纳入一次并提示核对，跨题、越页或引入更多正文则放弃自动裁图。裁图扩大不改变文字归属，不据此删除正文或独立公式。结构读取失败的脱敏错误摘要及原件、派生件和页码引用保留在提取任务中，临时目录清理不删除这份诊断。

无明确题号、复杂跨栏/表格或归属不明的内容按下面规则保留待校对。旧 DOC 的公式对象损失必须显示 `limited / legacy-object-loss`，人工裁图改字不等于自动还原。完整自动整理仍按[提取判据](../acceptance/mvp-matrix.md#extraction)验收；实现、已验证范围及缺口统一见[项目状态](../plans/run-state.md)。

## 图片与扫描页识别

整理任务通常沿用原生 Word/PDF 文字。若同一原稿和预览版本已有当前识别修订的完成页，且可确认教学内容表结构，优先采用其表格结果；即使暂时没有可提取题目，也保留待处理内容，不再混入原生解析的活动和点评。这个入口复用已完成结果，不为有文字层的 PDF 另行启动识别。图片及没有文字层的 PDF 页继续调用共用页识别，成功页可复用，失败页只在明确重试时再识别。默认重试继续所有未完成页，包括取消时尚未运行的页面。工具未配置、资源不足或识别失败时保留原稿与已完成草稿，显示可重试原因。取消后的完整机器证据固定到原整理任务，保存来源、原始结果和全部图片附件，后续重试仍能读取；题库不采用这些迟到结果为草稿。无法确认进程清理时任务显示失败，不能误报停止完成。

题库从机器 Document 取回原始公式源和真实图片，复用文字拆题及跨页归并。答案和明确标号的续题先按同一原件匹配；跨文件只在本次收录中双方唯一时关联，重复题号或不明归属留在未分配内容。普通页面的配图自动归属限于题号与图片位置明确的单栏；教学表另按下述同格题号规则处理。歧义配图保留原稿位置并提示补图。PDF 位置由固定预览映射提供，不采用模型的局部页码。新增处理结果只替换未校对的机器草稿，人工修改、已入库内容及忽略操作继续保留。

教学表按明确表头识别教学内容列，提取带“例”“练习”“思考”等明确标题的候选，保留原公式和同格配图。自动候选须有非空小问、明确数学关系或原有配图等数据证据；仅有引导语或函数名称时保留未分配，不因出现数学符号就认定题目完整，无法判断的纯文字题也须人工分配。活动、点评和环节标题保留为未分配内容。仅在同一原件、同一预览版本、连续原页且表格结构相容时沿用前页表头，并保留列归属的校对疑点；这是结构推断，不是模型提供的跨页关联。同一识别块内的表题及表前、表后正文也按原顺序截断继承范围，后续表格有自己的明确表头时可重新识别。换环节、列角色矛盾、缺少前页、跨列内容或普通无题号列表保持待处理。没有可靠单元格坐标时，来源仍指向原表范围，不按等分表格伪造定位。同格多题配图仅在下述数字题号范围能确定归属时采用。

教学表的隐式跨页续题仅在前页末尾有唯一未完整题目、相邻原页开头是从1连续排列且每项含数学关系的小问时形成待校对候选。两端行须能从保留的原始 HTML 证明为独立单元格，沿用成熟 HTML 解析器核查跨度，题干和公式仍直接采用原 Document。新表题、教师活动、缺页、另一原件、多个待续题、列变化、缺格、合并格或空小问均不自动关联。候选保留两页真实表块位置及原始未分配片段，带跨页边界阻断项；老师核对前不能入库，归属不对时可拆分或忽略，重试不会恢复已忽略的候选或覆盖人工稿。除此以外的未明确归属续文仍保持未分配。

明确的检测、练习或作业环节内，独立教学内容格可按段首数字题号拆分；函数名称本身不算完整题目数据，明确数学关系、小问、区间或真实配图仍须保留。小结、回顾、点评及范围不明的数字列表保持未分配。连续配图只有在同格内被当前题号与后续题号夹住时才随前题采用；集中放在多题之后的图不猜归属。数字拆分保留边界校对项，原公式不重写。教学表外明确的小结、教学成效、调查报告范围保留为未分配并提示部分完成；明确的例题/练习标题、答案或后续新环节可结束该范围，普通“1.”数字行本身不结束报告范围；不因同页有教学表就禁用其他表外收录。

未编号题的身份结合原始来源与题目内容，重试保留人工公式、配图、入库及忽略状态。

识别成功不代表已校对：共享层可恢复有明确边界的几何下标，题库直接采用其数学节点；其余没有数学定界符的 LaTeX 保留为原文并标出公式疑点，不能仅点“已核对”就入库；题图与题目位置仍需确认，原稿未提供答案时不生成答案。无法可靠分离的表格内容保留机器结构及原稿，列入未分配内容并显示部分完成。文字层存在但质量差、又没有可采用的已完成教学表识别结果时，PDF 仍走原生路径，不承诺自动切换 OCR 修复复杂版式。

## 浏览、自建和保存

首屏提供“从资料收录”和“手动录题”，空态说明收录后可查找、改编和关联班级反馈。左侧找题，右侧默认阅读已保存的题干；答案、笔记和导出按需展开。“编辑题目”进入编辑，直接在题干输入或粘贴；公式和图片就地插入，选项、表格等结构从更多内容添加。题型、标签和笔记在编辑区按需展开。

浏览布局与分类入口见[题库与分类](#u-m3-题库与分类)。搜索、选中、滚动不因连续切题丢失；编辑、改编、原稿和教学反馈操作就近放在当前题目区域。退出编辑回到已保存内容，未保存修改另存设备草稿并提供继续入口；新题草稿从找题区继续。

自建先形成设备草稿，首个保存才创建服务器 ID；无有效内容的空稿可直接退出。题型、标签、答案、笔记均非必填，题面要有有效内容。编辑修改原 ID；复制改编以所选版本为基础，首个保存创建新 ID，保留原题快照和双向联系，笔记清空、标记关闭、分类沿用。原题后续改动、归档或彻底删除不改变副本来源快照。明确放弃非空稿才丢弃输入。

共享保存反馈和恢复规则见[工作台保存契约](../contracts/workbench.md#写入冲突与未知结果)。特别是保存中的新输入不能被旧响应覆盖；未确认时保留原键、原请求及后续草稿；分类删改造成题目升版时也要保住未提交笔记。未保存输入不能作为已保存题目传给消费者。

## U-M1 收录、等待与再次进入

“从资料收录”依次呈现选择材料、对照检查、确认入库。第一步提供图片（可多选并排序）、PDF、Word、粘贴文字四入口；手动录题是独立动作。收录不先要求题型或标签，名称与出处可选。先保存原始材料，再自动开始拆题。上传字节进度与“原稿已保存”“正在整理”“已整理 3 页，还有 1 页待处理”分别呈现，不能把接收请求显示为已收录题目。

原始材料保存后进入中央对照区。右侧题目草稿逐批出现，默认排版阅读，用“修改题目”进入编辑。每题默认待校对，机器的高置信度不代表老师确认。处理中的草稿可看；等当前运行结束或停止后编辑，避免后台替换正在修改的内容。工具栏显示已入库数量与待检查数量，题库列表有“继续收录”入口，重新打开沿用同一材料和已保存校对结果。

```text
全局导航   原始材料                         题目草稿                      工具 / AI
           文件名  页码  缩放  选区         3/6 题  待校对  保存校对
           [原页，当前题相关框]             [题干、选项、小问、配图]
           [独立滚动]                       [答案解析] [定位疑点]
                                             拆开 / 合并 / 忽略 / 确认收录
```

一次收录多张图片按老师确认的顺序编号；原图字节不旋转重写，识别用的纠偏图映射回原图坐标。PDF 页码从 1 开始，以整份 PDF 为准。只选第 7-8 页时仍显示 7、8，不显示模型局部序号 1、2。Word 优先显示固定转换版本的页面，同时提供原始段落定位；没有可靠分页时明确显示“段落 N”，不把显式分页符数冒充真实页数。文字原稿逐字保留，用字符范围高亮。

原生文字整理按题号识别候选；无题号正文先保留为待校对题目，不能凭空生成答案。答案题号匹配兼容全半角数字、末尾标点和 `Q` 前缀，只有题目与答案均唯一对应才自动关联；同号歧义保留在待核对项和未分配片段。归一化仅用于题号比较，原文与定位不变。只有答案或教师活动的输入不生成空题。

DOCX 保留段内换行和制表符，换行后的题号与答案标记可分别识别。同一 PDF 的页首 `续第 N 题` 或 `第 N 题（续）` 可关联到前页唯一同号题，保留两页原始定位，后续独立题目仍单独整理。缺少前页、同号歧义或页序倒置时，续文保留为未分配片段；不跨收录材料猜测归属。普通跨页正文仍须人工核对。

常规双栏文字 PDF 按左栏、右栏的阅读顺序整理，保留行边界与整份原稿页码。双栏长题换行、无结构标签且内部写入顺序相反的页面、独立双栏答案页已有真实上传验证；左栏题目、右栏答案的同页材料沿题号关联，不把整页误判成答案页。机器结果仍须校对；跨栏图像不靠纵向位置猜测归属，复杂混排和数学版式不属于这些样本的保证范围。

关闭、切模块、AI 切换和刷新后，从待整理材料恢复原稿页、缩放、草稿选择和已保存结果；未上传的文件字节不会跨设备恢复，显示重新选择同一文件的动作。已保存材料跨设备可用。停止后显示“正在停止”，重开仍可见；它只停止后续处理，已保存原稿/成功单元保留；已运行请求可能稍后结束，停止后不得自动覆盖草稿。丢失创建响应时先确认原请求，避免建立第二份收录。

## U-M2 校对和局部失败

选题时定位该题的所有原稿位置，包括题面、分散的答案和跨页续题。左右阅读区各自滚动，不永久强制联动。“调整原稿选区”展开重框定位与裁图；右侧用“修改题目”改文字与公式、移动段落、增删选项/小问。公式以可编辑源和即时排版同处呈现；渲染错误保留输入并标出位置。

待检查项用具体问题表达，确认时定位首个未解决项；每题确认后提供“查看题目”和“检查下一题”。分类与拆分、合并、忽略分别折叠；重试只在处理失败或中断时显示，补充照片和材料归档在材料操作中。归档与彻底删除按[内容生命周期](#归档恢复与彻底删除)处理。

识别文字不一致或原行留白以局部疑点显示，“查看疑点位置”切换原稿页并标出对应区域。提示不提供猜测的正确文字；教师可保留缺失说明、局部修正或补充原稿，再保存校对状态。检测边界与无法确定归属时的处理见[共用页识别](../contracts/recognition.md#机器页结果)，没有提示不能当作已校对。

拆分把一个草稿变成两个独立草稿，合并把选定草稿按选择顺序组成一题；均在同一校对保存中提交完整结果和定位，旧草稿被显式移除。已入库的草稿不能再次拆分或改变映射，转入题库编辑；其余草稿仍可继续。忽略可辨识的页眉、教师活动等片段不删除原稿；未分配片段有独立列表，可归入题干、答案、笔记或忽略。教师活动默认留在未分配内容，不自动混入题干。 结构化片段直接显示保留的表格、公式和图片；“归入题干”追加这些原块和来源，保存、刷新及入库保留结构。已归入的片段不能重复点击追加，明确改回“待处理”后可再次处理；旧纯文字片段仍按文字归入。

同一文字段落中的题目可先在分界处换行，再按段拆分；公式、图片、列表与表格保持完整。拆分后的两题都重新检查题干；原草稿有答案或答案待核对时，完整原答案保留在第一题，两题都须重新核对答案归属，不能自动把第二题标成未提供答案。

缺字、遮挡、丢图、公式转换失败、截断响应分别定位。未看到答案时保持“未提供答案”；只读到部分答案为“答案待核对”，不能当成不存在或模型补做。只有题干可读、必需图已绑定、公式可编辑、所有阻断疑点已由老师解决，才能“确认收录”。允许一次收录已校对的部分题，其余继续保存；成功响应包含新题 ID，可直接查看。手工补充是局部恢复动作，不能成为四入口自动整理的正常主流程。

请求空正文、非完整 JSON、页数遗漏或超时不会显示“全部完成”。有完整可独立验证的题片段时保留为待核对候选，外层截断使整批为部分失败。每次重试只覆盖选定失败单元，已校对或已入库内容不被替换；新增候选供显式选择。新照片作为补充原稿加入原材料，旧遮挡图仍保留。重试有新任务 ID，网络请求结果未知时先重放确认原任务。

## U-M3 题库与分类

找题与当前题目分区沿用约 35%/65% 可调布局；列表显示题干/公式/图的辨识片段。默认搜索标题、题干、公式源、长期笔记；展开筛选后可选择“同时搜索答案与解析”。搜索范围随浏览现场保留，清除条件恢复默认范围；原稿不参与搜索。自定义题型（单选）、标签（多选且全部匹配）、标记可组合筛选；归档内容使用独立列表。

找题区的筛选只查找题目，编辑区的题型与标签修改当前题目。没有预置分类；可在编辑和校对时就地创建，创建成功即保存分类，选用后仍须保存题目或校对进度。“题库选项”提供分类管理、归档内容和多选；分类管理中可改名和删除，同类名称去首尾空白后不区分大小写唯一。改名保留关联；删除先显示影响题数，确认后移除关联，题目仍在，题型变为未分类。删除后以同名重建获得新身份，不自动恢复旧关联。自动整理只建议已有分类，老师确认后采用，不自动创建标签体系。

编辑、复制和来源快照按[自建和保存](#浏览自建和保存)。校对定位可修正，原文件和原始文字保持不变。

## 归档、恢复与彻底删除

题目与收录材料的可恢复移除称为“归档”。确认后离开详情，回到题库列表，同时清除详情路由；刷新继续停留在列表。归档内容从“题库选项”进入，支持查看、恢复和彻底删除。恢复后回到归档列表，该内容重新出现在题库。设备上未保存的题目修改随归档保留，恢复后可继续编辑。

彻底删除只在归档对象上出现，确认框说明不可恢复及具体影响。删除材料不删除已入库的题目；删除题目不删除改编副本。源对象彻底删除后无法再打开详情或恢复，已有快照仍可阅读。题库所属的材料记录、题目记录及相应处理数据会移除；受管文件保留遵循[材料契约](../contracts/materials.md#题库归档与彻底删除)。处理仍在运行时，先停止或等待完成再彻底删除。

题目详情中的来源入口在确认源对象不存在后改为说明，当前题目继续可读；改编题仍可查看采用时的原题和并排对照。临时网络故障不能误报来源已删除，打开失败保留当前题目并允许重试。

归档、恢复与彻底删除均校验当前版本；响应丢失时用原请求确认结果，成功后同样返回列表，不重复创建对象。

## 用于教学与 PPT

班级关联使用 [材料与教学接缝](../contracts/teaching-time.md#丰富题目关联)，从来源返回原记录并保留草稿，当前题目反馈随题目切换。PPT 素材支持复制题面文字与 LaTeX 源、下载透明题面 PNG 分片和单幅配图；具体像素/分片与权限在[材料契约](../contracts/materials.md#引用和输出)，不承诺自动制作整套 PPT。

- 普通题目保存先读[共享契约](../contracts/workbench.md)的身份、内容、引用及写入节；丰富题目、分类和校对再读[材料契约](../contracts/materials.md#内容)。字段只读对应 OpenAPI 操作，不需要通读其他模块或完整项目计划。
- 页面 `apps/web/src/features/questions/MaterialsQuestionsPage.jsx`；题库编辑与浮层 `QuestionControls.jsx`；校对拆分 `review-drafts.js`；请求 `materials-api.js`；上传恢复 `uploadRecovery.js`；原稿 `OriginalPane.jsx`。
- API `apps/api/src/modules/questions/materials-service.js`、`materials-router.js`、`extraction*.js`、`recognized-page.js`、`native-word.js`、`native-pdf.js`；共享编辑器 `apps/web/src/features/workbench/materials/DocumentEditor.jsx`。
- 当前交互浏览器验证 `apps/web/e2e/questions-ux.config.mjs`，用 `WORKBENCH_WEB_DIST` 指定隔离生产构建，覆盖录题、草稿、改编、分类、文字校对、结构编辑、搜索范围、拆分答案归属、未知保存恢复、归档与彻底删除、来源缺失/读取失败、详情返回及深浅色布局。文件上传另验 DOCX 段内换行、PDF 明示续题与缺页/倒序、双栏题干/选项/答案及入库来源页码、未分配片段处理后的保存重开；历史保存场景见 `manual-questions.config.mjs`。HTTP `apps/api/test/first-flow-questions.test.js`、`materials-questions*.test.js`；保存基例 [WB-003/004/011-018](../acceptance/first-flow.feature)，材料基例 [WB-M001-012/025-028](../acceptance/materials.feature)。

保存行为变更至少走自建、直接修改、复制改编、刷新重开；再覆盖本次影响的断线未确认、版本冲突、保存中继续输入、分类变更、身份切换和保存后取用。确认原 ID/来源快照/独立笔记正确，不能仅凭 toast 判断。当前能力边界见[项目状态](../plans/run-state.md)，回归从[核查入口](../plans/run-state.md#核查入口)进入。

识别消费者使用 `apps/web/e2e/questions-recognition.config.mjs`；结构边界在 `questions-tables.spec.js` 和 API `materials-questions*.test.js`。固定输入及真实产物位置见[样本索引](../acceptance/samples.md#固定输入与回放)。回归核对原题、原有答案、公式、题图、来源页码、未分配范围、跨页阻断与人工状态；重试、取消和迟到结果不得覆盖已校对内容。表格列角色、同格多题配图、隐式续题等详细用例由相应测试维护。

从界面上传、校对入库并刷新读回，实际阅读公式与配图并查看深浅主题和窄屏截图。固定产物回放只证明消费与保存；修改识别配置后须按[共用路线与验证](../contracts/recognition.md#路线与验证)重新验证真实原稿，不能复用旧缓存冒充新结果。外部 PDF 回放只需按样本索引下载原件并设置 `M33_PRIVATE_PDF`；固定 E7/E8/E9 机器结果随 `recognition-document-4/` 入库，测试核对完整原件与实际渲染页摘要。`QUESTIONS_OCR_EVIDENCE_DIR`、`QUESTIONS_OCR_EXPANDED_DIR` 仅用于替换同布局的回放目录；默认自编材料消费回归不需要这些变量。缺外部原件只跳过对应专项，不用受控转录代替真实输入通过。

开发模式的列表读取、手动保存和刷新还须通过[开发服务回归](../acceptance/README.md#开发服务回归)。组件重新初始化后恢复读取，过期请求的成功或失败都不能覆盖当前列表状态。
