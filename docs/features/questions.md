# 题库：录入、编辑与复用

题目支持图片、PDF、Word、文字四入口，也可从零自建。题面、答案、长期笔记独立；题型和标签完全由老师定义。保存后可检索、改编、用于备课和关联班级反馈。网站来源通过文件、截图或文字进入，不自动登录网站抓题。

## 实现与剩余能力

手工编辑、复制改编、分类、笔记、原稿对照及备课取用已接入。文字/DOCX 原生拆题、文字层 PDF 有固定样本结果；DOCX 保留段内换行，文字 PDF 支持常规双栏阅读顺序和页首明确标注题号的续题。无题号文字可先形成待校对候选，尚不承诺自动识别多题边界。图片、扫描 PDF 没有生产视觉 provider；复杂图文混排、跨栏配图归属、未标明归属的跨页续文及旧 DOC 数学对象仍有限制。完整自动整理继续属于产品目标，质量标准与候选路线见[自动提取](../research/c21-open-source-reuse.md)。

旧 DOC 只能如实显示 `limited / legacy-object-loss`；人工裁图和改字能保存不等于公式已自动还原。DOCX 的段落原文视图不是 Word 原分页。转换环境的即时状态只见[运行台账](../plans/run-state.md)。

## 浏览、自建和保存

首屏提供“从资料收录”和“手动录题”，空态说明收录后可查找、改编、用于备课。左侧找题，右侧默认阅读已保存的题干；答案、笔记、使用位置和导出按需展开。“编辑题目”进入编辑，直接在题干输入或粘贴；公式和图片就地插入，选项、表格等结构从更多内容添加。题型、标签和笔记在编辑区按需展开。

浏览布局与分类入口见[题库与分类](#u-m3-题库与分类)。搜索、选中、滚动不因连续切题丢失；编辑、改编、原稿、取材操作就近放在当前题目区域。退出编辑回到已保存内容，未保存修改另存设备草稿并提供继续入口；新题草稿从找题区继续。

自建先形成设备草稿，首个保存才创建服务器 ID；无有效内容的空稿可直接退出。题型、标签、答案、笔记均非必填，题面要有有效内容。编辑修改原 ID；复制改编以所选版本为基础，首个保存创建新 ID，保留原题快照和双向联系，笔记清空、标记关闭、分类沿用。原题后续改动、归档或彻底删除不改变副本来源快照。明确放弃非空稿才丢弃输入。

共享保存反馈和恢复规则见[工作台保存契约](../contracts/workbench.md#写入冲突与未知结果)。特别是保存中的新输入不能被旧响应覆盖；未确认时保留原键、原请求及后续草稿；分类删改造成题目升版时也要保住未提交笔记。未保存输入不能作为已保存题目传给消费者。

## U-M1 收录、等待与再次进入

“从资料收录”依次呈现选择材料、对照检查、确认入库。第一步提供图片（可多选并排序）、PDF、Word、粘贴文字四入口；手动录题是独立动作。收录不先要求题型或标签，名称与出处可选。先保存原始材料，再自动开始拆题。上传字节进度与“原稿已保存”“正在整理”“已整理 3 页，还有 1 页待处理”分别呈现，不能把接收请求显示为已收录题目。

原始材料保存后进入中央对照区。右侧题目草稿逐批出现，默认排版阅读，用“修改题目”进入编辑。每题默认待校对，机器的高置信度不代表老师确认。处理中的草稿可看；等当前运行结束或停止后编辑，避免后台替换正在修改的内容。工具栏显示已入库数量与待检查数量，题库列表有“继续收录”入口，重新打开沿用同一材料和已保存校对结果。

```text
全局导航   原始材料                         题目草稿                      工具 / AI
           文件名  页码  缩放  选区         3/6 题  待校对  保存校对
           [原页，当前题相关框]             [题干、选项、小问、配图]
           [独立滚动]                       [答案解析] [定位疑点]
                                             拆开 / 合并 / 忽略 / 确认收录
```

一次收录多张图片按老师确认的顺序编号；原图字节不旋转重写，识别用的纠偏图映射回原图坐标。PDF 页码从 1 开始，以整份 PDF 为准。只选第 7-8 页时仍显示 7、8，不显示模型局部序号 1、2。Word 优先显示固定转换版本的页面，同时提供原始段落定位；没有可靠分页时明确显示“段落 N”，不把显式分页符数冒充真实页数。文字原稿逐字保留，用字符范围高亮。

原生文字整理按题号识别候选；无题号正文先保留为待校对题目，不能凭空生成答案。答案题号匹配兼容全半角数字、末尾标点和 `Q` 前缀，只有题目与答案均唯一对应才自动关联；同号歧义保留在待核对项和未分配片段。归一化仅用于题号比较，原文与定位不变。只有答案或教师活动的输入不生成空题。

DOCX 保留段内换行和制表符，换行后的题号与答案标记可分别识别。同一 PDF 的页首 `续第 N 题` 或 `第 N 题（续）` 可关联到前页唯一同号题，保留两页原始定位，后续独立题目仍单独整理。缺少前页、同号歧义或页序倒置时，续文保留为未分配片段；不跨收录材料猜测归属。普通跨页正文仍须人工核对。

常规双栏文字 PDF 按左栏、右栏的阅读顺序整理，保留行边界与整份原稿页码。双栏长题换行、无结构标签且内部写入顺序相反的页面、独立双栏答案页已有真实上传验证；左栏题目、右栏答案的同页材料沿题号关联，不把整页误判成答案页。机器结果仍须校对；跨栏图像不靠纵向位置猜测归属，复杂混排和数学版式不属于这些样本的保证范围。

关闭、切模块、AI 切换和刷新后，从待整理材料恢复原稿页、缩放、草稿选择和已保存结果；未上传的文件字节不会跨设备恢复，显示重新选择同一文件的动作。已保存材料跨设备可用。停止后显示“正在停止”，重开仍可见；它只停止后续处理，已保存原稿/成功单元保留；已运行请求可能稍后结束，停止后不得自动覆盖草稿。丢失创建响应时先确认原请求，避免建立第二份收录。

## U-M2 校对和局部失败

选题时定位该题的所有原稿位置，包括题面、分散的答案和跨页续题。左右阅读区各自滚动，不永久强制联动。“调整原稿选区”展开重框定位与裁图；右侧用“修改题目”改文字与公式、移动段落、增删选项/小问。公式以可编辑源和即时排版同处呈现；渲染错误保留输入并标出位置。

待检查项用具体问题表达，确认时定位首个未解决项；每题确认后提供“查看题目”和“检查下一题”。分类与拆分、合并、忽略分别折叠；重试只在处理失败或中断时显示，补充照片和材料归档在材料操作中。归档与彻底删除按[内容生命周期](#归档恢复与彻底删除)处理。

拆分把一个草稿变成两个独立草稿，合并把选定草稿按选择顺序组成一题；均在同一校对保存中提交完整结果和定位，旧草稿被显式移除。已入库的草稿不能再次拆分或改变映射，转入题库编辑；其余草稿仍可继续。忽略可辨识的页眉、教师活动等片段不删除原稿；未分配片段有独立列表，可归入题干、答案、笔记或忽略。教师活动默认留在未分配内容，不自动混入题干。

同一文字段落中的题目可先在分界处换行，再按段拆分；公式、图片、列表与表格保持完整。拆分后的两题都重新检查题干；原草稿有答案或答案待核对时，完整原答案保留在第一题，两题都须重新核对答案归属，不能自动把第二题标成未提供答案。

缺字、遮挡、丢图、公式转换失败、截断响应分别定位。未看到答案时保持“未提供答案”；只读到部分答案为“答案待核对”，不能当成不存在或模型补做。只有题干可读、必需图已绑定、公式可编辑、所有阻断疑点已由老师解决，才能“确认收录”。允许一次收录已校对的部分题，其余继续保存；成功响应包含新题 ID，可直接查看或加入备课。手工补充是局部恢复动作，不能成为四入口自动整理的正常主流程。

请求空正文、非完整 JSON、页数遗漏或超时不会显示“全部完成”。有完整可独立验证的题片段时保留为待核对候选，外层截断使整批为部分失败。每次重试只覆盖选定失败单元，已校对或已入库内容不被替换；新增候选供显式选择。新照片作为补充原稿加入原材料，旧遮挡图仍保留。重试有新任务 ID，网络请求结果未知时先重放确认原任务。

## U-M3 题库与分类

找题与当前题目分区沿用约 35%/65% 可调布局；列表显示题干/公式/图的辨识片段。默认搜索标题、题干、公式源、长期笔记；展开筛选后可选择“同时搜索答案与解析”。搜索范围随浏览现场保留，清除条件恢复默认范围；原稿不参与搜索。自定义题型（单选）、标签（多选且全部匹配）、标记可组合筛选；归档内容使用独立列表。

找题区的筛选只查找题目，编辑区的题型与标签修改当前题目。没有预置分类；可在编辑和校对时就地创建，创建成功即保存分类，选用后仍须保存题目或校对进度。“题库选项”提供分类管理、归档内容和多选；分类管理中可改名和删除，同类名称去首尾空白后不区分大小写唯一。改名保留关联；删除先显示影响题数，确认后移除关联，题目仍在，题型变为未分类。删除后以同名重建获得新身份，不自动恢复旧关联。自动整理只建议已有分类，老师确认后采用，不自动创建标签体系。

编辑、复制和来源快照按[自建和保存](#浏览自建和保存)。校对定位可修正，原文件和原始文字保持不变。

## 归档、恢复与彻底删除

题目与收录材料的可恢复移除称为“归档”。确认后离开详情，回到题库列表，同时清除详情路由；刷新继续停留在列表。归档内容从“题库选项”进入，支持查看、恢复和彻底删除。恢复后回到归档列表，该内容重新出现在题库。设备上未保存的题目修改随归档保留，恢复后可继续编辑。

彻底删除只在归档对象上出现，确认框说明不可恢复及具体影响。删除材料不删除已入库的题目；删除题目不删除改编副本或已有备课引用的快照。源对象彻底删除后无法再打开详情或恢复，已有快照仍可阅读。题库所属的材料记录、题目记录及相应处理数据会移除；受管文件保留遵循[材料契约](../contracts/workbench/materials.md#题库归档与彻底删除)。处理仍在运行时，先停止或等待完成再彻底删除。

题目详情中的来源入口在确认源对象不存在后改为说明，当前题目继续可读；改编题仍可查看采用时的原题和并排对照。临时网络故障不能误报来源已删除，打开失败保留当前题目并允许重试。

归档、恢复与彻底删除均校验当前版本；响应丢失时用原请求确认结果，成功后同样返回列表，不重复创建对象。

## 用于备课、教学与 PPT

单题或多题加入备课时就地选择目标，成功后留在题库，提供“前往备课”。有未保存修改时显式“保存并加入备课”，引用采用真实保存版本；长期笔记不进入引用，某课备注归备课。原题/改编对照在中央并排，退出恢复浏览现场。

班级关联使用 [材料与教学接缝](../contracts/teaching-time.md#丰富题目关联)，从来源返回原记录并保留草稿，当前题目反馈随题目切换。PPT 素材支持复制题面文字与 LaTeX 源、下载透明题面 PNG 分片和单幅配图；具体像素/分片与权限在[材料契约](../contracts/workbench/materials.md#引用和输出)，不承诺自动制作整套 PPT。

## 文字 PDF 运行依赖

题库使用独立的 Xpdf 4.06 `pdftohtml` 可执行文件读取文字层；页面预览与配图定位继续使用已有 Poppler。Xpdf 的 HTML 保留按阅读顺序排列的逐行文字，适配层只取文字节点，不向浏览器提供生成的 HTML，也不自建分栏算法。`pdftotext -layout` 会跨栏拼横行，Xpdf 默认纯文本又会合并段落内的题号行，因此二者不能替代此入口。

Linux x86-64 的官方包为 [xpdf-tools-linux-4.06.tar.gz](https://dl.xpdfreader.com/xpdf-tools-linux-4.06.tar.gz)，SHA-256 为 `940c137cbd1856e45813da1a25c12e8dd3dc8997b8ea735feb858684603031e3`。解压并保留完整包后，将运行环境的 `QUESTIONS_XPDF_PDFTOHTML` 指向 `bin64/pdftohtml` 的绝对路径；未配置时查找 `/usr/local/bin/xpdf-pdftohtml`，不要指向 Poppler 的同名命令。开发测试可以装在当前 worktree 的 `.scratch/questions-tools/`，部署时放在独立持久工具目录。安装步骤：

```bash
mkdir -p .scratch/questions-tools
curl --fail --location https://dl.xpdfreader.com/xpdf-tools-linux-4.06.tar.gz -o .scratch/questions-tools/xpdf-tools-linux-4.06.tar.gz
printf '%s\n' '940c137cbd1856e45813da1a25c12e8dd3dc8997b8ea735feb858684603031e3  .scratch/questions-tools/xpdf-tools-linux-4.06.tar.gz' | sha256sum -c -
tar -xzf .scratch/questions-tools/xpdf-tools-linux-4.06.tar.gz -C .scratch/questions-tools
export QUESTIONS_XPDF_PDFTOHTML="$PWD/.scratch/questions-tools/xpdf-tools-linux-4.06/bin64/pdftohtml"
```

启动 API、HTTP 测试和上述浏览器验证时使用同一配置。读取在已有 Bubblewrap 禁网沙箱内逐页执行，输入只读，输出写入独立临时目录并在结束后清理，沿用时间与内存限制。工具缺失或失败时原稿保留、整理任务失败，修复配置后可重试；不静默退回会串栏的路径。Xpdf 包声明 GPL v2 或 v3，重分发二进制需保留包内 README、手册、COPYING 和 COPYING3；本仓库只调用外部工具，不收录其二进制或源码。
