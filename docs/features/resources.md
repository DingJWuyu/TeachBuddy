# 资源库：收录、整理、预览与文件版本

接口、持久化与跨模块调用读[当前技术入口](../subsystems/resources.md)。

资源库保存真实 PPT、模板、图片、文档及外部工具产物，支持已有配色、版式和素材积累；题目编辑归题库，作品制作归数学工坊，实体书籍不在范围。

实现及转换环境的当前状态见[台账](../plans/run-state.md)。本页定义资源行为，完整格式质量由相关验收确认。

## U-M4 资源浏览、预览与替换

资源库按“上传收录、浏览查找、预览取用、按需整理”组织。标题操作区与浏览/预览区是背景上的独立面板。首次空库只突出用途和上传入口；有资料后显示搜索、文件夹路径、缩略图/列表切换。格式筛选使用共享多选筛选，标签从模块右轨选择，已选条件可单独清除；无结果时说明如何调整搜索。“已归档”从模块右轨进入，文件夹树、标签和当前资料信息在同一右轨按场景呈现。

浏览右轨显示自定义文件夹与标签；打开文件后替换为当前资料的名称、文件夹、标签和备注。桌面预览与资料信息并排、外框等高，内容分别滚动；窄屏资料信息位于预览上方并限制高度，表单独立纵向滚动，预览保留可用空间。AI 辅助栏打开时覆盖模块右轨，浏览和返回不抢占已经打开的 AI。返回列表恢复原文件夹栏、筛选、选择与滚动位置。

文件夹同时承担分类，不再增设并行分类树。文件夹可移动、改名、删除；上级选项排除自身及后代，新版树删除会移除选定整棵文件夹子树，树内资料移至未分组，不删除资料。资料信息中可以就地创建文件夹或标签并选入当前草稿，点击“保存修改”后归属生效。浏览栏的标签用于筛选，资料信息中的标签用于标记当前资料；标签由资源库独立拥有，名称、排序与八色选择在账户内真实保存，刷新和其他设备保持一致。旧设备颜色只补入服务端尚未指定颜色的标签，不覆盖已保存的颜色。

上传即收录，名称默认文件名，单份成功后显示“文件已保存”并保持列表，不要求再次保存；预览完成后自动显示缩略图，点击资料打开预览。一次可选择多个文件，按选择顺序收录到当前文件夹，保持列表并显示处理进度。队列及未确认请求保存在当前设备；刷新后继续原请求，已保存条目不重复创建。当前上传结果未知时，重新选择原文件校验后确认；已明确失败的文件可跳过，继续剩余队列。选择前检查单文件 100 MB、文件名 200 字符限制。

相同字节的原件命中本账户已有活动或归档资料时，先展示“发现重复资料”，由教师跳过或明确另存。重复判断使用服务端文件摘要，不按文件名猜测；选择与剩余队列同样跨刷新保留。跳过只取消新资料条目，已保存的受管文件仍遵循材料契约的保留规则。

“选择资料”按需显示勾选与批量操作，每批最多 100 份。可以移动到文件夹、追加标签、归档或恢复；移动不改变其他信息，加标签保留原标签。整理先确认范围，版本过期或外账户对象使本次批次全部不生效；未知结果用原键确认。切换活动/归档列表时清除选择。改名、分类、标签与备注由“保存修改”提交，显示独立的保存状态；未保存草稿在收起信息栏和刷新后保留。搜索名称、原文件名、备注与当前文件正文，结合文件夹（含后代）、标签与格式筛选。缩略图来自第一页或原图片。预览提供真实内容、缩放与下载，多页文件才显示翻页与页码跳转操作；页面与阅读位置按文件和页保留。PPT/PPTX 预览为静态幻灯片，Word 为固定转换版本页面，PDF/图片直接查看。上传 HTML 以安全文本查看或下载；交互展示归数学工坊，资源库不执行其中脚本。

无法完整转换时显示“预览需核对”并标出缺页/公式对象风险。转换失败显示核对原文件、重试及补充 PDF 入口，明确已保存原件。格式本身不支持在线预览时说明下载后用对应软件打开或补充 PDF，不显示无效重试。单份文件信息或预览读取失败只影响该份资料，正常资料仍能预览、下载；失败条目保留并可重新读取。PDF、图片和 HTML 预览独立于 Office 工具路径；Office 未安装或路径失效不阻断这些格式。旧 DOC 必须提供实际转换页和可供对照的外部 PDF/图片补充入口，不能把空公式页标为完整，也不能只给下载按钮。补充预览绑定该次文件版本；新的原文件替换后不沿用旧补充。教师可上传由目标 Office 导出的 PDF 作为该版本的补充预览，逐页核对后明确采用。

“文件历史版本”、更新文件、补充预览和归档放在当前资料的更多菜单。历史按新到旧排列，可下载原件核对；恢复旧版前再次确认，成功后以新保存版本采用旧原件及其补充预览，保留名称、文件夹、标签和备注。归档资料可下载历史文件，恢复资料后才能切换当前文件。只改变备注或分类不新增文件历史。已有资料从启用文件历史时的当前文件开始记录，不推测重建更早版本。

归档后立即返回原资料列表，保留浏览条件和文件夹栏；成功提示约 3 秒后自动消失，错误及结果待确认提示保留到处理完成。已归档资料可查看、下载和恢复，更多菜单提供“彻底删除”；二次确认后条目永久移除，不能恢复。取消确认保留原现场，彻底删除后的刷新和检索也不再出现该条目。受管文件继续保留。“更新文件”先确认新旧文件名，再上传新文件；成功后才替换条目的当前文件，保留名称、分类、标签和备注。预览尚未完成不阻止原件安全收录，但状态持续可见。失败保留旧当前文件。

更新、归档、恢复与彻底删除使用统一的带图标确认弹层，取消在前、确认在后；归档和恢复使用普通动作色，彻底删除使用危险色。取消保留当前文件和草稿，关闭后焦点返回有效入口。开始关闭后即停止响应确认，退场动效期间不能再次触发写入；快速重开以当前操作为准。

## 正文查找与复制

搜索覆盖可提取文字的 PDF、已完成 PDF 转换的 Word/PPT、UTF-8 纯文本及下述已完成的页识别正文。采用补充 PDF 后以补充预览的正文为准；替换、恢复历史文件后按当前文件检索，旧历史内容不混入结果。正文命中显示摘录和第一处命中的页码，打开结果定位该页；纯文本只显示摘录。中英文不区分大小写，连续空白归一，中文换行可连续匹配；不提供语义搜索。

首次检索逐步读取正文，界面说明尚未完成的数量并自动补充结果。无可提取文字、等待预览和读取失败与零匹配分别处理；某份正文失败不会阻断其他结果，可重新读取。检索中途断网时停止等待提示，提供“继续检索”接续剩余结果。归档列表独立检索，文件夹、标签与格式筛选继续有效。

PDF 与 Word/PPT 的 PDF 预览保留原页图，在其上叠加 PDF.js 文字层，支持拖选后复制与“复制本页文字”。成功反馈在按钮内短暂显示，保持阅读位置。扫描页没有文字时明确提示；文字读取失败可重试，页图和下载仍可用。缩放、窄屏和翻页同步文字层。复制结果为纯文本，复杂公式、表格和多栏顺序仍需核对原件。

预览工具栏的“查找本页”按需展开输入框、匹配数和上/下一处。按普通文字字面匹配，英文不区分大小写，支持同一行跨文字项命中；原生高亮保留页图和用户选区。Enter/Shift+Enter 切换本页命中，Escape 关闭并将焦点还给入口。手动翻页保留词语并重置命中位置，不自动跨页；切换文件或退出预览清空查找状态。加载、文字读取失败、无文字和无匹配分别提示。浏览器缺少原生高亮能力时说明查找不可用，原预览和复制继续可用。页图高亮只使用原生文字坐标，不提供正则或跨页匹配。

## 扫描内容识别

预览工具栏的“识别文字”按需展开当前页状态、识别正文与复制操作，与“查找本页”互斥展开。教师明确选择识别本页或识别剩余页后才发起共享识别任务；打开资料、读取状态和全文搜索均不触发模型。多页任务显示完成数量，可停止后续识别；已完成页面保留，失败或中断由教师明确重试。请求结果未知时使用设备保存的原请求确认，刷新不重复创建任务。

“重新识别本页”使用固定原件、预览版本和所选页，可复用当前修订的成功结果，不承诺每次重跑模型。停止未确认时保留原因和恢复入口，不误报完成；重试与进程清理按[共用识别契约](../contracts/recognition.md)，普通读取不触发新识别。

识别正文绑定当前原件及固定预览版本，翻页、切换文件和刷新后读取对应页。OCR 搜索命中打开时核对当前文件与预览来源，过期命中留在列表并要求从最新结果打开。机器结果只读并标明尚未校对。识别面板复用共享 DocumentView 排版公式、表格和图片，长页在面板内滚动；公式、表格和版式疑点提示对照原页，不将 OCR 文字投影伪装成精准文字层。“复制本页识别文字”复制包含公式源码的原始 text，提供短暂成功反馈；纯文字备用区通过“查看可复制原文”展开，剪贴板失败时自动展开供手动选择复制。成功但正文为空只说明未识别到文字，不断言原页为空白。

搜索轮询期间由其他客户端更新文件时，打开最新命中使用核验后的资料与文件信息，文件名、原件下载和识别正文保持同一来源。

正文搜索合并当前来源已完成的 OCR 结果，原生同页命中优先，保留原 PDF 选择、复制与高亮行为。原生读取状态按资料计数，OCR 的未识别、处理中和失败状态按页计数；部分页失败不遮蔽已完成正文。识别期间搜索继续补充结果，断网停止等待并提供继续检索。共享识别不可用时仍可查看原件及已有机器结果，新识别操作明确禁用。

识别引擎、页结果、来源与恢复契约见[共用页识别](../contracts/recognition.md)。资源库复用该服务，不拥有模型进程或独立识别缓存。

识别疑点显示具体原因；已保存结果若含局部文字冲突或留白提示，可通过“查看疑点位置”标出当前原页区域。切换文件或翻页清除前一页标记；只读机器文字和原件保持不变。

## 能力边界

正文能力与格式边界见上节；页图查找只处理当前页原生文字，OCR 正文通过识别面板读取与复制。条目彻底删除同时移除其文件历史记录，受管原件和衍生文件继续保留，尚无磁盘空间回收入口。文件历史进入个人资料包，并随实例备份保存；共享资料保留规则见材料契约。
