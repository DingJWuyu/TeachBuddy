# 资源库：文件整理、预览与替换

资源库保存真实 PPT、模板、图片、文档及外部工具产物，支持已有配色、版式和素材积累；题目编辑归题库，作品制作归数学工坊，实体书籍不在范围。

人工上传、分类、预览、替换和备课取用已接入。可转换不等于全部格式无损；当前工具状态见[台账](../plans/run-state.md)。

## U-M4 资源浏览、预览与替换

资源中央面板显示当前文件夹路径、搜索、缩略图/列表切换及上传。右侧为自定义文件夹和标签，与 AI 共用。文件夹同时承担分类，不再增设并行分类树。文件夹可移动、改名、删除；删除只把直接子文件夹与资源移到父级，不递归删除资料。标签操作与题库的规则相同，但两个模块分别拥有标签。

先上传即收录，名称默认文件名，可稍后分类、改名、加标签或备注。搜索名称、原文件名、备注，结合文件夹（含后代）、标签与格式筛选。缩略图来自第一页或原图片。点击预览扩展为主工作区，提供真实逐页内容、页码、缩放、备注和使用位置；关闭返回原筛选、选择及滚动位置。PPT/PPTX 预览为静态幻灯片，Word 为固定转换版本页面，PDF/图片直接查看。上传 HTML 以安全文本查看或下载；交互展示归数学工坊，资源库不执行其中脚本。

无法完整转换时显示“预览需核对”并标出缺页/公式对象风险。损坏文件显示失败和重试，原件仍可下载。旧 DOC 必须提供实际转换页和可供对照的外部 PDF/图片补充入口，不能把空公式页标为完整，也不能只给下载按钮。补充预览绑定该次文件版本；新的原文件替换后不沿用旧补充。教师可上传由目标 Office 导出的 PDF 作为该版本的补充预览，核对页数后明确采用。

“更新文件”先上传新文件，成功后才替换条目的当前文件，保留名称、分类、标签、备注及关联，显示新旧文件名和引用数量。预览尚未完成不阻止原件安全收录，但状态持续可见。失败保留旧当前文件。备课已有引用仍看旧版，显示“来源有更新”，明确采用新版才改快照；资源软删除后已引用文件仍能打开，恢复不自动刷新引用。

## 接口与验证

文件身份、上传未知结果、补充预览、授权下载见[材料契约的文件与定位](../contracts/workbench/materials.md#文件与定位)；分类、引用更新及删除见同页对应节。原件和历史引用文件持续保留；上传后安全保存原件与预览成功是不同结果。

Web `apps/web/src/features/resources/`，API `apps/api/src/modules/resources/`；共用 `apps/api/src/workbench/files/` 与 `jobs/`。浏览器入口 `apps/web/e2e/manual-resources.config.mjs`，HTTP `apps/api/test/materials-resources.test.js`，验收 [WB-M013-017](../acceptance/materials.feature)。

相关改动检查上传保存刷新、真实逐页预览/缩放/下载、分类检索、文件替换后身份与备注保持。备课保持旧快照，查看新旧文件并采用后重开验证；失败或结果未知不得通过重复新建资源规避。原件可下载而转换失败应明确区分，不展示文件封面冒充预览。
