# 资源库：文件整理、预览与替换

资源库保存真实 PPT、模板、图片、文档及外部工具产物，支持已有配色、版式和素材积累；题目编辑归题库，作品制作归数学工坊，实体书籍不在范围。

实现及转换环境的当前状态见[台账](../plans/run-state.md)。本页定义资源行为，完整格式质量由相关验收确认。

## U-M4 资源浏览、预览与替换

资源库按“上传收录、浏览查找、预览取用、按需整理”组织。标题操作区与浏览/预览区是背景上的独立面板。首次空库只突出用途和上传入口；有资料后显示搜索、文件夹路径、缩略图/列表切换。格式和标签筛选通过“筛选”展开，已选条件可单独清除；无结果时说明如何调整搜索。“已删除资料”从资源库更多菜单或文件夹栏进入，不与是否用于备课混为同一状态。

右侧工具与 AI 共用现有辅助栏。浏览时工具显示自定义文件夹与标签；打开文件时收起浏览工具，点击“资料信息”才展开当前资料的名称、文件夹、标签、备注及使用位置。两种工具互换，不并列挤占预览；浏览和返回不抢占已经打开的 AI。返回列表恢复原文件夹栏、筛选、选择与滚动位置。

文件夹同时承担分类，不再增设并行分类树。文件夹可移动、改名、删除；上级选项排除自身及后代，删除只把直接子文件夹与资源移到父级，不递归删除资料。资料信息中可以就地创建文件夹或标签并选入当前草稿，点击“保存修改”后归属生效。浏览栏的标签用于筛选，资料信息中的标签用于标记当前资料；标签由资源库独立拥有。

先上传即收录，名称默认文件名，成功后明确显示“文件已保存”并打开预览，不要求再次保存。改名、分类、标签与备注由“保存修改”提交，显示独立的保存状态；未保存草稿在收起信息栏和刷新后保留。搜索名称、原文件名、备注，结合文件夹（含后代）、标签与格式筛选。缩略图来自第一页或原图片。预览提供真实内容、缩放、下载与加入备课，多页文件才显示翻页操作；页面与阅读位置按文件和页保留。PPT/PPTX 预览为静态幻灯片，Word 为固定转换版本页面，PDF/图片直接查看。上传 HTML 以安全文本查看或下载；交互展示归数学工坊，资源库不执行其中脚本。

无法完整转换时显示“预览需核对”并标出缺页/公式对象风险。损坏文件显示失败、重试及补充 PDF 入口，明确原件已保存且仍可下载。旧 DOC 必须提供实际转换页和可供对照的外部 PDF/图片补充入口，不能把空公式页标为完整，也不能只给下载按钮。补充预览绑定该次文件版本；新的原文件替换后不沿用旧补充。教师可上传由目标 Office 导出的 PDF 作为该版本的补充预览，逐页核对后明确采用。

更新文件、补充预览和删除放在当前资料的更多菜单，恢复在已删除资料的预览中直接提供。“更新文件”先确认新旧文件名及已有引用的影响，再上传新文件；成功后才替换条目的当前文件，保留名称、分类、标签、备注及关联。预览尚未完成不阻止原件安全收录，但状态持续可见。失败保留旧当前文件。备课已有引用仍看旧版，显示“来源有更新”，明确采用新版才改快照；资源软删除后已引用文件仍能打开，恢复不自动刷新引用。

## 接口与验证

文件身份、上传未知结果、补充预览、授权下载见[材料契约的文件与定位](../contracts/workbench/materials.md#文件与定位)；分类、引用更新及删除见同页对应节。原件和历史引用文件持续保留；上传后安全保存原件与预览成功是不同结果。

Web `apps/web/src/features/resources/`，API `apps/api/src/modules/resources/`；共用 `apps/api/src/workbench/files/` 与 `jobs/`。真实认证浏览器流程入口 `apps/web/e2e/resources-ui.config.mjs`，用 `WORKBENCH_WEB_DIST` 指向[隔离构建](../SETUP.md#新的隔离环境)，截图和 trace 可用 `RESOURCE_UI_RESULTS` 指定目录。Office 格式专项入口 `apps/web/e2e/manual-resources.config.mjs`，HTTP `apps/api/test/materials-resources.test.js`，验收 [WB-M013-017](../acceptance/materials.feature)。

相关改动检查上传保存刷新、真实逐页预览/缩放/下载、分类检索、文件替换后身份与备注保持。备课保持旧快照，查看新旧文件并采用后重开验证；失败或结果未知不得通过重复新建资源规避。原件可下载而转换失败应明确区分，不展示文件封面冒充预览。
