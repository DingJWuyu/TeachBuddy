# 资源库：收录、整理、预览与文件版本

资源库保存真实 PPT、模板、图片、文档及外部工具产物，支持已有配色、版式和素材积累；题目编辑归题库，作品制作归数学工坊，实体书籍不在范围。

实现及转换环境的当前状态见[台账](../plans/run-state.md)。本页定义资源行为，完整格式质量由相关验收确认。

## U-M4 资源浏览、预览与替换

资源库按“上传收录、浏览查找、预览取用、按需整理”组织。标题操作区与浏览/预览区是背景上的独立面板。首次空库只突出用途和上传入口；有资料后显示搜索、文件夹路径、缩略图/列表切换。格式和标签筛选通过“筛选”展开，已选条件可单独清除；无结果时说明如何调整搜索。“已归档资料”从资源库更多菜单或文件夹栏进入，不与是否用于备课混为同一状态。

右侧工具与 AI 共用现有辅助栏。浏览时工具显示自定义文件夹与标签；打开文件时收起浏览工具，点击“资料信息”才展开当前资料的名称、文件夹、标签、备注及使用位置。桌面主区域与辅助栏上下对齐、外框等高，内容分别滚动。两种工具互换，不并列挤占预览；浏览和返回不抢占已经打开的 AI。返回列表恢复原文件夹栏、筛选、选择与滚动位置。

文件夹同时承担分类，不再增设并行分类树。文件夹可移动、改名、删除；上级选项排除自身及后代，删除只把直接子文件夹与资源移到父级，不递归删除资料。资料信息中可以就地创建文件夹或标签并选入当前草稿，点击“保存修改”后归属生效。浏览栏的标签用于筛选，资料信息中的标签用于标记当前资料；标签由资源库独立拥有。

上传即收录，名称默认文件名，单份成功后显示“文件已保存”并打开预览，不要求再次保存。一次可选择多个文件，按选择顺序收录到当前文件夹，保持列表并显示处理进度。队列及未确认请求保存在当前设备；刷新后继续原请求，已保存条目不重复创建。当前上传结果未知时，重新选择原文件校验后确认；已明确失败的文件可跳过，继续剩余队列。选择前检查单文件 100 MB、文件名 200 字符限制。

相同字节的原件命中本账户已有活动或归档资料时，先展示“发现重复资料”，由教师跳过或明确另存。重复判断使用服务端文件摘要，不按文件名猜测；选择与剩余队列同样跨刷新保留。跳过只取消新资料条目，已保存的受管文件仍遵循材料契约的保留规则。

“选择资料”按需显示勾选与批量操作，每批最多 100 份。可以移动到文件夹、追加标签、归档、恢复或一起加入备课；移动不改变其他信息，加标签保留原标签。整理先确认范围，版本过期或外账户对象使本次批次全部不生效；未知结果用原键确认。切换活动/归档列表时清除选择。改名、分类、标签与备注由“保存修改”提交，显示独立的保存状态；未保存草稿在收起信息栏和刷新后保留。搜索名称、原文件名、备注与当前文件正文，结合文件夹（含后代）、标签与格式筛选。缩略图来自第一页或原图片。预览提供真实内容、缩放、下载与加入备课，多页文件才显示翻页与页码跳转操作；页面与阅读位置按文件和页保留。PPT/PPTX 预览为静态幻灯片，Word 为固定转换版本页面，PDF/图片直接查看。上传 HTML 以安全文本查看或下载；交互展示归数学工坊，资源库不执行其中脚本。

无法完整转换时显示“预览需核对”并标出缺页/公式对象风险。转换失败显示核对原文件、重试及补充 PDF 入口，明确已保存原件。格式本身不支持在线预览时说明下载后用对应软件打开或补充 PDF，不显示无效重试。单份文件信息或预览读取失败只影响该份资料，正常资料仍能预览、下载；失败条目保留并可重新读取。PDF、图片和 HTML 预览独立于 Office 工具路径；Office 未安装或路径失效不阻断这些格式。旧 DOC 必须提供实际转换页和可供对照的外部 PDF/图片补充入口，不能把空公式页标为完整，也不能只给下载按钮。补充预览绑定该次文件版本；新的原文件替换后不沿用旧补充。教师可上传由目标 Office 导出的 PDF 作为该版本的补充预览，逐页核对后明确采用。

“文件历史版本”、更新文件、补充预览和归档放在当前资料的更多菜单。历史按新到旧排列，可下载原件核对；恢复旧版前再次确认，成功后以新保存版本采用旧原件及其补充预览，保留名称、文件夹、标签、备注和已有备课快照。归档资料可下载历史文件，恢复资料后才能切换当前文件。只改变备注或分类不新增文件历史；资源库的使用位置区分“资料信息有更新”和“文件有更新”，无法判断旧采用版本时使用通用提示。已有资料从启用文件历史时的当前文件开始记录，不推测重建更早版本。

归档后立即返回原资料列表，保留浏览条件和文件夹栏；成功提示约 3 秒后自动消失，错误及结果待确认提示保留到处理完成。已归档资料可查看、下载和恢复，更多菜单提供“彻底删除”；二次确认后条目永久移除，不能恢复。取消确认保留原现场，彻底删除后的刷新和检索也不再出现该条目。已有备课快照和受管文件继续保留，避免破坏引用。“更新文件”先确认新旧文件名及已有引用的影响，再上传新文件；成功后才替换条目的当前文件，保留名称、分类、标签、备注及关联。预览尚未完成不阻止原件安全收录，但状态持续可见。失败保留旧当前文件。备课已有引用仍看旧版，显示“来源有更新”，明确采用新版才改快照；资源归档或条目彻底删除后，已引用文件仍能打开；恢复不自动刷新引用。

## 正文查找与复制

搜索覆盖可提取文字的 PDF、已完成 PDF 转换的 Word/PPT、UTF-8 纯文本及下述已完成的页识别正文。采用补充 PDF 后以补充预览的正文为准；替换、恢复历史文件后按当前文件检索，旧历史内容不混入结果。正文命中显示摘录和第一处命中的页码，打开结果定位该页；纯文本只显示摘录。中英文不区分大小写，连续空白归一，中文换行可连续匹配；不提供语义搜索。

首次检索逐步读取正文，界面说明尚未完成的数量并自动补充结果。无可提取文字、等待预览和读取失败与零匹配分别处理；某份正文失败不会阻断其他结果，可重新读取。检索中途断网时停止等待提示，提供“继续检索”接续剩余结果。归档列表独立检索，文件夹、标签与格式筛选继续有效。

PDF 与 Word/PPT 的 PDF 预览保留原页图，在其上叠加 PDF.js 文字层，支持拖选后复制与“复制本页文字”。成功反馈在按钮内短暂显示，保持阅读位置。扫描页没有文字时明确提示；文字读取失败可重试，页图和下载仍可用。缩放、窄屏和翻页同步文字层。复制结果为纯文本，复杂公式、表格和多栏顺序仍需核对原件。

预览工具栏的“查找本页”按需展开输入框、匹配数和上/下一处。按普通文字字面匹配，英文不区分大小写，支持同一行跨文字项命中；原生高亮保留页图和用户选区。Enter/Shift+Enter 切换本页命中，Escape 关闭并将焦点还给入口。手动翻页保留词语并重置命中位置，不自动跨页；切换文件或退出预览清空查找状态。加载、文字读取失败、无文字和无匹配分别提示。浏览器缺少原生高亮能力时说明查找不可用，原预览和复制继续可用。页图高亮只使用原生文字坐标，不提供正则或跨页匹配。

## 扫描内容识别

预览工具栏的“识别文字”按需展开当前页状态、识别正文与复制操作，与“查找本页”互斥展开。教师明确选择识别本页或识别剩余页后才发起共享识别任务；打开资料、读取状态和全文搜索均不触发模型。多页任务显示完成数量，可停止后续识别；已完成页面保留，失败或中断由教师明确重试。请求结果未知时使用设备保存的原请求确认，刷新不重复创建任务。

“重新识别本页”向固定原件、预览版本和所选页提交新的识别请求，不依赖旧 Job 的引擎修订仍可重试。共享服务继续复用同修订的成功页；新请求不承诺重跑已有成功结果。停止操作使用现有 Job 取消接口，普通读取和失败状态不会自动重发。

未能确认识别进程停止时，面板保留“尚未确认识别进程停止”的失败原因，刷新后仍可见，不误报取消完成。下一次明确识别由共享服务先清理旧进程，成功后才运行新尝试。

识别正文绑定当前原件及固定预览版本，翻页、切换文件和刷新后读取对应页。OCR 搜索命中打开时核对当前文件与预览来源，过期命中留在列表并要求从最新结果打开。机器结果只读并标明尚未校对，复用共享 DocumentView 排版公式、表格和图片，长页在面板内滚动；公式、表格和版式疑点提示对照原页，不将 OCR 文字投影伪装成精准文字层。“复制本页识别文字”复制包含公式源码的原始 text，提供短暂成功反馈；纯文字备用区通过“查看可复制原文”展开，剪贴板失败时自动展开供手动选择复制。成功但正文为空只说明未识别到文字，不断言原页为空白。

搜索轮询期间由其他客户端更新文件时，打开最新命中使用核验后的资料与文件信息，文件名、原件下载和识别正文保持同一来源。

正文搜索合并当前来源已完成的 OCR 结果，原生同页命中优先，保留原 PDF 选择、复制与高亮行为。原生读取状态按资料计数，OCR 的未识别、处理中和失败状态按页计数；部分页失败不遮蔽已完成正文。识别期间搜索继续补充结果，断网停止等待并提供继续检索。共享识别不可用时仍可查看原件及已有机器结果，新识别操作明确禁用。

识别引擎、页结果、来源与恢复契约见[共用页识别](../contracts/workbench/recognition.md)。资源库复用该服务，不拥有模型进程或独立识别缓存。

## 接口与验证

文件身份、上传未知结果、补充预览、授权下载见[材料契约的文件与定位](../contracts/workbench/materials.md#文件与定位)；分类、引用更新及删除见同页对应节。原件和历史引用文件持续保留；上传后安全保存原件与预览成功是不同结果。

Web `apps/web/src/features/resources/`，API `apps/api/src/modules/resources/`；共用 `apps/api/src/workbench/files/` 与 `jobs/`。真实认证浏览器流程入口 `apps/web/e2e/resources-ui.config.mjs`，用 `WORKBENCH_WEB_DIST` 指向[隔离构建](../SETUP.md#新的隔离环境)，截图和 trace 可用 `RESOURCE_UI_RESULTS` 指定目录。Office 格式专项入口 `apps/web/e2e/manual-resources.config.mjs`，HTTP `apps/api/test/materials-resources.test.js`，验收 [WB-M013-017](../acceptance/materials.feature)。

相关改动检查上传保存刷新、真实逐页预览/缩放/下载、分类检索、文件替换后身份与备注保持。备课保持旧快照，查看新旧文件并采用后重开验证；失败或结果未知不得通过重复新建资源规避。原件可下载而转换失败应明确区分，不展示文件封面冒充预览。

新增能力还需验证多文件队列在重复选择、保存响应丢失和刷新后继续；批量整理取消、过期版本整批拒绝、原键重放；历史原件下载、取消恢复、恢复后刷新、跨账户拒绝及旧引用不变。实际 Office 预览验证使用已配置的 LibreOffice 与真实 DOC/DOCX/PPT/PPTX 样本，检查每页解码和原件下载；页图可读取不代表复杂公式和目标 Office 排版全部无损。

正文验证使用真实文件、鼠标拖选与系统剪贴板，核对中文、全文命中页、当前文件替换与历史恢复、归档、筛选、账户隔离、扫描页和失败后重试。PDF.js 的 worker、CMap 和标准字体随应用在本机部署，不依赖外部 CDN。

页内查找需核对真实中英文、重复与跨文字项命中、字面符号、仅当前页的计数、键盘导航及关闭焦点；缩放 75%-200%、深浅主题与 390px 下查看实际高亮、操作可达性和原文字选择/复制。延迟旧文件读取、快速翻页、账户切换、重开与失败重试不串结果。资源库浏览器入口可用 `RESOURCE_UI_DEV=1` 运行隔离 Vite 开发服务，核对 StrictMode；固定构建仍用 `WORKBENCH_WEB_DIST`，两种环境分别记录证据。

OCR 消费沿同一浏览器入口，使用真实上传、认证 HTTP、Job、SQLite 和 Files。固定模型产物回放只验交互及数据机制，输入边界见[回放样本](../../apps/web/e2e/fixtures/resources-recognition/README.md)，不能替代实际模型验收。覆盖指定页识别、复制、搜索定位、失败重试、停止、响应丢失后原键确认、断网继续、账户隔离及当前文件更新；另核对深浅主题、窄屏和关闭焦点。

实际模型验收使用同入口的“真实 OCR 运行链”，明确设置 `RESOURCE_OCR_REAL_HOME` 为[已配置工具目录](../SETUP.md#本地页识别工具)才启用，先取得本机运行窗口。流程从 UI 上传发起，检查真实公式与题图、逐字复制、OCR 搜索来源及刷新复用，并保留截图和机器页结果；普通回归不启用本地模型。

开发模式的上传、页面往返、刷新和中文文字层还须通过[开发服务回归](../acceptance/README.md#开发服务回归)。组件重新初始化后应建立有效请求范围；卸载或身份变化时取消原范围，迟到的读取结果不覆盖当前恢复状态。

资源库浏览器回归需验证归档后返回、成功提示自动消失、桌面辅助栏等高、彻底删除的取消/确认及刷新不可恢复、响应丢失按原键确认、跨账户和过期版本拒绝。PDF 用真实文件验证已解码的页图、翻页及原件下载，包含失效 Office 路径的运行配置；单凭图片 DOM 可见不能证明内容成功载入。

## 能力边界

正文能力与格式边界见上节；页图查找只处理当前页原生文字，OCR 正文通过识别面板读取与复制。条目彻底删除同时移除其文件历史记录，受管原件和衍生文件继续保留，尚无磁盘空间回收入口。文件历史进入个人资料包，并随实例备份保存；共享资料保留规则见材料契约。
