# AI 助理：对话与真实业务操作

本分区是产品内 AI 助理，与开发 Codex 及数学工坊的网页 AI 分开。下面是有效行为规格，不授权模型调用。首批工具和四模块完整工具的边界见契约；已装配的代码不能当作全范围完成。新班级的主动提问和记录保存约定见[班级 AI 边界](classroom.md#ai-接入边界)，其实际工具接入另行实现，不套用退役班级工具。

## 入口与布局

首页完整工作区与业务页右栏挂接同一个按可信账户分区的对话 store，选中的 conversationId、消息、引用、输入和发送状态只有一份。顶栏首页打开完整工作区；业务页通过右侧 AI 切换进入。全站入口位置沿[共同交互](workbench.md#整体结构)，不恢复已取消的侧栏底部入口。首页不另开右侧 AI；本分区不属于业务模块目录。

历史、会话菜单、输入区、生成过程与结果卡的界面和动效沿[设计输入](../design-system/README.md)及其完整应用原型，不另设视觉基线。业务模块右轨与助理覆盖关系见[共同交互](workbench.md#右侧辅助栏)。首页消息、业务列表、文稿与对话各自滚动；用户停在旧消息时保留阅读位置，已在底部时跟随生成。

课程、模型和侧栏历史菜单完成选择或按 Escape 关闭后，焦点回到触发控件；可继续 Tab 或用键盘再次打开。

窄屏首页的对话列表可由列表按钮打开；选择对话、点击列表外部或按 Escape 收起。Escape 关闭列表后回焦入口，列表内的菜单和重命名先处理自己的退出操作。新对话和列表入口不被内容覆盖。

新对话显式创建，旧对话从历史重找；会话默认标题来自首次发送内容；若老师已明确重命名，首次发送保留该标题。历史列表摘要来自最近的非空助理回答，刷新和新设备保持一致。发送过程中可查看其他对话，每账户只运行一个生成，切页面、切对话或关闭辅助栏不会停止生成。

会话重命名、置顶和删除保存到本账户服务器状态，其他设备重读历史取得相同结果。置顶单独分组；重命名支持最多 80 字符，不改变最近活动排序。删除移除该会话的草稿、消息、引用、事件与工具记录，不删除已保存的业务对象；生成中或存在未执行、执行中、结果待确认的写操作时拒绝删除，先停止并核实结果。删除当前会话后选择下一条，没有其他会话则新建。

旧设备保存的会话名称和置顶继续作为本设备兜底，服务器新的明确选择优先；旧隐藏选择继续隐藏，不自动变成服务器删除。旧示例对话保留历史查看和本地重命名、删除，不继续生成脚本回复。旧卡已完成状态继续可见；已提交但未确认的请求可明确核实，只处理原来已提交的部分，不补做未开始的题目。

新对话与新增引用始终使用真实 API 和模型运行。明确点击“载入一周的示例数据”会经现有 API 把题目、资源、日程、数学作品、班级与考试成绩保存到当前账户；它们是真实业务记录，刷新后仍可读取。

## 页面往返与引用

普通浏览、切题和筛选保持 AI 开闭状态；进入业务编辑时保留 AI 草稿。工具的分类、目录、展开位置、选择、业务草稿和滚动归原业务现场 store，不写入 Agent 草稿。设置/帮助/更新日志使用既有独立布局；导航从这些支持页进入首页，并保留返回支持页的位置。

当前题目内容旁提供“加入对话”，将已保存对象版本加入输入区可移除的引用 chip；发送前可打开核对。输入 @ 可选择题目、资源条目和近期课程，首页选课可附带日程引用；更换或取消选课只移除该次选课带入的引用，保留独立加入的其他引用。通过正文中间的 `@关键词` 选择引用时，只移除本次触发片段，保留前后正文，并在原位置继续输入。引用保存明确版本；资源引用包含条目公开元数据与备注，不代表已读取附件全文。日程可保留整条安排，或以 originDate 指向该次实例。仅浏览不自动引用，不把未保存编辑内容冒充服务端版本。 资源深链只在仍阅读该资料时展示对应上下文；返回列表或改看另一份资料后回到通用建议，老师已主动加入的引用仍保留。存在未保存业务输入时，“加入对话”说明它引用已保存版本，并可先回业务保存。

发送时服务器核对引用归属和版本并捕获快照；历史引用继续显示当时内容。打开当前对象时读取最新对象，标明更新或已删除；无法访问时保持消息里的既有快照，显示“当前内容不可用”。跨账户不能返回快照。操作成功卡包含真实对象、版本和“打开题目”，打开后保留对话及原业务现场。Agent 改到当前正在编辑的对象时，干净编辑器可刷新；有本地草稿只提示“内容有更新”，保留双份内容供对照，不替换输入。

## 输入、生成与保存

输入草稿与引用在停止输入后保存，输入区明确区分“保存中”“草稿已保存”“仅保留在此设备”。本地先按账户保留，再写服务器；服务器确认的草稿可在其他设备恢复。本地未上传草稿只保证当前设备恢复，不能显示云端已保存。

点击发送时固定文字、引用和所选模型，先确认该版草稿持久化，再提交一次 turn。等待保存或发送确认时可继续输入，新打的下一条输入独立保留；确认成功只清除已发送版本。网络断开后同键重试发送不新增消息或模型请求。另一设备修改同一草稿时显示两份，老师选“保留本机内容”或“采用已保存内容”；两者都先读最新版本，采用本机内容才用新键提交，不后台合并。

回答下方的复制按钮仅在剪贴板实际写入成功后显示“已复制”；拒绝或剪贴板不可用时显示失败提示，保留正文和输入，可再次点击复制重试。

正文显示流式文本，状态行显示“生成中”，工具卡分别显示查找、写入进行中、已保存、失败、结果待确认。模型文字不能把失败卡改成成功。每次完整已持久化文本片段才推送，刷新可重读这些片段；最后尚未落盘的 token 不承诺恢复。读取持久记录失败显示重试，不显示空会话、不覆盖本地草稿。

只读与写入均从持久 toolCalls 呈现一张工具卡，按所属 turn 的 ordinal 排序；失败详情包含工具动作、已校验参数和公开 Problem，即使没有后续模型文字也独立显示。只读开始显示“查找中”，成功显示本次实际结果，空列表明确“未找到”；失败、未执行和读取中断分别显示。刷新/重登不触发重查，保留原结果快照和失败详情。写卡关联原 operationId，“确认结果”仅用于待确认写入，同一操作的复用卡标明引用同一提交。

“停止”立即停止后续模型请求与尚未开始的工具，已开始的写入先核实结果。停止不是回滚；已保存结果保留，未确认结果仍提供“确认结果”。网络断开只重连消息，不自动新增一轮生成。服务器重启后保留部分回答，显示“上次生成已中断”；先确认未决写入，再由老师发送“继续”，形成新 turn。失败重试也通过明确再次发送完成，已完成业务操作不会因继续而重做。

## 讲解安排与练习提案

模型可生成讲解安排、分层练习和单道变式卡。卡片是可审阅提案，生成不改题库或日程；老师点击后才保存。讲解安排的“加到日程”新建未排期的“备课”安排，步骤作为事项，不改引用的课程。练习按顺序保存全部题目，变式新建一道题，不修改原题，也不自动建立复制关系。题干与解答转为可编辑文稿，保留提案中的题型和标签。

卡片保存状态取自服务器 Operation，同一提案与题目槽只对应一个逻辑提交。多题部分完成时保留已保存部分；未知结果先显示“确认结果”，沿原键核实后再继续，不能把超时当成失败另建题目。刷新、重登及其他设备重读同一提案与保存状态。已成功卡提供打开题库或日程入口。

## 失败与模型

| 情况 | 可见结果与恢复动作 |
| --- | --- |
| 写入结果待确认 | 保留操作目标和原请求，点击“确认结果”执行原键原体核实，不调用模型；未确认前不再开始生成。 |
| 业务版本或引用版本冲突 | “内容已被修改”，展示请求基线及最新对象的对照入口；保留提案，老师手工整理保存，或明确重新发起基于新版的请求。 |
| 某一步失败 | 逐步显示已成功与未执行部分；例如复制成功、继续修改副本时冲突，不回滚副本、不报告整个任务完成。 |
| 401、退出待确认或账户切换 | 沿认证流程锁住工作区并停止生成；旧流立即隐藏，相同账户验证成功后恢复其历史和待确认操作。 |
| 配置缺失/模型不可用 | 历史与草稿可读，禁用发送并显示“AI 暂不可用”；不提示在聊天框填写密钥。 |
| 额度/计费授权失败 | 停止自动请求，保留部分回答与工具结果，显示“模型调用被拒绝”；配置处理完成后由老师重试。 |
| 模型或网络错误 | 显示失败或中断，不自动换模型，不无限重试。工具结果独立保留。 |
| 上下文超限 | 保留完整历史，提示“这段对话过长，请新建对话并重新选择引用”；不静默丢弃旧消息。 |

模型选择只列两个精确 ID 对应的名称，默认 DeepSeek；GLM 显示其当前配置就绪状态。选择对下一次发送生效，不改已有 turn 的模型。用量详情放在每个 turn 的状态旁：仅列已报告 token，并把缺失部分标为“用量不完整”。当前账单、余额和单价未知时费用显示“实际费用未知”，不能显示 ¥0、免费或虚构余额，不照搬套餐/订阅 UI。

## 外部 AI 衔接

本节描述通用文本交接的产品要求，实现见 [#66](https://github.com/DingJWuyu/TeachBuddy/issues/66)。数学工坊的网页协作按[数学规格](math.md#geogebra-数学画布与网页-ai)。

从当前账户可见对象/草稿在客户端生成提问文本，老师预览后复制，使用白名单普通 HTTPS 外链并加 `noopener,noreferrer`；不把正文塞进 query、不内嵌或自动登录第三方网页、不共享 API 会话。成果由老师粘贴/上传，仍走原业务校验。外部 AI 默认目标的旧偏好设计不扩大当前设置 UI。
