# 班级教学与日程：实际反馈、安排和提醒

班级记录实际进展与共性问题，日程只记录计划；两班共用备课时各自保存反馈。不增加学生个人档案、任务完成、逾期或催办体系。当前手动主链已接入，完整组合与目标条件仍需验收。

## 入口与布局

业务路径 `/classes`、`/classes/:classId`、`/classes/:classId/records/:recordId`、顶部唯一 `/calendar`。通知打开 `/calendar?entry=<UUID>&on=<原始日期>`，非重复安排省略 on。对象解析后按实际时段展开日期并定位，不把 on 误当调课后的日期。跨模块只导航到允许的本地业务路径；返回位置保存在本账户设备现场，不接受任意外部 return URL。

```text
班级：既有侧栏 | 高一(1)班  最近实际位置                    | 班级 / 相关备课 或 AI
                | 写一句… [保存] [补充]                     |
                | 9月21日：实际记录，连续阅读、独立滚动       |

日程：既有侧栏 | 9月21日 - 10月1日 [日期范围] [记一件事]     | 月份 / 日期 / 安排 或 AI
                | 日期表头固定；时间网格纵横向滚动             |
                | 15:00 ┌备课─────────────────────┐         |
                |       │ ①选例题   ②印讲义       │         |
                | 16:30 └────────────────────────┘         |
                | [未排期 3] [优先事项] 紧凑可展开列表         |
```

日期范围控件在中央工具条也可达，右栏为 AI 时不必先切工具。任意合法连续起止日，或起日 + 正整数天数（含首日），可跨周/月/年；初始今天起 7 天，切范围保持所选天数。月份翻页只改变月历，不提交可见范围，选起止日或点“应用”才改变网格。长期范围按可视区域加载、网格内部水平滚动，不截成自然周。网格最小列宽 160px；横向溢出局限网格，日期表头与列同步。

沿用产品现有令牌和规则中的实测紧凑控件，不另建主题。桌面 1440×900 右栏与主区并排；辅助栏开/关都验证。平板 768×1024 在主内容与辅助栏之间切换，关闭辅助栏回原选段，提供日期/时间输入与上移下移操作作为触控和键盘替代。一个区域只设一个主滚动容器，空态不撑出大框。浮层渐进出现、Esc 取消并还焦、reduced-motion 沿用共同规则；时间格可聚焦，选择结果有日期/时间文本读出。

## 状态和动作

| 状态 | 可见内容/动作 | 结果、失败与返回 |
| --- | --- | --- |
| TT-U1 班级浏览 | 没有班级时只显示“新建班级”；班级名必填，可改名、删除、从已删除恢复。当前班级始终在中央可见。 | 选班保持 AI；删班确认“记录保留，关联显示已删除”，不连带删课。班级被删除后记录只读，恢复班级后继续。 |
| TT-U2 一句话/补充 | 班级下输入一句话，日期默认账户今天；“补充”展开教到哪里、未讲内容、共性问题、下次备注和关联。任一文字项有内容即可保存，不必命名。 | 保存后留在本班并清空已确认的快记输入，继续输入形成下一条。保存失败保留原句。顶部“最近实际位置”取最近日期中最后更新且填写位置的活动记录，不从日程推断；只有一句话时显示最近记录摘录，无伪造进度。 |
| TT-U3 记录阅读/关联 | 按实际日期降序读记录，可编辑、删除、恢复。备课/题目链接带保存时标题，原对象删除仍能认出。 | 就地选择已有资料，取消不写入。进入资料/返回保留记录草稿及滚动；源标题变化显示最新标题及“记录时：…”；已删除来源给只读回看/恢复入口，不清除反馈。 |
| TT-U4 日程范围 | 网格、未排期入口、范围内安排；无选段时右栏为范围概览。空日写“暂无安排”。 | 换日期不切 AI；清除选段回范围概览。读取失败保留旧网格并标“未能更新”，不画成空日。 |
| TT-U5 选段/编辑 | 鼠标在同一天网格按住拖选，以 15 分钟吸附，支持向上拖。拖动中仅高亮范围，松开后右栏出现日期、起止、标题、事项。 | 正式拖选或点已有安排切日程工具并保留 AI 草稿。跨列拖动锁定起始日；Esc 取消。手工时间输入精确到分钟，可跨午夜；拖选不覆盖已有安排，重叠段并排且可各自打开。新空段取消不落库。 |
| TT-U6 未排期/事项 | “记一件事”只需一句话，默认普通优先级。可改优先级、移入已有非重复时段或给本条安排时间。段内按序号排列，支持拖动和上下移。 | 优先级只用低/普通/高，优先事项视图按优先级看全部未排期及当前日期范围实例；调整段内顺序不改优先级。移回未排期或移入另一段原子保存，失败不在两个位置各留副本。 |
| TT-U7 周重复/单次例外 | 勾选“每周重复”后填结束日期，显示首日星期；点某次时默认“仅这一次”，整组编辑是明确的另一个动作。 | 改一次可跨日/跨周，不改其他周；删除这次显示“本次取消”，更多中可“恢复原安排”。整组修改时间/文字保留所有例外并告知“单独改过的安排保持不变”。整组缩短结束日时预览隐藏的例外日期。没有“此后全部”第三种范围。 |
| TT-U8 课程关联/反馈 | 安排中的“关联”按需展开班级、备课、实际记录；普通记事无需打开。实际反馈入口“记课后情况”。 | 进入班级快记，预带所选班级/备课但只在老师保存后生成实际记录，再可选关联回该次安排。写入记录成功、关联安排失败时保留已保存记录并给“重试关联”，不重复创建。 |
| TT-U9 自选提醒 | 默认“不提醒”；展开后选择结束前/后和分钟数，立即显示具体提醒日期时间。每段/每次一个提醒，可清除。 | 提醒时间早于或等于当前时刻时禁止新设置，提示换时间；无默认提醒。已经发出后编辑显示原通知仍保留，不生成第二条。取消整组/本次只停止后续提醒，已到期的留在通知。 |
| TT-U10 通知 | 顶部既有通知面板显示安排标题、原定提醒时间和未读态；到期只加一条，无 toast 连发、声音或站外通知。支持单条已读、全部已读、清空。 | 点击尝试标已读并导航到实际时段；已读失败仍可打开，保留未读并提供重试。再次点击仍打开。已取消/删除目标显示“安排已取消/删除”及可用恢复入口；缩短重复范围后显示“这次已不在重复范围内”并可打开整组；来源恢复后可正常回到同一标识。清空仅删除展示，幂等痕迹保留。 |
| TT-U11 删除/恢复 | 班级、记录、非重复安排和整组安排可从各自“已删除”过滤中恢复。 | 已删除只读；不级联删除来源、实际记录或反馈。单次取消在整组的“已调整日期”中恢复；恢复不补发取消期间已过去的提醒。 |

## 现场与错误

保存状态、结果未确认、冲突、身份失效和本地存储失败沿用 [first-flow 保存与恢复](../contracts/workbench.md#保存与恢复反馈)，不再定义另一套保存协议。所有编辑显式保存，Ctrl/Cmd+S 同义。未确认请求先以原键原体确认；老师新增输入保存在另一个草稿中。版本冲突保留双方内容，不自动覆盖。

设备现场按 B11 可信 accountKey 分区：当前班级/记录、筛选、展开字段、记录日期、日程范围/选段/原始实例日期、未排期展开、各区滚动、右栏形态、输入草稿和待确认请求。切换、刷新、离开再返回均恢复；丢弃草稿须明确确认。换设备恢复已保存业务与账户时区，未上传草稿不跨设备。异账户与迟到旧请求遵守 B11 的身份代次隔离。通知引导离开当前草稿先保存本地现场；存储失败时提示复制/在线保存后继续。

时区在日程范围控件的次级设置中可见，初始“上海时间”。更改账户显示时区不会挪动已有课程；非当前时区的重复课编辑时显示其排课时区。实际教学日期是老师填写的日期，不随显示时区转换。窄屏短时段卡片只显示标题，完整事项在右栏，不把文字挤出格子。

作品选择和反向反馈已连接真实 math/classes 提供方，SourcePicker 读取活动作品，记录与反馈使用 v2。加载失败保留草稿并提供重试，不显示虚假作品；普通无关联记录仍可保存。已有局部链路不代替完整教学与目标设备验收，具体边界见[能力证据](../plans/run-inputs.md)。

## 实现验收证据

[WB-T001 至 020](../acceptance/teaching-time.feature) 覆盖以上状态。两视口分别记录空态、长文本/重叠段、编辑、保存失败、冲突、已删除、通知定位与返回，检查外壳不滚动、无页面级水平溢出、焦点和实际指针/触控。时间选择使用真实指针轨迹验证，不借合成事件证明；HTML 拖放排序与指针选段是不同手势，按设计规则分别记录。这些是变更后的验收判据，已有执行范围以[能力证据](../plans/run-inputs.md)为准。

| 状态 | 操作与可见结果 | 失败与恢复 |
| --- | --- | --- |
| TT-MU1 选择 | 关联资料中切到“数学作品”，可按标题搜索和类型筛选；活动的公式/平面/立体/动态/HTML 均可选。勾选后回到记录草稿，显式保存才建立关系；取消不写入。 | 搜索失败显示“未能加载作品”和重试，保留已选项；空列表才显示“暂无作品”。选择后已删除，保存明确失败并保留文字，可移除该选择或重试。 |

| TT-MU4 版本与未知结果 | 新页面统一读写记录 v2；旧页面遇 unsupported-content-version 提示“请刷新页面后继续编辑”，先保留草稿与待确认请求。 | 待确认写请求必须先在原路径用原键原体确认，成功后读 v2 当前记录；有新草稿时不被旧响应覆盖。409 对照整理后新键保存。401 按原账户锁定草稿，切账户不显示旧数据。 |

班级现场保存选中班级/记录、日期、展开项、各区域滚动和草稿；选择器另保存 q/kind/已选 ID。作品现场由 math 按账户分区保留。URL 只携稳定 ID，不携完整记录或任意 return URL；打开作品不提交未保存输入，返回不重新创建记录。公共日程选择记录只需原摘要，不加载作品源码或海报。

两班使用同一作品分别保存；作品后续更新不改反馈文字或变成采用版本快照。render=invalid 不禁用教学关联，渲染状态归工坊自己的展示。所有入口沿用单一工具/AI 右栏，普通浏览不抢 AI。

相关交互变更需在桌面 1440×900、平板 768×1024 验证长标题、选择失败、已删除、往返草稿/滚动、焦点与无页面级横向溢出。桌面局部结果不能替代真实平板触控与完整教学验收。
