# 班级教学与日程：实际反馈、安排和提醒

班级记录实际进展与共性问题，日程只记录计划；两班共用备课时各自保存反馈。不增加学生个人档案、任务完成、逾期或催办体系。当前能力与未验条件见[当前状态](../plans/run-state.md)。

## 入口与布局

业务路径 `/classes`、`/classes/:classId`、`/classes/:classId/records/:recordId`、顶部唯一 `/calendar`。通知打开 `/calendar?entry=<UUID>&on=<原始日期>`，非重复安排省略 on。对象解析后按实际时段展开日期并定位，不把 on 误当调课后的日期。跨模块只导航到允许的本地业务路径；返回位置保存在本账户设备现场，不接受任意外部 return URL。

```text
班级：既有侧栏 | 高一(1)班  最近实际位置                    | 班级 / 相关备课 或 AI
                | 写一句… [保存] [补充]                     |
                | 9月21日：实际记录，连续阅读、独立滚动       |

日程：既有侧栏 | 九月 2026       [视图] [今天] [前后翻页] | 小月历拖选日期段
                | 日期表头、全天区、独立滚动的时间网格        | 即将到来 / 任务编辑
                | 任务支持拖动、拉伸和重叠显示               | 标题、日期、时间
                | 月视图连续滚动跨月                         | 标签、备注、重复
```

日程主区和右侧月份卡片参照 EMStudio 日历。初始今天起 7 天；视图菜单提供日、周、月、2 至 9 天及自定义 1 至 31 天。小月历按住拖选连续日期后立即切换对应天数，可跨周、跨月，无额外“应用”步骤；小月历翻月只浏览月份。月视图连续滚动跨月，“今天”回到当前日期。主时间网格以 5 分钟吸附，可拖选创建、拖动改期、从上下边缘调整时长，日期/时间输入可精确到分钟。

桌面主区与右卡片并排，顶部与外壳保持不变；时间网格、任务编辑和即将到来各自滚动。窄屏通过“打开月份与任务”进入辅助卡片并可关闭返回。打开 AI 时使用既有 AI 栏，明确编辑任务时回到日程卡片，保留 AI 草稿。视图、选段、月视图滚动和任务草稿按账户保留，刷新或切模块可恢复。

## 现场与错误

保存状态、结果未确认、冲突、身份失效和本地存储失败沿用 [first-flow 保存与恢复](../contracts/workbench.md#保存与恢复反馈)，不再定义另一套保存协议。所有编辑显式保存，Ctrl/Cmd+S 同义。未确认请求先以原键原体确认；老师新增输入保存在另一个草稿中。版本冲突保留双方内容，不自动覆盖。

设备现场按 B11 可信 accountKey 分区：当前班级/记录、筛选、展开字段、记录日期、日程范围/选段/原始实例日期、未排期展开、各区滚动、右栏形态、输入草稿和待确认请求。切换、刷新、离开再返回均恢复；丢弃草稿须明确确认。换设备恢复已保存业务与账户时区，未上传草稿不跨设备。异账户与迟到旧请求遵守 B11 的身份代次隔离。通知引导离开当前草稿先保存本地现场；存储失败时提示复制/在线保存后继续。

时区在日程范围控件的次级设置中可见，初始“上海时间”。更改账户显示时区不会挪动已有课程；非当前时区的重复课编辑时显示其排课时区。实际教学日期是老师填写的日期，不随显示时区转换。窄屏短时段卡片只显示标题，完整事项在右栏，不把文字挤出格子。

作品选择和反向反馈已连接真实 math/classes 提供方，SourcePicker 读取活动作品，记录与反馈使用 v2。加载失败保留草稿并提供重试，不显示虚假作品；普通无关联记录仍可保存。已有局部链路不代替完整教学与目标设备验收，具体边界见[能力证据](../plans/run-state.md#证据边界)。

## 实现验收证据

[WB-T001 至 020](../acceptance/teaching-time.feature) 覆盖以上状态。两视口分别记录空态、长文本/重叠段、编辑、保存失败、冲突、已删除、通知定位与返回，检查外壳不滚动、无页面级水平溢出、焦点和实际指针/触控。时间选择使用真实指针轨迹验证，不借合成事件证明；HTML 拖放排序与指针选段是不同手势，按设计规则分别记录。这些是变更后的验收判据，已有执行范围以[能力证据](../plans/run-state.md#证据边界)为准。

| 状态 | 操作与可见结果 | 失败与恢复 |
| --- | --- | --- |
| TT-MU1 选择 | 关联资料中切到“数学作品”，可按标题搜索和类型筛选；活动的公式/平面/立体/动态/HTML 均可选。勾选后回到记录草稿，显式保存才建立关系；取消不写入。 | 搜索失败显示“未能加载作品”和重试，保留已选项；空列表才显示“暂无作品”。选择后已删除，保存明确失败并保留文字，可移除该选择或重试。 |
| TT-MU2 回看 | 记录链接显示当前标题；与 labelAtLink 不同则显示“记录时：…”。空标题显示“未命名作品”。打开 `/math?workId=<UUID>`，返回 `/classes/:classId/records/:recordId`。 | deleted=true 显示“已删除”，仍可打开工坊只读对象及其恢复入口。404 显示“无法打开作品”，503 显示“未能加载”，均保留原草稿和可重试入口，不显示假删除态。 |
| TT-MU3 作品反馈 | 工坊反馈区域由组合层挂入 classes 的反馈组件，显示班级、实际日期、原记录文字及打开记录动作；来源已删除仍可看反馈。 | 查询失败保留已加载内容并标“未能更新”，不能显示“暂无反馈”。删班/删记录按活动过滤排除，恢复后刷新可见；不在工坊复制记录或编辑班级。 |
| TT-MU4 版本与未知结果 | 新页面统一读写记录 v2；旧页面遇 unsupported-content-version 提示“请刷新页面后继续编辑”，先保留草稿与待确认请求。 | 待确认写请求必须先在原路径用原键原体确认，成功后读 v2 当前记录；有新草稿时不被旧响应覆盖。409 对照整理后新键保存。401 按原账户锁定草稿，切账户不显示旧数据。 |

班级现场保存选中班级/记录、日期、展开项、各区域滚动和草稿；选择器另保存 q/kind/已选 ID。作品现场由 math 按账户分区保留。URL 只携稳定 ID，不携完整记录或任意 return URL；打开作品不提交未保存输入，返回不重新创建记录。公共日程选择记录只需原摘要，不加载作品源码或海报。

两班使用同一作品分别保存；作品后续更新不改反馈文字或变成采用版本快照。render=invalid 不禁用教学关联，渲染状态归工坊自己的展示。所有入口沿用单一工具/AI 右栏，普通浏览不抢 AI。

相关交互变更需在桌面 1440×900、平板 768×1024 验证长标题、选择失败、已删除、往返草稿/滚动、焦点与无页面级横向溢出。桌面局部结果不能替代真实平板触控与完整教学验收。

日历浏览器验证使用 `apps/web/e2e/calendar-emstudio.config.mjs`，班级及原协议验证使用 `manual-teaching.config.mjs`、`teaching-time-auth.config.mjs`；HTTP `apps/api/test/teaching-time-*.test.js`。相关任务核对两班隔离、计划不改实际记录、单次例外不误改整组、关闭期间提醒补呈现和点击返回；作品真实关联须用真实提供方，不用样本替身证明。

## 教学实现

classes 拥有实际记录、来源链接及反向反馈；schedule 拥有日期、日历标签、重复规则/例外及事项移动，提醒是其内部能力。UI 和 Agent 通过同一公开操作调用，时间算法只有一份。端口约束见[教学契约](../contracts/teaching-time.md#公共端口与协议版本)，组合顺序以 `apps/api/src/workbench/teachingTime.js` 为准。

重复实例查询时展开原始日期并应用例外，再按实际区间筛选，必须覆盖从区间外移入的例外。删除/恢复保留实例身份、例外和通知痕迹。迁移只追加，保留原记录、来源顺序及旧幂等回执；用空库和旧库验证重启，实际数据备份见[数据管理](data.md#部署备份与还原)。
