# 班级教学：实际记录与课前回顾

本分区拥有班级、实际教学记录、来源关联及反向反馈；两班共用备课时分别保存自己的记录。计划安排归[日程](schedule.md)，不从计划推断实际进展，也不增加学生个人档案。范围见[产品分区](../PRODUCT_SCOPE.md#产品分区)，当前能力与未验条件见[项目状态](../plans/run-state.md)。

## 入口与布局

业务路径为 `/classes`、`/classes/:classId`、`/classes/:classId/records/:recordId`。跨分区只导航到允许的本地业务路径；返回位置保存在本账户设备现场，不接受任意外部 return URL。

```text
既有侧栏 | 班级教学 · 高一(1)班                      | 我的班级 或 AI
         | 最近教到 / 最近记录、下次教学想法          | 切换班级、创建班级
         | 写一句… [添加补充] [关联资料] [保存记录]  |
         | 9月21日：实际记录，连续阅读、独立滚动       |
```

班级主区与班级列表是背景上的独立浮层，各自滚动。首次进入用用途说明和“创建班级”开始；创建只需名称。班级主页列出活动班级及其最近教学位置或记录摘要，每项标明日期，不自动进入详情；详情页始终提供返回班级主页的入口。回主页和刷新保留列表状态，进入班级后继续其草稿。窄屏或 AI 已打开时，班级列表收起，通过标题旁的当前班级打开切换浮层，选班不关闭 AI。

课堂记录默认只显示正文、日期和保存；补记保存完成后的空白表单回到账户今天。自动日期在跨日与返回页面时更新，有内容的草稿和手选日期保持不变，补记时可用“今天”回到当前日期；“添加补充”逐项选择教学进度、未讲内容、共性问题或下次教学想法，每项独立展开，已有内容自动显示。空补充可收起，有内容时先清空再收起；关联资料是独立入口，确认选择后仍需保存记录。编辑旧记录期间收起新记录区但保留其草稿，使用“保存修改”和“返回记录”；返回后继续原来的新记录草稿。班级维护、已归档班级和已删除记录在各自更多菜单中。归档成功立即返回班级主页并移出活动列表；归档中可回看记录、恢复班级或彻底删除，不在归档后继续展示原详情或只读说明。彻底删除前明确确认班级名、全部课堂记录及无法恢复的影响；成功后移出归档列表。

“公式与图片”按需打开共享文稿编辑器，上传板书图片或填写公式源，保存后与记录一起回看。原有文字字段不转成富文本；图片支持说明、替换和移除，公式预览失败保留源码。新建时仅公式或图片也可保存。图片上传结果未确认时先确认上传再保存记录，刷新后可重新选择原图片继续原草稿。

记录更多菜单可“移到其他班级”，选择目标后明确确认。目标班级得到独立记录，原记录进入原班级的“已删除”，已有日程仍关联原记录，恢复原记录不会删除目标记录。未保存的编辑草稿需先处理，移动不会搬走新记录输入框中的另一份草稿；成功打开目标记录，失败或未知结果保留恢复入口。

记录区通过“查找记录”按需展开关键词搜索，进一步展开日期范围、补充类型和关联资料筛选。关键词匹配正文、补充及资料当前/保存时名称；筛选按账户、班级及活动/已删除列表保留，关闭查找清除条件。无匹配与空班级使用不同提示；已打开记录即使不匹配筛选也保留可见并说明原因。日期包含年份，跨年回看不混淆。

“课前回顾”按需展开近期记录中的未讲内容、共性问题与未收起想法，保留来源日期并可打开原记录；当前只展示实际文字，不自动判断教学完成情况。已删除记录的更多菜单可确认后彻底删除该条，其他记录、资料和日程保留，结果未知时在模块顶部确认。

已有资料暂不可用或无法找到时，记录保留正文和保存时标题，分别显示对应状态，并提供重试关联资料。既有正文仍可编辑，新增关联必须验证资料；身份错误不降级成资料异常。

## 状态和动作

| 状态 | 可见内容/动作 | 结果、失败与返回 |
| --- | --- | --- |
| TT-U1 班级浏览 | 空态解释用途并提供“创建班级”；班级名必填。当前班级始终在主区可见。 | 选班保持 AI；归档保留记录并立即回主页，恢复后可继续。彻底删除仅针对已归档班级，永久移除该班及全部记录，关联的备课、题目、作品和日程保留。 |
| TT-U2 一句话/补充 | 日期默认账户今天，任一文字项有内容即可“保存记录”，不必命名。补充和关联按前述使用顺序展开。 | 保存后留在本班并显示新记录，只清空本次已确认的输入。失败保留原句，期间新输入保留为草稿。顶部“最近教到”取最近日期中最后创建且填写位置的活动记录，编辑旧记录不改变其先后；没有位置时改称“最近记录”。“下次教学想法”取最近填写该项的活动记录，可停止提示或在原记录菜单恢复；停止提示不删原文，也不自动翻出更旧想法。两者标明各自日期，不从日程推断。 |
| TT-U3 记录阅读/关联 | 按实际日期降序阅读，编辑与新建有明确区分，可删除、恢复。资料链接带保存时标题，原对象删除仍能认出。 | 就地选择已有资料，取消不写入。进入资料/返回保留记录草稿及滚动；源标题变化显示最新标题及“记录时：…”；已删除来源给只读回看/恢复入口，不清除反馈。 |

## 现场与错误

保存状态、结果未确认、冲突、身份失效和本地存储失败沿用 [共享保存与恢复](../contracts/workbench.md#保存与恢复反馈)，不再定义另一套保存协议。班级记录显式保存，Ctrl/Cmd+S 只保存当前编辑区。未确认请求先以原键原体确认；老师新增输入保存在另一个草稿中。版本冲突保留双方内容，不自动覆盖。

设备现场按可信 accountKey 分区，保存当前班级/记录、筛选、展开字段、记录日期、各区滚动、右栏形态、输入草稿和待确认请求。切换、刷新、离开再返回均恢复；丢弃草稿须明确确认。换设备读取已保存业务，未上传草稿不跨设备。异账户与迟到旧请求遵守[共享身份代次隔离](../contracts/workbench.md#身份与-http)；存储失败时提示复制/在线保存后继续。

## 数学作品关联与反馈

作品选择和反向反馈已连接真实 math/classes 提供方，SourcePicker 读取活动作品，记录与反馈使用 v2。加载失败保留草稿并提供重试，不显示虚假作品；普通无关联记录仍可保存。已有局部链路不代替完整教学与目标设备验收，具体边界见[项目状态](../plans/run-state.md)。

| 状态 | 操作与可见结果 | 失败与恢复 |
| --- | --- | --- |
| TT-MU1 选择 | 关联资料中切到“数学作品”，可按标题搜索和类型筛选；活动的公式/平面/立体/动态/HTML 均可选。勾选后回到记录草稿，显式保存才建立关系；取消不写入。 | 搜索失败显示“未能加载作品”和重试，保留已选项；空列表说明暂时没有可选资料，搜索无匹配单独提示。选择后已删除，保存明确失败并保留文字，可移除该选择或重试。 |
| TT-MU2 回看 | 记录链接显示当前标题；与 labelAtLink 不同则显示“记录时：…”。空标题显示“未命名作品”。打开 `/math?workId=<UUID>`，返回 `/classes/:classId/records/:recordId`。 | deleted=true 显示“已删除”，仍可打开工坊只读对象及其恢复入口。404 显示“无法打开作品”，503 显示“未能加载”，均保留原草稿和可重试入口，不显示假删除态。 |
| TT-MU3 作品反馈 | 工坊反馈区域由组合层挂入 classes 的反馈组件，显示班级、实际日期、原记录文字及打开记录动作；来源已删除仍可看反馈。 | 查询失败保留已加载内容并标“未能更新”，不能显示“暂无反馈”。归档班级/删除记录按活动过滤排除，恢复后刷新可见；班级彻底删除后不再出现；不在工坊复制记录或编辑班级。 |
| TT-MU4 版本与未知结果 | 新页面统一读写记录 v2；旧页面遇 unsupported-content-version 提示“请刷新页面后继续编辑”，先保留草稿与待确认请求。 | 待确认写请求必须先在原路径用原键原体确认，成功后读 v2 当前记录；有新草稿时不被旧响应覆盖。409 对照整理后新键保存。401 按原账户锁定草稿，切账户不显示旧数据。 |

班级现场保存选中班级/记录、日期、展开项、各区域滚动和草稿；选择器另保存 q/kind/已选 ID。作品现场由 math 按账户分区保留。URL 只携稳定 ID，不携完整记录或任意 return URL；打开作品不提交未保存输入，返回不重新创建记录。公共日程选择记录只需原摘要，不加载作品源码或海报。

两班使用同一作品分别保存；作品后续更新不改反馈文字或变成采用版本快照。render=invalid 不禁用教学关联，渲染状态归工坊自己的展示。所有入口沿用单一工具/AI 右栏，普通浏览不抢 AI。

相关交互变更需在桌面 1440×900、平板 768×1024 验证长标题、选择失败、已删除、往返草稿/滚动、焦点与无页面级横向溢出。桌面局部结果不能替代真实平板触控与完整教学验收。

## 接口与实现

Web `apps/web/src/features/classes/` 和 API `apps/api/src/modules/classes/` 各自拥有本分区实现，经[静态模块目录](../../packages/shared/src/moduleCatalog.js)装配。记录日期当前消费外壳读取的账户时区，时区存储和同步由日程拥有；读取失败时保留明确的重试入口，不让账户模块了解记录业务。

班级、记录与来源协议见[班级契约](../contracts/teaching-time.md#班级实际记录与回看)；作品关联/兼容见[数学扩展](../contracts/teaching-time.md#数学作品关联)，丰富题目见[题目接缝](../contracts/teaching-time.md#丰富题目关联)，跨分区端口见[公共端口](../contracts/teaching-time.md#公共端口与协议版本)。UI 与接入后的 AI 助理调用同一公开操作，这不表示六模块助理已接线。

迁移只追加，保留原记录、来源顺序及旧幂等回执；用空库和固定旧库验证重启，实际数据备份见[数据管理与恢复](data.md#部署备份与还原)。

## 验证入口

[教学场景](../acceptance/teaching-time.feature)中的班级、实际记录及数学关联是本分区的验收判据，交换预期见[契约案例](../contracts/teaching-time-cases.md)。两班反馈独立、计划不改实际记录、来源更新/删除后仍可读、往返草稿与滚动须使用真实提供方验证。检查空态、长文本、保存失败、冲突、删除及返回；实际指针/触控、外壳固定、无页面级横向溢出和焦点都要核对。

班级教学当前交互使用 `apps/web/e2e/classes-journal.config.mjs`，`WORKBENCH_WEB_DIST` 必须指向隔离生产构建。覆盖从空态保存、按需补充、备课关联、编辑/新建切换、两班草稿与日期恢复、AI 展开时切班、窄屏、主页往返、归档恢复、彻底删除及取消、已删除记录定位、保存与彻底删除响应丢失后重试、长列表编辑返回及菜单快速反向；身份为真实认证，邮件使用测试替身。`apps/api/test/teaching-time-classes-lifecycle.test.js` 验证彻底删除的账户/版本/归档校验、事务回滚、记录与来源关系清理、重放、重启及保留日程关联的备份还原。

`classes-capabilities.spec.js` 验证补记与跨日日期、同日编辑顺序、故障来源降级、主页进度、关键词/日期/内容筛选及草稿保留、课前回顾与想法提示恢复、单条彻底删除、公式图片编辑、图片上传与跨班移动的未知结果重试，以及旧待确认请求升级后的草稿结算。API `teaching-time-classes-capabilities.test.js` 覆盖归属、版本、回滚、幂等、文稿兼容、文件所有权、移动后的日程关联与含图片的备份还原。

身份专项使用 `apps/web/e2e/teaching-time-auth.config.mjs`，HTTP 从 `apps/api/test/teaching-time-*.test.js` 选择班级及来源关联范围。`manual-teaching.config.mjs` 针对旧界面，不能直接证明当前入口。代码存在和接口可调用不等于已验；当前候选和具名结果见[核查入口](../plans/run-state.md#核查入口)。
