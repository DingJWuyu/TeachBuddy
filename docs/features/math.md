# 数学工坊：制作、源码与课堂使用

公式、平面/空间图形、动态作品和外部 HTML 均以可保存、可二次修改的源为中心。实现与目标环境的验证范围见[当前状态](../plans/run-state.md)。新模板替换非空作品或参数草稿前须明确确认，取消保持原稿。

## U-MA0 共同框架与保存

工坊首页展示公式、平面图形、空间图形、动态演示四类用途与成果示意，下方为本设备草稿、可搜索的作品列表和已删除筛选。HTML 从“导入已有 HTML 演示”进入。首页与编辑各自保留滚动位置。

编辑区顶部以图标和标题标识模块，当前作品名与“返回工坊”在下一行。桌面主面板与右侧辅助栏等高、上下对齐，以背景间隙区分；字号、浮层和 reduced-motion 按[界面规则](../rules/design-and-verification.md)。保存、下载图片或下载演示保持文字入口；另存、使用位置和删除归“作品操作”菜单。下载展开文件格式、背景和尺寸，使用明确的已保存版本。

“返回工坊”保留有内容的设备草稿，首页可继续制作；仅进入而未改动的空白稿直接退出。丢弃草稿、以新作品替换非空未保存稿或替换图形示例须确认，取消后内容与设置保留。未知结果的保存、导出或删除仍按原操作确认，不因返回首页丢失。

选择类型进入可编辑空稿，默认未命名，无需先填课题或分类。平面图提供二次函数起点，空间图提供正方体和棱锥；动态示例先可试演，编辑工具在明确选择后展开。示例均可修改和删除，不代替老师的作品。

画布上方提供添加图形、图形与标注、画布设置；动态作品另有设置滑杆和编排步骤。右栏只显示当前操作的内容，不与作品列表混排。点击静态画布上的曲线、点、标注或棱，与右栏列表双向选择并高亮；可用 Enter 或空格选择静态图形。空间点和棱在同一列表中编辑，棱的端点和线型跟随当前选择。对象先显示名称、表达式或坐标，定义域、标注和样式按需展开。

工具与 AI 共用一列，切换保留两边现场；普通浏览不抢走 AI，明确选择对象或编辑操作可打开制作工具。窄屏面板可以关闭并返回画布。1440×900、1024×768及窄视窗分别检验溢出、焦点与独立滚动；实际触屏支持仍需目标设备验证。

保存状态为“未保存”“保存中”“已保存”“保存结果待确认”“保存失败”；渲染状态另示，保存源码成功不能冒充可展示。最后有效预览可留作对照，但明确“上次预览”，不能导出为本次版本。字段错误定位源/对象；语法错误仍能保存源码，修正再渲染。后端版本冲突显示服务器版本和本地稿，老师选择整理后提交或另存作品。保存结果未知保留原键、原请求和后续草稿，先确认原请求。

作品保存到服务端，刷新/重启/同账户换设备后可读。未提交稿、缩放、对象选择、列表筛选、滚动、面板和返回目标按账户存于设备现场；另一设备只恢复已保存内容。切换作品/模块可留草稿，破坏性丢弃必须明确。身份失效锁住画面及嵌入预览；同账户恢复后继续确认，其他账户不显示旧稿。

## U-MA1 公式

“常用结构”提供分式、根式、上下标，选择后填写分子分母等内容并实时预览；结构及输入保留为设备现场，切换结构覆盖已有公式前确认。“LaTeX 源码”可继续编辑完整公式，分式、根式、上下标、cases 插入当前光标处，选中文字时替换该选区；中文说明在独立可编辑栏，可选择纳入成果。实时预览、错误位置与公式源同屏。改颜色、字号和说明后保存，重开仍是可编辑内容。导出 SVG 或透明 PNG；棋盘格仅是透明预览底，不进入文件。源内容可复制，不能把 SVG 宣称为 Office 可编辑公式。中文说明选入后须实际出现在导出边界内。

## U-MA2 静态图

函数起点可输入 `x^2-2*x-3`，添加多条曲线、设置定义域/坐标窗，选择点、线、圆/椭圆、折线/多边形及文字标注；对象列表可以选择细小或遮挡对象。标注文本、位置、字号、颜色和线宽/虚实可直接改。支持单调区间的彩色线段、箭头与文字标注。无定义点断开，不跨渐近线连线。

立体图以三维点、棱和固定正交投影生成示意，提供正方体/长方体、棱锥起点；老师能改尺寸、点名、投影角度和遮挡棱虚线，并添加辅助线。圆柱/圆锥/球面示意可由平面椭圆和轮廓组合，保持可改；不承诺自动几何证明或自动判断所有遮挡。预览与 PNG/SVG 使用同一制作源和渲染器。导出可选透明或白底，不从屏幕截图取代矢量源。

## U-MA3 动态制作与展示

从“参数函数”起点或空画布建立表达式、参数、点和标签。右栏按当前选择显示参数名、最小/最大/步长/初值；拖点绑定明确的两个参数，每个轴可独立锁定。范围修改同时校验初值与步长，超界要求老师修正，不悄悄截断源。步骤列表可新增、改名、排序，每步选择显示哪些对象和本步参数值。

M-D 三步固定为母函数、平移后曲线、带系数完整式；每步实际绘制的曲线、顶点与解析式必须一致。切步骤应用该步值，自由探索只改变演示现场；“设为开场画面”才改制作稿。“课堂展示”隐藏编辑控件，保留滑杆、拖点、步骤、重置和退出；退出回原编辑位置。保存范围、步骤文字、初值、对象后重开逐项恢复。

教学意图超出结构化表达时，可由 Agent 起草 HTML，再走 U-MA4；不以固定抛物线模板覆盖全部动态需求。创建、读取、修改、导出端口可由手动界面使用；Agent 真实接线须单独验收，当前暂停。

## U-MA4 外部 HTML

选择本地 HTML → 保存原件 → 显示名称、源码入口和“运行预览”。原件上传与作品建立分两次持久操作，后一操作失败可复用已上传文件，不要求重新上传。首次不自动执行代码。运行于隔离框架；关闭/切换/失效时销毁。依赖外网时显示“此作品需要外部资源，当前预览可能不完整”，可继续保存与取回；不自动联网下载依赖或替用户修补任意脚本。

作品改名只改目录名称。作品内部标题、滑杆范围、图形逻辑等通过“编辑源码”或 Agent 修改，预览确认后保存新版本。只有原生结构化作品显示统一参数工具；不会猜“第一个 range 就是 k”。文件即使坏了也能保存原件，非 UTF-8/过大文件可下载，但不进入源码编辑。保存源与预览运行成功分开提示，超时/异常可停止后回源。

导出菜单区分“取回原文件”“下载当前源码”“下载隔离演示”。前两者保留对应真实字节，提示打开原始 HTML 会运行其中代码。隔离演示包封装当前源，不混入账户数据；对外部源显示“离线效果待检查”，不能仅扫描 URL 就盖章可离线。支持内联脚本/CSS/SVG/data 图片；需要模块加载、CDN、后端或相对资源的作品可能受限，老师可补成自包含源码再试。原件永不被修改版覆盖。

## U-MA5 备课往返与版本

从备课环节“制作数学作品”进入，保留 lessonId/sectionId 和设备内完整备课草稿、选中/滚动；先保存未保存的新备课以获得 ID。备课旧保存结果未确认时先完成确认，再进入制作。可在工坊切换已有作品，目标条始终可见。

“带回备课”先确认当前作品已保存且可引用，再回到原备课草稿，在原位置插入该保存版本，立即按完整草稿保存；只有备课保存成功才提示“已加入”。作品保存与备课保存是两次明确提交，后者失败不回滚作品。取消返回只恢复备课现场，不加入引用；作品已保存内容保留。

目标环节被删时不自动放到别处：恢复原稿并显示冲突，允许在对照当前备课后选择新环节或“本课材料”。目标备课被删/身份变更时停在已保存作品，保留原账户返回意图，提供重新选目标。未知结果沿同键确认，不能再插一份。

引用固定采用版本，源改动显示“有更新”，老师选择“采用更新”才替换本引用快照；本课备注保持。要只改这一课，选择“另存作品并替换本处”，新作品独立，原引用移除、新建引用 ID。普通选择去重；“再放一次”明确生成第二个引用。原作品删除后旧快照、静态预览和已保存演示仍可用；可从引用找到源并恢复，不能自动采用恢复后的版本。

## U-MA6 导出与课堂

原生公式/静态图先保存再导出，下载基于明确版本。动态演示下载为自包含隔离 HTML，老师双击打开，不需要制作服务、账户或 CDN。下载失败保留作品，可重试原请求；选择其他版本或选项是新请求。原生动态课堂操作不写回工坊，重新打开回保存初态。

备课教案/讲义中的公式保持 Document 数学源；静态图用快照 PNG；动态作品用标题和已固定初态图，外部 HTML 无图则用标题及“交互演示见单独文件”，不执行 HTML 排版。练习成果仍只选择题目，不把作品当作题。演示另行下载，不伪造 PDF 内可交互或 HTML 可嵌入 PPT。

当前具名本地与个人 Windows 切片证据见[输入索引](../plans/run-state.md#证据边界)。M43/M44 使用最终下载物在全新配置、禁网和关闭制作服务后验证；Windows Chrome/Edge 与教师实际 PPT/WPS 设备分别记结果，未测不宣传支持。窄屏能阅读不等于触屏拖动已验。

## U-MA7 使用位置与教学反馈

作品操作中的“使用位置与教学反馈”列活动备课、环节和采用版本，点击恢复对应文稿。教学反馈使用 T51 的只读列表，按班级/日期回看；从作品进入记事由 classes 保存关联，工坊不写教学记录表。使用已冻结的教学作品扩展，关联成功以真实持久结果为准。精确扩展见[教学时间交接](../contracts/teaching-time.md#数学作品关联)。

## 实现与验证入口

[数学契约](../contracts/workbench/math.md)拥有源、revision、渲染/隔离与导出字段；[制作实现](#制作实现)拥有表达式及渲染接缝。Web/API 分别为 `apps/web/src/features/math/`、`apps/api/src/modules/math/`；制作界面、保存导出与窄屏流程使用 `apps/web/e2e/math-workspace.config.mjs`，扩展数学场景见 `apps/web/e2e/manual-math.config.mjs`，API 使用 `apps/api/test/math-*.test.js`。

相关变更检查真实保存重开、第二次修改、准确图式、导出边界、源码/原件不丢及取消覆盖。离线从实际下载物、全新浏览器环境禁网冷启动，不能用在线页面或缓存代替。

## 制作实现

公式使用本地 MathJax，静态/动态作品使用原生 SVG/JavaScript 与受控表达式求值器。UI、导出和 Agent 共用数学规则，函数表达式不执行任意 JavaScript。版本与依赖由代码和锁文件维护，字体及离线资源随构建提供。

math 拥有制作源、历史版本、渲染与导出；files 拥有不可变字节；lessons 拥有采用快照与返回草稿；classes 拥有实际教学反馈。具体进程内端口及事务约束见[公共端口](../contracts/workbench/math.md#公共端口)。反馈由组合层注入，不形成 math 对 classes 的服务端依赖。

迁移保留已有 File、旧引用和历史 revision，不重写旧成功回执。验证旧库升级、两次重启、真实制作导出及下载物冷启动；完整交付条件见[数学判据](../acceptance/mvp-matrix.md#math)。
