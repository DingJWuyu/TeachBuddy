# 数学工坊：制作、源码与课堂使用

公式、平面/空间图形、动态作品和外部 HTML 均以可保存、可二次修改的源为中心。当前手动制作与往返有局部独立证据，课堂目标设备仍待验证。新模板替换非空作品或参数草稿前须明确确认，取消保持原稿。

## U-MA0 共同框架与保存

```text
全局导航 | 当前作品名  保存状态       保存  展示  导出 | 工具 / AI
         | [来自：二次函数 · 探究]  带回备课  取消返回 | 我的作品
         |                                          | 当前对象属性
         |          画布 / 公式预览                  | 参数 / 步骤
         |          本区独立滚动                     | 按需编辑
```

名称和操作跟随当前作品；只有从备课进入才有第二行目标。作品列表在共享右栏工具页，搜索名称/类型、切换、复制、已删除筛选，默认不挤占画布。打开 AI 保留同一对话、草稿和选择；普通切作品不抢走 AI，明确编辑对象可切工具。窗口窄时工具作为可收起面板，展示只保留画面和必要控制；不建立另一个助理栏。

使用项目现有令牌，菜单约30px、导航36px、正文14/20px、面板圆角12px。画布与工具之间露出背景，不给每个参数套卡片。浮层用180ms透明度+0.96缩放，尊重 reduced-motion。键盘可进入对象列表、属性、滑杆和步骤；画布拖动同时提供数值输入。1440×900、1024×768及窄视窗分别检验溢出、焦点、独立滚动；触屏实际支持待目标设备验证。

空工坊显示“新建公式 / 新建图形 / 新建演示 / 导入 HTML”。选择类型立即进入可编辑空稿，不先要求课题或分类。标题默认“未命名公式/图形/演示”，可直接改。原型样例只能作为起点，须能删除、增添和修改对象。

保存状态为“未保存”“保存中”“已保存”“保存结果待确认”“保存失败”；渲染状态另示，保存源码成功不能冒充可展示。最后有效预览可留作对照，但明确“上次预览”，不能导出为本次版本。字段错误定位源/对象；语法错误仍能保存源码，修正再渲染。后端版本冲突显示服务器版本和本地稿，老师选择整理后提交或另存作品。保存结果未知保留原键、原请求和后续草稿，先确认原请求。

作品保存到服务端，刷新/重启/同账户换设备后可读。未提交稿、缩放、对象选择、列表筛选、滚动、面板和返回目标按账户存于设备现场；另一设备只恢复已保存内容。切换作品/模块可留草稿，破坏性丢弃必须明确。身份失效锁住画面及嵌入预览；同账户恢复后继续确认，其他账户不显示旧稿。

## U-MA1 公式

直接输入 LaTeX，提供分式、根式、上下标、cases 的插入动作；中文说明在独立可编辑栏，可选择纳入成果。实时预览、错误位置与公式源同屏。改颜色、字号和说明后保存，重开仍是可编辑内容。导出 SVG 或透明 PNG；棋盘格仅是透明预览底，不进入文件。源内容可复制，不能把 SVG 宣称为 Office 可编辑公式。中文说明选入后须实际出现在导出边界内。

## U-MA2 静态图

函数起点可输入 `x^2-2*x-3`，添加多条曲线、设置定义域/坐标窗，选择点、线、圆/椭圆、折线/多边形及文字标注；对象列表可以选择细小或遮挡对象。标注文本、位置、字号、颜色和线宽/虚实可直接改。支持单调区间的彩色线段、箭头与文字标注。无定义点断开，不跨渐近线连线。

立体图以三维点、棱和固定正交投影生成示意，提供正方体/长方体、棱锥起点；老师能改尺寸、点名、投影角度和遮挡棱虚线，并添加辅助线。圆柱/圆锥/球面示意可由平面椭圆和轮廓组合，保持可改；不承诺自动几何证明或自动判断所有遮挡。预览与 PNG/SVG 使用同一制作源和渲染器。导出可选透明或白底，不从屏幕截图取代矢量源。

## U-MA3 动态制作与展示

从“参数函数”起点或空画布建立表达式、参数、点和标签。右栏按当前选择显示参数名、最小/最大/步长/初值；拖点绑定明确的两个参数，每个轴可独立锁定。范围修改同时校验初值与步长，超界要求老师修正，不悄悄截断源。步骤列表可新增、改名、排序，每步选择显示哪些对象和本步参数值。

M-D 三步固定为母函数、平移后曲线、带系数完整式；每步实际绘制的曲线、顶点与解析式必须一致。切步骤应用该步值，自由探索只改变演示现场；“设为初始状态”才改制作稿。课堂展示隐藏编辑控件，保留滑杆、拖点、步骤、重置和退出；退出回原编辑位置。保存范围、步骤文字、初值、对象后重开逐项恢复。

教学意图超出结构化表达时，可由 Agent 起草 HTML，再走 U-MA4；不以固定抛物线模板覆盖全部动态需求。创建、读取、修改、导出端口可由手动界面使用；Agent 真实接线须单独验收，当前暂停。

## U-MA4 外部 HTML

选择本地 HTML → 保存原件 → 显示名称、源码入口和“运行预览”。原件上传与作品建立分两次持久操作，后一操作失败可复用已上传文件，不要求重新上传。首次不自动执行代码。运行于隔离框架；关闭/切换/失效时销毁。依赖外网时显示“此作品需要外部资源，当前预览可能不完整”，可继续保存与取回；不自动联网下载依赖或替用户修补任意脚本。

作品改名只改目录名称。作品内部标题、滑杆范围、图形逻辑等通过“编辑源码”或 Agent 修改，预览确认后保存新版本。只有原生结构化作品显示统一参数工具；不会猜“第一个 range 就是 k”。文件即使坏了也能保存原件，非 UTF-8/过大文件可下载，但不进入源码编辑。保存源与预览运行成功分开提示，超时/异常可停止后回源。

导出菜单区分“取回原文件”“下载当前源码”“下载隔离演示”。前两者保留对应真实字节，提示打开原始 HTML 会运行其中代码。隔离演示包封装当前源，不混入账户数据；对外部源显示“离线效果待检查”，不能仅扫描 URL 就盖章可离线。支持内联脚本/CSS/SVG/data 图片；需要模块加载、CDN、后端或相对资源的作品可能受限，老师可补成自包含源码再试。原件永不被修改版覆盖。

## U-MA5 备课往返与版本

从备课环节“制作数学作品”进入，保留 lessonId/sectionId 和设备内完整备课草稿、选中/滚动；先保存未保存的新备课以获得 ID。备课旧保存结果未确认时先完成确认，再进入制作。可在工坊切换已有作品，目标条始终可见。

“带回备课”先确认当前作品已保存且可引用，再回到原备课草稿，在原位置插入该保存版本，立即按完整草稿保存；只有备课保存成功才提示“已加入”。作品保存与备课保存是两次明确提交，后者失败不回滚作品。取消返回只恢复备课现场，不加入引用；作品已保存内容保留。

目标环节被删时不自动放到别处：恢复原稿并显示冲突，允许在对照当前备课后选择新环节或“本课材料”。目标备课被删/身份变更时停在已保存作品，保留原账户返回意图，提供重新选目标。未知结果沿同键确认，不能再插一份。

引用固定采用版本，源改动显示“有更新”，老师选择“采用更新”才替换本引用快照；本课备注保持。要只改这一课，选择“另存作品并替换本处”，新作品独立，原引用移除、新建引用 ID。普通选择去重；“再放一次”明确生成第二个引用。原作品删除后旧快照、静态预览和已保存演示仍可用；可从引用找到源并恢复，不能自动采用恢复后的版本。

## U-MA6 导出与课堂

原生公式/静态图先保存再导出，下载基于明确版本。动态演示下载为自包含隔离 HTML，老师双击打开，不需要制作服务、账户或 CDN。下载失败保留作品，可重试原请求；选择其他版本或选项是新请求。原生动态课堂操作不写回工坊，重新打开回保存初态。

备课教案/讲义中的公式保持 Document 数学源；静态图用快照 PNG；动态作品用标题和已固定初态图，外部 HTML 无图则用标题及“交互演示见单独文件”，不执行 HTML 排版。练习成果仍只选择题目，不把作品当作题。演示另行下载，不伪造 PDF 内可交互或 HTML 可嵌入 PPT。

当前具名本地与个人 Windows 切片证据见[输入索引](../plans/run-state.md#证据边界)。M43/M44 使用最终下载物在全新配置、禁网和关闭制作服务后验证；Windows Chrome/Edge 与教师实际 PPT/WPS 设备分别记结果，未测不宣传支持。窄屏能阅读不等于触屏拖动已验。

## U-MA7 使用位置与教学反馈

作品页“使用位置”列活动备课、环节和采用版本，点击恢复对应文稿。教学反馈使用 T51 的只读列表，按班级/日期回看；从作品进入记事由 classes 保存关联，工坊不写教学记录表。使用已冻结的教学作品扩展，关联成功以真实持久结果为准。精确扩展见[教学时间交接](../contracts/teaching-time.md#数学作品关联)。

[数学契约](../contracts/workbench/math.md)拥有源、revision、渲染/隔离与导出字段；[制作实现](#制作实现)拥有表达式及渲染接缝。Web/API 分别为 `apps/web/src/features/math/`、`apps/api/src/modules/math/`；浏览器 `apps/web/e2e/manual-math.config.mjs`，API `apps/api/test/math-*.test.js`。

## 制作实现

### 选择与数据归属

采用 C23 候选A的本地 MathJax 3.2.2 + 原生 SVG/JavaScript。公式路径已有可编辑源与PNG/SVG实证，静态/动态作品采用数学契约定义的受控源，不能把C23的硬编码按钮或localStorage迁作产品存储。JSXGraph候选B未运行，无证据要求引入第二套制图内核。函数用封闭表达式解析器和单一求值实现，UI、导出、Agent共用；无eval、服务端运行任意JS或通用脚本平台。

Math Module 吸收制作源、历史版本、数学校验、可信图形渲染、隔离预览包装与成果导出。调用者只使用小的业务Interface，不了解渲染步骤/临时文件。持久资产调用R31 File接缝；事务内只做同步归属/版本/快照检查，文件字节与重渲染在事务外准备。成功文件写入后再次校验当前版本，同一mutations事务保存Work/Revision/成功回执；冲突留下的File按材料规则保留，不回滚或删除用户原件。

| 所有者 | 数据与持久性 |
| --- | --- |
| math | accountKey、Work、完整WorkRevision、渲染标识/固定海报/隔离演示文件、导出记录/版本/选项/fileId；软删除；迁移 `math_*` |
| files | 原始HTML、编辑后的HTML、规范JSON下载、PNG/SVG/隔离HTML字节；不可变、授权读、fsync提交；不新增HTML执行权限 |
| lessons | v3含math引用的完整聚合、采用快照、本课备注、使用位置；迁移 `lessons_math_*`；旧question/resource语义不变 |
| classes | 教学记录和反向反馈链接；math只供读取和页面组合，不写该表 |
| Web feature | 按账户分区的未保存稿/未知请求/设备现场；无业务唯一数据只存在localStorage |

math源与revision保存JSON，但必须按唯一schema及跨字段规则校验。文件ID不作为可执行URL。源码下载JSON不携服务器私有标识；原版Source可以通过API读取，备份包含服务器关联。数学导出纯本地有界任务，同步响应足够；单用户体量不需要给材料Job枚举追加任意工作流。源码、海报和导出有明确所有者，避免两套“资源”和“作品”编辑状态。

### 公共接口与唯一写者

公共方法由 Module 工厂提供，DTO直接使用math.openapi.json命名类型；不再手写第二份JSON模型。业务异常仍为 `{status, problem}`，principal只从可信入口传入。提供方只读方法必须同步，供同一SQLite事务调用；绝不借HTTP回环或跨表访问。

| Interface | 结果 / 语义 | 提供 / 消费 |
| --- | --- | --- |
| `createMathModule({db, mutations, files, content}) -> {router, port, migrations}` | 仅声明式组合，构造时不读业务；renderer为math内部依赖 | M41共用骨架，M42顺序接续 |
| `math.port.operations.<operationId>({principal,key,input,id,query})` | Promise<{status,body}>；操作与HTTP逐一对应，读省key，无字段不传；version历史路径由query.version传入 | M41/M42实现；UI/Agent消费 |
| `math.readForReferenceV1(principal,id)` | 同步ReferenceReadWork，当前本账户含tombstone；只投影保存结果，不现场生成文件，invalid仍可读，调用者决定能否新引用 | M41提供基础，M42补完整Source；M43 lessons消费 |
| `math.readForTeachingLinkV1(principal,id)` | 同步TeachingWork，只投影id/version/title/deletedAt，不含源或文件 | M41提供；T51消费 |
| `lessons.listUsagesV3(principal,{kind,id})` | 同步UsageList，kind=question/resource/math；原listUsages不变 | M43提供，math使用位置消费 |
| `lessons.port.operations.<v3 operationId>(...)` | 同HTTP，完整聚合一次保存，新增/更新引用同一事务解析math | M43 |
| `classes.listSourceRecordsV2(principal,{kind,id})` | 教学时间新版的RecordList；math分支语义见扩展，不借用UsageList | classes 提供；math页面由M43的可选反馈容器消费 |

`files.store/read/open`、`content.validate`原样复用冻结[材料端口](../contracts/workbench/materials.md#公共端口)。math无业务必需依赖；lessons工厂在原questions/resources外显式注入math；classes 通过 math 教学端口读取，schedule不因此反向依赖工坊。显示反馈只经组合层注入，不把classes注册成math的强制依赖。

返回过程由lessons拥有草稿与ReturnTarget，math拥有编辑并返回已保存id/version；不用URL携带全备课，不新建“跨模块事务”表。API/Agent写者也必须先保存作品再保存备课，并分别报告结果。

### 运行、迁移与验证

M41迁移保留R31全部File/Document/旧引用和认证表；M42增加源分支不重写M41 revision；M43新增引用类型读取，不批量改旧快照。空库、R31旧库、含M41作品库、含R35备课库分别迁移并重启两次，ID/版本/旧未确认请求不变。配置入口沿底座隔离DB/文件目录，无新模型凭据；MathJax与需要的字体/离线脚本跟应用构建，运行时不拉CDN。

验证分为：公开HTTP的事务/归属/版本；浏览器真实制作/重开/导出；数学结果与图形目视；最终下载物冷启动；目标PPT/WPS取用。源码结构测试不能替代图片检查，C23原件不能替代最终实现导出。自验结果均self，M44独立复现WB-MA001至017及019/020并按缺陷归属返回；WB-MA018 的真实作品关联已接线，完整教学往返仍由 T54 在合格提供方上独立验收，不由设计或局部实现结果代签。
