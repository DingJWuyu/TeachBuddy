# 数学工坊：统一制作与课堂使用

制作行为读本页，交换字段读[数学契约](../contracts/math.md)，安装运行读[数学运行依赖](../SETUP.md#数学运行依赖)。后续开发边界见[数学任务](../plans/math-workshop.md)，当前授权、状态与剩余验证见[项目状态](../plans/run-state.md)。集成状态以项目状态及 Git 为准。

## 一个作品、一处制作

首页提供“新建作品”、搜索与真实作品缩略图，导入作品、导入网页和归档筛选从相邻菜单进入。首页与编辑器使用同一数学助理上下文；首页可描述想法并“开始制作”，连接成功后进入新作品并自动执行这次请求，输入不需重填。未连接时展开连接引导并保留输入，不建立空记录。新建直接打开统一编辑器：同一作品容纳可编辑公式、一个完整数学构造、参数和教学步骤。“平面 / 三维 / 双视图”切换同一构造的视图，添加内容保持作品 ID。纯公式作品没有空坐标画布；空白作品直接退出，不建立空记录。

顶行提供返回、作品名、保存状态、试演、下载与更多操作，课堂展示从更多操作进入。常用制作工具为公式、图形、参数、步骤、撤销与重做；“内容列表”打开当前对象。公式在主面上方按顺序排版，单击后直接聚焦公式输入，Enter 确认并退出编辑；“公式源码”按需展开以编辑或复制 LaTeX。数学画布与步骤轨道位于其下。“输入算式”可展开或收起表达式，建立图形后保持输入焦点，便于连续输入；也可使用点、线、圆、多边形和立体等工具。画布、对象列表和属性面板共享选择；细小对象可从列表选择。

“AI 助理”和“编辑”共用一列并可直接切换，属性围绕当前公式、图形、参数或步骤展示；样式等按需展开。自由滑杆参数以“取值”数值框和滑杆共同编辑当前值，“改为算式”按需展开，并说明转换后不再使用滑杆；有步骤取值或播放引用时先确认，取消保留原对象及引用。函数和依赖对象直接显示定义。双视图在宽屏左右排列、窄屏上下排列；调整尺寸保持可见范围、中心与比例，不作为内容修改。窄屏辅助栏可以关闭并返回画布。作品内容在深浅主题下都使用白纸表面，工具与侧栏跟随主题，不改变数学对象颜色或保存源。模块使用工作台自有界面，GeoGebra 提供构造与绘图能力，画面保留署名。视觉及真实手势验证遵守[设计规则](../rules/design-and-verification.md)；目标设备触屏体验仍须另验。

## 内容、试演与自动保存

编辑模式的公式、构造、参数、步骤与视图共同进入内容历史；一次 AI 混合修改是一批可撤销操作。撤销不改变服务端版本、作品 ID 或请求回执，也不承诺跨刷新保留。参数播放支持单次、循环和往返，在线与离线均按参数步长取值并限制在设定范围；点对象可设置试演轨迹。

“试演”中的滑杆、拖点、播放和步骤切换只改变运行现场；“设为开场”才提交到制作内容。每次应用步骤先恢复完整基准构造，再设置该步参数、对象显隐、公式显隐与视图。退出试演恢复编辑内容；课堂展示隐藏制作与对话，保留参数、步骤、播放、重置和退出。独立公式是可编辑文稿，不自动随参数求值；随构造更新的数学标注由图形对象表达。

有效内容修改后合并自动保存，首页只展示作品，不提供另一套本设备内容管理。作品保存到服务端，同账户刷新或重开后可读；未提交内容与对话现场按账户保存在本设备，不能把本地保护称为服务器已保存。保存状态区分正在保存、已保存、失败与结果待确认；失败可重试。请求结果未知时保留同键原请求，先确认已创建的 ID 或版本，再处理随后输入，避免重复创建。

尚未点击加入的公式与图形表达式只保存在本设备，同账户切换模块或刷新后恢复，不进入作品 Source 或服务器保存。返回工坊时先明确确认是否放弃这些输入，取消继续编辑；空白输入不产生空作品。

保存、导出、离开保护和 AI 批次使用完整内容快照。取消或离开使迟到操作失效，执行失败恢复批次之前的公式、图形和步骤，包含此前即时手动修改。等待 AI 时发生手动修改，旧回复不能覆盖新状态。断网和保存失败时保留内容，并提供重试或留在编辑器的处理路径。

版本冲突展示服务器与当前版本，提供以服务器版本为基线保留当前内容、另存作品或读取服务器作品。历史版本按固定保存记录预览；恢复替换当前编辑内容，覆盖未保存修改前确认，随后保存生成新 revision，既有历史和备课快照保持。恢复不会改写过去的成功回执。

## GeoGebra 数学画布与网页 AI

统一编辑器从项目本地加载固定源码构建的 GeoGebra 运行时；正常制作、保存和重开不需要 GeoGebra 官方服务。构建与许可边界见[运行指南](../SETUP.md#数学运行依赖)。

右侧 DeepSeek 网页助理使用老师正常登录的免费网页账号，需要一次安装[浏览器扩展](../../extensions/math-web-ai/README.md)。连接入口收在输入区底部的模型选择器中，点击弹出连接设置，不常驻占据消息区。首次接入面向桌面 Chrome/Edge，只呈现当前所需的安装、登录或连接操作；正式安装指向当前浏览器的真实商店条目，未发布时如实提示，不提供占位安装链接。开发者安装步骤留在开发说明中。状态反映当前浏览器实例，其他浏览器中的成功连接不能代替它。

安装或更新后，已打开工作台重新探测扩展，保留作品和未发送内容；完成 DeepSeek 登录返回时再次确认连接。更新不自动重发生成请求，兼容旧版仍可继续使用，真正不兼容时提示更新；版本判断留在内部，界面不要求老师理解版本号。商店分发及实际自动更新的验证范围见[项目状态](../plans/run-state.md#剩余事项)。

对话中 Enter 发送、Shift+Enter 换行；输入法组合、长按和其他修饰组合不触发发送。每次发送读取当前作品的公式、对象、参数、样式、视图和步骤，不发送其他模块数据。模型只返回有界数学操作，由统一编辑器校验、执行并读回；执行结果与持久保存状态分别确认。离开作品停止请求，临时关闭辅助栏保留对话。网页桥依赖真实 DeepSeek 页面和会话，改版、断连或登录失效时明确报错；对话按账户保存在本设备，不承诺跨设备恢复。真实线上模型与隔离 Chromium 回归分别核验，结果见[项目状态](../plans/run-state.md#工作现场与授权)。

## 导入、归档与兼容

“导入制作源 JSON”沿完整 Source 校验保存为独立作品，不修改原件；客户端文件上限 1 MiB。HTML 使用下节的独立入口。当前源为 `schemaVersion=1, kind=workshop`，完整字段由[数学契约](../contracts/math.md)和 schema 维护。

旧 `formula`、`plane`、`space`、`dynamic`、`geogebra` 与 `html` 源仍可读取，并按各自已有兼容页面打开；旧历史 revision、文件、引用快照及成功回执保留。新建作品统一使用 workshop，本轮不要求迁移测试用途旧作品。

归档将作品移出当前列表并返回首页；归档作品可恢复或彻底删除。彻底删除须确认，删除作品及历史版本，既有备课快照、教学记录和已下载文件保留。归档、删除等请求结果未知时沿原请求确认。

## U-MA4 外部 HTML

选择本地 HTML → 保存原件 → 显示名称、源码入口和“运行预览”。原件上传与作品建立分两次持久操作，后一操作失败可复用已上传文件，不要求重新上传。首次不自动执行代码。运行于隔离框架；关闭/切换/失效时销毁。依赖外网时显示“此作品需要外部资源，当前预览可能不完整”，可继续保存与取回；不自动联网下载依赖或替用户修补任意脚本。

作品改名只改目录名称。作品内部标题、滑杆范围、图形逻辑等通过“编辑源码”修改，预览确认后保存新版本。只有原生结构化作品显示统一参数工具；不会猜“第一个 range 就是 k”。文件即使坏了也能保存原件，非 UTF-8/过大文件可下载，但不进入源码编辑。保存源与预览运行成功分开提示，超时/异常可停止后回源。

导出菜单区分“取回原文件”“下载当前源码”“下载隔离演示”。前两者保留对应真实字节，提示打开原始 HTML 会运行其中代码。隔离演示包封装当前源，不混入账户数据；对外部源显示“离线效果待检查”，不能仅扫描 URL 就盖章可离线。支持内联脚本/CSS/SVG/data 图片；需要模块加载、CDN、后端或相对资源的作品可能受限，老师可补成自包含源码再试。原件永不被修改版覆盖。

## U-MA5 备课往返与版本

从备课环节“制作数学作品”进入，保留 lessonId/sectionId 和设备内完整备课草稿、选中/滚动；先保存未保存的新备课以获得 ID。备课旧保存结果未确认时先完成确认，再进入制作。可在工坊切换已有作品，目标条始终可见。

“带回备课”先确认当前作品已保存且可引用，再回到原备课草稿，在原位置插入该保存版本，立即按完整草稿保存；只有备课保存成功才提示“已加入”。作品保存与备课保存是两次明确提交，后者失败不回滚作品。取消返回只恢复备课现场，不加入引用；作品已保存内容保留。

目标环节被删时不自动放到别处：恢复原稿并显示冲突，允许在对照当前备课后选择新环节或“本课材料”。目标备课被删/身份变更时停在已保存作品，保留原账户返回意图，提供重新选目标。未知结果沿同键确认，不能再插一份。

引用固定采用版本，源改动显示“有更新”，老师选择“采用更新”才替换本引用快照；本课备注保持。要只改这一课，选择“另存作品并替换本处”，新作品独立，原引用移除、新建引用 ID。普通选择去重；“再放一次”明确生成第二个引用。原作品归档或彻底删除后旧快照、静态预览和已保存演示仍可用；归档作品可找到源并恢复，不能自动采用恢复后的版本；彻底删除后源不可恢复。

## 导出与课堂

下载使用明确的已保存版本。菜单区分图片、编辑文件和课堂演示。下载、历史和确认弹窗以 Enter 确认、Escape 关闭并恢复入口焦点；输入法确认候选、长按和修饰键组合不误提交。无效或等待状态不绕过按钮限制。

| 成果 | 当前边界 |
| --- | --- |
| 整份作品 PNG | 按保存初态输出公式和数学视图 |
| 公式 PNG / SVG | 单条公式，可透明底；LaTeX 源仍可编辑和复制 |
| 数学视图 PNG / SVG | 平面支持真实矢量 SVG；三维与并排只提供白底 PNG |
| 制作源 JSON | 保存公式、完整构造、视图、参数播放和教学步骤 |
| `.ggb` | 仅图形构造，不包含独立公式和教学步骤 |
| 课堂演示 ZIP | 解压后打开 `index.html`，含固定本地运行时、作品内容与许可材料 |

平面输出按保存的可见范围适配目标尺寸，保持中心与轴比例并包含原可见矩形；旧源缺少有效视区尺寸时沿原生开场范围。课堂窗口缩放保留当前平移，重置与切换步骤恢复保存视区。

课堂 ZIP 已在 Linux Chromium 的禁网 `file://` 场景独立验证，公式、参数、步骤和二维/三维内容不依赖制作服务、账号或 CDN；播放及轨迹沿同一运行时实现。Windows Chrome/Edge、教师实际 PPT/WPS 和触屏设备仍需目标环境验证，不能由 Linux 结果推定。

备课教案与讲义按保存的开场状态筛选公式，依序生成可编辑 Document 数学节点与说明，再接独立图形 PNG；整份作品海报用于预览，不重复嵌入公式。无图的公式作品不生成图形引用。外部 HTML 不执行排版，无预览图时以标题和单独演示提示代替。练习输出仍只选择题目；互动演示须单独打开。

## U-MA7 使用位置与教学反馈

编辑侧栏中的“使用记录”列活动备课、环节和采用版本，点击恢复对应文稿。教学反馈使用 T51 的只读列表，按班级/日期回看；从作品进入记事由 classes 保存关联，工坊不写教学记录表。使用已冻结的教学作品扩展，关联成功以真实持久结果为准。精确扩展见[教学时间交接](../contracts/teaching-time.md#数学作品关联)。

## 制作实现

`WorkshopWorkspace` 承接页面，`workshop/editor.js` 统一内容、快照、试演和撤销，`geogebra/workshop-runtime.js` 封装本地 GGB 控制。公式输入使用 MathLive，排版使用本地 MathJax；完整 GGB 是构造的唯一保存源，派生对象信息不另存一份几何真相。对象改名、删除及参数范围修改同步维护步骤、播放和轨迹引用，受影响内容先确认。

API 沿既有 Work / WorkRevision / Export 与幂等请求服务保存，完整 Source 结构和构造引用在服务端复核。`workshop-render.js` 使用隔离、限时 Chromium 与 Web 同一资产根目录的本地运行时生成固定 PNG、图形 PNG 和课堂成果，禁用导入文件脚本且拒绝外部资源。纯公式渲染不启动 GGB。数学源错误与运行时缺失、浏览器故障分别处理，服务故障不伪装为用户数学错误。

math 拥有制作源、历史、渲染和导出；files 拥有不可变字节，lessons 拥有采用快照和备课返回现场，classes 拥有教学反馈。端口和事务边界见[数学契约](../contracts/math.md#公共端口)。旧类型的表达式、静态 SVG 和动态兼容运行时只服务已有内容。

## 验证入口

统一制作浏览器回归使用 `apps/web/e2e/math-unified.config.mjs`，连续输入、弹窗与播放使用 `math-unified-repair.config.mjs`；保存保护和取消分别使用 `math-geogebra.config.mjs` 中的具名场景。API 核验入口为 `apps/api/test/math-workshop.test.js`、`math-workshop-view.test.js` 和既有 `math-*.test.js`，固定输入在 `apps/api/test/fixtures/math-workshop/`。网页桥回归按[扩展说明](../../extensions/math-web-ai/README.md)执行。

验收须操作真实界面、刷新读回并打开实际文件，区分作者自验、独立核验和用户目标环境。运行与必要回归只依赖仓库内源码、固定输入及按运行指南准备的工具；preview 的 `test-results/math-handoff/math-unified/` 只提供既有执行证据，不是安装或接手前置。整体完成条件与剩余验证在[项目状态](../plans/run-state.md)维护。
