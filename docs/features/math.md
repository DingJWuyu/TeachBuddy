# 数学工坊：制作、源码与课堂使用

公式、平面/空间图形、动态作品和外部 HTML 均以可保存、可二次修改的源为中心。实现与目标环境的验证范围见[当前状态](../plans/run-state.md)。新模板替换非空作品或参数草稿前须明确确认，取消保持原稿。

## U-MA0 共同框架与保存

### GeoGebra 数学画布与网页 AI

首页的“GeoGebra 数学画布”进入可直接手动作图的原生编辑器。右侧 AI 助理关联当前画布，老师用自然语言起稿、继续修改，也可在两次对话之间手动调整。当前接入 DeepSeek 网页账号，安装与连接见[浏览器扩展](../../extensions/math-web-ai/README.md)。连接需一次网页登录；日常对话和应用结果留在工作台，无需复制指令或 API Key。

每次发送包含当前作品名、对象定义、坐标、参数、样式与视窗；不发送其他模块数据。AI 返回有界的数学操作，由 GeoGebra 执行后读回结果。等待期间画布发生变化时拒绝旧版本操作，使用最新状态重新判断；执行失败恢复修改前完整作品，取消后不再应用迟到回复。只有执行结果能确认“已修改”，持久保存仍由老师点击保存。

新画布保留完整 `.ggb` 源，保存、历史版本、冲突处理使用现有作品服务；可下载 `.ggb`。原生撤销重做仅覆盖当前打开期间，重新加载、历史恢复及失败时的整图恢复会重置原生撤销历史。当前 GGB 作品不提供海报、带回备课或自包含离线 HTML；其他制作类型的既有输出保持各自行为。

画布从 GeoGebra 官方加载，需要网络，加载失败可重试。网页版 AI 依赖已登录的专用后台标签页及网页 DOM；网页改版或会话失效须明确报错，不能把部分回复当完整指令。对话和未发送文字按工作台账户保存在本设备，已保存作品在服务端；对话不承诺跨设备恢复。离开画布停止当前 AI 请求，临时关闭辅助栏保留进行中的对话。

### 共同制作行为

工坊首页展示公式、平面图形、空间图形、动态演示四类用途与成果示意，下方为本设备草稿、可搜索的作品列表和已归档筛选。HTML 从“导入已有 HTML 演示”进入。首页与编辑各自保留滚动位置。

“导入制作源 JSON”可重新打开工坊导出的公式、平面、空间或动态制作源，服务端沿创建作品的完整校验检查后保存为独立新作品。导入不修改原作品；错误文件保留当前草稿，替换未保存稿前确认。请求结果未知时保留同一请求，刷新后可确认，不重复创建。支持 schemaVersion=1、1 MiB 以内的原生制作源；HTML 沿独立导入入口处理。

编辑区顶部以图标和标题标识模块，当前作品名与“返回工坊”在下一行。桌面主面板与右侧辅助栏等高、上下对齐，以背景间隙区分；字号、浮层和 reduced-motion 按[界面规则](../rules/design-and-verification.md)。保存、下载图片或下载演示保持文字入口；另存、使用位置和归档收进“作品操作”菜单。下载展开文件格式、背景和尺寸，使用明确的已保存版本。

“返回工坊”保留有内容的设备草稿，首页可继续制作；仅进入而未改动的空白稿直接退出。丢弃草稿、以新作品替换非空未保存稿或替换图形示例须确认，取消后内容与设置保留。未知结果的保存、导出、归档或彻底删除仍按原操作确认，不因返回首页丢失。

归档将作品移出当前列表，成功后清空当前作品并返回工坊首页，同时移除详情地址；刷新不重新打开归档作品。归档列表可直接恢复或彻底删除，也可打开只读预览。彻底删除须确认作品名和不可恢复的范围，取消保持原现场；完成后移除作品及历史版本。既有备课快照、教学记录和已下载文件保留。

选择类型进入可编辑空稿，默认未命名，无需先填课题或分类。平面图提供二次函数起点，空间图提供正方体和棱锥；动态示例先可试演，编辑工具在明确选择后展开。示例均可修改和删除，不代替老师的作品。

画布上方提供添加图形、图形与标注、函数分析和画布设置；动态作品另有设置滑杆和编排步骤。右栏只显示当前操作的内容，不与作品列表混排。点击静态画布上的曲线、点、标注或棱，与右栏列表双向选择并高亮；可用 Enter 或空格选择静态图形。空间点和棱在同一列表中编辑，棱的端点和线型跟随当前选择。对象先显示名称、表达式或坐标，定义域、标注和样式按需展开。

工具与 AI 共用一列，切换保留两边现场；普通浏览不抢走 AI，明确选择对象或编辑操作可打开制作工具。窄屏面板可以关闭并返回画布。1440×900、1024×768及窄视窗分别检验溢出、焦点与独立滚动；实际触屏支持仍需目标设备验证。

保存状态为“未保存”“保存中”“已保存”“保存结果待确认”“保存失败”；渲染状态另示，保存源码成功不能冒充可展示。最后有效预览可留作对照，但明确“上次预览”，不能导出为本次版本。字段错误定位源/对象；语法错误仍能保存源码，修正再渲染。后端版本冲突显示服务器版本和本地稿，老师选择整理后提交或另存作品。保存结果未知保留原键、原请求和后续草稿，先确认原请求。

作品名旁的撤销/重做处理当前作品的内容编辑，包括图形增删、参数、样式和历史恢复；连续输入合并为一步，保留最近 100 步。撤销不回退作品 ID、服务端版本或请求回执；保存后仍可撤销本次打开期间的编辑，刷新或切换作品后重新开始记录。输入框和可视化公式内部使用各自的编辑快捷键；其他制作控件支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z。归档、保存中及结果待确认时禁止作品撤销。

“作品操作 → 历史版本”按保存记录预览公式和图形；动态显示该版本的固定初态，HTML 不自动运行。恢复先替换为未保存草稿，覆盖当前修改前确认，取消保留现场；保存时基于当前作品版本生成新 revision，不改已有历史和备课快照。当前保存版也可用于恢复未保存的修改。读取失败可重试。

作品保存到服务端，刷新/重启/同账户换设备后可读。未提交稿、缩放、对象选择、列表筛选、滚动、面板和返回目标按账户存于设备现场；另一设备只恢复已保存内容。切换作品/模块可留草稿，破坏性丢弃必须明确。身份失效锁住画面及嵌入预览；同账户恢复后继续确认，其他账户不显示旧稿。

## U-MA1 公式

“常用结构”提供分式、根式、上下标，选择后填写分子分母等内容并实时预览；结构及输入保留为设备现场，切换结构覆盖已有公式前确认。“LaTeX 源码”可继续编辑完整公式，分式、根式、上下标、cases 插入当前光标处，选中文字时替换该选区；中文说明在独立可编辑栏，可选择纳入成果。实时预览、错误位置与公式源同屏。改颜色、字号和说明后保存，重开仍是可编辑内容。导出 SVG 或透明 PNG；预览底色按公式颜色选择明暗，保证深浅主题下均可阅读；底色仅用于查看，不进入透明导出。源内容可复制，不能把 SVG 宣称为 Office 可编辑公式。中文说明选入后须实际出现在导出边界内。

“可视化编辑”使用 MathLive，在公式内部直接输入、选择和粘贴，可将选中内容组成分式、根式、上下标或向量，并插入分段式。与源码模式共享同一 LaTeX，切换不主动改写源；转去编辑作品名等控件后保持新焦点，公式组件的延迟回调不得抢回输入。编辑器加载失败可重试或返回源码。组件和字体随本地构建提供，按需加载；预览、保存、公式允许范围和 PNG/SVG 导出继续使用统一 MathJax 流程。

## U-MA2 静态图

函数支持 `x^2-2*x-3`、`x²-2x-3`、`2(x+1)` 等自然输入，添加多条曲线、设置定义域/坐标窗，选择点、线、圆/椭圆、折线/多边形及文字标注；对象列表可以选择细小或遮挡对象。标注文本、位置、字号、颜色和线宽/虚实可直接改。支持单调区间的彩色线段、箭头与文字标注。无定义点断开，不跨渐近线连线。

“添加分段函数”按段填写表达式和条件，最后一段用于其余情况；从上到下采用首个满足条件的分段，完整表达式仍可编辑。简单区间条件的跳跃边界区分空心与实心端点。坐标轴可显示刻度与轴名，画布设置可关闭。图形预览采用浅色画布衬底，深色主题下也保持线条与标注可读；此衬底不改变制作源或透明导出。

“函数分析”在指定范围与定义域的交集中求零点或两条函数的交点，显示近似候选点；动态作品采用源中开场参数。结果可作为固定点加入，函数或范围变化后需重新查找，不把固定结果冒充关联构造。数值搜索检验残差、排除极点和跳跃，并尝试寻找相切根；密集或极窄的根仍可能遗漏，界面提示缩小范围。重合曲线与恒零函数不列为有限点集。

“添加图形 → 关联构造”支持中点、两点连线、垂足、过点平行线/垂线、直线与圆交点、指定圆心与圆上点的圆。构造依赖已有对象，原点坐标或动态参数变化时重新计算。线段在垂足、平行/垂直和交点运算中按所在直线使用；圆的两个交点按 x、y 排序选择分支。构造不能循环引用；改名同步引用，删除原对象前确认依赖对象的移除，撤销可一起恢复。构造点由关系确定，不独立绑定拖动参数。

立体图以三维点、棱、面和固定正交投影生成示意，提供正方体/长方体、棱锥起点；老师能改尺寸、点名、投影角度和遮挡棱虚线，并添加辅助线。圆柱/圆锥/球面示意可由平面椭圆和轮廓组合，保持可改；不承诺自动几何证明或自动判断所有遮挡。面按边界顺序引用共面顶点；正方体和棱锥示例包含完整面。面边与显式棱重合时采用棱的线型、颜色和宽度，其余面边与截面保留各自样式。通过 `ax+by+cz=d` 添加封闭凸多面体截面，修改平面系数或顶点后重算；缺面、非凸、退化或无面积的交截直接显示当前语言的原因与修正提示。面与截面可从画布或列表选择、调整样式、保存和导出。预览与 PNG/SVG 使用同一制作源和渲染器。导出可选透明或白底，不从屏幕截图取代矢量源。

## U-MA3 动态制作与展示

从“参数函数”起点或空画布建立表达式、参数、点和标签。右栏按当前选择显示参数名、最小/最大/步长/初值；拖点绑定明确的两个参数，每个轴可独立锁定。范围修改同时校验初值与步长，初值超界要求老师修正；已有步骤取值会归入新范围并按新步长吸附，保存前提示该影响。步骤列表可新增、改名、排序，每步选择显示哪些对象和本步参数值。

已保存平面图可从“作品操作 → 制作动态副本”继续制作，保留原图全部对象、样式和坐标窗，建立带参数 t 的独立草稿。老师在表达式中使用参数后试演，保存才建立新作品；原图保持不变。动态源为平面参数场景，保留关联构造；更复杂的范围见文末。

步骤由老师编排，每步实际曲线、点位与解析式必须一致；固定验收作品见[数学样本](../acceptance/samples.md#数学作品)，不将样本三步限定为产品唯一结构。切步骤应用该步值，自由探索只改变演示现场；“设为开场画面”才改制作稿。“课堂展示”隐藏编辑控件，保留滑杆、拖点、步骤、重置和退出；退出回原编辑位置。保存范围、步骤文字、初值、对象后重开逐项恢复。

“设置滑杆 → 自动播放与轨迹”选择播放参数、单程时长及单次/循环/往返方式；没有自定义设置时可往返播放第一个参数。播放须主动点击，暂停、手动调参、切换步骤、窗口失焦、页面隐藏或离开作品会停止播放。只有“设为开场画面”才将当前取值写入制作稿。

可为最多 10 个点记录采样轨迹，每点最多保留最近 600 个采样位置，以散点显示，不臆测中间曲线。清除轨迹不改变参数；重置或切换步骤清空轨迹。轨迹现场不进入制作源或静态图片，所选点与播放设置随作品保存，下载的离线演示可重新播放与采样。

教学意图超出结构化表达时，可导入外部起草的 HTML，再走 U-MA4；不以固定抛物线模板覆盖全部动态需求。产品 Agent 的数学工具是单独的接线目标，实现与授权见[项目状态](../plans/run-state.md)。

## U-MA4 外部 HTML

选择本地 HTML → 保存原件 → 显示名称、源码入口和“运行预览”。原件上传与作品建立分两次持久操作，后一操作失败可复用已上传文件，不要求重新上传。首次不自动执行代码。运行于隔离框架；关闭/切换/失效时销毁。依赖外网时显示“此作品需要外部资源，当前预览可能不完整”，可继续保存与取回；不自动联网下载依赖或替用户修补任意脚本。

作品改名只改目录名称。作品内部标题、滑杆范围、图形逻辑等通过“编辑源码”修改，预览确认后保存新版本。只有原生结构化作品显示统一参数工具；不会猜“第一个 range 就是 k”。文件即使坏了也能保存原件，非 UTF-8/过大文件可下载，但不进入源码编辑。保存源与预览运行成功分开提示，超时/异常可停止后回源。

导出菜单区分“取回原文件”“下载当前源码”“下载隔离演示”。前两者保留对应真实字节，提示打开原始 HTML 会运行其中代码。隔离演示包封装当前源，不混入账户数据；对外部源显示“离线效果待检查”，不能仅扫描 URL 就盖章可离线。支持内联脚本/CSS/SVG/data 图片；需要模块加载、CDN、后端或相对资源的作品可能受限，老师可补成自包含源码再试。原件永不被修改版覆盖。

## U-MA5 备课往返与版本

从备课环节“制作数学作品”进入，保留 lessonId/sectionId 和设备内完整备课草稿、选中/滚动；先保存未保存的新备课以获得 ID。备课旧保存结果未确认时先完成确认，再进入制作。可在工坊切换已有作品，目标条始终可见。

“带回备课”先确认当前作品已保存且可引用，再回到原备课草稿，在原位置插入该保存版本，立即按完整草稿保存；只有备课保存成功才提示“已加入”。作品保存与备课保存是两次明确提交，后者失败不回滚作品。取消返回只恢复备课现场，不加入引用；作品已保存内容保留。

目标环节被删时不自动放到别处：恢复原稿并显示冲突，允许在对照当前备课后选择新环节或“本课材料”。目标备课被删/身份变更时停在已保存作品，保留原账户返回意图，提供重新选目标。未知结果沿同键确认，不能再插一份。

引用固定采用版本，源改动显示“有更新”，老师选择“采用更新”才替换本引用快照；本课备注保持。要只改这一课，选择“另存作品并替换本处”，新作品独立，原引用移除、新建引用 ID。普通选择去重；“再放一次”明确生成第二个引用。原作品归档或彻底删除后旧快照、静态预览和已保存演示仍可用；归档作品可找到源并恢复，不能自动采用恢复后的版本；彻底删除后源不可恢复。

## U-MA6 导出与课堂

原生公式/静态图先保存再导出，下载基于明确版本。动态演示下载为自包含隔离 HTML，老师双击打开，不需要制作服务、账户或 CDN。下载失败保留作品，可重试原请求；选择其他版本或选项是新请求。原生动态课堂操作不写回工坊，重新打开回保存初态。

备课教案/讲义中的公式保持 Document 数学源；静态图用快照 PNG；动态作品用标题和已固定初态图，外部 HTML 无图则用标题及“交互演示见单独文件”，不执行 HTML 排版。练习成果仍只选择题目，不把作品当作题。演示另行下载，不伪造 PDF 内可交互或 HTML 可嵌入 PPT。

仓库内回归从[核查入口](../plans/run-state.md#核查入口)进入，目标设备结果按[项目状态](../plans/run-state.md#用户验收与待决定)单列。离线验收使用最终下载物，在全新配置、禁网和关闭制作服务后验证；Windows Chrome/Edge 与教师实际 PPT/WPS 设备分别记结果，未测不宣传支持。窄屏能阅读不等于触屏拖动已验。

## U-MA7 使用位置与教学反馈

## 制作实现

公式输入使用 MathLive，公式渲染使用本地 MathJax；静态/动态作品沿用 SVG；[Math.js](https://mathjs.org/docs/expressions/expression_trees.html) 解析表达式后，仅解释封闭的实数运算节点。[Flatten.js](https://github.com/alexbol99/flatten-js) 处理平面构造，[Three.js](https://threejs.org/docs/pages/Plane.html) 的数学组件处理共面性及线面求交；数值搜索复用 [bisect](https://github.com/mikolalysenko/bisect) 与 [一维黄金分割搜索](https://github.com/scijs/minimize-golden-section-1d)。作品撤销使用现有 Zustand 加 Zundo，仅追踪可编辑内容。UI、导出与接入后的 Agent 共用数学规则，函数表达式不执行任意 JavaScript。版本与依赖由代码和锁文件维护，字体、许可证及离线资源随构建提供。离线演示使用 esbuild 打包同一共享运行时和依赖，不拼接或执行用户 JavaScript 表达式。新源字段为可选，已有源保持可读；已有 revision 的海报和离线文件保持不变。

math 拥有制作源、历史版本、渲染与导出；files 拥有不可变字节；lessons 拥有采用快照与返回草稿；classes 拥有实际教学反馈。具体进程内端口及事务约束见[公共端口](../contracts/math.md#公共端口)。反馈由组合层注入，不形成 math 对 classes 的服务端依赖。

制作源模型与编辑规则可由浏览器和 Node 直接使用；参数校验返回稳定文案键，由界面按当前语言翻译。浏览器国际化初始化由界面入口负责，不进入纯数学编辑依赖。

迁移保留已有 File、旧引用和历史 revision，不重写旧成功回执。验证旧库升级、两次重启、真实制作导出及下载物冷启动；完整交付条件见[数学判据](../acceptance/mvp-matrix.md#math)。

## 数学范围与可选增强

以下边界不自动成为核心待办；如实际教学需求触及边界，先明确目标，再更新[项目状态](../plans/run-state.md)。

- **一般约束求解**：当前为有向、无环的构造依赖。循环约束、拖动结果反推原点、任意角度/长度联立约束暂缺。完整几何引擎有相关能力，但还需适配对象引用、撤销、版本与离线数据模型，不能仅替换画布即获得可靠一致的行为。
- **复杂三维**：非凸实体、多实体布尔运算、曲面截交、自动消隐、三维动画暂缺。当前线面求交组件不足以构成通用实体建模内核；透明面与可手动设虚线的棱仍用于教学示意。
- **完整代数求解**：函数分析是有界数值搜索，不能证明根已找全；任意分段条件的精确端点、隐式曲线与符号精确解暂缺。数学表达式保持受控实数范围，未开放任意 Math.js 函数。
- **复杂动画编排**：当前每次播放一个参数，步骤由老师切换；多参数时间线、自动切步骤及轨迹方程推导暂缺，需明确插值与步骤切换语义。
