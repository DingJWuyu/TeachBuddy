# 备课：文稿、取材与成果输出

按课题、专题或课时组织教学。目标、已有基础、讲解顺序、指导意见和课后体会按需填写，不要求统一学校表单。教学环节由老师命名、增删和排序；同一题目、资源、作品可在多份备课复用，不重复建立来源对象。

当前实现、转换环境和目标 Office 的验证范围见[台账](../plans/run-state.md)。

## U-M5 备课编排与取材

文稿开头、任意命名环节、环节正文、引用材料和本课备注构成一份备课。右栏为我的备课/本课大纲或 AI，保留滚动。环节可增删改名和排序，删除时明确“材料移到本课材料”或“一并移除本课引用”。移动引用保持引用身份和备注；“再放一次”建立第二个独立引用。

从环节取题/资源时中央临时替换为选择界面，显示目标课题与环节。多选按选择顺序插入，成功后返回原段落；取消保持未提交选择与文稿草稿，目标已删或版本变化则对照后重选，不悄悄插到别处。从题库/资源主动加入备课后留在原模块，提供前往备课链接。

本课材料总览同时列出环节内材料及未安排材料；同一引用只存一次，总览是投影。未安排的备用内容默认不进入输出。资源引用显示原件版本、预览和打开来源；题引用就地显示题面，答案展开、本课备注独立编辑。资源整文件不能自动拆成可编辑题面；需要题目时从该文件发起收录。数学作品通过现有 lessons v3 引用，保存采用版本快照；字段和旧客户端限制见[数学引用契约](../contracts/workbench/math.md)。

## U-M6 六种成果与手工 PPT

输出前保存备课，选择“教案/提纲”“导学案/讲义”“练习”、Word/PDF、答案解析开关、教师注记开关、包含的环节和备用引用。两个开关独立；所有类型默认关闭，用户明确勾选才纳入。默认取全部环节、排除未安排材料，练习默认只取题目。选项只控制本次输出，不更改备课或题库。

| 成果 | 固定组成规则，顺序由备课决定 |
| --- | --- |
| 教案/提纲 | 课题、开头文稿、所选环节标题与文稿、环节内题目和资源目录；所选备用材料置文末。 |
| 导学案/讲义 | 同一可编辑文稿结构；题面后留可编辑作答空白；资源仅列标题与文件名，无私密 URL/原文件附件。 |
| 练习 | 课题，所选环节中的题目按顺序重新编号；保留选项、小问和配图，题后作答空间；排除开头和环节说明、非题文件目录。 |

答案解析放在全部题面之后的单独答案部分，保持输出题号；缺答案不补造。教师注记部分只在开关开启时收录本课备注及显式教师注记块，排除题库长期笔记与资源备注。自由文稿默认是正文，编辑器提供明确“教师注记”块；老师手动把答案写入正文时输出预览必须能检查，系统不承诺靠猜测清除自由文本。自动整理和输出器须守住结构角色，不把 solution 复制入 body。

预览显示将分发的最终结果、页数和选项，文件生成与校验成功才出现下载。公式不支持时定位到公式并回编辑，保留旧的成功输出；不能自动把 Word 的文字/公式栅格化冒充成功。转换中可离开；重回仍显示任务和已有结果，修改备课后原任务仍固定在原保存版本。停止、失败和未确认均按 U-M1 恢复。

题目面板另有“用于 PPT”：复制题面文字（公式用 LaTeX 源）、分别复制公式源、下载题面 PNG 或单幅配图 PNG。题面 PNG 默认排除答案/笔记，透明背景，长题按段落分片且不截公式或图；剪贴板受限时提供下载或可全选文字。该素材是辅助老师手工排版，公式编辑仍可回源。M40 负责进一步的公式透明素材、SVG 和作品能力。

## 目录、数学往返与反馈

文稿开头信息可收起，课题及操作固定，文稿独立滚动；“我的备课”和本课大纲放在工具/AI 共用右栏。课题顺序是独立版本化对象，正文编辑不重排目录，规则在[课题顺序](../contracts/workbench/materials.md#课题顺序)。

从未保存的新备课进入制作前先保存获得 ID；已有草稿保留。数学“带回”须先保存作品，再将作品采用版本插入原备课草稿并保存；后一提交失败不回滚作品。目标被删不能悄悄换环节。详细往返和三类数学输出投影见[数学作品](math.md#u-ma5-备课往返与版本)。

在文稿中可查看不同班级的实际反馈；计划不等于实际授课。进入来源再返回保留原草稿与位置。引用固定快照，源改动只提示更新，逐处确认采用；嵌套文件预览一次关闭只退一层并恢复焦点。
