# 备课：文稿、取材与成果输出

按课题、专题或课时组织教学。目标、已有基础、讲解顺序、指导意见和课后体会按需填写，不要求统一学校表单。教学环节由老师命名、增删和排序；同一题目、资源、作品可在多份备课复用，不重复建立来源对象。

当前实现、转换环境和目标 Office 的验证范围见[台账](../plans/run-state.md)。

## 首次使用与课稿编辑

主页列出备课与本地草稿；空态说明用途，并提供只读备课示例和新建入口。示例不写入用户资料。新建后可直接输入课题与讲课思路，通过“添加教学环节”组织内容；“插入内容”按需加入公式、图片、列表、表格或教师注记。

已有备课默认显示可阅读的课稿，进入“编辑备课”后才显示输入框与结构操作。“查看课稿”显示已保存内容，另有未保存草稿时明确提示并提供继续入口；草稿未处理时不能从阅读状态输出旧课稿。未输入的空白新稿返回后不留草稿，已有输入返回和刷新后可继续。

## 查找、撤销与复制

搜索覆盖课题、开头和环节文稿、环节名称、本课备注，以及已采用的题面、答案、资源标题/文件名和数学公式/说明；搜索引用快照，不因来源更新而改变本课的搜索内容。活动与归档列表使用同一搜索范围。

编辑状态提供“撤销”“重做”，支持 Ctrl/⌘ Z、Ctrl/⌘ Shift Z 和 Ctrl Y。覆盖当前页面内未保存的文稿、环节、材料及备注改动，连续输入合并为一步；保留最近 100 步。确认保存、采用服务器版本、刷新或离开详情后重新开始记录，草稿仍由原保存机制保护。不会撤销已提交的取材、归档或复制操作，已保存版本由下述历史功能独立管理。实现复用 Zustand 与 zundo，限定在备课编辑器。

“备课操作 → 复制备课”经确认后创建并打开独立副本。有活动草稿时明确先保存再复制；归档课稿可复制为活动副本，原稿保持归档。保留正文、环节、备用材料、本课备注及采用快照，环节和引用使用新身份；来源已更新、归档或移除时仍保留原课采用的内容，不自动升级。副本不带原课输出或班级记录。创建结果未知时留在原课，刷新可确认同一份副本，避免重复创建。

复制接口 `POST /api/modules/lessons/v3/{id}/copy` 使用 `{baseVersion}` 和幂等键；校验当前账户和原课版本，在同一事务中创建副本。定义见[材料接口](../contracts/workbench/materials.openapi.yaml)。

## 已保存版本与环节复用

“备课操作 → 查看已保存版本”列出最近 50 个课稿版本，选择后先阅读完整正文、材料与备注，再执行“恢复此版本”。恢复前先保存当前草稿；恢复结果是新版本，恢复前的内容仍在历史中。归档课稿可查看历史，先恢复备课才能采用旧版本。旧数据从启用历史时的当前保存版本开始记录，之前的旧稿无法追溯。整课复制从副本版本 1 开始，不复制原稿历史。

编辑课稿底部的“从其他备课复用环节”用于查找其他当前或归档课稿，预览并勾选环节，按来源顺序追加到本课末尾。确认前保存本课草稿，保留已采用快照、备注和混排位置，环节与引用生成独立身份；来源已更新、归档或移除仍不改变已采用内容。创建成功即已保存，可继续调整位置。关闭选择窗口保留原草稿，不创建环节。

两项操作都校验当前版本，复用还校验来源版本；结果未知时保留原请求，刷新后“确认课稿更新”仍使用同一幂等键，不重复恢复或插入。接口见[材料接口](../contracts/workbench/materials.openapi.yaml)：`GET /api/modules/lessons/v3/{id}/history`、`GET .../history/{version}`、`POST .../history/restore`、`POST .../sections/copy`。历史保存在实例数据库并随实例备份保留；个人资料包目前仅包含当前课稿，不包含课稿历史。

## 归档、恢复与彻底删除

“备课操作 → 归档备课”移出当前列表，成功后返回备课主页；刷新仍留在主页。列表选项中的“查看已归档备课”可打开归档课稿，只读查看，并提供“恢复备课”和“彻底删除”。恢复后返回当前备课列表；归档和恢复保留本设备未保存的草稿。

彻底删除须再次确认，永久移除课稿、保存历史、教学环节、本课引用快照、输出记录和本设备该稿的草稿，停止未完成的输出任务。来源题目、资源、数学作品及班级教学记录仍保留。操作结果未知时保留原请求；即使彻底删除后的详情已不存在，刷新仍能重试确认，确认成功后同样返回主页。

接口沿用 `deletedAt`、`state=deleted` 和 `/deletion` 表达可恢复的归档状态，保持已有客户端兼容。彻底删除使用 `POST /api/modules/lessons/v3/{id}/purge`，请求含 `baseVersion` 并使用幂等键；要求当前账户拥有且已经归档，版本冲突需重新读取。协议定义见[材料接口](../contracts/workbench/materials.openapi.yaml)。受管文件与幂等操作记录按各自生命周期保留，彻底删除不等于擦除实例备份或已下载的副本。

## U-M5 备课编排与取材

文稿开头、任意命名环节、环节正文、引用材料和本课备注构成一份备课。更多菜单可打开我的备课索引或本课大纲，保留滚动。环节可增删改名和排序，删除时明确“移到备用材料”或“一并移除”。移动引用保持引用身份和备注；“再放一次”建立第二个独立引用。

材料操作中的“放到正文之间”可选环节开头、指定正文块后或全部正文后；正文、题目、资源与作品在阅读和输出中使用同一顺序。指定正文块随上移/下移保持其后的材料；删除正文块保留材料并移到前一个位置。“全部正文之后”包含以后新增的正文。修改位置仍需保存，未保存时可撤销。

引用可选字段 `afterBlock` 为正文块边界，0 表示开头，正整数表示第几个顶层块后，null 表示全部正文后；备用材料使用 null。省略字段保留本处已保存位置，越界请求拒绝。旧 v1 接口拒绝读取或改写有明确混排位置的课稿，避免丢失位置；v2/v3 保留可选字段。

从环节取题/资源时中央临时替换为选择界面，显示目标课题与环节。多选按选择顺序插入，成功后返回原段落；取消保持未提交选择与文稿草稿，目标已删或版本变化则对照后重选，不悄悄插到别处。从题库/资源主动加入备课后留在原模块，提供前往备课链接。

材料总览显示各环节用量与备用材料数，点击定位对应位置；同一引用只存一次，总览是投影。“备用材料”按需展开，未安排的内容默认不进入输出。资源引用显示原件版本、预览和打开来源；题引用就地显示题面，答案展开，本课备注通过“添加本课备注”出现；清空仍保留输入框，明确收起空备注后才隐藏。资源整文件不能自动拆成可编辑题面；需要题目时从该文件发起收录。数学作品通过现有 lessons v3 引用，保存采用版本快照；字段和旧客户端限制见[数学引用契约](../contracts/workbench/math.md)。

## U-M6 六种成果与手工 PPT

“生成教学资料”先按用途选择“教案/提纲”“导学案/讲义”或“练习”，再选择 Word/PDF、答案解析、教师注记及内容范围。每种成果解释使用对象和内容，环节与备用引用选择按需展开；返回与生成操作固定在滚动区域之外。输出前保存备课。两个开关独立；所有类型默认关闭，用户明确勾选才纳入。默认取全部环节、排除未安排材料，练习默认只取题目。选项只控制本次输出，不更改备课或题库。

“按材料细选与留白”在所选范围内逐份勾选材料；排除题目时同时排除该题的答案和本课备注，输出题号重新连续编号。讲义和练习可为各题单独设置 0–20 行作答空白，也可恢复统一留白；教案不添加作答空白。摘要显示实际题数，没有题目时提示至少选择一道题，并禁用生成练习。选择与单题留白在返回和刷新后保留。

`ExportInput` 的可选字段 `excludedReferenceIds` 与 `answerSpaceOverrides: [{referenceId, lines}]` 控制本次排除和单题留白。省略时维持原行为；未知引用、重复覆盖或非题引用留白被拒绝，不创建输出任务。

| 成果 | 固定组成规则，顺序由备课决定 |
| --- | --- |
| 教案/提纲 | 课题、开头文稿、所选环节标题与文稿、环节内按位置穿插的题目和资源目录/原页；所选备用材料置文末。 |
| 导学案/讲义 | 同一可编辑文稿结构；题面后留可编辑作答空白；资源默认列标题与文件名，可逐份选择按原页插入；无私密 URL/原文件附件。 |
| 练习 | 课题，所选环节中的题目按顺序重新编号；保留选项、小问和配图，题后作答空间；排除开头和环节说明、非题文件目录。 |

资源在“按材料细选与留白”中可选择“按原页插入”，支持 PDF、Word、PPT 与 PNG/JPEG/WebP，练习不包含资源。`ExportInput.resourcePageReferenceIds` 指定资源引用；默认空数组，只列标题。转换复用已有 LibreOffice/Poppler 文件预览和 Pandoc 输出链，始终读取采用快照的原文件，不使用更新后的来源或补充预览。每个原页完整缩放为图片，保持比例，文字和公式不能直接编辑；普通课稿与题目仍保持原来的可编辑输出。

原文件页面是完整内容，其中答案和教师注记不受输出开关过滤。勾选时和输出摘要说明边界，分发前须预览核对。部分转换或转换失败不给出缺页成品，已保存课稿和旧成功输出保留，提示核对原件或取消该资源的原页选项。

答案解析放在全部题面之后的单独答案部分，保持输出题号；缺答案不补造。教师注记部分只在开关开启时收录本课备注及显式教师注记块，排除题库长期笔记与资源备注。自由文稿默认是正文，编辑器提供明确“教师注记”块；老师手动把答案写入正文时输出预览必须能检查，系统不承诺靠猜测清除自由文本。自动整理和输出器须守住结构角色，不把 solution 复制入 body。

预览显示将分发的最终结果、页数和选项，文件生成与校验成功才出现下载。公式不支持时定位到公式并回编辑，保留旧的成功输出；不能自动把 Word 的文字/公式栅格化冒充成功。转换中可离开；重回仍显示任务和已有结果，修改备课后原任务仍固定在原保存版本。停止、失败和未确认均按 U-M1 恢复。

题目面板另有“用于 PPT”：复制题面文字（公式用 LaTeX 源）、分别复制公式源、下载题面 PNG 或单幅配图 PNG。题面 PNG 默认排除答案/笔记，透明背景，长题按段落分片且不截公式或图；剪贴板受限时提供下载或可全选文字。该素材是辅助老师手工排版，公式编辑仍可回源。M40 负责进一步的公式透明素材、SVG 和作品能力。

## 目录、数学往返与反馈

课题及操作固定，文稿独立滚动；备课索引与本课大纲使用辅助栏，桌面与主面板上下对齐，内部各自滚动。课题顺序是独立版本化对象，正文编辑不重排目录，规则在[课题顺序](../contracts/workbench/materials.md#课题顺序)。

从未保存的新备课进入制作前先保存获得 ID；已有草稿保留。数学“带回”须先保存作品，再将作品采用版本插入原备课草稿并保存；后一提交失败不回滚作品。目标被删不能悄悄换环节。详细往返和三类数学输出投影见[数学作品](math.md#u-ma5-备课往返与版本)。

在文稿中可查看不同班级的实际反馈；计划不等于实际授课。进入来源再返回保留原草稿与位置。引用固定快照，源改动只提示更新，逐处确认采用；嵌套文件预览一次关闭只退一层并恢复焦点。

## 暂缺能力

- 外部 Word/PDF 无损拆解为可编辑文稿、题目和公式，扫描页 OCR，以及从原件页面自动区分/排除答案。现有转换器可可靠生成整页预览，但通用转换不能保证复杂表格、浮动图形、旧公式对象及扫描页的结构和语义；当前明确提供原页插入，不声称可编辑导入。
- 个人资料包携带课稿历史；历史目前随完整实例备份保存。本模块不扩展设置与资料包的格式。
