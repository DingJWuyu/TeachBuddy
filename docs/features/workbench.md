# 工作台共同交互

页面各自的需求、动作和异常放在[功能规格](../README.md#功能规格)；本页只定义所有页面共同使用的布局与往返约定。视觉尺寸、参考站边界及动效只由[界面规则](../rules/design-and-verification.md)维护。

## 整体结构

左侧是题库、备课、数学工坊、资源库、班级教学的稳定入口，日程从顶部进入，侧栏不重复。首页承担产品 Agent 完整工作区，不另设传统 dashboard。用户希望沿用 Codex Desktop 的左导航、中间工作、右侧辅助布局关系；实际视觉仍遵循现有产品基线。

导航分组、模块位置和可见性按[领域定义](../../GLOSSARY.md)归属账户，通过 `GET/PUT /api/workbench/navigation` 保存；同账户在其他设备登录、刷新或重新回到页面时读取已保存布局。系统默认分组以可选 `nameKey` 标记，随账户语言显示；教师改名后清标记，旧记录无标记则保持保存的名称，不按文字猜测是否为系统名称。分组折叠和侧栏开合仍是设备现场。导航隐藏只影响入口，不停用模块；目录暂时缺少的模块保留原位置与隐藏选择，新增侧栏模块出现在未分组。

账户首次接入且服务器尚无布局时，导入此设备原有的分组、顺序和隐藏选择；没有本机选择则保存当前默认模板。已有服务器布局优先，不让另一设备的旧本机记录自动覆盖。读取失败显示重试并暂停布局编辑，不把默认导航写回服务器；已有草稿和原始记录保留。

拖放、分组和隐藏操作自动保存，沿用[共享保存与冲突规则](../contracts/workbench.md#写入冲突与未知结果)。保存中仍可继续调整，后续输入另作草稿；结果未确认时保留原键和原请求，刷新或同账户重新登录后可重试确认。并发修改按整份布局版本拒绝覆盖，提供本机与账户布局对照；老师确认后可采用已保存布局或保留本机布局，后者仍检查所对照的版本。未解决的冲突及原编辑基线跨刷新保留，读取失败或重试确认不会解除冲突。侧栏收起时，以紧凑状态按钮展开侧栏处理失败、未确认或冲突。请求迟到不能回填另一账户。精确字段和结构约束见[导航接口](../../apps/api/src/contracts/navigation.js)，验证入口为 `apps/web/e2e/navigation-sync.config.mjs` 与 `apps/api/test/navigation.test.js`。

Agent 首页和业务辅助栏是同一个助理的两种形态，延续对话和引用。AI 助理图标在所有页面的顶栏最右侧常驻，统一使用既定星芒图标，不随业务模块更换；与其他图标同尺寸、无常驻文字，中间“首页 / 日程 / 支持”的位置不因图标增减而变化。业务页图标切换辅助栏，其余页面进入首页；侧栏底部无额外 AI 入口。Agent 后续能力与编排授权由[台账](../plans/run-state.md)维护。

全站浅色/深色覆盖顶栏、侧栏与内容。内容区采用背景上的独立内容块，保留各模块内容组织和操作位置；留白及块间间隙显示统一背景。账户外观字段、保存行为与样式归属见[账户外观与共享呈现](settings.md#账户外观与共享呈现)。

## 右侧辅助栏

桌面右栏占实际布局空间，主区随之调整，两侧可以同时操作。业务工具与 AI 共用一列，不叠加第二列。关闭右栏释放宽度；切换工具/AI 保留各自分类、展开、草稿、对话。当前分类、班级或课题仍在主区可辨认，不为此再建跨区顶部栏。

| 页面 | 中央工作区 | 右侧工具 |
| --- | --- | --- |
| 题库 | 找题/当前题；收录或改编时原稿/结果并排 | 自定义分类与标签 |
| 备课 | 文稿、环节和临时取材界面 | 我的备课、本课大纲 |
| 数学 | 工坊首页与作品选择、当前画布及预览 | 当前图形、滑杆、步骤和画布的按需编辑 |
| 资源 | 缩略图/列表、展开预览 | 文件夹与标签 |
| 班级 | 当前班级实际位置与记录 | 班级切换、相关备课 |
| 日程 | 连续日期时间网格 | 月份、日期范围、选段编辑 |

普通浏览、切题、改日期范围不抢走 AI；明确进入编辑，例如拖出时间段，可切到工具，同时保留 AI 草稿。原稿/识别结果、原题/副本在中央比较，不争用辅助栏。窄屏切换面板时保存两侧现场，实际触屏支持需目标设备验证。

## 所有现场都保留

持久内容、设备草稿与界面现场的保存层次见[共享保存契约](../contracts/workbench.md#保存与恢复反馈)。每个功能页列出自己的额外现场；共同包括对象、搜索/过滤、选中与批量顺序、各区锚点、展开/面板/宽度、对话和输入。

取材确认回原目标和位置，取消保留草稿；普通从题库/资源主动加入备课后留在来源，提供前往目标的动作。进入源对象再返回不暗中提交编辑。目标删除或版本变更须显式处理，不悄悄改目标。备课固定采用快照，教学记录连接当前对象，两种关系不能混用。

## 滚动与支持页面

外壳及主要工具栏稳定，长列表、文稿、预览、时间网格、对话各自滚动；不把每个小卡片都做成滚动容器。独立区域有可见间隙，操作就近，删去重复标题与无用说明。

设置、帮助和更新日志采用适合内容的独立布局，不强行套工具/AI 分栏。导航、外壳细部可按[原型 manifest](../../prototype/behavior/manifest.md)进入已确认参考；旧模块名称、样例数据和模拟结果不定义真实业务需求。
