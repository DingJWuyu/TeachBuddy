# 工作台与设置

本分区拥有外壳、导航、辅助栏、页面往返、外观与语言偏好，以及设置、帮助和更新页。业务内容与工具归各分区，首页和右侧对话归[AI 助理](agent.md)；本页规定它们的承载方式。视觉尺寸、参考站边界及动效只由[界面规则](../rules/design-and-verification.md)维护。

修改布局先读[整体结构](#整体结构)至[滚动与支持页面](#滚动与支持页面)；修改偏好和支持页先读[设置边界](#设置的有效边界)至[帮助与更新日志](#帮助与更新日志)。账户操作调用[账户与身份](identity.md)的公开能力，资料导出调用[数据管理与恢复](data.md)；公共保存、文件和编辑能力的所有权不因代码位于 `workbench/` 而归本分区。

## 整体结构

左侧是题库、数学工坊、资源库、班级教学的稳定入口，日程从顶部进入，侧栏不重复。首页承担 AI 助理完整工作区，不另设传统 dashboard。用户希望沿用 Codex Desktop 的左导航、中间工作、右侧辅助布局关系；实际视觉仍遵循现有产品基线。

导航分组、模块位置和可见性按[领域定义](../../GLOSSARY.md)归属账户，通过 `GET/PUT /api/workbench/navigation` 保存；同账户在其他设备登录、刷新或重新回到页面时读取已保存布局。系统默认分组以可选 `nameKey` 标记，随账户语言显示；教师改名后清标记，旧记录无标记则保持保存的名称，不按文字猜测是否为系统名称。分组折叠和侧栏开合仍是设备现场。导航隐藏只影响入口，不停用模块；目录暂时缺少的模块保留原位置与隐藏选择，新增侧栏模块出现在未分组。

账户首次接入且服务器尚无布局时，导入此设备原有的分组、顺序和隐藏选择；没有本机选择则保存当前默认模板。已有服务器布局优先，不让另一设备的旧本机记录自动覆盖。读取失败显示重试并暂停布局编辑，不把默认导航写回服务器；已有草稿和原始记录保留。

拖放、分组和隐藏操作自动保存，沿用[共享保存与冲突规则](../contracts/workbench.md#写入冲突与未知结果)。保存中仍可继续调整，后续输入另作草稿；结果未确认时保留原键和原请求，刷新或同账户重新登录后可重试确认。并发修改按整份布局版本拒绝覆盖，提供本机与账户布局对照；老师确认后可采用已保存布局或保留本机布局，后者仍检查所对照的版本。未解决的冲突及原编辑基线跨刷新保留，读取失败或重试确认不会解除冲突。侧栏收起时，以紧凑状态按钮展开侧栏处理失败、未确认或冲突。请求迟到不能回填另一账户。精确字段和结构约束见[导航接口](../../apps/api/src/contracts/navigation.js)，验证入口为 `apps/web/e2e/navigation-sync.config.mjs` 与 `apps/api/test/navigation.test.js`。

AI 助理首页和业务辅助栏是同一个助理的两种形态，延续对话和引用。AI 助理图标在所有页面的顶栏最右侧常驻，统一使用既定星芒图标，不随业务模块更换；与其他图标同尺寸、无常驻文字，中间“首页 / 日程 / 支持”的位置不因图标增减而变化。业务页图标切换辅助栏，其余页面进入首页；侧栏底部无额外 AI 入口。AI 助理后续能力与编排授权由[台账](../plans/run-state.md)维护。

全站浅色/深色覆盖顶栏、侧栏与内容。内容区采用背景上的独立内容块，保留各模块内容组织和操作位置；留白及块间间隙显示统一背景。账户外观字段、保存行为与样式归属见[账户外观与共享呈现](#账户外观与共享呈现)。

## 右侧辅助栏

桌面右栏占实际布局空间，主区随之调整，两侧可以同时操作。业务工具与 AI 共用一列，不叠加第二列。关闭右栏释放宽度；切换工具/AI 保留各自分类、展开、草稿、对话。当前分类、班级或课题仍在主区可辨认，不为此再建跨区顶部栏。

| 页面 | 中央工作区 | 右侧工具 |
| --- | --- | --- |
| 题库 | 找题/当前题；收录或改编时原稿/结果并排 | 自定义分类与标签 |
| 数学工坊 | 工坊首页与作品选择、当前画布及预览 | 当前图形、滑杆、步骤和画布的按需编辑 |
| 资源库 | 缩略图/列表、展开预览 | 文件夹与标签 |
| 班级教学 | 当前班级实际位置与记录 | 班级切换、相关题目与作品 |
| 日程 | 连续日期时间网格 | 月份、日期范围、选段编辑 |

普通浏览、切题、改日期范围不抢走 AI；明确进入编辑，例如拖出时间段，可切到工具，同时保留 AI 草稿。原稿/识别结果、原题/副本在中央比较，不争用辅助栏。窄屏切换面板时保存两侧现场，实际触屏支持需目标设备验证。

## 所有现场都保留

持久内容、设备草稿与界面现场的保存层次见[共享保存契约](../contracts/workbench.md#保存与恢复反馈)。每个功能页列出自己的额外现场；共同包括对象、搜索/过滤、选中与批量顺序、各区锚点、展开/面板/宽度、对话和输入。

进入教学记录关联的源对象再返回时保留原草稿、焦点和滚动，不暗中提交编辑。目标删除或版本变更须显式处理；教学记录连接当前对象，保存时标题与当前内容分开。

## 滚动与支持页面

外壳及主要工具栏稳定，长列表、文稿、预览、时间网格、对话各自滚动；不把每个小卡片都做成滚动容器。独立区域有可见间隙，操作就近，删去重复标题与无用说明。

设置、帮助和更新日志采用适合内容的独立布局，不强行套工具/AI 分栏。导航、外壳细部可按[原型 manifest](../../prototype/behavior/manifest.md)进入已确认参考；旧模块名称、样例数据和模拟结果不定义真实业务需求。

## 设置的有效边界

设置参考真实登录态 EMStudio 的布局、留白、细线和紧凑控件；排除套餐、计费、学生统计等商业功能。按内容分组、独立滚动，不套业务工具/AI 分栏。全站主题、内容背景和头像共享由外壳应用；模块内容组织与业务操作仍归各模块。

| 项目 | 当前真实行为 | 行为边界 |
| --- | --- | --- |
| 账户资料 | 昵称悬停或键盘聚焦显示编辑图标，点击后在原字号位置编辑；保存后同步侧栏和默认头像首字，邮箱只读 | 昵称去首尾空白后为 1-40 个 Unicode 字符；加入时间未由认证响应提供，不能虚构 |
| 头像 | 选择不超过 5 MB 的 JPG/PNG/WebP，上传与删除同步侧栏，按账户保存 | 原图不保留，仅保存裁剪后的头像 |
| 外观与背景 | 浅色/深色覆盖全站；网格/羊皮纸/圆形/条纹覆盖所有内容区，按账户保存 | 背景不覆盖顶栏、侧栏和内容卡片 |
| 语言 | 简体中文与 English 即时应用全站，设置和侧栏共用账户偏好 | 只提供有完整词库的语种；不改教师内容或导出正文 |
| 个人资料导出 | 真实生成、查询、下载，保留未确认请求重试 | 不等于可直接恢复的部署备份 |
| 退出 | 调用真实认证撤销；失败/未知时保留重试 | 只有确认撤销才报告已退出 |
| 数据处理协议 | 占位弹层 | 用户没有要求协议体系，不照搬参考站法律文本 |
| 删除账户 | 独立危险确认要求输入账户邮箱；调用真实认证删除 | 204 才报告完成；失败或结果未知跨关页保留原请求核实，可暂缓并登录其他账户 |

设置不提供每周开始日、最近删除聚合、阅读字号/动效、设备草稿管理、恢复隔离记录或备份说明入口。每周开始日无对应服务端字段；最近删除聚合不提供 API，各模块自身的删除和恢复、资料导出及维护 CLI 继续有效，见[数据管理](data.md)。

危险操作使用独立细红边卡片，标题带警示图标；左侧说明删除账户及不可撤销的后果，右侧为红色垃圾桶图标按钮。最终执行能力以上表为准。

昵称编辑不使用弹层：Enter 或移开焦点保存，Escape 取消；输入法选字的 Enter 不提交。空白或超长在原位提示，保存失败保留输入；仅在服务端确认后同步显示，刷新和重新登录读取账户昵称。修改昵称消费身份模块的公开能力，不重建工作台或丢失其他编辑现场。

## 账户外观与共享呈现

`GET/PUT /api/reliability/v1/preferences` 的 `values` 拥有 `theme`（`light` / `dark`）、`background`（`grid` / `parchment` / `circles` / `stripes`）、`avatar`（WebP data URL，空字符串表示删除）和 `locale`（`zh-CN` / `en`）。默认浅色、网格、无头像、简体中文；旧账户读取补默认值，旧客户端省略新字段时保留已存值。接口校验及默认值由 `apps/api/src/reliability/preferences.js` 维护。该接口还保留 `readingSize`、`motion`、`externalAi` 兼容字段；它们不构成当前设置 UI，也不扩大上文范围。

客户端居中裁剪头像为 256 × 256 WebP；服务端校验实际格式、尺寸和单帧，限制 data URL 为 128 KiB、请求体为 144 KiB。头像与其他偏好沿现有账户版本、幂等键和身份隔离保存，不另建上传文件或数据库迁移。

选择后立即更新全站显示，后台串行保存；保存过程中产生的新选择继续保存。失败或回执未知保留输入，提供原键重试；版本冲突由用户核对并采用服务端设置。刷新、重新登录和另一浏览器读取已确认的账户值；前台重新读取不覆盖未保存选择。

`WorkbenchApp.jsx` 持有共享偏好，`appearance.css` 拥有全站调色板和内容画布。主题传到顶栏、侧栏、各模块、菜单与弹层；内容背景只绘制在 `.wb-workspace`。模块保留内容组织和操作位置，使用外层留白、独立内容块及透明间隙露出背景。设置头像和侧栏头像消费同一个值。

语言词库在 `apps/web/src/i18n/locales/`，按模块组织，使用 i18next/react-i18next 的显式词条与插值。导航、工具、帮助、身份提示、动态状态、无障碍名称和日期数字格式使用当前语言；教师输入的名称、正文、代码、公式及导出内容保留原文。无身份入口默认简体中文，不沿用上一账户语言。新建默认导航分组通过 `nameKey` 标记为系统名称；重命名后清除标记。旧导航未带标记时按已保存名称显示，不猜测教师是否使用了默认名称。

账户删除确认列明不可恢复范围，取消不提交。提交后卸载工作台并显示清理进度；未知或未完成状态保留原 Cookie 和请求，同容器其他页退出也不清除该核实载体，刷新后仍可核实，不能以登录失效冒充删除成功。若认证读取确认原浏览器上下文已失效，明确原删除结果无法核实，允许显式重新准备登录；沿现有 bootstrap 建立新上下文，不把 401/409 当删除成功，不清未确认的账户设备资料。服务器确认后清理当前浏览器内该账户的草稿、待上传数据和助手缓存，并阻止迟到编辑重新写入；其他账户设备资料保留。本设备清理失败单独重试。服务器范围和外部副本边界见[账户永久删除](data.md#账户永久删除)，认证证明见[删除交换](../contracts/auth.md#账户删除交换-i08)。

未决退出状态由账户持有，离开设置再返回仍显示同一核实提示和重试动作；其他模块沿工作台现有身份提示位置提供同目标核实，不将退出锁误报为保存或连接故障，原业务草稿保留。未决删除有显式继续入口；当前退出尚未确认时禁用该入口，先完成原目标撤销。可信的另一账户不会仅因本机存在旧删除记录而被锁住；关页接续规则见[账户](identity.md)，不由设置复制认证状态。

## 帮助与更新日志

帮助提供本地简体中文与英文内容：五模块、日程提醒及常见问题。独立目录、首页搜索、章节/文章、面包屑、下一篇；标题和正文按当前语言检索，支持上下键、Enter、Escape、Ctrl/Cmd K。章节与文章有独立 URL，支持刷新、前进后退和新标签；目录与正文滚动按账户保留。联系支持使用常见问题入口，不新增在线客服。

更新日志页面按用户决定仅显示报纸图标和无障碍名称，不显示版本、构建或提交信息。自动生成发布数据与 CHANGELOG 仍由发布流程管理。

## 实现与验证入口

`apps/web/src/features/workbench/WorkbenchApp.jsx` 装配外壳、导航、辅助栏、偏好和支持页；导航 API 在 `apps/api/src/workbench/navigation.js`，偏好 API 在 `apps/api/src/reliability/preferences.js`，虽在 reliability 路径，职责属于本分区。共享草稿/文稿位于 workbench 目录的部分属于[共享技术底座](../README.md#共享技术底座)。

`apps/web/src/features/workbench/WorkbenchSettings.jsx`、`settings-shell.css` 拥有设置；`SupportPages.jsx`、`helpContent.js`、`support-shell.css` 拥有帮助。真实导出在 `apps/web/src/features/reliability/DataManagement.jsx`；退出调用认证 transport。字段和数据保护见[数据管理](data.md)与[认证退出](../contracts/auth.md#退出交换-i07)。

功能边界以上文为准；交互动效、焦点、参考尺寸见[界面规则](../rules/design-and-verification.md)。修改设置时用 `apps/web/e2e/settings-shell.config.mjs` 的隔离真实认证/可靠性服务；帮助用 `help-shell.config.mjs`。资料包及备份恢复用 `manual-data/manual-data.config.mjs`，跨模块草稿、冲突和未确认请求用 `manual-support/playwright.config.mjs`；这些入口均相对于 `apps/web/e2e/`。

完成相关 UI 修改应实际检查桌面及 390px 窄屏、各页面主题/背景组合、头像上传/删除同步侧栏及重新登录读回、键盘菜单、弹层退出中间态、快速反向和焦点恢复；同时确认偏好保存失败可重试、真实导出和退出可用。语言和删号使用 `apps/web/e2e/settings-implementation.config.mjs` 与 `apps/api/test/account-deletion.test.js` 验证真实认证、跨账户和未知结果。后端用 `apps/api/test/reliability.test.js` 核对账户隔离、版本冲突、旧字段兼容及头像输入校验。帮助另检查搜索空结果、无效文章、刷新返回和目录现场。当前验证入口见[核查入口](../plans/run-state.md#核查入口)。
