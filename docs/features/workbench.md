# 工作台与设置

本分区拥有外壳、导航、辅助栏、页面往返、外观与语言偏好，以及设置、帮助和更新页。业务内容与工具归各分区，首页和右侧对话归[AI 助理](agent.md)；本页规定它们的承载方式。界面、交互和动效沿[设计输入](../design-system/README.md)及其完整应用原型核对，本页维护持久化与跨分区职责。

修改布局先读[整体结构](#整体结构)至[滚动与支持页面](#滚动与支持页面)；修改偏好和支持页先读[设置边界](#设置的有效边界)至[帮助与更新日志](#帮助与更新日志)。账户操作调用[账户与身份](identity.md)的公开能力，资料导出调用[数据管理与恢复](data.md)；公共保存、文件和编辑能力的所有权不因代码位于 `workbench/` 而归本分区。

## 整体结构

左侧模块导航、顶部首页/日程与支持入口沿设计输入装配。首页承担 AI 助理完整工作区；业务模块通过单一模块目录开放，实际开放状态查[技术入口](../subsystems/README.md#代码结构)。

导航分组、模块位置和可见性按[领域定义](../../GLOSSARY.md)归属账户，按账户保存；同账户在其他设备登录、刷新或重新回到页面时读取已保存布局。系统默认分组保留默认名标记，随账户语言显示；教师改名后清标记，旧记录无标记则保持保存的名称，不按文字猜测是否为系统名称。分组折叠和侧栏开合仍是设备现场。导航隐藏只影响入口，不停用模块；目录暂时缺少的模块保留原位置与隐藏选择，新增侧栏模块出现在未分组。

账户首次接入且服务器尚无布局时，导入此设备原有的分组、顺序和隐藏选择；没有本机选择则保存当前默认模板。已有服务器布局优先，不让另一设备的旧本机记录自动覆盖。读取失败显示重试并暂停布局编辑，不把默认导航写回服务器；已有草稿和原始记录保留。

拖放、分组和隐藏操作自动保存，沿用[共享保存与冲突规则](../contracts/workbench.md#写入冲突与未知结果)。保存中仍可继续调整，后续输入另作草稿；结果未确认时保留原键和原请求，刷新或同账户重新登录后可重试确认。并发修改按整份布局版本拒绝覆盖，提供本机与账户布局对照；老师确认后可采用已保存布局或保留本机布局，后者仍检查所对照的版本。未解决的冲突及原编辑基线跨刷新保留，读取失败或重试确认不会解除冲突。侧栏收起时，以紧凑状态按钮展开侧栏处理失败、未确认或冲突。请求迟到不能回填另一账户。精确字段和结构约束见[导航接口](../../apps/api/src/contracts/navigation.js)，验证入口见[工作台验证](../acceptance/README.md#账户与工作台专项)。

学期组织和反馈记录属于按账户分区的本设备现场，不承诺跨设备同步；自定义背景图随账户偏好保存；导航布局、普通偏好及日程通知分别消费现有真实接口。

AI 助理首页和业务辅助栏是同一个助理的两种形态，延续对话和引用。业务页顶栏的星芒图标控制辅助栏，首页承载完整助理工作区；入口位置、支持页处理和开闭动效以设计输入为准。对话、真实能力与后续工具边界见[AI 助理](agent.md)。

全站浅色/深色覆盖顶栏、侧栏与内容。内容区采用背景上的独立内容块，保留各模块内容组织和操作位置；留白及块间间隙显示统一背景。账户外观字段、保存行为与样式归属见[账户外观与共享呈现](#账户外观与共享呈现)。

## 右侧辅助栏

题库、资源库、数学工坊、班级和日程在主卡片旁拥有自己的右轨，承载本模块筛选、管理、编辑或详情。AI 辅助栏只承载助理，打开时覆盖模块右轨；关闭后回到原右轨，两者状态分别保留。右轨与辅助栏的宽度、出现退出、窄容器变形与操作入口以[完整应用原型](../design-system/teachbuddy-app/index.html)为准。

普通浏览、切题、改日期范围不抢走 AI，模块现场与对话草稿继续保留。原稿/识别结果、原题/副本在主区比较，不能借助助理栏另建第二套业务界面。实际触屏支持需目标设备验证。

## 所有现场都保留

持久内容、设备草稿与界面现场的保存层次见[共享保存契约](../contracts/workbench.md#保存与恢复反馈)。每个功能页列出自己的额外现场；共同包括对象、搜索/过滤、选中与批量顺序、各区锚点、展开/面板/宽度、对话和输入。


## 滚动与支持页面

外壳及主要工具栏稳定，长列表、文稿、预览、时间网格、对话各自滚动；不把每个小卡片都做成滚动容器。独立区域有可见间隙，操作就近，删去重复标题与无用说明。

设置、帮助和更新日志采用适合内容的独立布局，不强行套工具/AI 分栏。导航与外壳细节见[完整应用原型](../design-system/teachbuddy-app/index.html)；样例数据和模拟结果不定义真实业务能力。

全局搜索及设置阅读/确认弹层打开后把键盘焦点限制在活动弹层内；Escape 关闭并恢复触发控件的焦点，不让退出动画丢失返回位置。

## 设置的有效边界

设置采用清晰的布局、留白、细线和紧凑控件；排除套餐、计费、学生统计等商业功能。按内容分组、独立滚动，不套业务工具/AI 分栏。全站主题、内容背景和头像共享由外壳应用；模块内容组织与业务操作仍归各模块。自定义背景图随服务端账户偏好保存，刷新、重登和其他设备登录后读回。

| 项目 | 当前真实行为 | 行为边界 |
| --- | --- | --- |
| 账户资料 | 昵称悬停或键盘聚焦显示编辑图标，点击后在原字号位置编辑；保存后同步侧栏和默认头像首字，邮箱只读 | 昵称去首尾空白后为 1-40 个 Unicode 字符；加入时间未由认证响应提供，不能虚构 |
| 头像 | 选择不超过 5 MB 的 JPG/PNG/WebP，上传与删除同步侧栏，按账户保存 | 原图不保留，仅保存裁剪后的头像 |
| 外观与背景 | 主题、背景选项与自定义背景图按账户保存 | 背景不覆盖顶栏、侧栏和内容卡片；保存未确认时保留原请求与图片 |
| 语言 | 简体中文与 English 即时应用全站，设置和侧栏共用账户偏好 | 只提供有完整词库的语种；不改教师内容或导出正文 |
| 个人资料导出 | 真实生成、查询、下载，保留未确认请求重试 | 不等于可直接恢复的部署备份 |
| 退出 | 调用真实认证撤销；失败/未知时保留重试 | 只有确认撤销才报告已退出 |
| 数据处理协议 | 展示设计输入的模拟协议阅读弹层 | 明确说明仅为排版示例，不能视为已生效法律承诺 |
| 删除账户 | 独立危险确认要求输入账户邮箱；调用真实认证删除 | 204 才报告完成；失败或结果未知跨关页保留原请求核实，可暂缓并登录其他账户 |

设置不提供每周开始日、最近删除聚合、阅读字号/动效、设备草稿管理、恢复隔离记录或备份说明入口。每周开始日无对应服务端字段；最近删除聚合不提供 API，各模块自身的删除和恢复、资料导出及维护 CLI 继续有效，见[数据管理](data.md)。

危险操作沿设计输入的统一确认控件，账户删除在确认正文中保留邮箱校验。最终执行能力以上表为准。

昵称编辑不使用弹层：Enter 或移开焦点保存，Escape 取消；输入法选字的 Enter 不提交。空白或超长在原位提示，保存失败保留输入；仅在服务端确认后同步显示，刷新和重新登录读取账户昵称。修改昵称消费身份模块的公开能力，不重建工作台或丢失其他编辑现场。

## 账户外观与共享呈现

默认值与可选背景外观沿设计输入；仅提供完整词库的简体中文与 English。主题覆盖全站，背景只在内容区空隙露出，不覆盖顶栏、侧栏或内容卡片。设置头像和侧栏使用同一个账户值，头像居中裁剪后保存，不保留原图。接口限制与兼容字段见[偏好契约](../contracts/workbench.md#账户偏好兼容)，不由兼容字段增加设置入口。

选择后立即更新全站显示，后台串行保存；保存过程中产生的新选择继续保存。失败或回执未知保留输入，提供原键重试；版本冲突由用户核对并采用服务端设置。刷新、重新登录和另一浏览器读取已确认的账户值；前台重新读取不覆盖未保存选择。

导航、工具、帮助、身份提示、动态状态、无障碍名称及日期数字格式跟随当前语言；教师名称、正文、源码、公式及导出保持原文。匿名入口默认简体中文，不沿用上一账户语言。系统默认导航名称随语言显示，教师改名及旧记录按已保存名称显示，不猜测是否默认名称。

账户删除确认列明不可恢复范围，取消不提交。提交后卸载工作台并显示清理进度；未知或未完成状态保留原 Cookie 和请求，同容器其他页退出也不清除该核实载体，刷新后仍可核实，不能以登录失效冒充删除成功。若认证读取确认原浏览器上下文已失效，明确原删除结果无法核实，允许显式重新准备登录；沿现有 bootstrap 建立新上下文，不把 401/409 当删除成功，不清未确认的账户设备资料。服务器确认后清理当前浏览器内该账户的草稿、待上传数据和助手缓存，并阻止迟到编辑重新写入；其他账户设备资料保留。本设备清理失败单独重试。服务器范围和外部副本边界见[账户永久删除](data.md#账户永久删除)，认证证明见[删除交换](../contracts/auth.md#账户删除交换-i08)。

未决退出状态由账户持有，离开设置再返回仍显示同一核实提示和重试动作；其他模块沿工作台现有身份提示位置提供同目标核实，不将退出锁误报为保存或连接故障，原业务草稿保留。未决删除有显式继续入口；当前退出尚未确认时禁用该入口，先完成原目标撤销。可信的另一账户不会仅因本机存在旧删除记录而被锁住；关页接续规则见[账户](identity.md)，不由设置复制认证状态。

## 帮助与更新日志

帮助提供本地简体中文与英文内容：开始使用、题库、日程、教学助理、数学工坊、资源库及账户与数据。独立目录、首页搜索、章节/文章、面包屑、下一篇；标题和正文按当前语言检索，支持上下键、Enter、Escape、Ctrl/Cmd K。主题与文章使用 `/help/:topic` 和 `/help/:topic/:article`，支持刷新、前进后退和新标签；目录与正文滚动按账户保留。联系支持使用常见问题入口，不新增在线客服。

更新日志页保留报纸图标与无障碍名称；发布数据与 CHANGELOG 由发布流程生成，不把内部构建信息拼入页面。
