# 日程：安排、事项与提醒

接口、持久化与跨模块调用读[当前技术入口](../subsystems/schedule.md)。

本分区拥有日期视图、安排、事项、标签、重复规则、提醒和账户时区。日程记录计划，事项可以标记完成，不推断实际教学进度，不增加逾期或催办体系。范围见[产品分区](../PRODUCT_SCOPE.md#产品分区)，当前能力与未验条件见[项目状态](../plans/run-state.md)。

## 入口与布局

顶部唯一入口 `/calendar`，侧栏不重复。通知打开 `/calendar?entry=<UUID>&on=<原始日期>`，非重复安排省略 on。对象解析后按实际时段展开日期并定位，不把 on 误当调课后的日期。跨分区只导航到允许的本地业务路径；返回位置保存在本账户设备现场，不接受任意外部 return URL。

日历与任务看板通过共享分段控件切换。主卡片、月份右轨、任务编辑面板、三列看板及其打开关闭动效对照[设计输入](../design-system/README.md)与完整应用原型；业务日期、重复和提醒语义见以下各节。

日程由主区和右侧月份卡片组成。初始今天起 7 天；视图提供日、周、月、2 至 9 天及自定义 1 至 31 天。支持日期为 1900-01-01 至 2100-12-31，边界视图的读取范围裁剪到有效日期，浏览与拖动不能落入范围外。

- 小月历拖选连续日期后立即切换对应天数，可跨周、跨月；翻月只浏览月份。鼠标点选不追加焦点外圈，键盘保留日期导航。
- 主网格以 5 分钟吸附，日期/时间输入可精确到分钟。只有拖选创建任务，单击空白关闭当前编辑或取消新建选区。灰色选区以单层背景居中显示起止时间。短任务从主体拖动改期，右侧上下边缘调整时长；当前时间线位于任务卡片下方。
- 日、周与多日视图的全天卡片只显示标题，不加颜色圆点；月视图各类任务保留颜色圆点。全天与跨夜任务横跨实际占用日期，跨周分行。月视图按可用高度折叠，跨日任务按跨度优先排列；“还有 N 项”渐进打开、立即关闭，再次点击同一入口关闭。弹层只在标题显示日期，长标题截断；任务可打开或拖到其他日期，拖动不触发点击，保留钟点、时长与全天跨度。选中任务背景不透明，日期背景只作用于所属格。月视图连续滚动跨月，“今天”回当前日期。
- 全天任务拖入时间网格成为落点开始的 60 分钟任务；时间段任务拖入全天区成为落点当天的全天任务，不恢复旧跨天长度。全天区内移动和拉伸保留或调整跨度。Escape 只取消当前拖动、拉伸或日期拖选，保留父编辑器；松手不创建或提交已取消的操作。

桌面主区与右卡片并排，顶部与外壳保持不变；时间网格、任务编辑和即将到来各自滚动。窄屏通过“打开月份与任务”进入辅助卡片并可关闭返回。打开 AI 时覆盖月份右轨，编辑任务时保留任务和 AI 各自现场。视图、选段、月视图滚动和任务草稿按账户保留，刷新或切模块可恢复。

## 状态和动作

| 状态 | 可见内容/动作 | 结果、失败与返回 |
| --- | --- | --- |
| TT-U4 日程范围 | 日、周、多日网格或连续月视图；右栏为小月历及即将到来。支持按标签分组。 | 空日保留网格；读取失败保留旧内容并显示重试。浏览日期不创建任务。 |
| TT-U5 选段/编辑 | 任务在右栏编辑标题、起止日期时间、标签、备注与事项。有效修改自动保存，键盘行为见[日程键盘与保存](#日程键盘与保存)。 | 空标题新建直接取消，不因填写其他字段创建任务。无效时间在对应控件下方提示，关闭恢复最后有效时间并保留其他有效输入；新建无效时间取消。保存、切换及迟到响应保留规则见[现场与错误](#现场与错误)。 |
| TT-U6 标签/事项 | 标签可搜索、创建、改名、选颜色和删除；最多选 30 个，达到上限仍可取消已选标签。事项独立成区，支持添加、编辑、删除、完成切换、小点拖动排序及跨安排移动。 | 圆点完成时变绿、文字划线，再点恢复；长按或拖动不触发完成，完成事项仍可移动。聚焦小点时上下键排序。事项 ID 与完成状态随排序、移动保留；目标最多 200 条事项，达到容量时就近说明并限制移动。删除标签不删除任务。 |
| TT-U7 重复任务 | 任务菜单和时间区摘要提供重复规则入口，支持每天、工作日、每周、每两周、月日期、月星期、每年及自定义间隔、结束日期/次数。摘要显示具体规则；改规则后定位符合新规则的日期，不存在的月日期和闰日跳过。 | 编辑某一次的标题、时间、标签、备注、提醒或事项后，这一次保存为普通独立任务，原日期从系列取消，后续重复日期不变。之后的编辑、移动事项、移回待安排及删除均只作用于独立任务。不显示单次/整组选择、默认设置栏或恢复重复按钮。重复规则入口只修改排期规则，保留已有独立任务，不把当前单次内容写回模板。 |
| TT-U9 全天/提醒 | 任务菜单切换全天或打开“设置提醒”；提醒可选开始前、开始后、结束前、结束后及分钟数，已有提醒在日期时间下、标签上显示摘要，点击可调整或关闭。重复规则与提醒集中在时间区，移除“仅此任务”范围文案；已有提醒再次点击摘要即可调整或关闭。 | 全天结束日期含当天，跨夏令时保持当地午夜。新任务无提醒；0 分钟为所选开始或结束时，过去提醒的新增/调时按契约拒绝并保留输入。 |
| TT-U10 通知 | 顶部既有通知面板显示安排标题、原定提醒时间和未读态；通知行、错误和重试按钮保持在面板内且可点击，支持单条已读、再次点击已读通知撤销已读、全部已读和清空。点击面板及入口外的任意位置，包括顶部空白，关闭面板。 | 点击定位到当前实际时段；已取消、删除或移出重复范围的目标在日程卡片只读显示状态。清空通知仅删除展示，幂等痕迹保留。 |
| TT-U11 删除 | 删除普通任务或取消所选重复日期。 | 日程不提供回收站或恢复入口，删除前明确确认；未知结果仍以原键原体确认，不级联删除其他教学资料。 |

## 日程的按需操作

“待安排”的加号打开无时间草稿，输入有效标题后自动保存；空白离开不创建对象。已有任务可“安排时间”；无时间时菜单不显示重复、全天与设置提醒，安排时间后显示这些选项。排期任务在编辑器右上角菜单左侧显示带文字的“移回待安排”按钮，不再放在菜单内；确认后移除本次时间、提醒，保留标题、事项、标签、备注。重复实例先独立为普通任务，再移回待安排，后续日期继续重复。再次安排时间不恢复旧重复规则。

任务内的事项区逐项添加内容，数量以小括号显示，与即将到来和待安排一致；空白或仅含空格的事项离开输入框后自动移除，不触发删除任务；连续添加替换未填写的空行并聚焦新输入，已填写内容保留。左侧小点支持拖拽排序；事项左侧完成点可点击完成或恢复未完成，完成后仍可拖动，状态随保存、移动和刷新保留；事项菜单提供删除或“移到其他安排”。移动弹窗展示普通任务、待安排和重复任务，重复目标显示具体规则。选普通任务或待安排直接移动；选重复任务后在原弹窗选择“每次重复都需要”或“只在某一次需要”，后者再选择活动日期。每次模式加入原有系列的模板事项，不创建新系列，已独立任务及既有单次例外不变；单次模式将所选日期独立为普通任务并加入事项，其他日期不变。事项 ID 保持，目标时间与提醒保持原样。源和目标的版本与移动结果同事务保存，失败不部分移动；未知结果保留原请求确认，版本冲突须核对后继续。

右侧“即将到来”显示今天尚未结束的任务，按起始时间排序，编辑与选中不改变先后；“待安排”显示无时间任务。两区采用一致标题、数量、加号与列表/标签分类切换；分类名称小于区标题。空态以对应事项图标和“先记下要做的事，之后再安排时间。”说明用途。没有优先事项、时区选择或日程管理入口。

工作台采用浏览器读取的系统 IANA 时区：进入日程、窗口重新获得焦点或回到前台时检查，页面打开期间每 15 秒检查。左侧年月旁以淡色小文字显示 UTC 偏移和完整 IANA 标识，例如 `UTC-07:00 · America/Phoenix`；当前时间线按系统分钟边界更新。同步保留任务当地日期、开始钟点、时长和重复规则，迁移单次例外；待安排保持无时间，实际教学记录日期不换算。提醒随任务重新计算，已有通知保留原提醒瞬间，已过期的提醒不补发。未确认的写入先以原请求确认；同步中的输入保留，事项移动与时区同步可以顺序完成，不能互相等待。同步失败提供重试，确认前保持原显示。夏令时缺失时刻显示实际调整提示，结束时间按实际分钟计算，全天按当地日期计天。跨地区共同约定的固定实际时刻不在当前范围。

默认任务编辑器保持标题、日期时间、标签、备注与事项区；右侧列表、标签分类和任务编辑区隐藏滚动条，保留滚轮、触控板与触屏滚动，不占用内容宽度；展开任务列表不显示横向滚动条，纵向滚动仍可用；备注清空后恢复“添加备注…”占位。提醒按需弹窗，已有值显示摘要。新增提醒或调整任务时间使提醒过期被服务器拒绝时，立即显示弹窗，明确任务时间段、提醒规则及本次修改尚未保存，仅提供关闭提醒并保存或放弃本次修改，移除调整提醒、右上角关闭入口，Escape 放弃本次修改，点击遮罩不代替抉择；拖动失败时保留尝试的时间，修正提醒后仍可保存拖动结果；同一任务尚有未保存输入时，拖动合并最新时间与其他编辑内容，一次提交，关闭提醒并保存后不恢复旧时段。放弃修改恢复已确认的时间、提醒与编辑内容，不重新提交修改；未保存的新任务取消草稿。同步刷新卡片并解除失败状态，继续拖动、新建与切换任务；提示依据被拒绝请求的内容，响应等待期间的后续输入保留并用于重新保存；不在编辑器底部显示提醒错误。提醒时机选择框箭头距右边缘 12px；只有网络失败、未知结果和版本冲突提供相应重试或保存入口。所有保存继续使用共享未知结果、版本冲突与账户隔离协议。

## 日程键盘与保存

- 标题、起止日期/时间与备注 Enter 确认当前输入并移出光标，保留任务编辑器；待安排相同。已命名新建保存为当前草稿对应的任务，不生成副本；未命名确认不创建对象，关闭才取消。备注 Shift+Enter 换行，不显示快捷键说明。事项 Enter 确认当前项并聚焦下一条，空白不生成新行，离开时清理；达到 200 条只确认当前项。
- 标签列表 Enter 切换当前项的选择，再按取消，保持展开。搜索 Enter 选择首个可选匹配项并定位该项；上下键切换标签行，左右键在标签与同行编辑入口间切换。文字搜索的左右、Home/End 保留光标行为。菜单与列表以灰色背景定位焦点，不添加外圈。
- 日程所有弹窗以 Enter 执行唯一确认操作，包含移回待安排、移动事项、采用服务器内容、删除及提醒失效的关闭提醒并保存；焦点在取消或叉号时也确认，鼠标取消和关闭仍保留原作用。Escape 取消，提醒失效时放弃本次修改并恢复已确认内容。日期与下拉字段的 Enter 直接确认，不额外打开选项；无效输入、加载和保存等待不绕过按钮禁用状态。
- 提醒、重复中的并排数字/选择字段使用左右键移动焦点，选择字段上下键修改选项，数字字段上下键保留增减行为。颜色与星期按钮按横向布局使用左右键，Space 改变复选、单选与颜色选择。无字段弹窗初始聚焦确认按钮，不可用则聚焦弹窗本身；取消后快速重开重新读取当前对象。输入法确认候选词、按住 Enter 或修饰键组合不误提交；活动弹窗独占确认，底层编辑器和退出中的浮层不响应。
- 普通菜单上下键在当前层导航，Enter 或向右键进入子菜单，向左键回上层；关闭恢复触发控件。深链接恢复同一任务保留编辑器与字段焦点，迟到的旧读取不能覆盖已确认的新版本；保存中继续输入、取消后迟到响应及标签冲突恢复遵循[现场与错误](#现场与错误)。

关闭已有任务编辑器时，无效标题及日期时间恢复最后保存值，其余有效输入继续保存；待安排与已安排使用同一取消规则。事项拖动中 Escape 只取消手势，松开不改变完成状态或顺序。重复次数保留实际输入，仅允许 1 至 10000 的整数。保存结果未确认时，编辑器顶部固定显示原因与重试确认入口，长备注滚动后仍可见。即将到来与待安排的标签分类标题为 14px、图标 16px，低于区标题层级。

## 现场与错误

保存状态、结果未确认、冲突、身份失效和本地存储失败沿用[共享保存与恢复](../contracts/workbench.md#保存与恢复反馈)。未确认请求先以原键原体确认；老师新增输入保存在另一个草稿中。版本冲突保留双方内容，不自动覆盖。

设备现场按可信 accountKey 分区，保存日程范围、选段、原始实例日期、未排期展开、各区滚动、右栏形态、输入草稿和待确认请求。切换、刷新、离开再返回均恢复；丢弃草稿须明确确认。换设备先读取已保存业务和账户时区，再按系统时区规则同步；未上传草稿不跨设备。异账户与迟到旧请求遵守[共享身份代次隔离](../contracts/workbench.md#身份与-http)。通知引导离开当前草稿先处理有效修改并保留本地现场；存储失败时提示复制/在线保存后继续。

窄屏短时段卡片只显示标题，完整事项在右栏；按需弹窗和任务编辑各自滚动，末尾事项与操作可达。
