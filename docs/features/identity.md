# 账户与身份

本页是账户与身份产品分区的行为入口，定义登录、注册、找回、会话恢复、退出及账户删除的身份处理。工作台内的账号展示和设置操作入口见[工作台与设置](workbench.md)，业务内容和设备资料的清理职责见[数据管理](data.md)。协议语义归[认证契约](../contracts/auth.md)，精确交换见其 OpenAPI 和用例。

## 用户目标

教师可以用保存昵称的账户进入工作台，收取验证码注册或重置密码，在网络和保存失败后继续原流程，并确认退出是否完成。账户行为拥有注册/登录/找回/恢复卡和删除核实状态；工作台拥有账号行、已有首次引导与设置退出按钮。协议的 pending、页面头、Cookie 容器均不出现在产品文案中。

设置中的昵称原位编辑消费身份公开能力，保存后更新账户资料并同步侧栏，邮箱保持只读。昵称修改不重新激活会话；输入校验、未知结果核实和迟到响应隔离见[昵称修改交换](../contracts/auth.md#昵称修改交换-i09)，具体交互归[工作台与设置](workbench.md#设置的有效边界)。

## 状态接线

| 用户所见 | 触发与下一步 |
| --- | --- |
| 启动 | 首次状态读取期间保持中性入口占位，不先渲染登录或工作台；按可信身份核对未决退出和删除，再决定恢复、核实或S14。其他账户的未决记录不阻断当前可信账户。只有确有恢复目标才显示S46恢复卡，随后提交restore。 |
| 登录/注册提交中 S38 | 业务成功pending仍属于交接过程，继续activate；active确认前不挂载工作台。记住我沿提交快照，注册默认true，不加新控件。 |
| 保存失败 S45 | 明确“账户操作已完成，登录状态未保存”；继续当前会话、重试保存、返回登录。前两个只调用会话操作，不重新创建账户/验证密码/消费验证码；返回登录须先确认定向撤销并重新准备登录，用户无需刷新。已失效则回登录提示过期。 |
| 恢复等待/失败 S46/S47 | 等待卡不闪现其他内容；临时故障提供重试和返回登录。返回时定向放弃恢复目标，任何迟到结果不得改变当前表单。 |
| 未知结果 S44 | 注册或重置可能成功时保留输入，以中性提示说明未确认，提供回登录恢复。无已确认成功前不显示成功横幅、不自动重复业务。 |
| 退出等待/失败 | 设置按钮等待并禁用重复触发；确认撤销后重新准备登录。失败保留上下文可重试，未知时停止业务交互并提示“退出结果暂未确认”，重试相同目标；导航往返不丢提示，刷新不自动恢复未决旧目标。放弃登录状态保存和恢复沿用同一确认规则，不能伪装退出完成。 |
| 身份失效 | 收到当前身份失效的可信结果，锁住当前账户现场，清已登录视图，回S14说明过期；其他账户通知只触发核验，不直接清页面。 |

页面内提交快照和界面编辑代次分开。注册提交前的开放状态读取也属于本次提交，等待期间禁重复提交；编辑字段/换邮箱/切用途/切卡后，旧读取不能启动业务，已发业务的旧响应不能清新输入、安装旧挑战或跳入工作台。S45离开后须解绑旧pending及事件监听，覆盖 CA120。请求取消只停止等待，不作为业务回滚证明；超时覆盖完整响应读取，可能已提交的业务仍按未知结果恢复。

## 注册开放状态

注册默认开放。关闭只禁止新的注册和注册验证码，不删除已经创建的账户，不影响已有账户登录、找回或重置。已经打开的注册流程在填写、已发码或等待提交时收到关闭结果，显示明确关闭说明与返回登录；业务裁决关闭时不创建账户、不消费验证码。账户已创建后再关闭注册，不撤回已完成结果。此规则延续原 G04，独立验证见 [CC-CLOSED](../acceptance/auth-cases.md#cc-resetcc-storecc-closed)。

## 输入与本地校验

以下规则承接原 G06，精确传输与后端独立校验以 [OpenAPI](../../apps/api/src/contracts/auth.openapi.yaml) 为准。

- 邮箱输入保留原文，提交及只读展示使用 trim 后转小写的规范值。规范值为 ASCII、最长 254 字符、恰好一个 `@`；本地部分长 1-64，仅英文字母、数字及 `._%+-`，不能首尾为点或连续点。域名至少两个标签，各长 1-63，仅英文字母、数字及中间连字符。不查询 DNS。
- 昵称 trim 后为 1-40 个 Unicode code points；输入时不改写原文。
- 密码为 8-128 个 Unicode code points，保留空白、大小写及 Unicode 原值。确认密码只在本地逐值比较，显隐不改变密码。
- 验证码为 6 位 ASCII 数字字符串，保留前导零；形状错误不发业务请求或扣尝试次数。
- 注册条款默认未选，未同意不提交；链接行为沿设计输入，不据此新增协议体系。

本地校验顺序：登录为邮箱、密码；注册发码先邮箱，再由服务端判定开放与占用；注册提交先邮箱和开放状态，再昵称、密码、确认密码、是否发码、验证码形状、条款，最后提交真实业务；找回第一步先邮箱，服务端确认存在及成功发码才进入确认；找回确认依次验证码形状、新密码、两次密码一致、是否发码，再提交重置。形状合法的错误码与未勾条款同时出现，先提示条款且不扣次数。

验证码真实性、挑战用途与规范邮箱绑定、生命周期及剩余次数由认证服务裁决。有效期 10 分钟，错值最多 5 次，成功发码冷却 30 秒；重发成功才替换旧挑战，失败不清掉仍有效的旧码。只有注册或重置实际成功才消费挑战。值错可继续，过期、替换、已消费或耗尽需重新发码。对应验证归 [CC-INPUT/BOUNDARY/UI](../acceptance/auth-cases.md#cc-inputcc-boundarycc-ui) 与 [CC-SEND/CODE](../acceptance/auth-cases.md#cc-sendcc-code)。

字段校验及验证码错误落对应字段；凭据拒绝、存储及一般请求失败落非字段提示，凭据拒绝只清密码。注册或重置可能完成但响应未知时，沿 S44 保留输入恢复，不能伪装已回滚。业务、会话保存和恢复失败各走自己的状态，不以原型的浏览器模拟存储替代真实认证。

### 稳定状态编号

S 编号继续供交换用例与测试定位；视觉表现以设计输入为准，编号不表示当前候选已验收。

| 编号 | 业务含义 |
| --- | --- |
| S14 / S15 / S16 | 登录 / 注册未发码 / 活动验证码 |
| S17 / S18 | 找回第一步 / 成功发码后的确认卡 |
| S19 / S20 / S21 | 字段错误 / 注册邮箱占用 / 已确认登录工作台 |
| S36 / S37 / S38 | 已知请求失败 / 已确认成功提示 / 提交或发码等待 |
| S39 / S40 / S41 | 发码冷却 / 验证码裁决 / 找回地址锁定 |
| S42 | 保留旧“找回第二步待发码”编号，现行流程不产生 |
| S43 / S44 | 注册关闭 / 注册或重置结果暂未确认 |
| S45 / S46 / S47 | 业务成功但会话保存失败 / 恢复等待 / 恢复失败 |

CA01-CA120 的业务与纯界面归属由[认证覆盖表](../acceptance/auth-cases.md#上游归属与覆盖)承接；CA53 已由真实退出场景覆盖，不继承旧原型“缺少退出入口”的限制。S30-S35 属于旧侧栏编号，不用作认证状态。

## 保持既定呈现

入口铺满整个视口，外侧无留白，内容超高时按页面自然滚动。使用左右分栏：左侧仅展示四个几何角色，右侧承载登录、注册、找回密码、保存失败和恢复状态；窄屏改为上方角色、下方表单。角色根据焦点类别、指针、输入光标位置、密码显隐及已知反馈编排动作。输入内容仅用于瞬时测量可见光标位置，不持久保存文本或新增请求；隐藏密码仅按长度生成圆点测量，显示密码时测可见文本宽度。角色不发请求、不延迟身份交接，结果未确认时不表现为成功。系统减少动态效果时关闭动画与指针跟随。

登录和注册共用品牌与标题的顶部位置，标题分别为“欢迎回来”和“创建账户”；窄屏的角色区域等高，较长表单向下展开。字段保留独立标签，昵称、邮箱与确认密码用占位提示引导输入；昵称与密码不显示实时字数计数，长度约束和错误校验仍然生效。

- 字段错误落字段下；普通非字段问题用可关闭顶部横幅，尚待核实的退出状态持续呈现直到确认。只有凭据拒绝清密码，其他可恢复失败保留输入。
- 找回第一步成功发码后才进入第二步，邮箱只读；更换邮箱返回第一步清挑战并重新发码。不使用保留状态S42。
- 发码等待显示发送阶段，不显示正在注册。结果只说明已发送请求被接受；响应未知时明确尚未确认、可能收到邮件，不安装猜测的挑战，保留输入及冷却后重发路径。未收件时保留有效期、冷却、重发及换邮箱路径。长地址省略且全文可访问。
- 昵称完整值交工作台，账号行省略、无障碍名完整，头像保留完整Unicode字符；邮箱不作昵称替代。
- PC 1440×900、平板768×1024、手机390×844均检查错误、等待、S44-S47及设置退出的可见状态、焦点、键盘、触摸和溢出。UI只做浏览器交互验证，不写单元测试。

产品设置调用真实退出，账户与工作台入口已组合。真人邮件须在目标环境实际收发核验，不能从 API 替身结果推断三端、跨设备和目标网络全部通过。

## 接口与验收

协议见[认证契约](../contracts/auth.md)，当前代码接线见[身份技术入口](../subsystems/identity.md)，三端表单/协议/竞态与真实条件见[认证验收](../acceptance/auth-cases.md)和[验证选择](../acceptance/README.md#模块与底座入口)。

设置提供独立邮箱确认后的永久删除；提交后锁定业务，失败或未知保持原请求核实，服务端确认后清理本设备并进入默认中文匿名页。详见[账户删除交换](../contracts/auth.md#账户删除交换-i08)。登录后的产品语言读取账户偏好，身份失效后不沿用上一账户语言。
