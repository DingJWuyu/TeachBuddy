# 设置、帮助与更新日志

## 设置的有效边界

设置参考真实登录态 EMStudio 的布局、留白、细线和紧凑控件；排除套餐、计费、学生统计等商业功能。按内容分组、独立滚动，不套业务工具/AI 分栏。顶栏、侧栏、首页及认证不是普通设置打磨任务的写入范围。

| 项目 | 当前真实行为 | 尚缺什么 |
| --- | --- | --- |
| 账户资料 | 读取已认证昵称和邮箱，显示 TeachBuddy 账户 | 加入时间未由认证响应提供，不能虚构 |
| 头像 | 选择不超过 5 MB 的 JPG/PNG/WebP，本地预览及移除 | 上传、删除、跨设备持久化接口 |
| 外观与背景 | 设置页内预览，离开还原；背景为网格/羊皮纸/圆形/条纹 | 全站生效及账户持久化 |
| 语言和每周开始日 | 语言列表、星期日/一选择态 | 翻译、实际日历周起点及账户持久化 |
| 个人资料导出 | 真实生成、查询、下载，保留未确认请求重试 | 不等于可直接恢复的部署备份 |
| 最近删除 | 按类型筛选，恢复原 ID、版本和关系 | 不增加永久删除或分类回收能力 |
| 退出 | 调用真实认证撤销；失败/未知时保留重试 | 只有确认撤销才报告已退出 |
| 数据处理协议 | 占位弹层 | 用户没有要求协议体系，不照搬参考站法律文本 |
| 删除账户 | 确认弹层的最终执行禁用 | 无实际删除接口，不显示成功 |

用户已移除阅读字号/动效/保存偏好、设备草稿数量/下载/清理、继续旧现场、恢复隔离记录、备份说明及对应跳转。底层存储、偏好数据、恢复机制和维护 CLI 保留。打磨界面不能依据旧截图恢复这些入口，也不能把历史偏好 API 当作当前主题等字段已经支持。未来实现新偏好需明确对应字段、保存和全站消费者。

## 帮助与更新日志

帮助是本地中文内容：六模块、日程提醒及常见问题。独立目录、首页搜索、章节/文章、面包屑、下一篇；标题和正文检索支持上下键、Enter、Escape、Ctrl/Cmd K。章节与文章有独立 URL，支持刷新、前进后退和新标签；目录与正文滚动按账户保留。联系支持使用常见问题入口，不新增在线客服。

更新日志页面按用户决定仅显示报纸图标和无障碍名称，不显示版本、构建或提交信息。自动生成发布数据与 CHANGELOG 仍由发布流程管理。

## 代码与验收依据

`apps/web/src/features/workbench/WorkbenchSettings.jsx`、`settings-shell.css` 拥有设置；`SupportPages.jsx`、`helpContent.js`、`support-shell.css` 拥有帮助。真实导出与恢复在 `apps/web/src/features/reliability/DataManagement.jsx`；退出调用认证 transport。字段和数据保护见[数据管理](data.md)与[认证退出](../contracts/auth.md#退出交换-i07)。

交互动效、焦点、参考尺寸见[界面规则](../rules/design-and-verification.md)。修改设置时用 `apps/web/e2e/settings-shell.config.mjs` 的隔离真实认证/可靠性服务；帮助用 `help-shell.config.mjs`。旧 manual-data/support 配置有已移除界面断言，不能据此恢复旧功能。

完成相关 UI 修改应实际检查桌面及 390px 窄屏、主题/背景组合、头像预览/移除、键盘菜单、弹层退出中间态、快速反向和焦点恢复；同时确认真实导出、最近删除保存刷新和退出不被破坏，纯 UI 选择没有意外偏好写请求。帮助另检查搜索空结果、无效文章、刷新返回和目录现场。当前具名验证为设置 4 条、帮助 3 条 E2E 与构建通过，证明范围见[能力证据](../plans/run-inputs.md)，不是全站偏好完成。
