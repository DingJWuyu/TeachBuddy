# 设置、帮助与更新日志

## 设置的有效边界

设置参考真实登录态 EMStudio 的布局、留白、细线和紧凑控件；排除套餐、计费、学生统计等商业功能。按内容分组、独立滚动，不套业务工具/AI 分栏。全站主题、内容背景和头像共享由外壳应用；模块内容组织与业务操作仍归各模块。

| 项目 | 当前真实行为 | 行为边界 |
| --- | --- | --- |
| 账户资料 | 读取已认证昵称和邮箱，显示 TeachBuddy 账户 | 加入时间未由认证响应提供，不能虚构 |
| 头像 | 选择不超过 5 MB 的 JPG/PNG/WebP，上传与删除同步侧栏，按账户保存 | 原图不保留，仅保存裁剪后的头像 |
| 外观与背景 | 浅色/深色覆盖全站；网格/羊皮纸/圆形/条纹覆盖所有内容区，按账户保存 | 背景不覆盖顶栏、侧栏和内容卡片 |
| 语言 | 简体中文与 English 即时应用全站，设置和侧栏共用账户偏好 | 只提供有完整词库的语种；不改教师内容或导出正文 |
| 个人资料导出 | 真实生成、查询、下载，保留未确认请求重试 | 不等于可直接恢复的部署备份 |
| 退出 | 调用真实认证撤销；失败/未知时保留重试 | 只有确认撤销才报告已退出 |
| 数据处理协议 | 占位弹层 | 用户没有要求协议体系，不照搬参考站法律文本 |
| 删除账户 | 独立危险确认要求输入账户邮箱；调用真实认证删除 | 204 才报告完成；失败或结果未知跨关页保留原请求核实，可暂缓并登录其他账户 |

设置不提供每周开始日、最近删除聚合、阅读字号/动效、设备草稿管理、恢复隔离记录或备份说明入口。每周开始日无对应服务端字段；最近删除聚合不提供 API，各模块自身的删除和恢复、资料导出及维护 CLI 继续有效，见[数据管理](data.md)。

危险操作使用独立细红边卡片，标题带警示图标；左侧说明删除账户及不可撤销的后果，右侧为红色垃圾桶图标按钮。最终执行能力以上表为准。

## 账户外观与共享呈现

`GET/PUT /api/reliability/v1/preferences` 的 `values` 拥有 `theme`（`light` / `dark`）、`background`（`grid` / `parchment` / `circles` / `stripes`）、`avatar`（WebP data URL，空字符串表示删除）和 `locale`（`zh-CN` / `en`）。默认浅色、网格、无头像、简体中文；旧账户读取补默认值，旧客户端省略新字段时保留已存值。接口校验及默认值由 `apps/api/src/reliability/preferences.js` 维护。

客户端居中裁剪头像为 256 × 256 WebP；服务端校验实际格式、尺寸和单帧，限制 data URL 为 128 KiB、请求体为 144 KiB。头像与其他偏好沿现有账户版本、幂等键和身份隔离保存，不另建上传文件或数据库迁移。

选择后立即更新全站显示，后台串行保存；保存过程中产生的新选择继续保存。失败或回执未知保留输入，提供原键重试；版本冲突由用户核对并采用服务端设置。刷新、重新登录和另一浏览器读取已确认的账户值；前台重新读取不覆盖未保存选择。

`WorkbenchApp.jsx` 持有共享偏好，`appearance.css` 拥有全站调色板和内容画布。主题传到顶栏、侧栏、各模块、菜单与弹层；内容背景只绘制在 `.wb-workspace`。模块保留内容组织和操作位置，使用外层留白、独立内容块及透明间隙露出背景。设置头像和侧栏头像消费同一个值。

语言词库在 `apps/web/src/i18n/locales/`，按模块组织，使用 i18next/react-i18next 的显式词条与插值。导航、工具、帮助、身份提示、动态状态、无障碍名称和日期数字格式使用当前语言；教师输入的名称、正文、代码、公式及导出内容保留原文。无身份入口默认简体中文，不沿用上一账户语言。新建默认导航分组通过 `nameKey` 标记为系统名称；重命名后清除标记。旧导航未带标记时按已保存名称显示，不猜测教师是否使用了默认名称。

账户删除确认列明不可恢复范围，取消不提交。提交后卸载工作台并显示清理进度；未知或未完成状态保留原 Cookie 和请求，同容器其他页退出也不清除该核实载体，刷新后仍可核实，不能以登录失效冒充删除成功。若认证读取确认原浏览器上下文已失效，明确原删除结果无法核实，允许显式重新准备登录；沿现有 bootstrap 建立新上下文，不把 401/409 当删除成功，不清未确认的账户设备资料。服务器确认后清理当前浏览器内该账户的草稿、待上传数据和助手缓存，并阻止迟到编辑重新写入；其他账户设备资料保留。本设备清理失败单独重试。服务器范围和外部副本边界见[账户永久删除](data.md#账户永久删除)，认证证明见[删除交换](../contracts/auth.md#账户删除交换-i08)。

未决退出状态由账户持有，离开设置再返回仍显示同一核实提示和重试动作；其他模块沿工作台现有身份提示位置提供同目标核实，不将退出锁误报为保存或连接故障，原业务草稿保留。未决删除有显式继续入口，可信的另一账户不会仅因本机存在旧删除记录而被锁住；关页接续规则见[账户](identity.md)，不由设置复制认证状态。

## 帮助与更新日志

帮助提供本地简体中文与英文内容：六模块、日程提醒及常见问题。独立目录、首页搜索、章节/文章、面包屑、下一篇；标题和正文按当前语言检索，支持上下键、Enter、Escape、Ctrl/Cmd K。章节与文章有独立 URL，支持刷新、前进后退和新标签；目录与正文滚动按账户保留。联系支持使用常见问题入口，不新增在线客服。

更新日志页面按用户决定仅显示报纸图标和无障碍名称，不显示版本、构建或提交信息。自动生成发布数据与 CHANGELOG 仍由发布流程管理。

## 代码与验收依据

`apps/web/src/features/workbench/WorkbenchSettings.jsx`、`settings-shell.css` 拥有设置；`SupportPages.jsx`、`helpContent.js`、`support-shell.css` 拥有帮助。真实导出在 `apps/web/src/features/reliability/DataManagement.jsx`；退出调用认证 transport。字段和数据保护见[数据管理](data.md)与[认证退出](../contracts/auth.md#退出交换-i07)。

功能边界以上文为准；交互动效、焦点、参考尺寸见[界面规则](../rules/design-and-verification.md)。修改设置时用 `apps/web/e2e/settings-shell.config.mjs` 的隔离真实认证/可靠性服务；帮助用 `help-shell.config.mjs`。资料包及备份恢复用 `manual-data/manual-data.config.mjs`，跨模块草稿、冲突和未确认请求用 `manual-support/playwright.config.mjs`；这些入口均相对于 `apps/web/e2e/`。

完成相关 UI 修改应实际检查桌面及 390px 窄屏、各页面主题/背景组合、头像上传/删除同步侧栏及重新登录读回、键盘菜单、弹层退出中间态、快速反向和焦点恢复；同时确认偏好保存失败可重试、真实导出和退出可用。语言和删号使用 `apps/web/e2e/settings-implementation.config.mjs` 与 `apps/api/test/account-deletion.test.js` 验证真实认证、跨账户和未知结果。后端用 `apps/api/test/reliability.test.js` 核对账户隔离、版本冲突、旧字段兼容及头像输入校验。帮助另检查搜索空结果、无效文章、刷新返回和目录现场。当前验证入口见[核查入口](../plans/run-state.md#核查入口)。
