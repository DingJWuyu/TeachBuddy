# 数据管理与恢复

修改个人资料可带走、误删恢复、账户清理或维护还原的用户行为时读本页。各分区仍拥有自己的内容和删除操作，设置只消费公开能力。协议与恢复顺序归[数据契约](../contracts/data.md)，代码归[公共底座](../subsystems/foundation.md)，核验见[数据验收](../acceptance/data.md)。用户承诺改变时同步本页；实际能力、暂停及未验条件归[运行台账](../plans/run-state.md)。

个人资料包、模块误删恢复和实例备份是三个不同操作：个人包可阅读/取回内容，模块恢复保留原对象，维护备份还原整个实例。个人 ZIP 不覆盖账户。设置不提供最近删除聚合、设备草稿管理、恢复隔离或备份说明 UI，不能因为底层有数据结构或历史组件恢复这些入口。

## 恢复层次与冲突

教师已确认保存的内容随账户持久保留，包括原稿、校对稿、输出、作品版本、引用及对话；在另一设备登录可读取。未上传的编辑草稿与提交中的原始请求留在本设备，不能显示为跨设备已保存。设备视图与面板现场使用当地屏幕，账户偏好按已确认值读取。

上传中的字节不承诺跨刷新恢复；结果未确认时保留原请求及文件身份，重开需重新选择同一文件核实。保存中的新输入、未解决冲突和读取失败不能清除草稿；老师确认采用服务端内容或明确舍弃后才移除相应输入。多标签页不自动覆盖彼此的编辑分支。损坏或未来版本的记录保留原文并提示无法自动恢复。

### 逐模块设备现场

题库保留搜索/过滤、选择及批量顺序、原稿页/缩放/选区和校对/编辑输入；数学保留当前作品、工具、试演参数/步骤/视窗与源码草稿；资源保留列表/分类/选择、预览页与备注；日程保留范围、选段、原始实例日期、列表、编辑输入与滚动；全局保留路由、辅助栏、分栏、对话和未发送输入。恢复先定位稳定对象，布局变化后夹到可见范围。

这些是有效恢复要求，逐字段保证和未实现边界见[设备现场契约](../contracts/data.md#逐模块设备现场)，不能据此推定各页面均已完整接入。

### 从较旧部署备份恢复后的设备

恢复旧部署后，旧的未确认请求冻结，不自动重新执行；老师核对恢复后内容，再明确提交新的意图。原请求和草稿保留，不能把相同版本号当作同一个保存基线。普通服务重启仍核实原请求。

恢复隔离的查看/下载提示与 Agent v2 核实/放弃动作属于保留要求，当前主应用没有通用设备草稿管理入口，完整页面接续也不能从底座实现推断已完成。协议见[恢复点隔离](../contracts/data.md#从较旧部署备份恢复后的设备)，具体未接入项归台账，不自行恢复被移除设置。

## 个人资料包

教师可从设置生成、查询并下载自己的资料包；完成前不显示可完整下载。导出列表经确认可删除服务器上的该次生成包与记录；生成中先取消并等待结束，删除后原下载地址失效。删除资料包不影响教学原件、业务资料或已下载的副本。包内有可离线打开的阅读索引、机器数据与原文件，包含活动和可恢复删除的资料、题目来源快照、各资源文件版本、作品源码与历史、班级资料/成绩/导入证据、日程与通知、账户偏好及公开对话/工具结果。

原稿、公式和附件保持真实内容，外部 HTML 只提供下载，不在索引自动运行。账户秘密、会话、验证码、模型内部记录及尚未上传的设备草稿不进入个人包；历史原文不为删词而损坏。导出失败保留原业务与可重试结果，不输出缺附件的伪完整包。

导入采用内容取回：老师可重新上传原文件、导入数学 HTML 或复制正文/公式；新账户生成新身份和关联。个人包没有批量覆盖账户、恢复原 ID 或整体重建关系的入口。精确范围、快照和完整性见[个人包契约](../contracts/data.md#个人资料包)。

## 误删恢复

各模块从自身入口恢复可恢复删除对象，保留稳定身份、来源、文件与历史关系。设置没有跨模块“最近删除”。日程当前界面永久删除任务，兼容软删除 API 的保留不形成回收站 UI；班级恢复不抢占旧座位，也不复活另行删除的子对象。收录材料删除不级联删除已入库题。

题目、资源和作品的归档/彻底删除按对应规格；永久删除后不能恢复，已有快照、受管文件和下载副本遵守各自保留规则。文件物理回收与自动 TTL 尚未提供，不能把业务条目删除称为空间回收。

## 账户永久删除

设置经独立邮箱确认删除账户。范围包括本账户所有业务资料/关系/文件、偏好、对话、执行恢复记录与认证资料；其他账户不受影响。等待真实任务与文件清理完成后才报告成功，失败或未知继续核实原请求。

服务器确认后清理本设备该账户的草稿、待上传文件和助理缓存；清理失败可单独重试，其他账户设备资料保留。下载副本、外部资料和维护者备份独立存在，接口不搜索销毁它们。恢复删号前备份可能重新带回原账户，维护者需明确选择时间点。接口及清理归属见[数据清理契约](../contracts/data.md#账户永久删除)和[认证删除](../contracts/auth.md#账户删除交换-i08)。

## 部署备份与还原

维护者停服并保存完整数据库、文件及配置，再在独立目标恢复和核对。备份不是仅复制 SQLite；恢复后读回原 ID、源码、附件和关系，旧身份失效，重新登录仍使用备份内账户。恢复点之后的新建账户、改密和业务写入不自动合并，恢复前说明时间点与凭据回滚影响。

未完成删除意图、未知版本/迁移、损坏输入、锁竞争或认证撤销未确认均停止候选开放；失败保留原库与输入，不覆盖回写。已受理新写入后切回旧库属于新的时间点恢复，没有自动跨库合并。当前旧版升级会移除已退役备课/旧班级教学，不重新开放功能；未知升级链明确拒绝。

运行准备见[SETUP](../SETUP.md)，完整停服、校验、认证撤销、恢复点更新与 activate 顺序见[恢复契约](../contracts/data.md#部署备份与还原)。目标环境和真实完整工作日的剩余验收仍按台账处理。
