# 路线图

## 当前状态

当前版本是教师个人工作台底座：

- 账户注册、登录、退出和密码找回
- 教师账户隔离
- 始终存在的首页和设置入口
- 空模块目录与中性模块注册契约
- 账户级工作台布局、分组、排序、拖拽和可见性偏好
- 已验收并合入的账户入口、侧边栏与顶部栏 UI/UX 原型
- SQLite 持久化
- API 回归、真实浏览器验收和构建验证

## 当前方向

2026-09-21 已确认真实 MVP 范围：题库、备课、数学工坊、资源库、班级教学和日程，以及能实际操作全部模块的 Agent。优先面向中国大陆高中教师个人，第一位使用者为高一强基班的实习数学教师。详细交付要求与边界以产品范围文档为准。

首轮布局与模块连接探索已在独立 worktree 的 `prototype/src/workbench/` 中形成内存交互稿。用户已体验并指出视觉层级、冗余工具栏和说明小字、支持页面布局及真实数据衔接问题，该稿未通过整体验收。覆盖与限制见[模块原型行为](../prototype/behavior/modules.md)。接下来的交付目标是具备真实前后端与持久数据的 MVP。

## 推进方式

1. **以产品行为确定契约。** 写清老师的任务、入口、动作、结果、保存与再次使用、失败处理，以及跨模块联系；据此定义数据与接口约定。
2. **在契约下并行实现前后端。** 前端交互与后端数据语义遵守同一份约定，尽早连接真实服务，用实际材料持续联调。后续 Agent 协作由用户另行安排，本次仅完成范围基线记录。
3. **完成已确认的真实能力。** 图片、PDF、Word 和文字的自动提取与拆题；教案、学生资料和练习的可编辑 Word 与可打印 PDF；数学公式、静态图形及动态演示的制作、修改与导出；Office 文件预览与更新；班级记录；重复课程、临时调课与可靠提醒。
4. **接入 pi agent。** 以其作为核心运行时，通过适配后的扩展接入工作台能力。Agent 的操作真实保存，遵守手动操作的同一套规则，并能串联多个模块；具体版本和扩展机制待验证。
5. **完成产品基础与使用质量。** 电脑网页完整使用、平板基本适配、持久数据与跨设备访问、现场保留、个人资料导出、备份和误删恢复，以及可用的设置、帮助、更新日志。
6. **按完整行为验收。** 检查真实材料、导出文件、约定浏览器中的演示离线运行、保存与恢复、Agent 操作及跨模块返回；同时按设计规则验证视觉与易用性。

以上定义推进方式，不锁定六个模块的开发排序。用户已完成范围决策，范围内的行为细节、布局和技术方案交由 Agent 自行收敛，不再要求逐项拍板。长期围绕既定范围持续优化，暂不增加新模块或新的功能方向。

## 范围边界

- 学生个人成绩、错题和薄弱点追踪仅保留为后续候选，当前不做
- 不扩展学生或家长端、学校排课、出勤管理、独立课程标准管理或实体书籍管理
- 自动制作整套 PPT、任意网站自动登录抓题、外部 AI 网页自动化、本地文件自动同步和任意课堂设备兼容不作为本版要求
- 模块业务数据、跨模块协作和 Agent 操作属于本版必须交付的能力，接口、引用更新规则和扩展实现仍需设计
- 当前账户底座继续使用；设置、帮助与更新日志需按已确认范围接入真实内容，部署方案需支持网址访问和持久保存

中性模块注册、模块可见性、自定义分组和自由拖拽能力继续作为架构底座保留。原型历史模块名称仅为外壳交互样例，不构成本版交付清单。

产品仍面向独立教师账户，不包含组织管理、邀请审批、市场或管理员后台。
