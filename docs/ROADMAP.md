# 路线图与发布说明

[返回主 README](../README.md)

## v1.3 状态

v1.3 已完成并结项。

v1.3 的主要成果：

- 演示身份验证和受保护的 API 路由
- 周期性提醒支持
- 从课程到练习单的自动化
- 练习单导出支持
- Resource Vault 模块
- 从基于文件的 JSON 持久化迁移到 SQLite
- 覆盖核心流程的 API 回归测试
- 备课和练习单表单中的 Resource Vault 选择器
- 导出前更丰富的练习单题目编辑能力

## 已知限制

- 身份验证仍面向演示和本地使用，尚未达到生产就绪标准
- 尚未建立 UI 自动化测试
- 前端仍是单页外壳，尚未采用基于路由的结构
- 为了保持简单，部分 SQLite 字段仍以 JSON 数据块形式存储

## v1.4 候选重点

- 为工作台外壳和模块流程增加 UI 测试
- 增加基于路由的导航和更深入的工作空间视图
- 增加以日历为中心的视图并改进排程
- 加强身份验证并增加用户设置
- 增加跨模块搜索
- 增加通知和更丰富的跨模块工作流支持
