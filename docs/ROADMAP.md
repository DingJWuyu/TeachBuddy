# 路线图

## 当前状态

当前实现仍是教师个人工作台底座：

- 账户注册、登录、退出和密码找回
- 教师账户隔离
- 始终存在的首页和设置入口
- 空模块目录与中性模块注册契约
- 账户级工作台布局、分组、排序、拖拽和可见性偏好
- 已完成账户入口、侧边栏与顶部栏的 UI/UX 原型
- SQLite 持久化
- API 回归、真实浏览器验收和构建验证

业务模块页面目前仍是占位，第一版产品范围已经确认，具体功能尚未完成设计与实现。

## 第一版方向

第一版建设 **题库、备课、数学工坊、资源库、班级教学、日程** 六个功能模块，并以 Agent 作为串联各模块内容与能力的超级入口。

各模块的完整范围、相互关系、已确认行为和待细化事项统一记录在[第一版产品范围](PRODUCT_SCOPE.md)。

后续推进围绕以下工作展开，当前不预设模块的开发顺序：

1. 保持账户入口、侧边栏和顶部栏的设计基线，细化六个模块的页面、交互及协作流程。
2. 按这些教学需求确定首页的信息优先级、布局与交互，并与工作台外壳一致衔接。
3. 在实际教学材料和使用场景中验证题目整理、材料复用、数学演示、教学记录、日程及工作台内提醒。
4. 细化 Agent 的协作方式和实现边界，完成各模块及跨模块能力的实现与响应式验收。

## 长期迭代

长期优化这六个模块及已确认的跨模块能力，持续改善完整性、易用性、可靠性和协作体验。暂不新增模块或新的功能方向。

学生个人的成绩变化、错题与薄弱点追踪仅保留为后续候选，不进入当前计划。产品继续服务教师个人，不扩展学校或组织管理；完整边界见[第一版产品范围](PRODUCT_SCOPE.md)。
