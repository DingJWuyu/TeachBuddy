# 路线图

[返回主 README](../README.md)

## 当前状态

当前版本是教师个人工作台底座：

- 账户注册、登录、退出和密码找回
- 教师账户隔离
- 始终存在的首页和设置入口
- 空模块目录与中性模块注册契约
- 账户级工作台布局、分组、排序、拖拽和可见性偏好
- SQLite 持久化
- API 回归、真实浏览器验收和构建验证

## 下一步候选

- 引入第一个独立功能模块，并验证其身份、侧栏入口、自有面板和后端能力边界
- 为模块能力增加更明确的版本和兼容性约束
- 根据真实模块需求扩展通用账户数据存储接缝
- 增加可观测性、限流和更完整的生产部署策略

产品仍面向独立教师账户，不包含组织管理、邀请审批、市场或管理员后台。
