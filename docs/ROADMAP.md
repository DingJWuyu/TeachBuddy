# 路线图与发布说明

[返回主 README](../README.md)

## 当前状态

教师个人工作台的账户、数据边界、功能模块注册和工作台布局已完成：

- 开放注册、自动登录、退出、重新登录和邮箱验证码找回密码
- 周期性提醒支持
- 从课程到练习单的自动化
- 练习单导出支持
- Resource Vault 模块
- 从基于文件的 JSON 持久化迁移到 SQLite
- 所有教师业务数据、上传文件和工作台偏好按账户隔离
- 模块可见性、分组、排序和拖拽布局持久化
- API 集成测试和真实 Web/API/临时 SQLite 的 Playwright 浏览器验收
- 备课和练习单表单中的 Resource Vault 选择器
- 导出前更丰富的练习单题目编辑能力

## 当前边界

- 保留简单 Bearer 令牌模型，未引入刷新令牌、会话管理或单点登录
- 密码找回依赖标准 SMTP；开发环境没有 SMTP 时验证码写入 API 日志
- 前端仍是单页外壳，尚未采用基于路由的结构
- 为了保持简单，部分 SQLite 字段仍以 JSON 数据块形式存储

产品仍然只面向独立教师账户，不包含组织管理、市场、邮箱验证、邀请审批、限流或其他生产控制层。

## 后续候选重点

- 增加基于路由的导航和更深入的工作空间视图
- 增加以日历为中心的视图并改进排程
- 增加跨模块搜索
- 增加通知和更丰富的跨模块工作流支持
