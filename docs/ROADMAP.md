# 路线图

[返回主 README](../README.md)

## 当前状态

当前版本是教师个人工作台底座：

- 账户注册、登录、退出和密码找回
- 教师账户隔离
- 始终存在的首页和设置入口
- 空模块目录与中性模块注册契约
- 账户级工作台布局、分组、排序、拖拽和可见性偏好
- 已验收并合入的侧边栏与顶部栏 UI/UX 原型
- SQLite 持久化
- API 回归、真实浏览器验收和构建验证

## 当前方向

1. 保持已验收侧边栏和顶部栏的设计基线。
2. 按 TeachBuddy 自身需求确定首页的信息优先级、布局与交互，不复制 EMStudio 的业务功能设计。
3. 首页确定后，统一完成侧边栏、顶部栏与首页在桌面、平板和手机上的响应式验收。

## 暂缓范围

- 课程表、班级、规划器、课程、学生、课堂作业、成绩、出勤和课程标准等业务功能模块
- 模块业务数据、跨模块协作、教程生命周期和生产后端契约
- 账户设置、认证页面和生产部署的进一步 UI/UX 改造

中性模块注册、模块可见性、自定义分组和自由拖拽能力继续作为架构底座保留，但不构成近期业务模块交付承诺。

产品仍面向独立教师账户，不包含组织管理、邀请审批、市场或管理员后台。
