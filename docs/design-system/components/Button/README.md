# Button

按钮用一句动作说清会发生什么，三种分量对应三层重要程度。

- **主按钮**：`tb-primary` 底、`tb-on-primary` 字，44px 高（工具区 36–40px），圆角 `tb-r-md`，带一层同色柔和投影。每个区域最多一个。
- **次按钮**：`tb-fill` 底、`tb-ink` 字，悬停换 `tb-fill-hover`。
- **幽灵按钮**：透明底、`tb-muted` 字，悬停出现 `tb-fill-hover`。用于返回、取消、辅助操作。
- **小号**：30px 高、圆角 9px、12.5px 字，用在卡片头部和面板标题栏。
- **危险**：`tb-danger-soft` 底、`tb-danger` 字；执行前必须确认。
- 动效：悬停主按钮上移 1px；按下缩放到 0.97，用弹性曲线回弹。
- 图标在文字左边，17px，描边 2–2.2px。纯图标按钮必须有 `aria-label`。
- 文案写动作本身：“上传资料”“发送验证码”，不写“提交”“确定”。
