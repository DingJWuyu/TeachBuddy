# Composer

和教学助理说话的地方。首页里它是主角，模块侧栏里是紧凑版。

- 使用方提供：草稿文字、引用的题目、模型列表与当前模型、是否在生成、发送与停止回调、保存状态文案。
- 外框：`tb-surface`，1px `tb-line`，圆角 24px，下方一层长而淡的投影；获得焦点时边框换 `tb-accent-line` 并出现 `tb-ring`。
- 文本区自动增高，首页最高 260px，侧栏最高 180px；占位文字用 `tb-faint`。
- Enter 发送，Shift + Enter 换行，输入法组字时 Enter 不发送。提示写在底栏中间，有保存状态时换成状态文案。
- 模型选择是一枚胶囊，绿色小圆点表示可用；展开为向上弹出的菜单，每项写一句特点。
- 发送按钮是 38px 圆形 `tb-primary`；不可发送时变成 `tb-fill` 加 `tb-faint` 图标；生成中换成 `tb-ink` 底的停止方块。
- 生成中，外框用四种学生色的圆锥渐变缓慢旋转（3 秒一圈），这是全工作台唯一一处持续动画。
- 引用的题目显示在输入框上方，是 `tb-accent-soft` 小胶囊，可单独移除。
