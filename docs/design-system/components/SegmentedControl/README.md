# SegmentedControl

在两到四个并列视图之间切换，高亮块会滑到当前项，告诉人“你从哪儿到了哪儿”。

- 轨道：`tb-fill` 底加一圈 `tb-line-soft` 内描边；全局导航用胶囊圆角，模块内的视图切换（日历 / 任务）用 13px 圆角。
- 高亮块：`tb-surface`，两层柔和阴影；位移与宽度都用 460ms 快进慢出曲线过渡。
- 文字：未选中 `tb-muted`，选中 `tb-ink`，14px / 600。
- 使用方提供：选项文案、当前值、切换回调。每个按钮用 `aria-pressed` 表示状态。
- 当前页面不属于任何一项时（例如在题库里），高亮块淡出，不要停在错误的位置。
- 切换会改变整块内容时（日历 ⇄ 任务），把内容更新包进视图过渡，让舞台变形，而不是硬切。
