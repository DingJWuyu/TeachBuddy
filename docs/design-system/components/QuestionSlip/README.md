# QuestionSlip

题库左侧列表里的一道题：标题、题干摘录、题型与标签，一眼能认出是哪道题。

- 使用方提供：标题（为空时用题干前 36 字）、题干的第一段、题型、最多两个标签（多出的显示“+N”）、是否选中。
- 默认透明底；悬停 `tb-surface-2` 加一圈 `tb-line-soft`；选中 `tb-accent-soft`，右上角出现 `tb-accent` 小圆点（弹性出现）。
- 题干摘录最多两行，下沿渐隐，不用省略号截断公式。
- 题型按题库里的顺序轮流使用四种很淡的系统色底（蓝、黄、紫、橙的 soft 版本）配同色深字，标签一律 `tb-fill`。
- 列表进入时依次上浮，每项间隔 30ms，最多错开 150ms。
- 右侧的阅读页把题干放在方格纸上（17px / 1.9），左侧一道橙色页边线；答案默认折叠，避免投屏时提前露出。
