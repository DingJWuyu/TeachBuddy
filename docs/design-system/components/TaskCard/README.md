# TaskCard

日程任务看板上的一件事：什么时候、属于哪个标签、清单做到哪儿了。

- 使用方提供：标题（为空时用清单第一项）、时间（今天显示起止，之后的日子只显示开始时刻，待安排不显示）、标签（第一个标签的颜色和名字，多出的写“+N”）、清单（文字、优先级、是否完成）、备注、点击回调。
- 清单最多显示 4 项，其余写“还有 N 项”。完成的项打勾、划线、变淡；“重要”用 `tb-danger-soft` / `tb-danger`，“稍后”用 `tb-fill` / `tb-muted`。
- 左下角的进度环用 `tb-accent`，全部完成时卡片标题变为 `tb-muted`。
- 卡片底 `tb-surface`，圆角 16px，常态 `tb-shadow-1`；悬停上移 2px 换 `tb-shadow-2`；打开编辑时外圈 2px `tb-accent`。
- 看板三列：今天（`tb-accent-soft`）、接下来（按日期分组）、待安排（`tb-yellow-soft`）。卡片进入时依次上浮，间隔 35ms。
- 不在卡片上直接改数据；点开后在右侧编辑面板里改，保证保存与冲突处理只有一个入口。
