TeachBuddy 是给老师用的工作台：题库、资源库、数学工坊、日程，还有一位随时能聊的教学助理。视觉语言围绕一句话：**像 Apple 一样克制，像课堂一样有生气**。版面由白与中性灰撑起，只有一种动作色（系统蓝）；生气来自会回应操作的动效和恰到好处出现的系统色。

可运行的完整原型在 `teachbuddy-app/`：打开 `teachbuddy-app/index.html`，任意邮箱 + 8 位以上密码即可登录；首页有“载入一周的示例数据”。新界面层的源码在 `teachbuddy-app/ui/tbx/`（`src/` 是组件，`styles/` 是样式，`build/BUILD.txt` 说明构建方式）。

## 原则

每次改版时反复用到的几条，做新东西前先对一遍。

1. **少即是多。** 一个元素说不出它存在的理由，就去掉：概览条、重复的计数、没人点的提示、“进入某某模块”这类不属于当前页面的出口。宁可少一个功能，也不要一个吵闹的界面。
2. **动作是蓝色，不是黑色。** 主按钮用系统蓝；次要按钮是浅灰胶囊。危险操作才用红色，而且要真的像红色警告，不能是灰色。
3. **不写死文案。** 界面上的每一句话都走翻译（`tx()`，英文在 `ui/tbx/src/locales/en.js`），日期也按语言格式化。新增一句中文，就同时补上英文。用户自己的数据不翻译。
4. **为最长的语言排版。** 英文大约是中文的 1.6 倍宽。按钮不换行、不溢出；放不下先换更短的说法，再缩小，最后才省略。新组件要在中英文、浅深色下各看一遍。
5. **能复用就不要重画——不只是样子，还有行为和动效。** 图标、按钮、对话框、菜单、浮层、选择器、拖拽、折叠、进出场动画都先找现成的（`ui/tbx/src/kit/`、`ui/tbx/styles/kit.css`）。同一个意思在全站只有一张图、一个样子、一种动法。发现某处自己造了轮子，就把它换回共享件，再把共享件补齐。新写一个组件之前，先在 kit 里找；kit 里没有、但第二个地方也会用到的，就加进 kit。
6. **每一次删除都要确认，没有例外。** 删除、移除、解散、丢弃，以及退出登录、删除账户——全部先确认再执行。确认只有两种形态，全站共用：
   - **就地确认**（`ConfirmButton` / `ConfirmMenuItem`）：按钮或菜单项第一次点击变成红色的“确认删除”，3.2 秒内再点才执行；Esc、点别处或超时就复原。用于列表行、菜单、面板里的小动作。
   - **确认对话框**（`ConfirmDialog` / `confirmDialog()`）：同一个模板——圆角 22、44px 图标块、19px 标题、一段说明、右下角胶囊按钮（取消灰，危险红 `#ff3b30`，非危险蓝）。用于影响较大或需要多选一（“只删这一次 / 删除全部”）的情况。
   文案可以按场景不同；特殊要求（如删除账户要输入邮箱）放进对话框正文里，模板不变。可以撤销的编辑（编辑器里删掉一行字）不打断。
7. **文案像 Apple。** 短、具体、说人话；告诉用户发生了什么、接下来会怎样，而不是解释系统。
8. **深浅色都只用令牌。** 不出现一半灰一半黑的拼接；深色模式里避免大面积纯白或刺眼的高对比。
9. **示例要诚实。** 模拟的数据和协议要明说是示例。
10. **改一处，查一片。** 修一个问题时，顺手找出同类的地方一起改，并把规则记在这里。
11. **每个页面都放在卡片上。** 内容不直接摊在背景上：模块页是圆角 24 的白色（深色 `#1c1c1e`）卡片，背景只在卡片之间露出来。
12. **一个输入框只有一圈焦点环。** 焦点环画在整个输入框（含图标）外面，里面的 `input` 不再画自己的轮廓。
13. **编辑中的作品是一张纸。** 编辑器里的公式、图形、网页预览始终放在白纸上（深色模式也是），作品自己的颜色不被反转——老师看到的就是学生会看到的。缩略图只是预览，可以跟随深色。
14. **跟着容器排版，不只跟着屏幕。** 辅助栏打开后，同样的屏幕宽度里模块只剩一半空间。布局用容器查询（`@container`）决定何时把导航卡收成一行、何时把按钮叠起来。
15. **空白页要给出下一步。** 空的画布、空的列表不只写“还没有内容”，而是给出两三个能直接点的开始方式。
16. **一个动作只放一个入口。** 同一屏里不要同时出现两个“新建题目”或两个“从资料收录”。导航卡里有了，空状态就只解释，不再重复按钮（除非整个模块还是空的）。
17. **改了结构，就改文案。** 文案里提到的位置（“在左侧的‘已归档’里”）必须和当前界面一致；挪动了入口，要把指向它的提示一起改掉。CSS 的 `content` 里不写文字，所有文案走翻译。
18. **同一个分类在哪儿都是同一种颜色。** 题型按顺序领一种色（橙、蓝、紫、绿、粉、青）：导航卡里的圆点、列表里的胶囊、阅读页的标签用的是同一个颜色。
19. **图表只说真话。** 一张图只有一根纵轴；得分率统一用 0–100%，不同满分的考试也能放在一起。缺考、缺分、没考到的标签不画成 0，而是断开或写“缺分 / 未考到”。两条以上的线要有图例，悬停要有说明；网格和坐标轴退到最淡。
20. **人用颜色认，不用颜色排。** 学生、班级按 id 领一种色（蓝、绿、橙、紫、粉、青、靛、黄），头像、座位、导航圆点用同一个颜色；颜色不表示好坏，名次和分数也不改变颜色。
21. **拖拽要有手感，也要能撤回。** 列表排序全站一种拖法（侧栏模块、任务面板的事项都一样）：拖起时原位置变淡；跟手的是一张只有“图标 + 文字”宽度、略透明的小卡（`.tbx-drag-ghost`），**按下时手指抓住的那一点始终在光标下**（记下按下点相对行的偏移，横向不超过小卡宽度；资料卡抓在小卡的图标上），小卡不能飘到光标右下方；拖动过程中其他行**一动不动**，落点只用一条左端带小圆圈的蓝色横线（`.tbx-drop-line`）标出；松手后其他行再用 FLIP（`useFlip`）滑到新位置。改动先在界面上生效，再保存；保存失败就回到原样并说明原因。
23. **菜单只有一种。** 所有“…”菜单、右键菜单、下拉选项共用一套规格（`kit.css` 顶部）：面板内边距 6、圆角 14；每一项圆角 8、最小高 34；悬停的灰块四周都离面板边缘 6px，不贴角；危险项红字，悬停淡红底。选中用右侧蓝色对勾（`.tbx-pop-check`）。原 app 里自带的下拉和菜单（学期“复制来源”、学期“…”等）也按这套规格改，不留贴角的灰块。
24. **浮层不出屏幕。** 菜单、日期 / 时间选择器、筛选都用同一个 `Popover`：挂在 body 层（不被卡片裁掉、不被别的层盖住），默认在锚点下方，空间不够就翻到上方，始终离窗口边缘至少 12px。日期用 `DatePicker`（周一开头的月历；点标题切到月份，再点切到年份，选完逐级回到日历），时间用 `TimePicker`（左边 0–23 时，右边 00–59 分，任意一分钟两下选完：选小时不关，选分钟即完成）。
25. **从哪里来，就从哪里出现。** 由某个格子、按钮引出的浮层（日历的“还有 N 项”、筛选菜单）贴着它打开并从它的位置放大出来，不跳到屏幕中央。
26. **portal 也要穿同一套衣服。** app 直接挂到 `<body>` 的浮层（日历对话框、菜单、“还有 N 项”）加上 `tbx-portal-host`，构建时组件样式的作用域是 `:is(.wb-shell, .tbx-portal-host)`，所以它们和页面里的控件长得一样。
27. **固定定位的东西，祖先不要有 transform / containment。** 页面入场动画只用 `backwards` 填充，不留下 `transform`；日历容器不做尺寸容器。否则拖拽时跟手的卡片会以祖先为参照，偏出一大截。
28. **同一类页面，同一种骨架。** 列表型模块（题库、资源库、数学工坊、班级）和日程同构：主卡片在左，右栏在右、与辅助栏同宽，助理盖住右栏。新模块直接用 `Rail / RailSection / RailItem / RailAction / RailHint / PaneTitle / PrimaryButton`，不再各写一套导航卡。
29. **辅助栏只放助理。** 模块自己的筛选、管理、详情信息都放进右栏；同一个功能不在右栏和辅助栏各出现一次。
30. **真正的输入框是方角的，只是看不见。** 需要输入的地方，`input` / `textarea` 本身是方角（`border-radius: 0`）、透明、无边框、无轮廓；圆角、底色和焦点环都画在包住它（连同图标）的外层上。这样光标和选区不会被圆角切掉，也不会露出第二个方框。新建任务的标题和备注、资源库搜索、侧栏“新建分组”都是这样。外层放在会裁切的折叠容器里时（侧栏的折叠区），焦点只画内描边，不画外光晕——外光晕会被裁成方角露出来。
31. **不要闪。** 闪烁是最难受的效果，必须杜绝：
   - 暂时用不了的按钮**变暗、不可点**（`disabled`），不要从界面上拿掉，否则工具栏会跟着跳。
   - 状态变化时控件**尺寸不变**：筛选按钮选中后显示数量而不是类别名，名称和数量叠在同一个格子里，宽度由较宽的那个决定一次。
   - 输入搜索时，打字停顿约 280ms 才去查；查的过程中旧结果留在原地，数量和标题不变成“正在读取…”；已经加载过的缩略图记在内存里，卡片离开再回来时直接显示。
   - 关闭一块面板就直接收起，不要先跳回别的内容再收起（任务面板关闭时，用一张静止的副本跟着收起）。
32. **并排的几个选项，高亮会滑过去。** “首页 / 日程”、“日历 / 任务”、“缩略图 / 列表”都是同一种分段控件：白色高亮块滑到当前项（`kit/segmented.jsx` 的 `Segmented` / `useSlidingThumb`）。新的并排选项直接用它。当前项在悬停时不变色、不加底色——高亮块就是全部的状态。
33. **按类别筛选只有一种模板。** 模板是任务面板的“按标签筛选”：共享的 `Popover`，第一行“全部…”，下面每类一行可多选，点了不关菜单，右侧蓝色对勾；按钮选中后变蓝，显示选中的个数（`kit/filter.jsx` 的 `FilterMenu`）。选中的类别以小胶囊列在标题下面，可以一个个去掉；类型胶囊带页面图标，标签胶囊带它的彩色圆点，两者一眼能分开。
34. **下拉选择只有一种样子。** 原生 `select` 一律去掉浏览器自带的箭头，用和日程对话框相同的向下箭头，离右边 12px，右侧留 36px（`kit.css` 的统一规则）。不允许箭头贴边。
35. **提示出现在操作的地方。** 操作完成的提示（“已移动 2 份资料”）出现在当前卡片的水平中央、操作条的上方，几秒后淡出；不放在整个页面的中央。批量操作完成后操作条不收起，可以接着做下一步。
36. **已归档的东西都能彻底删除。** 任何“已归档”视图除了恢复，都要提供“彻底删除”（单个和批量），并按第 6 条先确认。
37. **用起来像文件管理器。** 凡是管理文件的地方：拖文件到文件夹就是移动，拖到标签就是加标签，拖到“已归档”就是归档，拖动时跟手的是小卡（`.tbx-drag-ghost`），目标行变蓝；在空白处按住拖出一个框，框到的就被选中（按住 ⇧/⌘ 是加选）；文件夹可以嵌套、折叠，打开的文件夹图标变成打开的样子，再点一次回到全部。Don't make users think。
39. **弹窗的背景一打开就是虚化的。** 遮罩层自己不做透明度渐变：父元素在渐变中（opacity < 1）时，子元素的背景模糊看不到后面的内容，要等渐变结束才突然模糊，造成闪烁。所以只让遮罩的颜色和对话框本身渐入，模糊从第一帧就在（`shell.css` 的 `.cal-overlay-presence` 规则，日程和资源库的对话框都走这里）。
40. **能拖就让它能拖。** 凡是位置、归属、顺序可以变的东西（模块、分组、事项、资料、文件夹、标签），只要拖动比点菜单更顺手，就主动支持拖拽，并按第 21 条的手感来做。
38. **标签是同一个系统。** 日程的标签和资源库的标签用同一套八色（`kit/colors.js`，与日程标签对话框相同），同一种新建 / 编辑对话框（名称 + 颜色 + 就地确认删除），在列表、卡片、筛选胶囊里都是“彩色圆点 + 名字”。
22. **服务器说的话，也要翻译。** 后端返回的提示带上模板和参数（`template` + `params`），界面用 `tx(template, params)` 显示，英文界面不会冒出一句中文。

## 内容与语气

- 像一位年轻、和气的同事说话：直接、具体、不说教。用“你”，不用“您”（法律与账户删除等严肃场景除外）。
- 按钮写清会发生什么：“载入一周的示例数据”“发送验证码”，不写“提交”“确定”。同一个动作从按钮到提示用同一个词。
- 空状态是一句邀请，不是一句抱歉：“收件箱空了。想到要做的事，随手记在这里。”
- 出错时说明发生了什么、怎么办，不道歉、不含糊。
- 不用 emoji 做装饰；不用全大写标签；标题里不单独给一个词换颜色或加粗。
- 课堂里的说法优先：值日、红笔、练习册、待安排、今天的课。

## 颜色

颜色少，所以每一处都有含义。界面骨架是白与中性灰，没有色调偏移；唯一的动作色是系统蓝；其他系统色只出现在小地方。

- 页面底色 `tb-canvas`（#f5f5f7），侧栏、面板和卡片一律 `tb-surface` 白；面板里安静的内区用 `tb-surface-2`。不用点阵或纹理铺底（“网格”背景是设置里的可选项）。
- 正文 `tb-ink`（#1d1d1f），次要说明 `tb-muted`（#6e6e73）；`tb-faint` 只给占位符和时间戳。
- **系统蓝 `tb-brand` / `tb-primary`** 是唯一的动作色：主按钮（白字，4.7:1）、“今天”、勾选框、链接与焦点环（链接文字用更深的 `tb-accent`）。一屏里只有一个蓝色主按钮。
- 选中的侧栏行用 `tb-fill-hover` 灰底，不用彩色底；只有图标换成该模块的颜色。
- 模块各认领一种系统色，只用在它的图标方块和侧栏图标上：题库橙 `tb-orange`、资源库蓝、数学工坊紫 `tb-lavender-deep`、班级绿（`#4cd964 → #30b14c`）。图标方块是由浅到深的同色渐变配白色线条，像 iOS 的设置图标。
- 黄色 `tb-yellow` 只给未读计数这样的小标记；红色 `tb-alert` 只给“现在”线、角标和红笔勾；绿色 `tb-mint` 表示进行中与完成。
- 头像是灰色渐变上的白色首字母，和“通讯录”一样。
- 助理生成回答时，输入框边缘流过一圈橙、粉、紫、蓝、绿的光，这是全界面唯一一处彩色渐变。
- 夜间模式是纯黑底配石墨色面板（#1c1c1e），系统色换成夜间版本（如蓝 #0a84ff）。每对文字与底色在两种主题下都满足 4.5:1，数值写在 tokens 的说明里。

## 字体

- 中文与界面用系统字体（苹方 / 微软雅黑），大标题用 `display` 族，字距收紧（-0.02em 到 -0.03em），字重 700–750。
- 层级：`display` 每屏最多一个；模块标题 `title-1`；对象标题（一道题、一个月份）`title-2`；分区与对话框 `title-3`。
- 题目正文用 `reading`（17px / 1.9 行高），对话与描述用 `body`，界面默认 `ui`，标签与按钮用 `label`。
- 数字在表格、时间和计数里用等宽数字（tabular-nums）。

## 形状与层次

- 圆角按角色递增（12 / 18 / 26px）：图标按钮 `tb-r-sm`，按钮与输入框 `tb-r-md`，卡片与面板 `tb-r-lg`，大面板与输入框外框 `tb-r-xl`，标签与分段控件 `tb-r-pill`。不要所有东西用同一个圆角。
- 层次用三级阴影：常态面板 `tb-shadow-1`，悬停抬起 `tb-shadow-2`，浮层、菜单、对话框 `tb-shadow-3`。不用描边线条代替层次。
- 浮在内容上的工具条（资源库筛选条、数学工坊工具坞、搜索）用半透明“玻璃”材质：`tb-surface` 82%–92% + 背景模糊。
- 纹理只留在有意义的地方：题目正文是带橙色页边线的方格纸。其余表面都是干净的白与灰。

## 动效

动效回应人的操作，并说明发生了什么变化；不为了动而动。

- 曲线：界面过渡用 `cubic-bezier(.22,1,.36,1)`（快进慢出）；有弹性的小细节（按下、勾选、小圆点出现）用 `cubic-bezier(.34,1.56,.64,1)`。
- 时长：悬停与按下 120ms，常规状态 220ms，面板与页面 420ms，大的形态变化 520–700ms。
- 按下缩小到 0.96–0.98；卡片悬停上移 2–4px 并换到 `tb-shadow-2`。
- 进入页面时内容上浮 6–14px 淡入，列表项按 30–40ms 依次出现。
- 分段控件的高亮块会滑动到当前项（全站同一个 `Segmented`）；日程的“日历 ⇄ 任务”用视图过渡让舞台变形。
- 同一批内容不论从哪里出现（切进页面、搜索、切换缩略图 / 列表视图），都用同一个依次上浮的入场。
- 助理生成回答时，输入框边缘有一圈系统色光缓慢流动；回答末尾有闪烁光标。
- 系统开启“减少动态效果”时，所有动画降为瞬时。

## 登录与注册

和工作台同一套克制的语言：左边一块浅灰（#f5f5f7）舞台站着四个角色，右边白底上一张居中的表单。没有装饰文字，没有渐变。登录页的动作色是墨黑（#1d1d1f）而不是蓝：颜色交给左边的角色，表单保持安静，也和黑色图标呼应。

- **四位角色**沿用原型最初的几何造型，形状圆润一些，用系统色：
  - 靛蓝高个是**老师**，有圆框眼镜和发髻；
  - 黑色是**戴红领巾的学生**；
  - 黄色是**好奇的学生**，头顶一根呆毛；
  - 橙色是**最小的学生**，头顶一棵嫩芽。
- **互动**保留原型的全部编排（跟随指针、输入时探头、显示密码时转开、出错一缩、成功欢呼），再加上：
  - 眼睛跟着输入光标读字，每敲一个字有一位学生点头；
  - 闲着时有人推眼镜、跳一下、歪头、弹一弹；
  - 输入密码时，红领巾学生偷瞄，老师眼镜反光，橙色学生闭眼；
  - 勾选“记住我”时老师点头；悬停会抬头脸红，点击会跳起来说一句话；
  - 成功时依次跳起、撒彩纸、嫩芽长大。
- **表单**：品牌图标居中在标题上方；32px 标题加一句不随功能过时的说明（登录：“教学的一切，都在这里。”注册：“一个账户，开启你的全部教学。”）；50px 白底细边输入框，聚焦时描边变成墨黑并有一圈很淡的灰色光晕；主按钮与勾选框是墨黑；链接 #0066cc；底部一条细线隔开“还没有账户？创建账户 ›”。

## 页面结构

- 左侧是一整块浮起的白色侧栏（品牌 + 账户 + 学期 + 模块），右侧是开放的画布；顶部没有横贯全屏的导航条，只有透明的工具区：侧栏开关、首页/日程/支持的分段控件、搜索胶囊、图标按钮和最右边的 AI 助理按钮（✦）。
- 首页是教学助理的工作区：左边是对话列表（今天 / 昨天 / 最近 7 天），右边是对话；空状态时问候、输入框和四个建议卡片居中排在一列。
- 每个模块页都由圆角卡片组成，背景只在卡片之间露出来。
- **模块布局和日程一样（`kit/rail.jsx` + `styles/split.css`）**：题库、资源库、数学工坊、班级都是“左边一张主卡片 + 右边一条栏（rail）”。右栏和日历右栏、辅助栏一样宽（340 / 320 / 300），离主卡片 14px。
  - **主卡片顶部**：模块色图标块 + 当前看的是什么（“全部作品”）+ 数量，然后是搜索、视图切换，最右一个蓝色主按钮（新建作品 / 上传资料）。放不下时工具整行换到标题下面，标题不被挤。
  - **右栏**：只放“看什么”——分类、文件夹、题型、标签、班级，一节一个标题（15px 粗体 + 灰色数量），右边是 32px 圆形按钮（新建是蓝色 +，管理是铅笔）；行高 40、圆角 12，当前项浅蓝底；可编辑的行悬停时数量换成“…”；最底下固定一行“已归档”；需要时有一行可点的助理提示。
  - **新东西出现在哪儿，+ 就放在哪儿**：新题目、新作品、新资料出现在主卡片里，按钮在主卡片顶部；新班级、新文件夹、新标签出现在右栏里，+ 在那一节的标题旁边。
  - **AI 助理盖在右栏上**：点顶栏最右的助理图标（✦），面板从右往左滑过右栏，右栏随后淡出，主卡片一动不动；和日历完全一样。辅助栏里只有助理，不再有“分类与标签”“文件夹与标签”“资料信息”这类和右栏重复的标签页。
  - **窄屏**（≤950px）：右栏收成主卡片上方的一行可横向滑动的胶囊，“已归档”在行尾。
- 帮助是目录卡 + 阅读卡。
- 日程可在“日历”和“任务看板”之间切换，详见下面的“日程”。

## 外壳：侧栏、顶栏、辅助栏

外壳只负责框架；辅助栏里放什么由各模块决定。

- **侧栏收起**：侧栏宽度在 420ms 内收成 64px 的图标栏。昵称、学期、分组标题一边收起自己的高度、一边上移淡出；模块文字先淡去，图标同时上移，正好落在图标栏里的位置（横向位置全程不变）。展开时反过来，文字稍晚一拍淡入。
- **当前模块**：浅灰底、文字加粗，图标换成模块色（题库橙、数学工坊紫、资源库蓝）；不用整块蓝底。
- **学期**：浮层从侧栏右侧弹出，不被页面遮住。“复制来源”下拉框总能打开；还没有别的学期时，里面只有一行灰色的“无”，大小和一个学期一样，按钮上写着“还没有其他学期”。编辑学期的“…”里，“删除学期”是红色的就地确认；最后一个学期也可以删。
- **账户行**：头像、昵称和地球图标在同一行，整行和下面的学期按钮一样宽；悬停时灰底覆盖整行。
- **语言**：地球图标右下角有一枚当前语言的小国旗。
- **模块图标**：侧栏、模块首页、帮助、助理里同一个模块用同一张图：题库是书，数学工坊是带 x 的根号。
- **分组**：原来的“工作台”就是老师自己的分组。整行分组标题都可以点，只负责折叠 / 展开，悬停是和模块行一样的灰底；重命名、解散都在“…”里（解散要就地确认），不靠双击。折叠时组内各行淡出、高度平滑收起，不会先闪出来再收。底部“新建分组”就地变成输入框；名字不能和已有分组重复，也不能叫“未分组”，输入框下方会直接说明原因。空分组显示一块虚线占位“把模块拖到这里”。没有分组的模块放在“未分组”里：有未分组的模块、或者所有分组都解散了，这个标题就会出现。收起成图标栏时，分组标题不占位置，图标之间没有空隙。
- **拖动**：按住移动 5px 开始（触屏长按 320ms）。按全站统一的拖法（原则 21）：原位变淡，跟手的是“图标 + 名字”宽度的半透明小卡，其他行不动，落点是一条带小圆圈的蓝线；放下后其它行滑到新位置。拖动时“未分组”会临时出现，方便把模块拖出分组。拖到折叠的分组上停一会儿会自动展开；分组标题也能拖动排序。拖到垃圾桶上时它变红、晃一下，文字变成“松开，移到垃圾桶”。
- **垃圾桶**：整行宽度，与模块行一致；点开向下展开列表，每一项悬停出现“恢复”，也可以直接拖回侧栏。
- **顶栏图标**：通知、反馈、使用教程、隐私，以及最右边的 AI 助理按钮：一大一小两颗四角星（`sparkles`，全站助理都用这张图）。因为助理在日程和各模块里都是盖在右栏上，而不是挤出一栏，它就是“打开 AI 助理”，不再是“辅助栏开关”。数字角标缩小并贴在右上角，不盖住图标。
- **通知**：点一条消息只是把它标为已读——文字带动画划掉、变灰，弹层不关；再点一次恢复。想去日程看，点行尾的“›”。删除消息是拖到底部的垃圾桶，松手后垃圾桶变成红色的“确认删除”，再点才删。
- **反馈附件**：输入框下方一个回形针按钮“附上截图或文件”，选好后变成文件小标签（可移除），按钮变成“继续添加”；也可以直接粘贴截图。
- **搜索**：Spotlight 浮层在屏幕上方约 1/6 处，宽 560，高度随结果增长、最多 460，不压在屏幕正中。
- **弹层**：主按钮一律是系统蓝的胶囊（发送、开始吧），不用黑色。发送反馈后按类型给出不同的回复：
  - 建议：“好主意，收到了。” / “每一条建议，我们都会认真读完。”
  - 错误报告：“谢谢你帮我们找到它。” / “我们会尽快修好这个问题。”
  - 问题：“你的问题，我们收到了。” / “我们会尽快给你答复。”
  - 赞扬：“这句话，我们会记很久。” / “谢谢你，这对我们意义重大。”
- **教程完成**：页面压暗、模糊，夜空里放约七秒烟花（牡丹、双环、金色垂柳、二次分裂、偶尔一颗心），中间一张卡片：绿色对勾画出来，“一切就绪。”“TeachBuddy 的每个角落，你都去过了。”按钮“开始吧”。减少动态效果时只显示卡片。
- **辅助栏**：所有模块宽度一致，等于日历右栏（≥1400px 时 340，以下 320，1150 以下 300）。普通页面里它从右边缘长出，内容固定宽度、从右侧滑入，页面平滑让位；在日历里它直接盖在右栏上，从右向左逐渐吞没右栏，日历本身一点不动。无论从哪个模块带着打开的辅助栏进入日程，都是覆盖，不会和右栏并排。窄屏时它浮在页面上方。

## 日程

- **两种视图**：日历和任务看板之间用一个分段控件切换，切换时舞台会变形过去。 日历从其他模块进入时，日历舞台、右侧“即将到来 / 待安排”和异步加载的日程卡片使用现有 `tbx-page-in` 与 `--tb-ease` 渐入、轻微上浮；日历 ↔ 任务看板的焦点变形期间不重复播放，`prefers-reduced-motion` 时不播放。
- **任务看板**：只有三列，没有额外的标题栏或标签栏。
  - 今天、接下来、待安排三列一样高、一样的样式。
  - 卡片右上角都显示时间段，比如“08:00 – 08:45”，全天显示“全天”。
  - 卡片上的事项可以直接点一下划掉，不用打开编辑面板：圆圈填满成蓝色对勾，文字加删除线，进度环跟着走。
  - 一次性的安排会改整条记录；重复的安排只改这一天的那一次。
  - 打开着的那张卡片显示的是面板里此刻的内容：两边勾选、改标题都即时同步。再点一次这张卡片，面板收起。
  - 面板的出现和收起用辅助栏的同一套动效：右栏宽度沿 `--tbx-aux-ease` 展开，卡片从右侧 28px 滑入并淡入；收起时反过来。点 × 或“完成”时用和 AI 助理完全相同的收起方式：卡片从左边缘收窄、内容停在原地，最后淡出（盖在原位的一张静止副本完成这段动画，底下的右栏在此期间隐藏），不会闪回日历，也不会闪白。 关闭时先保留无入场动画的视觉副本，等待自动保存确认且原面板实际卸载后才折叠；保存失败则撤掉副本、恢复原面板，禁止半收起或残影。
  - “移回待安排”先问一句（不是危险操作，蓝色按钮），确认后去掉时间和提醒，卡片回到“待安排”。待安排的面板里只有一行“放进日历，变成任务”，不再附说明。
  - 标题和备注的输入框高度始终贴合文字：面板滑入时宽度在变，输入框随宽度重新量高度，不会留下一大块空白。
  - 标签多于一个时，第一个标签后面跟一个灰色圆形的“+2”。
  - 每一列都能按标签筛选：今天和待安排的筛选按钮在“+”左边，接下来的在右上角。菜单是共享的浮层与对勾，可多选，也能选“无标签”；筛选生效时按钮变成浅蓝并显示个数。筛掉的卡片离开后，其余卡片用 FLIP 滑到新位置；筛到没有时给出“显示全部”。筛选记在本机浏览器里。
- **日历的手势**：
  - 月视图里在一天里拖一下（或双击这一天）就新建一个全天任务。
  - “还有 N 项”从那一天的格子上展开，贴着格子、向日历内侧长出；日历滚动时自动收起。
  - 周、日视图里新建时，选出来的时间段就是一张可以拖动、拉长的卡片，面板里的时间跟着变。这张卡片和拖选时一样：灰底，时间段在正中。
  - 在月历里选中刚好一整个月就切到月视图，刚好周一到周日就切到周视图；其他天数照旧。
  - 第一次打开周、日视图时停在 7:00，而不是半夜。
  - 拖动过程中不重绘日历（自动滚动的结果等松手后再记），所以拖进全天栏会正常保存；如果这样会让提醒落在过去，会弹出“提醒时间已过去”的确认。
- **重复是一整组**：一个重复任务只有一个 id，从任何一次打开都在改整组——改标题、改时间、把周一换成周三，所有次一起变；改成“不重复”时只留下当前这一次。删除时问“只删这一次 / 删除全部”。
- **优先级**：只给“事项”用，而且只显示在任务看板里，日历上不显示。只有三个预设：重要（红色小标签）、普通（不显示）、稍后（灰色小标签）。
- **新建和编辑（任务面板）**：打开时占满右栏，原来的小月历先让开。
  - 顶部：左边一个小标签写着“新任务”或“新的待安排”；右边并排三枚同样大小的按钮：有时间的任务（包括还没保存的新任务：一时没想好时间，就顺手放进待安排）有带字的“移回待安排”，然后是红色垃圾桶（就地确认；重复任务弹出“只删这一次 / 删除全部”），最后是关闭。没有“…”。
  - 正文：标题是 21px 的大字，没有输入框边框；下面一行浅色的备注。
  - 时间：一组 iOS 设置那样的分组列表，每行左边一个彩色小方块图标。
    - 日期显示“今天 · 10月17日”这样的胶囊，时间是“09:15 – 10:15”两个胶囊，点一下就打开共享的 `DatePicker` / `TimePicker` 浮层（不会出屏幕）。
    - 全天是一个绿色开关。关掉时，已有的任务回到它原来的时间段；新任务回到 9:00 – 10:00。
    - 重复是一个浮层菜单（带对勾，最后一项“自定义…”）；提醒点进去选。
    - 待安排没有时间，只显示一行蓝色的“放进日历，变成任务”，下面一句“默认今天 9:00 – 10:00，之后随时可以改”。
    - 标题、备注的光标完整可见（输入区左右各留 6px）。
  - 标签：彩色小圆点的胶囊，点一下选中或取消，双击可以编辑；最后一个虚线胶囊用来新建。
  - 事项：
    - 每行是一个圆形勾选框加一行文字，行与行之间用细线隔开，最底下是“添加事项”的快速输入行。
    - 按回车接着写下一条，空行按退格会删掉并回到上一行。
    - 悬停时左边出现拖动把手，按全站统一的拖法排序（小卡跟手、蓝线标落点）；右边的“…”里能设优先级（重要 · 普通 · 稍后三段选择）、移到其他安排、删除（就地确认）。
    - 标题右侧有完成进度条。
  - 底部：“自动保存”的状态文字，加一个蓝色胶囊“完成”。
- **对话框**：重复、提醒、标签、“提醒时间已过去”这些对话框和确认对话框同一套尺寸：圆角 22、19px 标题、36px 胶囊按钮，主按钮蓝色；输入框是浅灰填充，聚焦时一圈蓝色。删除标签是就地确认。

## 教学助理

首页和辅助栏里的助理是同一个模块，只是摆放不同：首页是全屏版，左边有对话列表；辅助栏是窄版。版式参考了 t3code：回答读起来像一页文章，过程收成一行，结果变成能直接用的卡片。

- **回答**：没有气泡、没有头像，就是正文（首页 15.5px / 1.78，辅助栏 14.5px）。小标题加粗，有序列表是带圆形序号、用细线串起来的步骤；公式用 KaTeX；表格是圆角细边框；“课堂提示”是一块浅黄色的提示框。老师的提问在右侧，浅灰圆角气泡。
- **过程**：助理查题库、看日程时，每一步是一行安静的小字（“在题库里找 二次函数、抛物线 · 3 道”），正在进行的那一步有一道光从文字上扫过（分 30 步跳动，不持续重绘）。回答开始后，这些行收成一行“查阅了 2 处 · 用时 2 秒 ›”，点开能再看。还没有动静时显示“正在思考 · 3 秒”。
- **结果卡片**：浅灰底、圆角 18 的卡片，左边是模块色的小图标，右上是一个像 App Store“获取”那样的白色胶囊按钮。
  - 找到的题：一行一题，点开去题库，悬停出现“引用到对话”。
  - 讲解顺序：可以“加到日程”，变成待安排里的一项，步骤成为清单。
  - 分层练习和变式题：可以“存进题库”。
  - 日程：列出时间和事项。
  - 演示：直接去数学工坊。
  - 做完的按钮变成绿色的“已存进题库 ›”。
- **回答下面**：复制（图标会变成对勾）、重新回答、时间和模型名。平时只在悬停时出现，最新一条常显。
- **输入框**：一块半透明的玻璃，圆角 24，细边加柔和投影；左下是模型选择和 @，右边是 32px 的圆形发送键，回答时变成黑色的停止键，边框流过彩色光。输入 @ 或点 @ 可以引用题目、日程、资料。引用以彩色小标签放在输入框下方的“抽屉”里，题目橙、日程靛蓝、资料蓝。

## 输入框与搜索

- 搜索框都是胶囊形的浅灰填充，图标在里面。聚焦时整个胶囊变白，外面一圈 1.5px 蓝线和淡蓝光晕；里面的输入框没有自己的轮廓（`base.css` 里的统一规则）。
- 全局搜索（⌘K）和帮助搜索是同一种 Spotlight 浮层：圆角 22、毛玻璃、54px 高的输入行，结果行 40px，按组排列，当前项浅蓝底。
- 旧代码里有一条 `label span` 的全局样式会把标签里的文字变成浅蓝、变成块级，已在工作台内撤销。

## 语言

- 外壳、首页、助理、日程、设置里我们自己写的文案都走同一个翻译函数 `tx()`，英文在 `ui/tbx/src/locales/en.js`。没有英文时显示中文原文，不会串到别的命名空间。
- 日期跟着语言走：中文“10月18日 / 周六”，英文“Oct 18 / Sat”。
- 英文按中文宽度的 1.6 倍来留位置。按钮文字不换行，放不下时先用更短的说法（“Import”“New Question”“Categories”），再不行就省略号；标题在窄栏里缩小字号而不是折行；日程工具栏在窄时依次收起时区、标题图标、年份。
- 用户自己的数据（题目、日程标题、标签）不翻译。

## 题库

## 资源库

左边是资料卡，右边是共享的右栏。原则：**像文件管理器一样顺手，不用想**（第 37 条）。

- **资料卡顶部**：蓝色文件夹图标块（在某个文件夹里时是打开的文件夹）、当前位置（上级文件夹是一串可点的面包屑）和数量；工具：搜索、类型（`FilterMenu`，可多选）、缩略图 / 列表（`Segmented`，高亮滑动）、选择（没有资料时变暗不可点），最右蓝色“上传资料”（第一次使用时只在空状态里出现一次）。
- **筛选胶囊**：选中的类型（页面图标 + 名称）和标签（彩色圆点 + 名称）列在标题下面，点 × 去掉。
- **右栏**：“全部资料”；“文件夹”树（可嵌套、可折叠，每行前面留出展开箭头的位置；数量包含子文件夹；当前文件夹图标是打开的；再点一次当前文件夹回到全部资料）。文件夹的用法和侧栏分组一样：点 + 就在列表里出现一个输入框，打字回车即建好，不弹窗；“…”菜单有“新建子文件夹”（在当前文件夹下就地输入）、“移到其他文件夹”（沿用菜单，列出根目录与其他有效目的地）、“重命名文件夹”（就地变成输入框）和“删除文件夹”（就地确认），再点一次“…”收起。删除父文件夹时整棵子树递归删除，子树所有资料统一归入“未分组”，不能重新挂到更高一级父目录。最下面永远有一个“未分组”，放不在任何文件夹里的资料，不能改名或删除。拖动文件夹时“未分组”临时显示“回到根目录”；文件夹可以拖进另一个文件夹（变成它的子文件夹），拖到“未分组”回到最外层；拖到“已归档”则先递归归档自己和所有子文件夹下的资料，成功后整棵文件夹树消失。标签可以上下拖动排序（蓝线标落点），但颜色、名称等标签设置绝不因为排序而改变；“标签”（彩色圆点 + 名称，点一下按标签筛选，+ 新建，“…”编辑颜色和名称）；最底下“已归档”。文件夹、标签、已归档三类行都可以接住拖过来的资料。
- **缩略图**：4:3 的浅灰底，预览图像像一张放在桌上的纸，左下角格式标签；没有预览时显示文件类型的颜色（PDF 红、PPT 橙、Word 蓝）。下面是名称，再下面是文件夹（文件夹图标 + 名称）和标签（彩色圆点 + 名称）。
- **列表**：名称（下面一行是文件名和标签）、文件夹、修改日期、大小四列，表头吸顶，每一列都在行的垂直中央；进入选择时表头和行一起给右侧的勾选圈让位，列始终对齐。
- **选择**：点“选择”，或在空白处拖出一个框。底部浮起毛玻璃操作条：已选几份、全选（全部选中后变蓝，变成“取消全选”）、下载原件（单选下载原件，多选逐份下载）、移动、标签、归档（红）。“标签”打开一份清单：每个标签显示它在所选资料上的状态（全有 ✓、部分有 – 和数量、没有），点一下给全部加上，全都有时点一下全部去掉；最下面可以新建标签。逐份精细修改在资料详情的右栏里。操作完成后操作条保留，提示出现在它上方。
- **已归档**：和全部资料同一个界面；操作条是“恢复”和“彻底删除”（先确认）。
- **拖放与上传**：从电脑拖文件进来，出现蓝色虚线框和“松开即可上传”；拖资料卡则是移动、加标签或归档，不会触发上传。上传成功后停留在资源库列表，不能自动打开资料详情；只有用户明确点击资料卡片才打开。
- **空状态**：第一次来是三张叠放的小卡片插图和一句邀请；筛选无结果、空文件夹、没有归档各有一句。
- **资料详情**：一整张卡片。顶部是圆形返回键、标题和文件名，右边是“下载原件”“资料信息”两个胶囊和“…”；窄的时候只留图标。下面是预览工具条，页面放在浅灰的台面上（深色 `#141416`），像纸一样带阴影。
- **打开一份资料**：左边是阅读卡，右栏直接变成“资料信息”：文件卡片在上，名称、文件夹、标签、备注是浅灰填充的输入框；标签是可以点选的胶囊；“保存修改”是蓝色胶囊。
- **对话框**：圆角 22，胶囊按钮，主按钮蓝色、危险红色；新建 / 编辑标签用日程标签的对话框模板（名称 + 八色）。

  - **学生**：搜索胶囊 + “添加学生”，学生卡片四列自适应：头像、姓名、“学号 · 第 1 排第 2 座”、兴趣一行；右边是最近一场的得分率和名次（淡绿小块）。
  - **成绩**：一行筛选（“全部考试”“全部标签”菜单，可多选、点了不关闭）和右侧蓝色“导入成绩”。“全班的变化”是一张得分率折线（平均实线、中位数灰色、最高到最低是淡绿色带），线条进场时从左向右画出，悬停出十字线和说明卡，点某场考试就切换下面的焦点。焦点是那场考试：四张数字卡（平均分为淡绿）、得分率分布（10 档柱子，点一档列出是谁）、排名（前三是金银铜圆标，同分并列）、各题得分率、标签得分率。低于 60% 的条用橙色，不用红色。
  - **记录**：最宽 780px 居中。上面是输入卡（聚焦时整卡一圈焦点环；日期胶囊；⌘↵ 记下），下面按月分组的时间线：左边大号日期和星期，右边浅灰卡片；编辑、归档两个小按钮悬浮在卡片右上角，悬停才出现。
- **学生**：在班级卡里打开，左上“‹ 初三（2）班”返回。76px 大头像（同色光晕）、姓名、“学号 · 生日 · 年龄”，下面两张“兴趣 / 性格”卡（点一下编辑），再是“记录 / 成绩”分段：成绩里是这位学生和班级平均的两条线、每场考试一行（分数、名次、班均），点开后看各题：蓝色条是这位学生，黑色细竖线是班级得分率。
- **考试**：列表是日历小卡（红色月份条 + 大号日期）+ 名称、“数学 · 满分 120 · 15 道计分题”和各班导入状态胶囊（已导入淡绿带勾，未导入灰色空心圆）。详情顶部是大日历卡和标题，下面是“同场比较”（每班一行：平均条、平均、中位数、人数；没成绩的班给“导入这个班”）和逐题的各班对比条，再是题目分组、原卷。新建 / 编辑考试是宽对话框：名称、日期、学科、总满分一行，下面是计分题表格（分组、题号、满分、标签选择器）和“添加 10 道题，每题 10 分”。
- **导入成绩**：三步对话框，顶部是 1-2-3 的步骤点（当前蓝、完成绿勾）。① 拖入 Excel（绿色上传图标块），可以下载带本班名单的模板。② 对应列：自动识别表头、姓名、学号、总分、缺考（没有“缺考”表头时会找写着“缺考”的列）和每道题（“第 3 题”“3”“Q3”都算），下面是表格预览，已对应的列淡蓝。③ 逐行校对：只看“需要看的”行，红色竖条是错误，黄色是提醒；可以改对应的学生、切换参加 / 缺考、改总分、改超出满分的那一题、忽略整行；学号和姓名对不上时有一个“就是 某某”的快捷确认。表里没有的学生列在下面，会记为“未记录”。确认后是一个弹出的绿色大勾。
- **题目标签**：顶部是一条输入胶囊，下面是三列标签卡（使用次数、改名、合并）。
- **已归档**：班级、学生、考试、记录分组列出，每行一个“恢复”。
- **窄的时候**：页面容器小于 860px 时，导航卡收成顶部一行（品牌 + 新建 + 可横向滑动的班级胶囊）；内容卡小于 760px 时，分段控件占满一行，课桌只留头像和名字，双栏变单栏。

## 帮助

帮助中心保留左右两栏：左边是目录，右边是阅读区，两张圆角 24 的卡片。

- **目录**：顶部是搜索（⌘K），然后是“帮助首页”和七个主题。每个主题前有一枚带主题色渐变的小图标块；展开后第一项是“概览”，下面是文章，左边一道细线串起来。当前文章是浅蓝底加一道蓝色竖条。进入别的主题时，其他主题自动收起。
- **主题色**：开始使用青、题库橙、日程红、教学助理靛蓝、数学工坊紫、资源库蓝、账户与数据绿。只用在图标块、文章顶部的小标题、步骤序号和插图里。
- **首页**：顶部淡淡一层蓝色光晕，“有什么可以帮你？”和一个大搜索框，下面是“大家常搜”的胶囊。接着是三张“从这里开始”的大卡片（上半是插图），七张主题卡（四列），最后是“常见问题”的分组列表。
- **主题页**：大图标块、标题、一句介绍、“3 篇文章 · 约 8 分钟读完”；文章是一张分组列表，每行有序号、标题、一句摘要和阅读时长。底部是其他主题的胶囊，不再有“进入某某模块”的按钮。
- **文章**：阅读栏最宽 680px，正文 16px / 1.75。顶部是主题小标题、标题、一句导语和“3 分钟阅读 · 更新时间”，再一道细线。步骤是带圆形序号、用细线连起来的列表；“小技巧”是浅蓝提示块，“请注意”是浅黄提示块；快捷键是一张小表；插图是用主题色画的简化界面（不是截图，深浅色都清晰）。宽屏时右侧有跟随滚动的“本页内容”。结尾是一行“这篇文章有帮助吗？”，再下面是小字的上一篇 / 下一篇。没有“还有疑问？”。
- **搜索**：像 Spotlight 的浮层，悬在页面上方三分之一处，背后模糊。没输入时列出常见问题；输入后按主题分组，标题和摘要里的关键词淡蓝高亮；没有结果时给出主题胶囊。底部提示 ↑↓ 选择、↵ 打开、esc 关闭。
- **文章内容**在 `ui/tbx/src/help/content.zh.js` 和 `content.en.js`，两份结构一一对应。目前是示例文案。

## 图标

- 外壳图标是一套 SF Symbols 风格的线性图标：24 网格、1.75px 描边、圆头圆角、留白宽松，颜色继承文字色。侧栏开关是“带栏窗口”，助理是两颗四角星 `sparkles`；学期是日历，题库是书，数学工坊是根号，资源库是文件夹，垃圾桶带两道竖线。同一个名字在全站都是同一张图（例如通知里的“删除消息”、侧栏垃圾桶和日程里的“删除事项”）。新组件先用已有的图标，不要再画一张相似的：模块里的小图标函数会优先取共享图标集，app 自带的图标（`upload`、`file`、`info` 等）也直接复用。下载用 `arrowDown`，提交用 `arrowUp`。共享图标集里新增了 `undo`、`redo`、`play`、`layers`、`students`（两个人，班级模块）。界面上不再用 ↶ ↷ × ↵ + 这类文字字符当图标。
- 模块的标识图标放在对应系统色的渐变圆角方块里（`tb-r-md`），白色线条。
- 品牌标识见资源组 Logos：近黑圆角方块里，一本向上张开的白色书本，上方一颗系统蓝的四角星——一位捧着书、灵感亮起的老师。
