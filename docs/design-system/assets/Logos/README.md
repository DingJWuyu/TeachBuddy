TeachBuddy 的图标：捧着一本打开的书，脑海里亮起一颗星。

- **构成**：两页向上微微张开的书，像一位老师张开双臂；书的上方是一颗四角星，在人的头部位置，代表灵感亮起的一刻，也代表陪在身边的教学助理。书与星合起来，是一位捧着书、正在思考的老师。
- `teachbuddy-app-icon.svg`：标准 App 图标。近黑方块（#1d1d1f），顶部一层很淡的高光；书是白色，星是系统蓝（#0a84ff）。
- `teachbuddy-app-icon-dark.svg`：深色背景用，方块换成 #2c2c2e，好和纯黑区分开。
- `teachbuddy-symbol.svg`：不带方块的单独图形，用在需要更轻的地方（加载状态、水印、印章）。
- 16px 是最小尺寸；任何尺寸都保留星的蓝色，它是整个图标唯一的颜色。
- 和字标并排时，字标“TeachBuddy”用 display 字族、字重 650、字距 -0.02em，图标与字标间距是图标宽度的 1/4。
- 不要拆开书与星，不要改变它们的比例或颜色，不要给图标加描边或彩色渐变。
