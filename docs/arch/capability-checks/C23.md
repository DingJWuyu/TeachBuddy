# C23/v1 数学制作与离线作品

- 目标：公式、静态图和动态演示能制作、二次修改、带走并用于课堂。
- 必读：[共同边界](../capability-checks.md#共同边界和交付)、[数学样本](samples.md#数学作品)、[环境](environment.md#本机实查)、[数学来源](sources.md#c23-数学离线演示)。范围见[数学工坊](../../PRODUCT_SCOPE.md#3-数学工坊)，结果交 M40 独立复核。
- 写入：`experiments/C23/`、`docs/arch/evidence/C23.md`、`docs/acceptance/evidence/C23/v1/`。

## 最多两条候选

| 候选 | 路径及要证实的假设 |
| --- | --- |
| A 本地公式 + SVG/JS | MathJax 生成公式 SVG；原生 SVG/JavaScript 表达静态函数、平面/立体示意和有界交互。制作内容与参数保留，下载作品自包含。 |
| B MathJax + JSXGraph | 保留同一公式路径，用 JSXGraph 承担函数/几何及拖动交互；将必要运行库、样式与字体本地打包。仅 A 的具体制作/修改需求不能满足时试 B。 |

本机 skill 清单未发现已验证的专用数学制作 skill，不把通用 prototype/imagegen 当数学正确性证明。不要求新建技能体系或通用数学编辑平台。候选依赖尚未安装；JSXGraph 的静态导出与两路线的离线封装都需实测。

## 固定批次与标准

| 场景 | 可观察通过条件 |
| --- | --- |
| MA-01 公式 | M-F 输入并保存公式源，重开后修改参数/符号再导出透明 PNG 与 SVG；分式、根号、分段、上下标正确，透明图置于有色背景无白底，图不裁边。 |
| MA-02 静态图 | M-S 的函数、平面和立体图均能制作；重开源码修改函数系数、几何标注或虚实线并重导 PNG/SVG。核对指定点、标注和遮挡关系，不要求导出 SVG 在 WPS 内继续编辑。 |
| MA-03 动态作品 | M-D 一件作品完成滑杆改参数、拖动受约束点、按步骤显示推导；普通指针/键盘可操作，函数点位与取值符合样本预期。保存后重开能继续修改作品内容。 |
| MA-04 真实制作调用 | 用一个允许模型生成或修改 M-D 的实际源码，运行后观察要求的变化并再修改一次。保存提示、实际 ID、脱敏输出和最终源码；人工样例只证明底层工具，不能冒充 Agent 制作成功。这里无须等 pi 或 B16。 |
| MA-05 离线与导入 | 下载 M-D 和导入样本 M-X，退出制作环境、关闭本地服务，在全新浏览器配置/无缓存环境禁网后以本地文件冷启动。无需登录，必要图形、字体、控制与步骤可用；网络面板不出现未满足的必要请求。M-X 能保存/预览，明确哪些参数、源码或内容可改，外部依赖缺失时明确报告。 |

离线检验使用真正下载的交付物，不以仍在线的编辑页或已缓存 CDN 代替。可采用内联资源或同目录资源包，以老师能解压后直接打开为准；不要求额外本地服务器。截图/录像补充证据，不能代替自由操作。

## 立即工作、停止与回执

本机 Chrome 可立即开展；离线实验用独立浏览器会话，不改共享浏览器当前页面。Windows Edge/Chrome 课堂实机作为目标设备补测，由 M40/M44/D72 消费；缺设备只阻塞该切片。模型入口临时不可用时继续制作/离线，真实 AI 制作切片单列 BLOCKED。

交付三类作品的源文件、两次修改结果、PNG/SVG/离线包、冷启动普通交互证据、外部 HTML 编辑范围和支持浏览器的实测版本。不能将“本机离线通过”写为大陆三端已交付。
