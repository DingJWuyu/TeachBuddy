# C21/v1 四入口自动提取

- 目标：教师一次交入多题材料后得到可校对、可编辑的独立题目，原稿与已有答案不丢失。
- 必读：[共同边界](../capability-checks.md#共同边界和交付)、[提取样本](samples.md#提取与-office-共用样本)、[环境](environment.md#本机实查)、[提取来源](sources.md#c21-提取)。范围见 [题库](../../PRODUCT_SCOPE.md#1-题库)，结果交 R30 独立复核。
- 写入：`experiments/C21/`、`docs/arch/evidence/C21.md`、`docs/acceptance/evidence/C21/v1/`。不接产品，不改 B11 字段。

## 最多两条候选

| 候选 | 路径及要证实的假设 |
| --- | --- |
| A 原生优先 | 文字直接进入；DOCX 读取段落、公式和图；PDF 优先文本/布局，扫描页及图片用本地 Tesseract 中文识别，再由允许模型整理拆题。默认 DeepSeek；GLM 只可作为同一路径的文本模型替代，记录实际 ID。原生结构能减少公式误识别，但 OCR 的数学保真未证实。 |
| B 视觉提取 | 将有版式的材料按页给 DeepSeek 视觉输入，保留原文件和区域定位；文字仍直接进入。先用一张含中文、分式和图的固定页核实 Provider 是否接受图像且能回答内容，再跑完整批次。官方 vision 文案不是成功证据；不假定 GLM 支持图像。 |

本地 Tesseract 是待安装的 OCR 组件，不调用另一个商业模型服务。候选 B 视觉不通属于该路径的明确失败，不临时增加第三种模型或付费 OCR。

## 固定批次与标准

执行 T、W、P、I 四入口六题，另测扫描 PDF PS、外部原件 E 和损坏样本 F，定义见样本索引。先保存未修正的机器输出再校对；不能把答案对照表喂给提取流程。输出结构自主选择，但应能定位题干、选项/小问、公式源、图、已有答案解析、原稿位置和待核对项。

| 场景 | 可观察通过条件 |
| --- | --- |
| EX-01 自动拆题 | T/W/P/I/PS 每份六题至少五题边界正确且无串题；至少四题的题干、数学含义及该题已有内容可直接使用，其余可局部校对，不需要整题重录。分别报告每入口分子/分母，不能由文字高分掩盖图片失败。 |
| EX-02 内容与编辑 | 逐题记录中文、公式、图、选项/小问、已有答案解析、定位七项正确/错误/不适用。Q2/Q5/Q6 图能对应原题；分式、根号、上下标、分段与区间端点可编辑，答案不变成另一题题干。现场修改一次公式和一次题面，保存再读回。未给答案的材料保持未给，不以模型解题伪装原答案。 |
| EX-03 真实版式 | E 的“例6（跨页）”“练习”“思考”三个题组至少两个完整分离；同题小问及配图关联正确，跨页原稿可定位。教学点评与教师活动不得当成题干。未完整项有局部校对入口，原页可继续查看。 |
| EX-04 失败后继续 | F 及一次外部调用失败：保留原件、成功题和可辨认片段，标注未完成位置，能从原件继续校对或重试。模糊缺字可以报告无法识别；不能无提示补造数字、图或答案。 |

这些标准用于选择可用的辅助提取路线，不要求零 OCR 错误。合格条件是自动完成主要录入、错误可定位和局部修正；仅列出六个空题壳不计边界正确。实测错误逐项公开，校对后的分数与机器原分数分开。

## 立即工作、停止与回执

本机可立即物化样本、验证文字和原生内容、安装免费 OCR 并准备调用；无需正式服务器或 B16。已授权模型凭据应通过执行环境注入，当前 C20 不检查其值。若执行者无法取得注入入口，仅模型切片 BLOCKED，继续原生/OCR 切片。按有限批次调用，每输入每候选一次主提取，失败修正遵守共同边界。

交付机器原始输出、逐题评分、原稿定位示例、局部校对保存证据、失败恢复记录和一条推荐路线。报告不能宣称产品自动收录已实现。
