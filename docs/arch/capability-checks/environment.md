# 实验环境条件

只在运行有界能力实验时读本页。当前启动和工具配置见[运行指南](../../SETUP.md)，已有环境缺口见[台账](../../plans/run-state.md)，本页不保存会过期的整机安装清单。

<a id="本机实查"></a>
## 每次执行前核对

- 固定候选、样本、独占输出目录及端口。
- 实际 Node/npm、浏览器、转换器/字体和该实验需要的库版本；声明依赖不等于本机可执行。
- 外部工具路径是否存在、实际有无编辑器 GUI、下载文件能否独立打开。模拟视口不代替物理设备。
- 产品凭据由已有私有运行入口注入；不输出、复制进报告或 Git。
- 调用窗口、模型白名单、许可和退出条件由本次任务与当前台账提供。旧实验设计中的预算不是可重用额度。

当前本地 OCR 权重方案未获执行许可，Agent 开发暂停。Windows/WPS、课堂设备、iPad/大陆网络和正式部署暂缓验证；可做的本机切片与未测目标条件分别交付。

## 结果必须分清

固定样本成功不等于通用产品成功；字体替代不等于排版相同；HTTP 200 不等于正常正文或正确工具结果；配置存在不等于真实邮件/模型/网络可用。

保存实际组件版本、样本摘要、命令或真实动作、结果和未决条件。普通重启、离线制品冷启动、全实例备份恢复是不同场景，分别提供证据。
