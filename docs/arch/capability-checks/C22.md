# C22/v1 Office 预览、编辑与打印

- 目标：老师已有课件/文档能查看，备课成果导出后能在 Office 里继续改文字与公式，并得到可打印 PDF。
- 必读：[共同边界](../capability-checks.md#共同边界和交付)、[Office 样本](samples.md#office-格式与成果)、[环境](environment.md)、[Office 来源](sources.md#c22-office)。范围见[备课与资源库](../../PRODUCT_SCOPE.md#2-备课)，结果交 R30 独立复核。
- 写入：`experiments/C22/`、`docs/arch/evidence/C22.md`、`docs/acceptance/evidence/C22/v1/`。

## 最多两条候选

| 候选 | 路径及要证实的假设 |
| --- | --- |
| A Pandoc + LibreOffice | Pandoc 将公式源和文稿生成含 OMML 的 DOCX；LibreOffice 转换现存 Office 为 PDF/页面预览，并从同一 DOCX 导出打印 PDF。已有 PDF/图片直接逐页查看。 |
| B docx.js + LibreOffice | 使用 docx.js 文档/数学节点构造 DOCX，共用 LibreOffice 的输入转换与 PDF 路径。仅当 A 的版式或公式表达有具体缺口时试此生成器，不能把第二候选视为转换器故障的替代证明。 |

两条均待安装及实测；共享转换器若不支持必需格式，明确报告缺口并回 C20，不临时购买在线 Office 服务。编辑验证可以先用本机安装的 LibreOffice GUI；最终 Windows/WPS 兼容性单列，不能由 Linux 代签。

## 固定批次与标准

| 场景 | 可观察通过条件 |
| --- | --- |
| OF-01 真实逐页预览 | O-W 的 `.doc/.docx`、O-S 的 `.ppt/.pptx`、P 与 E 的 PDF、I 图片逐个打开全部页/幻灯片。显示实际中文、公式与图，顺序和内容完整；无方框字、裁掉题干、遮挡公式或丢页。格式损坏时明确失败并保留可下载原件。报告每种格式的实际转换命令和限制。 |
| OF-02 可编辑成果 | 教案/提纲、导学案/讲义、练习三类各生成一份 DOCX 和对应 PDF。任选其中一份在真实编辑器修改一处中文、一处行内分式和一处独立根式/上下标公式，保存、关闭、重开并重新导出 PDF；三个修改都保留且公式继续能编辑。XML 检查只能补证，不能代替编辑。 |
| OF-03 分页与版本 | 三类成果均检查打印预览和 PDF 全部页，中文/公式/图完整，分页不截断题目必需内容，无意外空白页。学生版不含答案解析与教师注记，教师版含二者；固定标记串用于核查，不另造一套权限系统。允许合理字体替换和重排，不要求 WPS/LibreOffice 像素相同。 |
| OF-04 成本与故障 | 记录版本、字体/替换、原件与输出体积、各转换耗时、临时目录和候选部署所需组件。一次转换进程失败后原件仍在，重试能输出；不要求构建任务平台。 |

旧 `.doc/.ppt` 即使只支持先转再预览，也必须实际完成；不能用改后缀当真实旧格式。普通教学静态内容为本次范围，不追加动画播放、宏执行或复杂 OLE 编辑门槛。

## 立即工作、停止与回执

先准备样本和免费依赖，再在现有桌面尝试实际 GUI 编辑。本机有显示环境变量不等于编辑器已可控；若确实不能完成 UI 编辑，编辑切片 BLOCKED，保留已验证的预览/转换结果。Windows/WPS 的设备权限由外层落实，消费 R30/R35/D72；本机 PASS 必须注明编辑器，WPS 待测不阻止先形成技术路线，但最终目标兼容不能因此通过。

回执包含逐格式结果、三类成果及学生/教师变体、编辑前后文件与截图、分页对照、实际依赖和未验证设备。Office 实际编辑是本实验 PASS 的必要证据。
