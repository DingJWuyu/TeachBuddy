# 材料实验的消费边界

本页说明材料实现可以依赖哪些实验事实，以及哪些结论仍须在产品或目标环境证明。R30 已独立冻结；固定候选与报告见[输入索引](../plans/run-inputs.md#暂停与后续设计)。实际可用能力从[资源](../modules/resources.md)、[题库](../modules/questions.md)、[备课](../modules/lessons.md)进入，不把初始实验失败当成当前代码结论。

## 可依赖的事实

| 输入 | 可依赖的范围 | 不能推导的结论 |
| --- | --- | --- |
| C21 原生与视觉输入 | 原稿保留、题组候选、公式/图/定位的校对入库与重启回读有固定样本证据 | 任意扫描件均能自动拆题、任意在线模型均可用 |
| C21 E/F | 外部材料的部分题组可消费；截断、损坏、遮挡时保留原件、成功页和继续入口 | 将截断尾部补写成原稿内容，或把无正文的 HTTP 200 当提取成功 |
| C22 现代 Office | 本机 LibreOffice 的可编辑公式、保存重开、学生/教师隔离及打印切片已有独立关闭证据 | Windows Word/WPS 全范围通过，或初始固定 OMML 生成脚本就是通用产品转换器 |
| C22 旧 DOC | 部分旧格式公式无法保真，原件必须保留，可绑定完整 PDF 对照 | 把“能打开”写成公式无损，或用截图冒充可编辑公式 |
| C22 PPT/PPTX | 固定样本支持静态预览路线 | 动画、宏或未测字体均可重现 |
| 当前成果输出 | 正式实现已采用 Pandoc 路线，能力与目标软件反馈见当前输入索引 | 仅凭实验或旧成功文件证明当前运行实例仍能生成成果 |

当前运行转换工具另有路径失效问题，见[台账](../plans/run-state.md)。它和固定实验是否通过是两件事。

## 完整能力的核验责任

以下保留完整范围的条件，不表示对应工作尚未开始，也不要求每个 UI 任务重跑全表。

| 能力 | 可观察条件 | 责任 |
| --- | --- | --- |
| 自动收题 | T/W/P/I/PS 各至少 5/6 正确拆分、4/6 主要内容无需整题重录；E 的三个题组至少两个完整；逐题核对中文、数学、图、选项/小问、答案及定位，编辑保存后重开 | R33 实现，R35 独立；在线窗口与本地权重许可按当前台账，不自动续用 |
| 公式与图资产 | 数学源可编辑，实际图片有文件绑定；页码、region、跨页定位准确；失败部分可继续 | R33；共用裁图/文稿缺陷归 R31 |
| DOCX/PDF | 用户实际编辑的内容生成教案、讲义、练习的可编辑 DOCX 与同内容 PDF；中文、行内分式、独立公式可修改保存重开 | R34 实现，R35 独立 |
| 角色隔离与打印 | 答案/教师注记四种开关组合检查正文、OOXML 和 PDF；三类成果分别实际打印预览 | R34、R35，不能只查固定标记串 |
| 旧 DOC 受限预览 | 明示 limited，原件与绑定版本保留，补充 PDF 可对照且不覆盖原件 | R31 转换、R32 资源、R35 验收 |
| 目标软件 | 实际 Windows Word/WPS 打开、修改、重开及逐页核对六种输出；记录版本与制品 | 目标环境可用且用户安排后执行，不挡获准的本机工作 |
| 身份与账户隔离 | 当前真实认证下读取与写入，过期/退出保护；实验替身的结论保持原范围 | 具体集成与验收任务，认证约定见[身份入口](../modules/identity.md) |

若实际功能反复失败，先查成熟实现并适配；保持原稿和已实现手动能力，不自行将产品目标删掉。公共语义冲突交材料设计者决定，局部实现问题由所属模块修复。

## 六种格式样本与用途

这些固定样本包括反例，只用于契约和回归定位，不作为当前输出通过证明。

每行是 C22 制品提交中的实际文件，不是本批产品实现。新接口六种请求/受理响应由 OpenAPI 的 `Export_*`/`ExportAccepted_*` 样本唯一拥有。R34 用同一内容结构重新生成并验证，不能直接复制这些成品当完成证据。

| 成果 | 可编辑格式原件 | 打印格式原件 | 可消费的观察 |
| --- | --- | --- | --- |
