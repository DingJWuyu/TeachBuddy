# UI/UX 设计与验证

只在界面、交互或视觉验收任务中读取。根 AGENTS 的规则继续有效；当前页面授权与暂停状态读[台账](../plans/run-state.md)，实际领域入口见[文档地图](../README.md#功能规格)。

## 参考与不可丢失的边界

- 顶栏、侧栏、首页和登录注册有已确认原型。功能模块任务保留这些 UI/UX，只替换任务范围内的模块；不把重画整个外壳当成模块接入。
- 外壳和支持页参考真实登录态 EMStudio，使用只读观察与真实数值。功能模块沿已采用的 Impeccable 方向重组，以清晰、紧凑和实际工作为依据。
- 用户指定参考模块时，实际体验其首屏、展开、编辑与返回路径。提取任务分组、信息层级和操作出现时机；日程的独立浮层、字号层次与按需展开可作为模块重组的参考，具体控件随任务调整。
- 参考站的订阅、Pro、额度、套餐、学生统计、商业协议等不会自动进入 TeachBuddy。未授权的能力不为“复刻完整”而开发。
- 已确认范围内的细节自主完成，不要求用户逐按钮拍板；新范围与权限缺口才交用户。issue/ticket 等外部动作须有明确指令。
- 原型数据不进入生产作为固定回复或虚假文件；所有已实现手动功能、后端接线和用户数据随 UI 变化保留。

## 尺寸、留白与信息

先测最近的参考同类控件，再选尺寸。以下是既有 EMStudio 同类件实测锚点，不是要求所有页面套同一尺寸：

| 项 | 值 |
| --- | --- |
| 导航行 / 菜单项 | `36px`（导航）、`30px`（菜单） |
| 行内边距 | `10px`（导航行）、`6px 12px`（菜单项） |
| 正文字号 | `14px / 20px`，字重 `500`（导航）/ `400`（菜单） |
| 最小标签字号 | `10px / 15px`，大写，`0.5px` 字间距，70% 不透明 |
| 面板内边距 | `4px`（支持菜单） |
| 面板宽度 | `167px`（支持菜单）、`156px`（自建菜单） |
| 圆角 | `6px`（账户行）、`8px`（导航行）、`10px`（浮层）、`12px`（卡片/面板） |
| 卡片阴影 | `0 4px 12px 0 #0000000d, 0 2px 4px -1px #00000008`，不用大 blur |
| 细线 | `1px #e3e3e3`；面板细线用 **inset 阴影**绘制以免占用布局 |

- 紧凑轻盈，避免默认大行高、厚边框、重阴影、整屏空框和层层套卡片。空态为工作服务，不靠大框填满页面。
- 相关元素间距等大；调整时保留已确认锚点，用实际边界计算差值，不整体挪动不相关控件。
- 并列浮层使用同一工作区内边距作为上下基线；主面板、列表和辅助栏统一计算可用高度，避免主区 padding 与辅助栏 margin 各自叠加。窄屏浮层也沿同一边界留白。
- 输入内容、光标、占位提示与焦点框在各主题下清晰可见，搜索框须实际输入后核对文字与光标。下拉箭头与边缘保留内距。输入焦点框完整贴合控件边界。带图标的复合输入框由外层统一呈现焦点，内层输入不再单独圈框；紧邻裁切容器的输入使用内描边或 inset 阴影。核对四边、圆角和键盘焦点，避免外扩空隙、重复框线及局部缺口。
- 同类组件统一标题、计数格式、图标、空态和操作入口；分类小标题与图标低于区标题层级，高于或等于正文，不与大标题争抢注意力。空态沿用该区用途图标，常用添加入口保持一致。每个菜单项都有当前可用的作用，重复入口按常用位置合并；差异由用途决定。选中态、当前位置与键盘焦点分别表达，鼠标点击不额外叠加装饰性焦点圈；保留键盘导航所需的可见焦点。辅助线置于内容下层，选中反馈保持文字和卡片背景清晰。
- 模块标识用图标与清晰标题，当前作品名次之，正文易读，辅助信息退后。紧凑通过分组、间距和按需展示获得，保留标题与正文的字号差异；主操作通过位置和适度强调突出。
- 图标与文字按理解成本分工：箭头、关闭、更多可用纯图标，并提供可访问名称和悬停提示；“上传资料”“加入备课”“下载图片”等需要理解结果的操作保留文字。
- 按任务拆分职责明确的独立浮层，以轻边框、圆角和浅阴影区分，浮层之间露出页面背景。桌面并列的主面板与辅助栏上下对齐、外框等高，各自内部滚动；内容较少时也保持框架稳定。操作放在其作用对象附近，避免跨区工具栏、重复标题和多余说明。依赖时间或范围的摘要紧邻对应字段，附属能力按信息层级收纳；摘要须显示实际设置，范围限定直接跟在对应说明后，不散落到另一列。
- 删除不帮助完成任务的按钮或说明时，同时重新平衡留白。UI 不显示开发实现细节、任务编号、验收状态或原型免责文案。
- 不采用对角翻页 clip-path；拖拽不允许列表抽动或插入线乱跳，侧栏不用全宽大表单。

## 用途与渐进披露

- 首屏让用户知道“这里能做什么、第一步做什么、操作后得到什么”。空态用一句用途说明和一个明确主操作引导；按钮使用“动词 + 对象”，如“上传资料”“加入备课”。
- 导出先让用户按用途选择成果，再选择格式、内容范围等选项。描述应说明给谁使用、包含什么；生成操作与返回入口在长选项列表中仍可达，摘要与实际选项同步。
- 跨对象复用先展示来源与可选内容，明确复制到哪里、是否立即保存、是否影响原稿；取消保留当前编辑。历史恢复先供阅读，说明当前草稿如何保留，以及恢复是新版本还是覆盖。
- 内容混排在编辑、阅读与输出中使用同一顺序。移动正文时处理其关联材料，删除正文也不能悄悄删除材料；验证保存、刷新、撤销与真实文件中的顺序。
- 文件按原页插入时，显式区分可编辑正文和页面图片。原件的答案/注记不能被结构过滤时，在选择项和输出摘要说明；转换缺页必须失败，不生成看似完整的成品。
- 输出细选明确只影响本次成品；题目被排除时，其答案和附属注记同步排除，摘要使用实际题数。统一设置与单项覆盖分别显示，提供回到统一设置的入口。
- 模块有多种成果类型时，入口配简短用途与成果示意，帮助用户选择。进入后可提供能立即操作的示例，示例中的内容仍可修改、增添和删除；用户无需先理解源码或配置才能体验基本效果。
- 按浏览、查看、整理的任务顺序暴露操作。先展示内容和当前步骤需要的工具，筛选、属性编辑等在用户主动使用时展开；单页内容只显示页数，多页才出现翻页控件。
- 内容型模块默认呈现可阅读的成果，明确进入编辑后再显示输入框与结构工具。新建时直接提供最常用的输入位置，让用户先写内容；公式、图片、选项等结构在需要时插入。空白输入位置只是编辑入口，未输入就退出时不应因此产生草稿或空对象。
- 编辑工具先显示当前对象的必要字段，样式、范围及进一步设置按需展开。常见结构可用有名称的输入项表达，例如分子、分母；支持源码编辑的功能提供明确切换入口，切换保留已有内容，替换内容前说明影响。
- 可选信息按用途逐项添加，避免一个“展开更多”同时放出整套表单。已有内容直接显示；清空正在编辑的字段后恢复占位提示，保留字段和焦点以便继续输入。多行输入从紧凑高度随内容增长；离开从未填写的临时条目时清理空项，取消整个对象无需先删除空白子项。有内容的草稿按既定保留规则处理。关联资料等独立任务保留独立入口，说明选中后是否还需保存。
- 教学摘要按实际日期与记录先后展示，改错字不能改变业务进度。收起过时提示时保留历史原文，检索与回顾按需展开，不挤占默认记录流程。新增能力复用现有浮层、组件与样式令牌，并回归原有草稿、快捷键和返回行为。
- 扩展纯文本记录时保留旧文字的字面含义，公式与图片通过明确入口加入。上传成功与记录保存分别反馈，异步上传和移动不得覆盖期间的新输入；跨对象移动前说明原引用如何保留，成功后定位可继续操作的目标。
- 摘要名称必须与实际数据一致：记录摘录不能称为教学进度，空值不能靠推断补成事实。来自不同记录的摘要分别标明日期，帮助用户判断信息是否仍适用。
- 让操作范围可见：浏览区的文件夹和标签用于查找，当前资料的信息栏用于修改归属。标题、位置与选中反馈应帮助用户区分，避免相同控件同时承担筛选和编辑而没有说明。
- 画布、对象列表和属性栏共享当前选择：点击图形或标注后高亮对应对象，右栏显示它的属性，反向选择也能在画布定位。点击、拖动、缩放和排序划分明确的命中区域，小对象也保留可用的移动入口；拖拽手柄悬停与拖动时强调完整作用对象。点击、长按和拖动分别判定，拖动结束不触发点击动作；事项等完成标记可反复切换，完成后的对象仍可移动。拖选过程中在选区居中显示所选范围，只保留一层背景，短选区仍保持反馈可读。取消手势同步恢复选区、编辑器与数据状态。折叠列表展开后保留对象原有的编辑和移动能力。
- 试演、编辑和课堂展示有明确边界。用户应能判断滑杆或拖动是在临时试演还是修改作品；将试演结果写入作品时使用明确操作，退出展示回到原编辑现场。
- 在需要分类或选择对象的位置提供就地创建入口，完成后继续当前任务，保留输入。明确新建对象是否已经保存、当前资料的关联是否仍需保存。
- 常用操作保持可见，低频维护操作收进更多菜单；需要理解后果的常用操作使用清晰文字。尚未满足前提的设置随对象状态按需出现；必须补齐前提才能执行的主操作说明原因。遇到预览失败等具体问题时，就近展示可执行的补救操作。移除前说明影响，可恢复的操作提供清晰的恢复入口。
- 操作名称与后果一致：移出当前列表且可恢复的内容操作称为归档；归档列表提供恢复和彻底删除，后者说明影响范围和不可恢复。归档或删除成功后离开原对象，返回其所属列表，同时清除详情路由，刷新也不重开失效详情。未知结果确认成功后执行同样的导航。
- 区分各步骤的完成状态。例如上传成功表示原文件已保存，预览生成和资料信息修改各自反馈结果；错误说明已经保留什么以及下一步能做什么。加载中、无内容、无匹配结果和失败使用不同提示，避免用户误判数据丢失。
- 来源跳转失败时保留当前内容和可用快照。只有明确确认来源不存在，才将入口替换为删除说明；网络故障保留重试入口，不能表现成内容已删除。搜索等可选范围变化放在既有筛选中，选择状态、提示和实际结果保持一致。
- 校对与确认流程把阻断原因写成用户能回答的具体问题；提交时定位首个未解决项，完成一项后给出下一步。原稿保存、机器处理完成与用户确认分别显示，成功路径收起重试和补救操作。
- 操作被阻断时立即在当前视野说明原因、是否已保存与可执行的下一步。局部输入无效时在对应控件附近显示简短错误和必要图标，提示占用既有间距、不挤动其他字段；取消遵循模块的放弃规则，不能被保存校验困住。需要用户决策才能继续时使用明确询问，每个选项说明保存、放弃或影响范围；关闭、Escape 与外部点击遵循同一取消语义，必须抉择时只保留有效选项。询问说明具体冲突值、是否保存以及选项后果，保存采用最后一次确认的输入，放弃恢复此前状态。范围选择只在当前动作需要时出现，在执行动作前完成，连续输入期间保持编辑流程。后台刷新保持现有内容稳定，短暂加载不闪出零散状态文字；失败就近提供可执行的恢复入口。

## 动效与键盘

弹窗、菜单、气泡、抽屉和面板打开时渐进呈现。关闭方式按组件用途和用户已确认体验确定：快速收回的浮层立即消失；需要保留空间变化的展开区连续收起，退出完成再卸载。再次点击同一展开入口关闭，快速反向不闪烁、不重新从头播放。

- 优先复用当前动效组件与令牌；既有浮层可从约 `0.96` 缩放、`4px` 位移过渡，约 `180ms`，时长根据组件角色统一。
- transform-origin 对齐触发位置；居中元素的位移与动画 transform 一起处理，不能因覆盖 transform 横跳。
- 焦点、Escape、外部点击及嵌套弹窗按层处理；关闭恢复原触发控件，单次 Escape 不把所有层一并关闭。判断活动弹窗时排除退出动画中已 inert 的节点，避免关闭后立刻保存被静默拦截。
- 同一任务区只保留一个活动编辑目标，用“保存记录”“保存修改”等文案区分新建与编辑。收起的编辑器保留草稿，但不接收焦点或保存快捷键；弹窗打开时，底层编辑器也不能响应保存快捷键。
- 对话框先记录触发控件，再聚焦首个可编辑字段；统一处理初始焦点，避免字段的 `autoFocus` 抢先执行，导致关闭时无法恢复焦点。
- 键盘定位遵循视觉排布：垂直列表的上下键按行切换，同一行的主项与编辑入口由左右键切换；并排数字与选择字段用左右键移动焦点。选择字段上下键修改选项，数字字段保留上下增减；横排颜色、星期等按钮使用左右键。文字输入的左右、Home/End 保留光标行为，Tab 仍按顺序访问可用控件。
- 列表、菜单和按钮以控件内部的灰色背景呈现键盘焦点，彩色对象保留原色并轻微加深。当前行与同行操作的位置分别可辨；不添加外扩圈框，不因鼠标点击或按 Enter 叠加装饰框。选中状态沿用原有颜色、勾选等反馈，焦点移动不能改变选择。
- 确认型表单中，Enter 保存当前输入并移出该字段的光标，当前对象保持打开；对象关闭使用关闭入口，已保存对象不会因此产生副本。未命名新建不因确认其他字段创建空对象。多行确认输入使用 Shift+Enter 换行，作为默认行为，不在界面堆叠快捷键说明；连续事项输入按 Enter 确认并进入下一条，空白不生成新条目。
- 多选列表的 Enter 切换当前项的选择，再按取消，列表保持展开以便继续导航。搜索 Enter 可确认首个可选匹配项并定位该项；没有可选结果时保留搜索输入。上下键不串入同行编辑按钮。
- 弹窗内 Enter 执行该弹窗的确认操作，例如保存设置、移回待安排、移动、采用或删除；焦点落在关闭或取消按钮时也不改为关闭。Escape 取消或关闭，要求抉择的弹窗使用既有放弃操作；鼠标取消和关闭入口保留原作用。无输入字段时初始焦点落在确认按钮，确认不可用则聚焦弹窗本身；无效输入、加载和保存等待仍遵循按钮可用状态。下拉字段的 Enter 直接确认，不额外打开选项列表；复选、单选与颜色按钮可用 Space 改变选择。
- 弹窗之外，普通按钮的 Enter 执行当前聚焦按钮，菜单触发按钮打开菜单；菜单上下键在当前层导航，右键或 Enter 进入子菜单，左键返回父项。确认键只由当前活动弹窗处理，不能穿透到退出中的浮层或底层编辑器。
- 输入法确认候选词、长按 Enter 和修饰键组合不误提交；无效输入保留校验，不能靠快捷键绕过。保存等待期间的新输入仍须保留，重复确认不新增对象或重放不同请求；迟到的旧读取不能覆盖已确认的新版本。取消后立即重开，不复用已取消的弹窗输入。验证确认、焦点移出、继续编辑、再次确认及刷新读回，并分别检查菜单项、同行操作、并排字段和实际主题下的焦点反馈。
- `prefers-reduced-motion: reduce` 使用可访问的终态，遵循用户的减弱动效偏好。
- 动画不能吞掉保存、关闭或返回操作，也不能靠固定 sleep 让测试“看似通过”。

## 布局与现场

- 外壳稳定；列表、正文、预览、时间网格和对话分别滚动。滚动完整工作区，不给每个小卡片加滚动条。
- 内容保持在所属容器内，标题、选中行、焦点框、通知和跨日横条分别检查实际边界；相邻格的日期与操作入口始终可见。容量不足时截断、折叠或显示剩余数量，并提供查看完整内容的入口；展开后的长标题仍受容器约束。滚动条出现或隐藏时保持内容宽度稳定；隐藏滚动条的区域仍支持滚轮、触控与键盘滚动，末尾内容可达。
- 底部固定或吸附的操作栏放在任务内容之后，为最后一项内容保留可滚入的空间。展开折叠区后，末尾输入与操作必须可见且能真实点击；只验证元素存在或程序填值不能证明没有被遮挡。
- 桌面辅助栏占实际布局空间，工具与 AI 共用同一列；普通浏览不抢走现有工具/对话现场，明确选择对象或编辑操作时再打开对应工具。作品浏览与当前对象编辑各有入口，辅助栏围绕当前任务显示内容。设置、帮助、更新日志使用适合内容的独立布局。
- 每个编辑入口都有可见的返回路径，关闭辅助栏与退出编辑是不同操作。未改动的空白稿可直接返回；有内容的草稿返回后可继续，保留输入和设置。丢弃或覆盖未保存内容前确认，取消后保留原现场；返回、继续和刷新后的状态分别验证。
- 模块主页是可稳定停留的列表入口。已有对象不能让主页自动跳回详情；创建后返回、归档后返回、空列表和非空列表刷新都要验证，同时保留各对象自己的草稿。
- 跨模块取材、对照、编辑与返回保留对象、选择、搜索、草稿、滚动、面板和布局现场。服务端内容与本地草稿分开验证，保持挂载不代表持久保存。为取材先保存新对象时，切换到正式地址后仍应回到原编辑状态。
- 阅读已保存内容时，另有草稿须明确提示并提供继续编辑入口。复制改编说明会保留原件，首次保存才创建副本；直接创建副本的操作先说明是否保存原稿及复制范围，成功后打开副本。保存结果未知后的恢复必须接续已创建的对象，并保留之后补充的输入。
- 撤销、重做与放弃整份草稿分别表达操作范围。输入连续变化应合并为可理解的一步；保存、刷新和采用服务器版本后的历史边界须明确，不把本地撤销称为已保存版本恢复。
- 从长列表进入编辑再返回时，保留原记录在视口中的位置。展开与收起会改变内容高度，仅恢复旧的 scrollTop 不足；以记录为锚点，在过渡完成后核对位置并恢复操作焦点。
- 助理开发目前暂停；后续涉及入口时遵守用户指定的稳定图标，不增加侧栏底部多余“AI 助理”，也不因打开不同模块让顶栏忽有忽无。
- 设置和更新日志的具体删减按[当前页面边界](../features/settings.md#设置的有效边界)执行，不从旧截图恢复用户已删除的区域。

## 采集与验证

1. 先复现真实用户路径。使用可见可点击控件、普通键盘/指针操作；DOM click、dispatchEvent 和种子只能作机制探针，不能冒充用户操作通过。
2. 测量实际面板而非透明定位容器；区分普通行与选中行。图标还需检查实际图形在 SVG 内的占比，外框尺寸正确不代表视觉大小正确。终态截图等待字体、数据和展开过渡完成，避免把动画中的裁切误判为最终布局；动效仍按第 4 项另验。必要时用截图像素检查，不凭记忆推断参考值。
3. 自动重试断言等待可观察结果；操作前确认 aria-expanded 等当前状态，避免重复切换。拖拽实际手势与合成事件的中间态探针分开报告。
4. 动效使用页面内 requestAnimationFrame 或连续帧取样，包含进入、快速反向与焦点恢复；按实际规则分别验证连续退出或立即关闭，只看终态截图不足。
5. 客户端路由按 URL/元素验证；“无页面重载”先证明文档标识存在，再比较前后。跨刷新现场另验存储。
6. CSS 变更逐项查看 diff，并在实际候选上做生产构建，不能用 dev 热更新结果代替构建。验证不会修改在线用户实例，隔离方式见[运行指南](../SETUP.md)。
7. 浏览器连接能力按当前工具实际检查，使用用户真实登录态参考，避免反复建立调试连接打扰用户；不把旧浏览器版本的连接故障当永久规则。
8. 失败先区分产品、输入和脚本，保留证据；不削弱断言换绿，也不为旧测试复活已否定的行为。
9. 从首次进入走完模块的主要任务及保存、重开，核对仅凭界面是否能判断用途、下一步及保存结果；例如资源库从空态收录资料，再查看与按需整理。另走一次进入后不输入直接退出、有内容时返回再继续；按模块的必需字段与取消规则，补验只填写标签、备注或空子项后关闭和删除，核对请求与重开结果；涉及对象编辑时验证选择与侧栏联动，以及长列表编辑返回的位置和焦点。验证清空可选字段后能继续输入、新建与编辑切换后快捷键只保存当前内容。正常路径之外，验证无搜索结果、内容无法展示和保存结果未确认时的解释与恢复操作。
10. 深浅色、桌面与窄屏分别检查主操作、工具栏和辅助栏展开后的布局。核对并列面板的上下边界、背景间隙，以及可用高度内主要画面与必要控件是否可达。除页面横向溢出外，还要检查控件是否被父容器裁切、标签是否异常换行；原生复选框/单选框须核对实际占用宽度，避免继承通用输入框的全宽样式。从实际边界与 CSS 优先级定位问题。
11. 文本与公式编辑分别验证逐字输入、粘贴、删除和重开；一次性填入完整内容无法证明输入中间态可用。展开字段后先用真实点击取得焦点，再连续输入；直接填充可能聚焦尚被裁切的控件，须与用户可执行路径分别诊断。主题通过产品真实开关切换并核对实际颜色，不能仅用浏览器媒体偏好冒充深浅色验证。
12. 材料整理须从真实文件上传走到逐项阅读、确认入库和刷新，分别核对内容、选项、答案归属与来源页码。双栏样本覆盖长短不齐和内部写入顺序相反的文件；候选数量正确不足以证明没有串栏。按界面实际语义核对结构化选项，不把原稿中的标点样式当作唯一正确呈现。
13. 异步交互验证快速切换对象、请求未完成时取消、响应乱序与失败后重试；最终选择以用户最后一次操作为准，晚到响应不能重开已关闭对象或覆盖后续输入。数据排序、筛选和计数按实际业务字段核对，编辑或选中不能暗中改写排序。涉及时间的功能另验跨日、刷新与操作期间边界到期，核对界面和持久数据一致。控制请求完成顺序并等待响应处理后的可观察状态；固定业务时钟与推进定时器分开，避免时钟替身或过早断言掩盖竞态。
14. 体验示例用少量对象组合兼容的功能与边界，保持可读且可操作；密集重叠等压力场景单独准备。每个示例明确覆盖项，按授权管理示例数据；发现问题保留可重现的现场和证据，验证完成后按任务清理规则处理。

结论分别说明视觉、交互和持久数据的证据。与当前任务无关的目标环境暂缓项单列，不用流程数量代替实际使用质量。
