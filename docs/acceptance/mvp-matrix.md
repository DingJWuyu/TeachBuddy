## 自动提取质量

固定 [T/W/P/I/PS/E/F 样本](samples.md#提取与-office-共用样本)按入口分别评分，机器原结果与人工校对后结果分开。

| 场景 | 可观察通过条件 |
| --- | --- |
| EX-01 自动拆题 | T/W/P/I/PS 每份六题至少五题边界正确且无串题；至少四题的题干、数学含义及该题已有内容可直接使用，其余可局部校对，不需要整题重录。分别报告每入口分子/分母，不能由文字高分掩盖图片失败。 |
| EX-02 内容与编辑 | 逐题记录中文、公式、图、选项/小问、已有答案解析、定位七项正确/错误/不适用。Q2/Q5/Q6 图能对应原题；分式、根号、上下标、分段与区间端点可编辑，答案不变成另一题题干。现场修改一次公式和一次题面，保存再读回。未给答案的材料保持未给，不以模型解题伪装原答案。 |
| EX-03 真实版式 | E 的“例6（跨页）”“练习”“思考”三个题组至少两个完整分离；同题小问及配图关联正确，跨页原稿可定位。教学点评与教师活动不得当成题干。未完整项有局部校对入口，原页可继续查看。 |
| EX-04 失败后继续 | F 及一次外部调用失败：保留原件、成功题和可辨认片段，标注未完成位置，能从原件继续校对或重试。模糊缺字可以报告无法识别；不能无提示补造数字、图或答案。 |

这些标准用于选择可用的辅助提取路线，不要求零 OCR 错误。合格条件是自动完成主要录入、错误可定位和局部修正；仅列出六个空题壳不计边界正确。实测错误逐项公开，校对后的分数与机器原分数分开。

T 原文字不含 Q2/Q5/Q6 的图字节，图项按不适用记录，文字忠实性可单独判定；不能据此声称图被实现丢失，也不能声称实际提图成功。三题需要图才能完整使用时，missing-figure 保持阻断，真实补图后才可入库；无图题可先部分入库。真实图提取改用 W/P/I/E 的实际图资产判定，不能从答案重画补分。

## Office 预览、可编辑输出与打印

| 场景 | 可观察通过条件 |
| --- | --- |
| OF-01 真实逐页预览 | O-W 的 `.doc/.docx`、O-S 的 `.ppt/.pptx`、P 与 E 的 PDF、I 图片逐个打开全部页/幻灯片。显示实际中文、公式与图，顺序和内容完整；无方框字、裁掉题干、遮挡公式或丢页。格式损坏时明确失败并保留可下载原件。报告每种格式的实际转换命令和限制。 |
| OF-02 可编辑成果 | 教案/提纲、导学案/讲义、练习三类各生成一份 DOCX 和对应 PDF。任选其中一份在真实编辑器修改一处中文、一处行内分式和一处独立根式/上下标公式，保存、关闭、重开并重新导出 PDF；三个修改都保留且公式继续能编辑。XML 检查只能补证，不能代替编辑。 |
| OF-03 分页与版本 | 三类成果均检查打印预览和 PDF 全部页，中文/公式/图完整，分页不截断题目必需内容，无意外空白页。学生版不含答案解析与教师注记，教师版含二者；固定标记串用于核查，不另造一套权限系统。允许合理字体替换和重排，不要求 WPS/LibreOffice 像素相同。 |
| OF-04 成本与故障 | 记录版本、字体/替换、原件与输出体积、各转换耗时、临时目录和候选部署所需组件。一次转换进程失败后原件仍在，重试能输出；不要求构建任务平台。 |

旧 `.doc/.ppt` 即使只支持先转再预览，也必须实际完成；不能用改后缀当真实旧格式。普通教学静态内容为本次范围，不追加动画播放、宏执行或复杂 OLE 编辑门槛。

公式须覆盖一般 LaTeX → OMML 路径，分式、根式、上下标、函数/对数、不等式、区间、绝对值、两行 cases 和中文说明；固定硬编码 OMML 不证明通用转换。答案/教师注记四种开关组合检查 DOCX XML、正文/附件与 PDF，不仅检查文件名或固定串。

## 数学与离线

| 场景 | 可观察通过条件 |
| --- | --- |
| MA-01 公式 | M-F 输入并保存公式源，重开后修改参数/符号再导出透明 PNG 与 SVG；分式、根号、分段、上下标正确，透明图置于有色背景无白底，图不裁边。 |
| MA-02 静态图 | M-S 的函数、平面和立体图均能制作；重开源码修改函数系数、几何标注或虚实线并重导 PNG/SVG。核对指定点、标注和遮挡关系，不要求导出 SVG 在 WPS 内继续编辑。 |
| MA-03 动态作品 | M-D 一件作品完成滑杆改参数、拖动受约束点、按步骤显示推导；普通指针/键盘可操作，函数点位与取值符合样本预期。保存后重开能继续修改作品内容。 |
| MA-04 真实制作调用 | 用一个允许模型生成或修改 M-D 的实际源码，运行后观察要求的变化并再修改一次。保存提示、实际 ID、脱敏输出和最终源码；人工样例只证明底层工具，不能冒充 Agent 制作成功。这里无须等 pi 或 B16。 |
| MA-05 离线与导入 | 下载 M-D 和导入样本 M-X，退出制作环境、关闭本地服务，在全新浏览器配置/无缓存环境禁网后以本地文件冷启动。无需登录，必要图形、字体、控制与步骤可用；网络面板不出现未满足的必要请求。M-X 能保存/预览，明确哪些参数、源码或内容可改，外部依赖缺失时明确报告。 |

离线检验使用真正下载的交付物，不以仍在线的编辑页或已缓存 CDN 代替。可采用内联资源或同目录资源包，以老师能解压后直接打开为准；不要求额外本地服务器。截图/录像补充证据，不能代替自由操作。

## 整体可靠性与交付

真实身份下完成完整教学工作日，逐项对应上表，不用替身、固定 AI 或类型封面替代结果。普通保存、提交后丢响应、版本冲突、API 重启、身份失效及不同账户至少在受影响路径中验证。恢复到独立干净目录后读回文件、源码、对话和关联，仅复制 SQLite 不足。

认证恢复专项可先于全范围验收：开放恢复库前旧 Cookie/页面绑定全部失效，包含备份后已撤销却随备份回滚的会话；重登仍为原 accountKey。之后全范围验收还需真实邮件、跨设备及必要偏好对象。

实际交付验证真实 URL、目标设备和同一候选的生产构建、持久化、输出、Agent、备份/离线。目标环境缺失则单列未验证，不能拿 Linux 本地替代。最终交付 SHA 若变化，针对差异和关键冒烟复验。用户明确接受之前只称内部结果。
