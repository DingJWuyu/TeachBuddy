# MVP 验收矩阵与证据

本文件拥有验收质量要求和范围到节点的唯一映射。产品范围仍由 [PRODUCT_SCOPE](../PRODUCT_SCOPE.md) 拥有。只读任务包指定的锚点；普通实现/模块验收不需要通读。所有条目目前都是**待执行要求**，没有产品验收结果。

<a id="evidence"></a>
## 每次验证的基本证据

- 固定代码与契约版本、数据/样本版本、运行命令、端口、持久目录和身份模式。Git 输入按 commit + path 定位；未提交输入、外部样本和大制品按需要校验，不重复哈希已有提交中的每个文件。
- 每条场景写前置条件、操作、预期/实际、PASS/FAIL、截图/trace、脱敏网络和服务日志位置。请求关联信息足以追查失败即可，不建观测平台。通过与失败证据分存。
- 用产品/API 正常入口准备真实数据；迁移/恢复测试允许受控种子，数据库直写不能伪装用户操作成功。受限开发身份必须标记，不能充当真实认证结果。
- API/契约、重复课程计算、文件归属、迁移、幂等及恢复可按需要测试。UI 单元测试禁令归根 [AGENTS](../../AGENTS.md)。
- 构建、测试和证据必须对应当前候选。lint/test 失败或 flaky 必须复现并修复；重跑碰运气、跳过、改弱断言不能通过。旧断言只有经设计审查确认行为已被替代才更新。
- 证据路径、回执字段、版本等级和清理时机归[回执协议](../plans/execution-protocol.md#receipt)。另一个新 session 必须不问作者就能启动并定位失败。

<a id="persistence"></a>
## 涉及保存、身份、文件或恢复时

- 持久化证据读回对象、关联和实际文件，覆盖刷新、服务进程重启、真实重新登录和独立设备访问。仅开发身份可用的早期阶段明确局限；A12 后最终证据使用真实身份，F64 重测早期场景。toast 或 URL 不是持久化证明。
- 保存错误覆盖网络断开、服务/存储写入失败及请求结果未知；验证草稿可找回、重试幂等、冲突反馈及不能假成功。故障注入只在测试进程，不留下生产故障入口。
- 不把保持组件挂载视为持久保存。文件与内容归属、会话失效、重登及跨账户隔离按冻结契约检查；生产不能保留开发身份模式。

<a id="browser"></a>
## 涉及浏览器行为时

用真实服务和普通点击、键盘、指针拖选、上传、下载验证。优先使用现有 Playwright 和 `chrome-devtools-axi`。DOM `.click()`、`dispatchEvent`、强制点击或移除遮挡仅作机制探查，单独记录，不计行为 PASS。拖拽工具的限制如实报告，不能绕过用户可操作性。Gherkin 可由浏览器操作或 Playwright 执行，不强制引入 Cucumber。

<a id="backend-self"></a>
## 普通后端 CRUD 的自验切片

B13 等纯后端任务只自验本任务冻结的 API/契约场景：真实落库与关联、重启读回、账户隔离、冲突/重复请求和保存失败。写迁移时再检查空库与升级库。运行入口由公共底座的固定回执提供，具体操作以本任务契约为准。

这是实现自验，不包含 UI 视觉裁决；B15 接真实前端、B16 独立浏览器验收仍是阶段通过条件。修复已发现的产品缺陷仍先按实现协议从实际用户路径复现。

<a id="visual"></a>
## 涉及 UI 实现或视觉验收时

读取[设计与验证规则](../rules/design-and-verification.md)及本次 UX。在桌面 1440×900、较窄桌面及 Pad 768×1024 上走真实流程，覆盖长内容、空态、错误态。按既有 EMStudio 实测值与已验收外壳检查控件、细边框、间隙、独立滚动、右栏占位、弹层动效与减弱动效、可读性；支持页采用其适合的布局。逐项检查多余按钮/说明，删减后重新排版。

CSS 改动后的当前候选须过生产构建，此要求由设计规则定义。视觉、行为、数据可靠性分别给证据，任何一项不能由构建或原型截图替代。

<a id="design-review"></a>
## 设计冻结验收

独立设计 reviewer 只核对本批次：

- 用户故事和场景 ID、关键 UX 状态、成功/失败/恢复及跨模块结果齐全；只引用本批适用的已确认范围与规则。
- 唯一契约/schema、错误例、数据/文件所有权、逐文件任务边界与验收命令要求齐全；两侧可据同版分别实现。
- 代表性材料、通过标准、故障复现要求与外部阻塞明确；必要实验已有证据，不能靠未经验证的能力填空。
- 设计包含可直接派发的后续任务包，必读与条件读取精确到章节。作者不能自行冻结，缺项归本设计节点修订。
- B10 额外核对实际 diff、分支来源、文档入口一致及用户改动保留；落地前设计审查不能替代落地后复核。
- A10 额外核对认证交接说明中的每一项及源 revision；缺契约、服务或仍是旧回执即 BLOCKED，列明外部认证负责人要补的条目。
- M40 检查每类作品均能制作、保存、二次修改和导出，不假设任意 HTML 都可编辑；T50 检查正常、跨日、跨周和重启场景；F60 对照下文范围映射逐行无缺口且真实身份已接入。

| 实验 | 复核时机和责任 | 必要判据与阻塞 |

| C22 | R30 独立设计审查 | 真编辑文字/公式并保存、真实预览与分页。缺编辑器验证环境 BLOCKED；核对任务说明要求的环境与运行报告。 |

| C24 | C25 独立设计审查 | 真模型读写已有服务及失败轨迹；模型/版本能力不符 BLOCKED，开发 harness 不能替代产品 pi。 |

<a id="b16"></a>
## B16 首条链路与反馈设施

候选：B15 及其运行说明、首条 .feature。输出：独立报告、证据索引。

在新数据目录按说明重新启动，用普通浏览器事件走完整链路及至少一个失败恢复；检查真实网络、重启后数据、屏幕视觉和生产构建。能把一个具体失败原样交给新 W 复现，才说明反馈设施可用。

额外检查 B12 的两个测试账户、空库/升级库、启动失败退出和隔离构建；核对 B15 以真实故障证明假保存会被拒绝的证据。注明身份局限及未覆盖能力。

<a id="a12"></a>
## A12 真实认证与隔离

候选：A11 固定集成版本、认证负责人证据与工作台交接场景。输出：身份交接证据。

用真实账户从浏览器入口登录、退出重登、独立浏览器/第二设备访问同一持久对象，并以另一账户验证对象、文件、偏好和草稿隔离。覆盖设置退出及服务故障，不把手工注入 Cookie 或旧 Bearer 路径当作通过。

另核对 Cookie 会话失效/重登；开发身份不能替代真实身份结果。

<a id="c27"></a>
## C27 早期 Agent

候选：C26、Agent 契约及 .feature。输出：独立报告与工具证据。

用未在实现示例里固定的题目要求进行真实查询、改编与加入备课，检查页面、数据库和工具回执一致；中断后重开对话并继续，重复操作、越权和手动冲突均符合契约。

实验 PASS 或仅有建议文本不能通过。

<a id="r35"></a>
## R35 材料到备课成果

候选：R34 及 R31-R33、C21/C22 证据，materials .feature。输出：样本对照、独立报告和证据索引。

实走多题收录/校对/改编/取材/返回/输出；逐格式预览与资源替换；六种输出组合均打开检查，其中 Word 实际编辑再保存、PDF 实际打印预览。刷新/重启、保存失败、引用删除恢复与账户隔离按当前身份模式复测，指出其局限。

不能以全手工录入替代自动提取、图标封面替代预览，或仅网页打印/截图式 DOCX 替代六种输出；新材料复测且支持格式无遗漏。

<a id="m44"></a>
## M44 数学作品与课堂使用

候选：M43、支持环境、math .feature。输出：数学准确性、操作、视觉与离线证据。

三类作品各从制作到修改、保存、重开、导出；函数/平面/立体样本全覆盖；独立断网冷启动演示，核对备课往返和源码。注明实际浏览器/系统版本，不推断所有教室设备兼容。

导入预览不能替代自产动态作品；离线验证不能依赖登录、CDN 缓存或本地服务。缺支持环境按外部依赖处理。

<a id="t54"></a>
## T54 班级教学与时间

候选：T53、T51-T52、teaching-time .feature。输出：独立报告和证据。

安排某班课程 -> 临时只调一次 -> 关闭工作台到提醒时间后重进 -> 通知返回 -> 留下一句话反馈 -> 在对应备课回看。真实指针拖选、优先级/顺序独立变化、日期边界与服务重启均验证。

两班反馈独立；连续日期、排序/重复例外、补呈现和返回均有实际证据。不能用合成拖拽冒充真实通过。

<a id="f65"></a>
## F65 全范围功能与可靠性

候选：F64、A12 及范围映射每行的场景与证据。输出：完整缺陷表、证据索引。

核对每个范围行均有真实前后端结果，独立走完整工作日与异常恢复；验证所有文件类型/输出/离线作品/Agent 工具/通知补呈现/恢复。桌面和 Pad 基本操作检查，截图与普通用户事件相互印证，无认证替身、固定 AI 或文件封面冒充能力。

恢复到干净目录并读回文件/源码/对话/关联，仅拷贝 SQLite 不足。全范围真实身份、桌面/Pad、现场和支持页均检查，不能由编排者实质审查后放行。

<a id="d72"></a>
## D72 交付候选

候选：D71 固定 SHA、URL、干净启动说明和 F65 全证据。输出：最终验收报告，供用户评阅。

独立按说明启动/访问，从真实登录到完整教学流程，验证部署持久性、备份还原、服务故障及断网演示。核对当前候选的生产构建和全部适用回归、支持浏览器、无阻断缺陷、没有未完成范围；证据必须对应候选的同一代码 revision。

不能用本地旧测试替代真实交付环境；缺主机、设备、凭据或持久条件则 BLOCKED。

<a id="d75"></a>
## D75 实际交付版本

候选：D74 最终 revision、制品与地址。输出：交付复验回执。

确认交付代码与验收候选差异，重跑受影响检查及登录、持久化、导出、pi、备份和离线关键冒烟；部署与文档一致。最终 SHA 改变时不能直接复用原候选 PASS。

用户验收前只称完整 MVP 内部验收通过、待用户验收。
