# 班级验收

核验[班级行为](../features/classroom.md)与[接口契约](../contracts/classroom.md)时使用。本轮验收后端，不以接口通过代表教师界面或 AI 工具接入完成。实际候选和通过证据查[项目状态](../plans/run-state.md)。

## 必需场景

| 场景 | 可观察结果 |
| --- | --- |
| 身份与名单 | 真实认证创建班级、同名学生及自由记录；外账户 404、无会话拒绝、错误来源拒绝；换座/换班、删除恢复与重启保持正确归属 |
| 原卷 | 真 Word/PDF/图片上传及预览，考试保存固定页/区域；跨页题读回原位置，外账户文件及错页/错误来源拒绝；转换失败保留原件 |
| Excel 导入 | 真实 xlsx/xls、前导零学号、合并单元格及公式缓存；映射由服务端生成候选，重名可校对，错误可修正，空白/缺考/0 分不混同 |
| 确认与纠错 | 阻断错误全部回滚，确认一次原子保存；重试/重启不重复，源文件暂不可读时仍可重放成功回执；名单/考试/成绩变化返回冲突并保留草稿 |
| 统计 | 固定数字核对总分差异、同分排名、各题/标签分母、多标签去重、缺考/缺分、未考标签、不同满分、分布边界和同场跨班比较 |
| 标签与历史 | 重名拒绝、合并原子改所有考试且去重；已使用计分题不能直接移除，降低满分造成越界时整笔拒绝；改班/删除学生后重导入仍保留历史成绩与快照 |
| 数据生命周期 | 个人 ZIP 解压检查原件、JSON、可读层及关系；新库备份恢复、固定旧库升级、账户删除隔离；损坏/跨账户文件和关系拒绝恢复 |
| 外壳边界 | API 目录注册课堂后端但 Web 无班级入口；原四个页面继续可达，`/classroom` 与退役 `/classes` 不开放页面 |

## 固定计算样例

同一场考试满分 100，A 题 40 分标“函数”，B 题 60 分标“函数”和“图像”。甲班四人：总分及题分分别为 `80 / 30,45`、`80 / 40,40`、`50 / 缺失,50`、缺考；乙班为 `60 / 20,40`、`0 / 0,0`。

甲班总分均值 70、中位数 80、排名 1/1/3，缺考不排名。A 题已知 2 人、率 70/80；B 题已知 3 人、率 135/180。“函数”已知格 5、缺失格 1、得分 205、已观察满分 260，率 205/260；同时选“函数”和“图像”结果仍为同一题目并集。第一人的总分率 80/100、标签率 75/100，差异提示保留。乙班均值 30，真实 0 分参与。增加不同满分及未考标签的考试，核对时间序列与空缺语义。

## 运行入口

先按[隔离环境](../SETUP.md#新的隔离环境)安装锁定依赖。`apps/api/test/classroom-core.test.js`、`classroom-assessment.test.js`、`classroom-import.test.js`、`classroom-statistics.test.js`、`classroom-lifecycle.test.js`、`classroom-workbook.test.js` 使用真实 HTTP/SQLite 或真实工作簿；固定生成器在 `apps/api/test/fixtures/classroom/`，测试不读取 docs 作为输入。`classroom-paper.test.js` 使用公共转换器及真实原卷，需按[文件转换工具](../SETUP.md#文件转换工具)配置工具。

导航用 `apps/web/e2e/catalog-navigation.spec.js`，构建和 CI 分工沿[CI 与本地验证](../agents/github-workflow.md#ci-与本地验证)，不要为 API 另建 UI 单元测试。测试自行生成隔离数据，产物与清理沿[验证指南](README.md#隔离与产物)。

构造输入证明固定契约及处理行为，不能证明任意学校成绩表和复杂原卷均可识别。真实教师样例尚未提供；首份真实样例按实际版式核对匹配、校对负担和原题定位。真实邮件、教师设备上的 Word/WPS、前端观感和实际 AI 模型不由这些后端测试代签。
