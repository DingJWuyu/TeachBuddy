# 班级验收

核验[班级行为](../features/classroom.md)与[接口契约](../contracts/classroom.md)时使用。后端、教师页面与 AI 工具分别验证，接口通过不能代签页面或模型操作。实际候选和通过证据查[项目状态](../plans/run-state.md)。

## 必需场景

| 场景 | 可观察结果 |
| --- | --- |
| 身份与名单 | 真实认证创建班级、同名学生及自由记录；外账户 404、无会话拒绝、错误来源拒绝；换座/换班、删除恢复与重启保持正确归属 |
| 原卷 | 真 Word/PDF/图片上传及预览，Word取回原名和字节不变，PDF/图片仍为预览入口；考试保存固定页/区域；跨页题读回原位置，外账户文件及错页/错误来源拒绝；转换失败保留原件 |
| Excel 导入 | 真实 xlsx/xls、前导零学号、合并单元格及公式缓存；坏工作簿明确拒绝后可直接重选有效文件继续导入，未知结果仍须原键确认；映射由服务端生成候选，重名可校对，姓名学号冲突只建议唯一精确学号且不预填，显式确认后仍可改选；无足够证据不提供建议。错误可修正，空白/缺考/0 分不混同；无原卷、只对应学号、只录总分与无总分列均可校对确认，无总分提示不排名且不自动求和 |
| 确认与纠错 | 阻断错误全部回滚，确认一次原子保存；校对写入未确认时刷新先完成原键恢复再读草稿，首次即显示恢复值，恢复失败可从页面重新加载且保持原键；重试/重启不重复，源文件暂不可读时仍可重放成功回执；名单/考试/成绩变化返回冲突并保留草稿 |
| 统计 | 固定数字核对总分差异、同分排名、各题/标签分母、多标签去重、缺考/缺分、未考标签、不同满分、分布边界和同场跨班比较；真实重新导入插在统计响应送达前，分布钻取、排名名单及学生题目班级参照保持完整旧版，刷新后完整新版，数值与 dataVersions 一致；个人/同场比较不返回全班名单；考试列表读完后、比较读取前正式更新考试标题/满分/题目，比较页整份元数据和得分率沿同一快照，继续编辑使用其版本，读回新比较期间不显示前一份统计 |
| 标签与历史 | 重名拒绝、合并原子改所有考试且去重；已使用计分题不能直接移除，降低满分造成越界时整笔拒绝；改班/删除学生后重导入仍保留历史成绩与快照 |
| 归档层级 | 账户内归档页列出已归档父班级/学生下单独归档的学生和记录；刷新仍可见。上级未恢复时提前提示并禁用子项恢复；直接 HTTP 恢复同样拒绝且不改子项。先恢复班级、再学生、再记录，上级恢复不批量复活子项；外账户查询与操作不得读取这些关系 |
| 数据生命周期 | 个人 ZIP 解压检查原件、JSON、可读层及关系；新库备份恢复、固定旧库升级、账户删除隔离；损坏/跨账户文件和关系拒绝恢复 |
| 外壳边界 | 班级沿单一目录开放 `/classroom` 页面，题库、资源库、数学和日程继续可达；退役 `/classes` 不恢复 |
| 教师页面 | 对照设计输入操作班级/学生、拖拽换座与未排座、自由记录、考试与标签、三步导入、学生/班级成绩、同场比较及归档恢复；真实保存后刷新读回，缺分与缺考不画成零。班级/考试/学生保存读回期间Escape/遮罩不可提前关闭，字段和取消禁用；失败保留输入，重试不重复写入，改字段按已保存版本更新，继续添加成功后才清空。完成后连续切换不会被迟到导航拉回。考试及标签多选在统计加载或失败时保持菜单和已选条件，允许继续选择或重置；记录搜索清空或变更后，迟到的旧结果或旧错误不能覆盖当前列表 |

## 固定计算样例

同一场考试满分 100，A 题 40 分标“函数”，B 题 60 分标“函数”和“图像”。甲班四人：总分及题分分别为 `80 / 30,45`、`80 / 40,40`、`50 / 缺失,50`、缺考；乙班为 `60 / 20,40`、`0 / 0,0`。

甲班总分均值 70、中位数 80、排名 1/1/3，缺考不排名。A 题已知 2 人、率 70/80；B 题已知 3 人、率 135/180。“函数”已知格 5、缺失格 1、得分 205、已观察满分 260，率 205/260；同时选“函数”和“图像”结果仍为同一题目并集。第一人的总分率 80/100、标签率 75/100，差异提示保留。乙班均值 30，真实 0 分参与。增加不同满分及未考标签的考试，核对时间序列与空缺语义。

## 运行入口

先按[隔离环境](../SETUP.md#新的隔离环境)安装锁定依赖。业务规则和真实工作簿消费在 `apps/api/test/rebuilt/`，材料与真实文稿格式在 `apps/api/test/rebuilt-outputs/`；固定工作簿生成器位于 `apps/api/test/fixtures/classroom/`，测试不读取 docs 作为输入。需要原卷预览或文稿输出时按[文件转换工具](../SETUP.md#文件转换工具)准备真实工具。

教师页面接线从 `apps/web/e2e/rebuilt/` 进入，以 `WORKBENCH_WEB_DIST` 指定隔离构建。按变化核对名单、座位、记录、Excel 校对确认、统计和逐级恢复；特别区分缺分与零分、确认前失败与入库后丢响应，核对原请求重试后的实际记录。当前保护范围以测试源码及实际配置为准，具名运行结果见[运行台账](../plans/run-state.md#核查入口)，不用目录名或 CI 通过代签完整覆盖。测试产物与清理沿[验证指南](README.md#隔离与产物)。
