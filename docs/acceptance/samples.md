## 提取与 Office 共用样本

六道自编高中数学题以 Q1-Q6 为稳定 ID。Q1-Q2 排第1页，Q3-Q4 第2页，Q5-Q6 第3页；第4页给 Q1-Q5 的已有答案解析，Q6 故意无答案。每页正常字号、中文题号；每题不跨页。外部 E 另覆盖真实跨页/三列表格，不强造所有样本都有极端版式。

| ID | 固定题面和图 | 仅供人工评分的正确性核对 |
| --- | --- | --- |
| Q1 | 求函数 `f(x)=sqrt(2x-1)/(x-2)` 的定义域。选项 A `[1/2,+∞)`；B `[1/2,2)∪(2,+∞)`；C `(1/2,2)∪(2,+∞)`；D `(-∞,2)∪(2,+∞)`。 | B；根号内非负且分母不为零。 |
| Q2 | 已知 `f(x)=x²-2x-3`，配坐标轴与抛物线图，标出顶点和两个横轴交点。（1）求零点；（2）写出单调递增区间。 | 零点 -1、3；`[1,+∞)`。解析保留配方 `f(x)=(x-1)²-4`。图应过 `(-1,0)、(1,-4)、(3,0)`。 |
| Q3 | `f(x)={ax+1, x<0; x²-1, x≥0}`。若 `f(-2)=3`，求 a 和 `f(1)`。使用真正两行分段公式。 | `a=-1，f(1)=0`；代入负数分支求 a，再代入非负分支。 |
| Q4 | 解不等式 `log₂(x-1)≤1`。 | `1<x≤3`；先有 `x>1`，底数2大于1，故 `x-1≤2`。 |
| Q5 | “如图，直角三角形 ABC，∠A=90°。求 BC 的长及 tan B。”图示 A 左下、B 右下、C 左上；AB 边仅在图中标4，AC 边仅在图中标3。 | `BC=5，tan B=3/4`；勾股与正切定义。图关联错误或缺3/4会改变题意。 |
| Q6 | 正方体 `ABCD-A₁B₁C₁D₁` 的棱长为2。（1）求体对角线 `AC₁` 的长；（2）求体积。配顶点标注、遮挡棱虚线的空间示意图。 | 核对值 `2sqrt(3)`、8；这些答案不写入原稿，提取不得声称原件已有答案。 |

| 输入 ID | 固定物化形式 | 必须保留/观察 |
| --- | --- | --- |
| T | 六题 UTF-8 粘贴文字及原有答案；Q5 的图改为明确文字“AB=4，AC=3”。 | 文字中的换行、Unicode/公式源、选项和小问；定位可用题号/字符区间。 |
| W | 六题 DOCX，普通段落、可编辑公式、真实配图和第4页答案。 | 不是全页贴图 DOCX；来源可按段落/题号及页定位。 |
| P | 与 W 同内容的4页文本型 PDF。 | 文本层、数学符号、页号与图区域。 |
| PS | P 以约200 dpi 栅格化组成4页扫描 PDF，去除文字层。 | 同样题目，检验是否实际走图像识别。 |
| I | P 各页图片，其中第2页做约3°倾斜和轻度 JPEG 压缩，保持肉眼可读。 | 图像入口多题；原尺寸及裁图坐标/可回看区域。不是截图页面 UI。 |
| F | I 第2页副本，将 Q3 条件中的一个数字遮住；另准备截断的 PDF 副本。 | 缺失数字应待核对，损坏 PDF 应明确失败；不伪造原始信息，其他题仍可保留。 |
| E | 华南师范大学公开《函数的基本性质单元教学设计》PDF，第7-8页（PDF 序号，从1开始），保留全文件作原稿。 | 例6跨页、练习与思考两组各有小问，三列表格混有教学点评，第8页思考有函数图；按三个题组评分，小问不强制拆成顶层题。 |

固定 F 实际仅遮住条件数字右部，并损坏“求”字。它可检验局部破损与校对继续，不能证明完整缺失数字的检测能力；机器补出的文字与人工补标必须分别记录，不能把人工标记计为模型识别通过。

E 是已有真实教学材料，不依赖用户再找样本：[原件 URL](https://statics.scnu.edu.cn/pics/maths/2021/0218/1613615129109322.pdf)。固定输入校验：1,115,735 bytes，13页 A4，SHA-256 `b8d34a6aa76a59adfee125c8efb0a12620dffbb797666cbcc6c41b07390d082a`。完整原件不提交仓库。新机器可直接下载到自己的外部样本目录，无需向旧 session 索取：

```bash
materialInputs="$HOME/.local/share/teacherworkspace-test-inputs"
mkdir -p "$materialInputs"
curl --fail --location --user-agent 'Mozilla/5.0' --referer https://maths.scnu.edu.cn/ \
  https://statics.scnu.edu.cn/pics/maths/2021/0218/1613615129109322.pdf -o "$materialInputs/E.pdf"
printf '%s  %s\n' b8d34a6aa76a59adfee125c8efb0a12620dffbb797666cbcc6c41b07390d082a "$materialInputs/E.pdf" | sha256sum -c -
export M33_PRIVATE_PDF="$materialInputs/E.pdf"
```

下载失败或校验不符时保留对应专项未验证状态，不静默换成更简单的材料。

E 的期望结构仅由原页核对：例6与续页合并、练习三小问保持一组、思考三小问与图保持一组；原件无明确答案的地方留空。先人工确定范围后再看机器结果，避免按结果改评分单位。

## Office 格式与成果

Office 样本可按上述内容独立物化，不等待识别实验。

| ID | 固定材料与输出 |
| --- | --- |
| O-W | W 的真实 `.docx` 和另存的 Word 97-2003 `.doc`；保留格式转换记录/文件类型，旧格式未保留的对象单独列出。 |
| O-S | 同一3页课件分别保存真实 `.pptx` 与 PowerPoint 97-2003 `.ppt`：第一页中文标题/色块/教学目标；第二页 Q2 公式、函数图和说明；第三页 Q5 图与文字小结。不能改扩展名伪造格式。 |
| O-L | 2页以上教案/提纲：“二次函数的零点与图像”，包含目标、活动表格、Q2、教师注记。 |
| O-H | 2页以上导学案/讲义：Q2/Q3/Q4、分式/根式例子、图与学生作答留白。 |
| O-X | 3页以上练习：六题题面及已有答案，公式与配图同上。 |

O-L/O-H/O-X 都分别输出学生 DOCX/PDF 与教师 DOCX/PDF，共12个小文件。学生版关闭答案和注记，教师版开启二者；教师注记使用自编标记串 `C22教师注记-勿发学生`，答案区使用 `C22答案解析`。至少一个成果具有行内分式、独立根式/上下标与跨页段落。检查结构和版面可读性，不硬定每个编辑器的页数一致。

题库固定 W 的图片节点直接位于 `w:p` 下，缺少 `w:r` 包裹。原生提取可读出三张图，但 LibreOffice 分页预览不显示它们；其原生提取评分不能代替合法 DOCX 的分页兼容验证。原件保持固定，不静默修写字节。

Office 输入 `materials/samples/w.doc` 与题库 W 原件不同：旧 DOC 有 Q6 答案，但 Q3 分段公式对象已不在原件中；按实际原件评分，缺失内容保持缺失。题库 `materials-questions/W.docx` 包含有效 Q3 公式，Q6 无答案，仍按六题标准评分。旧 DOC 的格式风险提示不能单独证明转换丢失；需对照原件对象、转换稿与可见页面。

这些是可重复生成的兼容性样本，不宣称代表所有历史 WPS 文档。后续用老师实际常用资料补验，不把收集私人资料设为固定样本验证的前置。

### 人工 Office 样本

固定文件在 [Office fixtures](../../apps/web/e2e/fixtures/office/)：`docx/` 含教案、讲义、练习的学生/教师六份 DOCX；`source/` 含对应 Markdown、公式和配图。`make-sources.py` 重建 Markdown 源，不生成 DOCX，也不代表产品转换器。目标环境的当前安排见[项目状态](../plans/run-state.md#用户验收与待决定)，在相应验收任务中执行以下操作。

1. 在 Word、WPS 中分别从 [学生讲义](../../apps/web/e2e/fixtures/office/docx/handout-student.docx) 原件开始。确认中文、分式、根式、分段函数、对数公式和配图完整。
2. 第一轮改“我的判断”的中文、例 1 分母 `x-2` 为 `x-5`、第二页根式内指数 `2` 为 `3`。另存带软件名的新 DOCX，关闭重开，核对修改及公式可编辑性。
3. 第二轮再次改中文，分母改为 `x-7`、指数改为 `4`，另存、关闭重开。查看完整打印预览，导出 PDF 并核对这三处修改。
4. 其余五份分别逐页预览。中文/公式/配图无缺失、裁切、重叠或无内容空页；学生版无教师注记和答案解析。练习 Q5 的三角形、Q6 的立体图及教师版“原材料未提供答案”说明保持。
5. 记录软件版本、两轮编辑结果和各文件实际页数，保留修改制品。允许软件合理重排；Q2 的“原图待校对”是源材料疑点，不当成转换失败。失败保留现场，Linux PDF 不能代替目标软件打印预览。

这六份字节固定的输入用于兼容性比较，实际产品输出需另行生成并验证。当前输出按所测版本重新记录编辑、保存、重开和打印结果。

## pi 业务样本

以下对象通过正常页面/API 建立，使用隔离账号/库，不直写 SQL。

| ID | 固定数据与预期 |
| --- | --- |
| P-Q | 新建题目，标题为唯一检索串 `C24-函数零点-原题`，题面为 Q2，已有答案保留。保存后记录真实稳定 ID/版本。 |
| P-C | 模型查询 P-Q 并调用已有复制操作，副本标题为 `C24-函数零点-改编`，保留原题。复制的首次写入使用一个幂等键，响应丢失后重放同键同体，页面只找到一份副本。 |
| P-CONFLICT | pi 读取 P-Q 的版本后暂停写入；老师在真实页面把笔记改为 `C24-老师已改` 并保存。恢复旧版写入应冲突，笔记仍在，模型读取新版本再说明。 |
| P-FAIL | 一次明确工具失败与一次写入结果未确认时的中断；会话重开后读取真实对象/重放原请求，回答与实际状态一致。 |

为避免过度约束，失败和中断可复用 P-C 的响应丢失路径；不要求为每个现象新建一套故障设施。模型自然语言必须真实触发工具调用，人工执行 HTTP 后让模型复述不计 PI-03/04。
