# 设置页功能状态

范围：TeachBuddy 设置页按已登录 EMStudio 的设置布局和组件复刻。顶部栏、侧栏、首页、认证页、帮助页布局和六个功能模块不在本次实现范围；帮助中指向已删除设置能力的文案同步修正。参考站仅只读浏览，没有保存设置、退出、导出、签署或删除账户。

## 已接入真实能力

- 个人资料：昵称、邮箱取自已认证账户；账户标识显示 TeachBuddy 账户。
- 个人资料导出：沿用可靠性 API 的生成、状态、下载及未确认请求重试，不替换真实资料为模拟下载。
- 最近删除：保留资料类型筛选及原 ID、版本与关联的真实恢复。
- 退出登录：沿用认证撤销与失败/未确认重试行为。

| 项目 | 当前界面能力 | 未接入能力 |

- 阅读字号、界面动效偏好和保存偏好。
- 本设备草稿数量、下载、清理及检查入口。
- 继续旧草稿与现场、草稿内容查看。
