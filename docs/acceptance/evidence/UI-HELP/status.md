# 帮助与更新日志验收

范围：支持菜单中的帮助页与更新日志页。参考为用户登录态 EMStudio 的帮助首页、章节、文章和搜索弹窗，只读浏览。

## 页面与能力

| 项目 | 当前实现 |
| --- | --- |
| 帮助布局 | 独立文档目录、首页搜索、热门主题、章节列表、文章、面包屑和下一篇，沿用参考的紧凑目录与留白 |
| 中文内容 | 题库、备课、资源库、数学工坊、班级教学、日程与提醒、常见问题；保留项目实际操作说明 |
| 搜索 | 本地检索文章标题与正文；关键词、上下键、Enter、Escape、Ctrl/Cmd K；无后端依赖 |
| 导航 | 章节与文章有独立 URL，支持刷新、浏览器前进后退和原生新标签页；目录状态与正文滚动按账户保留 |
| 动效 | 目录与移动端目录连续展开收起；搜索进入、退出、快速反向及焦点恢复 |
| 联系支持 | 使用常见问题入口；未添加参考站的在线客服或商业功能 |
| 更新日志 | 页面仅保留报纸图标及无障碍名称；不展示版本、构建和提交信息；自动生成发布数据文件不变 |

本次仅涉及前端文档 UI 与导航，没有新增后端接口或待接后端的按钮，没有更改业务存储或认证逻辑。
