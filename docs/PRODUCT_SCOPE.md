# 产品范围

## 用户与交付目标

TeachBuddy 面向中国大陆高中教师个人。第一位使用者是高一理科强基班的实习数学教师；强基班背景不扩展成独立竞赛训练功能。产品围绕六个模块持续完善，不增加新的功能方向。

交付必须有真实前后端、持久内容和跨模块复用。点击原型、内存样例、固定 AI 回复不能代替实际保存、重新找到和继续使用。本页定义目标，当前实现与未完成条件见[状态](plans/run-state.md)。

## 六个模块

| 模块 | 必须交付的结果 | 完整行为与限制 |
| --- | --- | --- |
| 题库 | 图片/PDF/Word/文字多题自动提取与局部校对；可编辑公式和真实配图、已有答案、原稿/出处保留；自建、直接改、复制改编；自定义题型/标签、标记、笔记与检索；备课/班级复用 | [题库](features/questions.md) |
| 备课 | 自命名环节、自由编排、未安排材料、就地取题/资源/作品及往返；教案/提纲、讲义/导学案、练习各有可编辑 Word 和打印 PDF；答案与教师注记独立选择 | [备课](features/lessons.md) |
| 数学工坊 | 在同一作品中制作公式、图形与教学步骤；公式可编辑源与透明图；函数、平面/空间图形及 PNG/SVG；动态作品参数/拖动/步骤；二次修改、备课返回；外部 HTML 与无需登录的离线演示 | [数学工坊](features/math.md) |
| 资源库 | 保存真实课件、模板、图片和文档；分类/标签/备注/检索；常用 PPT、Word、PDF、图片真实预览和下载；更新文件保留条目与关联 | [资源库](features/resources.md) |
| 班级教学 | 班级创建、归档、恢复与彻底删除，一句话随记、实际位置、未讲内容、共性问题及下一步；记录检索、课前回顾、各班进度、公式与课堂图片、跨班移动和单条记录彻底删除；关联题/课/作品；两班反馈独立并能回到备课 | [教学与时间](features/teaching-time.md) |
| 日程 | 顶部入口、任意连续日期、时间段、多事项、未排期、全局优先级与段内排序；周重复/结束日/单次例外；自选结束前后提醒、关闭期间补呈现及通知返回 | [教学与时间](features/teaching-time.md) |

自动整理应完成主要录入，错误可定位和局部修正；人工整题重录不能当作自动提取达标。Word 文字与公式应能继续编辑，截图不构成替代。PPT 由教师沿用自己的工具和版式手工制作，工作台提供材料、思路和数学素材。

## 跨模块与基础能力

- **产品 Agent** 使用 pi 核心 runtime，真实查找、整理、创建、修改、关联全部六模块，和手工操作遵守同一业务规则。首页与业务辅助栏延续同一对话；具体入口按[共同交互](features/workbench.md)，当前实现与授权见[项目状态](plans/run-state.md)。
- **外部 AI** 减少搬运上下文，允许预览后复制并打开普通外链，产物通过粘贴/上传回流；通用文本交接见[数据与外部 AI](features/data.md#外部-ai-衔接)，数学工坊的浏览器扩展协作另按[数学网页 AI](features/math.md#geogebra-数学画布与网页-ai)。
- **账户与持久化** 刷新、退出重登、换设备能读取同一账户的已保存资料、文件和对话，账户间隔离。未保存设备草稿与服务端内容区别见[共享保存](contracts/workbench.md#保存与恢复反馈)。
- **现场** 切模块、取材、打开辅助栏、对照和返回保留草稿、选择、筛选、滚动及布局；保存失败诚实显示，不把保持挂载当作持久化。
- **数据带走与恢复** 个人资料导出、误删恢复、一致备份和还原，含文件、源码、对话与关系；三者不能混称，见[数据管理](features/data.md)。
- **支持页面** 设置最终提供实际生效偏好，当前功能与用户明确删减见[设置](features/settings.md)；帮助覆盖真实流程，更新日志 UI 按同页决定。自动发布文件不手改。
- **访问与体验** URL 使用，以电脑完整体验为主、平板基本操作；工作台整体不要求离线，数学演示需在约定浏览器离线可用。视觉、紧凑布局、渐进动效、独立滚动同属交付条件，见[界面规则](rules/design-and-verification.md)。

## 范围边界

当前不做学生个人成绩/错题/薄弱点追踪、学生或家长端、组织管理、学校排课、出勤、独立课程标准或实体书籍管理。成绩与个体追踪只保留为后续候选，不进入当前计划。

不承诺自动生成整套 PPT、自动登录任意网站抓题、任意外部 AI 网站自动化/跨平台会话互通、本地 Office 自动同步、HTML 直接嵌入 PPT、任意导入 HTML 自动结构化编辑、任意 SVG 在 Office 内继续编辑、所有课堂设备兼容。

学期为班级与时间安排提供语境，题库、作品与长期资料跨学期积累。导航隐藏模块不删除资料，导航垃圾桶也不等于业务误删恢复。细节在已确认范围内自主落实；真实环境不足和实验失败不自动缩减产品目标。
