# 产品范围

## 用户与交付目标

TeachBuddy 面向中国大陆高中教师个人。第一位使用者是高一理科强基班的实习数学教师；强基班背景不扩展成独立竞赛训练功能。产品按下列八个分区持续完善；分类涵盖现有教学业务、账户、共同工作环境和 AI 助理，不增加新的功能方向。

交付必须有真实前后端、持久内容和跨模块复用。点击原型、内存样例、固定 AI 回复不能代替实际保存、重新找到和继续使用。本页定义目标，当前实现与未完成条件见[状态](plans/run-state.md)。

## 产品分区

产品分区用于理解、分工和查阅。题库、资源库、数学工坊和日程是其中四个注册业务模块；班级是待实现分区；账户与身份、工作台与设置、AI 助理有独立职责，通过应用装配接入。共享技术底座另列，不为分类调整增加注册模块。实际代码归属见[代码结构](SETUP.md#代码结构)。

| 产品分区 | 必须交付的结果 | 完整行为与限制 |
| --- | --- | --- |
| 账户与身份 | 注册、登录、找回密码、会话恢复、退出与账户生命周期；向调用方提供可信身份及操作结果，业务草稿和内容规则归各分区 | [账户与身份](features/identity.md) |
| 工作台与设置 | 外壳、导航分组与可见性、辅助栏、页面往返与公共现场；实际生效的主题/背景/语言/头像偏好、设置、帮助与更新页；账户与资料操作仅提供入口 | [工作台与设置](features/workbench.md) |
| 题库 | 图片/PDF/Word/文字多题自动提取与局部校对；可编辑公式和真实配图、已有答案、原稿/出处保留；自建、直接改、复制改编；自定义题型/标签、标记、笔记与检索 | [题库](features/questions.md) |
| 资源库 | 保存真实课件、模板、图片和文档；分类/标签/备注/检索；常用 PPT、Word、PDF、图片真实预览和下载；更新文件保留条目、分类、标签与备注 | [资源库](features/resources.md) |
| 数学工坊 | 在同一作品中制作公式、图形与教学步骤；公式可编辑源与透明图；函数、平面/空间图形及 PNG/SVG；动态作品参数/拖动/步骤；二次修改；外部 HTML 与无需登录的离线演示 | [数学工坊](features/math.md) |
| 班级（待实现） | 帮助老师记住班里的每个人及这个班正在经历的教学；学生资料、自由记录、正式考试成绩观察和班级整体回顾的共识已确认，交互与接口待设计 | [班级讨论](plans/classes-discussion.md) |
| 日程 | 顶部入口、任意连续日期、时间段、多事项、待安排与段内拖动排序；重复规则及单次独立任务；开始前后与结束前后提醒、离线到期通知及返回；自动跟随系统时区并保留当地日期钟点 | [日程](features/schedule.md) |
| AI 助理 | 使用 pi 核心 runtime，按手工操作的同一业务规则查找、整理、创建、修改和关联四模块；首页与业务辅助栏延续同一对话，执行结果可核实 | [AI 助理](features/agent.md) |

自动整理应完成主要录入，错误可定位和局部修正；人工整题重录不能当作自动提取达标。Word 文字与公式应能继续编辑，截图不构成替代。PPT 由教师沿用自己的工具和版式手工制作，工作台提供材料、思路和数学素材。

## 共享技术底座与跨分区约定

公共文件、OCR、文稿编辑、保存、后台任务及数据管理支撑各分区，不作为第九个产品分区。各分区拥有自身数据和业务规则，经公开接口协作；接口保持兼容时，可集中打磨一个分区。入口和操作呈现归产品分区，公共机制及恢复完整性归底座。

- **外部 AI** 减少搬运上下文，允许预览后复制并打开普通外链，产物通过粘贴/上传回流；通用文本交接见[外部 AI 衔接](features/agent.md#外部-ai-衔接)，数学工坊的浏览器扩展协作另按[数学网页 AI](features/math.md#geogebra-数学画布与网页-ai)。
- **账户与持久化** 刷新、退出重登、换设备能读取同一账户的已保存资料、文件和对话，账户间隔离。未保存设备草稿与服务端内容区别见[共享保存](contracts/workbench.md#保存与恢复反馈)。
- **现场** 切模块、查看关联来源、打开辅助栏、对照和返回保留草稿、选择、筛选、滚动及布局；保存失败诚实显示，不把保持挂载当作持久化。
- **数据带走与恢复** 个人资料导出、误删恢复、一致备份和还原，含文件、源码、对话与关系；三者不能混称，见[数据管理与恢复](features/data.md)。
- **访问与体验** URL 使用，以电脑完整体验为主、平板基本操作；工作台整体不要求离线，数学演示需在约定浏览器离线可用。视觉、紧凑布局、渐进动效、独立滚动同属交付条件，见[界面规则](rules/design-and-verification.md)。

## 范围边界

现有产品不提供学生个人资料和成绩观察。新班级分区的正式考试成绩与记录属于[已确认但待实现的设计](plans/classes-discussion.md)，不据此声明已实现学生追踪。学生或家长端、组织管理、学校排课、出勤、独立课程标准或实体书籍管理仍不在范围内。

不承诺自动生成整套 PPT、自动登录任意网站抓题、任意外部 AI 网站自动化/跨平台会话互通、本地 Office 自动同步、HTML 直接嵌入 PPT、任意导入 HTML 自动结构化编辑、任意 SVG 在 Office 内继续编辑、所有课堂设备兼容。

学期为班级与时间安排提供语境，题库、作品与长期资料跨学期积累。导航隐藏模块不删除资料，导航垃圾桶也不等于业务误删恢复。细节在已确认范围内自主落实；真实环境不足和实验失败不自动缩减产品目标。
