## 接任后的决定

1. 先确认当前任务授权。此时等待用户，不因为 DAG 中有未完节点就自行开工。
2. 收到新任务，按[模块入口](../README.md#模块入口)选择相关资料和写者；同一开发树避免并发写共享文件。
3. 收到回执，核对任务、版本、实际范围与产物；把失败交回具体责任人，保留未变的有效证据。
4. 仅在明确异常或用户要求检查时核查有关 session 一次。正常等待用主动回执。

旧任务文件与真人记录的定位见[归档索引](worktree-archive.md)，不恢复旧工作树作为常驻开发入口。
