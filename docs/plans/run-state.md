# 项目状态

本页是项目进度、剩余事项与当前授权的唯一总表。产品目标见[范围](../PRODUCT_SCOPE.md)，行为细节从[功能索引](../README.md#功能规格)进入。下面区分已实现、已集成和已验证；既往本机验收只覆盖当时的版本、输入与环境，新候选按影响范围补验。

## 工作现场与授权

本机用户体验直接运行 `TeacherWorkspace-preview` 源码，入口与维护方式见[SETUP](../SETUP.md#已有本机实例)。新环境按[隔离环境](../SETUP.md#新的隔离环境)启动；当前分支、HEAD 及未提交文件以 Git 为准。原 `TeacherWorkspace` 的 main 不在本轮开发范围。

总控负责专属 session 的收发消息、公共文件唯一写者、集成与冲突。新任务按本节阶段授权及[开发约定](../agents/module-development.md#git-与运行现场)确认分支起点和工作现场。本机旧 session 仅供查阅，不作为新环境前置。AI/Agent 扩展开发仍暂停；已接入的首批能力与后续设计边界见下表。

非 Agent 的本机 MVP 验收与发现的范围内缺陷修复已完成；成果集成到 preview，验收任务现场按收尾规则清理。用户在 `TeacherWorkspace-agent`（`agent/mvp-supervised`）的专属 session 中讨论 Agent，先核对已实现工具、冻结设计与实际缺口，未经用户后续指令不推进实现。该现场保留供用户继续讨论，任务完成并集成后清理；接续实现前由总控核对并同步最新集成基线。总控负责公共文件、稳定修复同步和集成，普通验收回执不转发给 Agent session。

本轮验收执行现有范围与矩阵中可在本机完成的非 Agent 项，包含真实本地 OCR、文件输出检查、测试收件器与隔离浏览器、数据备份恢复及手工跨模块流程。用户明确暂缓实际 Word/WPS 修改、保存、重开与打印，真实邮件送达，以及实际平板、课堂设备和学校网络；这些项目记为暂缓未验，不计通过，也不阻塞本轮收尾。真实产品模型调用及 Agent 组合验收随 Agent 线另行安排，可选增强不纳入本轮，MVP 范围和验收门槛保持不变。

当前仅在本地开发，集成分支为 `preview/integration`，体验目录为 `TeacherWorkspace-preview`；暂不合 main、push 或接入 GitHub Actions。新任务从该集成分支经总控核对的提交创建短期分支，完成集成验证后按[收尾规则](../agents/module-development.md#集成后的清理)清理任务现场。这是根 AGENTS 中“从 main 创建分支”的阶段例外；合并 main 仍须用户明确批准。已验收成果合入 main 并完成集成验证后，结束此例外并更新本节，后续任务从 main 创建分支。preview 目录和体验服务可以继续保留。

当前源码集成了日程、导航、材料修复、OCR 内容疑点处理、全站中英切换与账户删除；这些范围曾在本机完成独立验收，新环境须按[核查入口](#核查入口)对所需结论重新验证。数据处理协议继续占位。用户授权总控自主安排专属 session、工作树及技术决策；已集成代码以当前 Git 为准。

合 main、push、公开部署、费用和模型窗口按对应授权执行。测试业务数据可丢弃，不以旧库、草稿保留或历史迁移作为开发前置；代码、未提交成果、固定输入、有效证据和私有配置须保留。

## 开发基线

当前代码可继续开发：共享静态目录驱动 Web 的页面、导航及辅助栏；六模块通过同步只读端口提供资料包业务值；文件模块统一拥有固定预览来源读取。代码入口及职责见[SETUP](../SETUP.md#代码结构)，用户体验沿 preview 源码更新。

当前独立浅 clone 已验证依赖与浏览器安装、shared/API/Web 构建及固定输入齐备时的完整 API 回归。固定旧版升级输入随仓库提供，不需要旧 Git 引用、checkout 或私人验收库；外部 E 原稿仍按文档下载并校验。具体验证版本、数量、开发启动与浏览器范围见[核查入口](#核查入口)。语言曾覆盖六模块及支持页、跨浏览器读回、未知保存核实和教师原文保持。账户删除曾覆盖身份撤销、文件及业务清理、另一账户/实例隔离和 OCR 任务停止。OCR 曾覆盖固定 F 和真实缺字对照的局部提示，以及题库、备课、资源库的定位、校对、保存与刷新。固定 raw 回放只证明消费者，不证明再次进行模型推理。

当前可重现的代码、样本与测试入口见[核查入口](#核查入口)。六模块手工教学工作日已在本机真实 UI 完成；本机结果不替代下表的能力边界、产品模型调用和目标环境验收。

### 可选增强与明确暂缓

以下属于能力边界或待选增强，不自动进入核心待办：任意裸 TeX 纠错、教学环节自动划分、所有极端版式无损转换、精确单元格框选、OCR 生成 PDF 文字层、跨页/语义搜索、通用几何约束求解、复杂三维和多参数动画。现有原页/区域定位若不足以完成实际校对，或常用材料必须大量重录，则按具体失败纳入核心缺陷。

受管文件物理回收继续暂缓；业务条目永久删除与磁盘回收不同。已由用户移除的设置入口、自动整套 PPT 及其他范围外能力不因旧文档或测试重新恢复，范围以[PRODUCT_SCOPE](../PRODUCT_SCOPE.md)为准。

## 接续顺序与完成条件

本轮非 Agent 的本机验收完成，发现的数学显示、输出分页及过时验证入口已修复。后续按影响范围复验，不因固定样本通过而扩大质量承诺，也不把通用能力边界变为无限扩展待办。

1. 用户在专属 session 讨论 Agent 实际工具、冻结设计与缺口；未经后续指令不推进实现。获准后实现核心工具与恢复衔接，并验证真实模型及跨模块组合。
2. 新出现的可复现核心问题由 agent 按真实路径处理；当前资料足够时自行验证，不把技术回归全部交给用户。
3. 用户解除暂缓或选定目标环境后，再完成真实邮件、Office 编辑打印与课堂设备验收。正式部署及 main/远端操作仍按授权执行。

每个事项只有满足其具名结果才改变状态；保留问题归属、证据及下一动作。缺材料/环境标待验证，用户选择标待决定，代码已合入但未验证不写验收完成。
