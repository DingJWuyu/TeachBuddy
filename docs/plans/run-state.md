## 开发基线

当前代码可继续开发：共享静态目录驱动 Web 的页面、导航及辅助栏；六模块通过同步只读端口提供资料包业务值；文件模块统一拥有固定预览来源读取。代码入口及职责见[SETUP](../SETUP.md#代码结构)，用户体验沿 preview 源码更新。

独立 clone 已验证依赖与浏览器安装、shared/API/Web 构建及新 OCR 工具从公开来源安装和实际开发服务识别。固定旧版升级输入随仓库提供，不需要旧 Git 引用、checkout 或私人验收库；外部 E 原稿仍按文档下载并校验。具体验证版本、数量、开发启动与浏览器范围见[核查入口](#核查入口)。语言曾覆盖六模块及支持页、跨浏览器读回、未知保存核实和教师原文保持。账户删除覆盖身份撤销、文件及业务清理、另一账户/实例隔离和 OCR 任务停止。当前 OCR 的质量、速度、消费者和受损输入边界见[选型验收](../acceptance/ocr-selection.md)；旧双路结果中的疑点可继续读取，新识别不生成第二路文字复核。固定 raw 回放只证明消费者，不证明再次进行模型推理。

当前可重现的代码、样本与测试入口见[核查入口](#核查入口)。六模块手工教学工作日已在本机真实 UI 完成；本机结果不替代下表的能力边界、产品模型调用和目标环境验收。
