## 开发基线

当前实现边界：共享静态目录驱动 Web 的页面、导航及辅助栏；五模块通过同步只读端口提供资料包业务值；文件模块统一拥有固定预览来源读取。代码入口及职责见[SETUP](../SETUP.md#代码结构)，用户体验使用 preview 集成源码。

独立 clone 已验证依赖与浏览器安装、shared/API/Web 构建及新 OCR 工具从公开来源安装和实际开发服务识别。固定旧版升级输入随仓库提供，不需要旧 Git 引用、checkout 或私人验收库；外部 E 原稿仍按文档下载并校验。具体验证版本、数量、开发启动与浏览器范围见[核查入口](#核查入口)。语言曾覆盖五模块及支持页、跨浏览器读回、未知保存核实和教师原文保持。账户删除覆盖身份撤销、文件及业务清理、另一账户/实例隔离和 OCR 任务停止。当前 OCR 的质量、速度、消费者和受损输入边界见[选型验收](../acceptance/ocr-selection.md)；旧双路结果中的疑点可继续读取，新识别不生成第二路文字复核。固定 raw 回放只证明消费者，不证明再次进行模型推理。

当前可重现的代码、样本与测试入口见[核查入口](#核查入口)。备课退役影响的五模块导航、班级/日程关联、资料包、旧库恢复及公共转换已定点验证；既往手工教学工作日只证明其固定版本，不扩大为当前全部功能已重验。

## 接续顺序与完成条件

已集成的非 AI 助理能力有既有本机验收依据，账户与身份集成及备课退役均已完成，公共能力保留。后续以用户确认的产品分区目标逐个推进，日程暂时保留。新任务从最新 `preview/integration` 创建现场；数学按[后续开发边界](math-workshop.md)推进。验收按实际影响补充，不因固定样本通过而扩大质量承诺，也不把通用能力边界变为无限扩展待办。

1. AI 助理保持暂停；用户重新授权后创建新会话与工作树，核对实际工具和冻结设计，实现核心工具与恢复衔接，并验证真实模型及跨模块组合。

3. 用户解除暂缓或选定目标环境后，再完成真实邮件、Office 编辑打印与课堂设备验收。正式部署及 main 发布仍按授权执行。

每个事项只有满足其具名结果才改变状态；保留问题归属、证据及下一动作。缺材料/环境标待验证，用户选择标待决定，代码已合入但未验证不写验收完成。
