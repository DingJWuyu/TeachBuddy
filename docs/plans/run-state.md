# 项目状态

本页是项目进度、剩余事项与当前授权的唯一总表。产品目标见[范围](../PRODUCT_SCOPE.md)，行为细节从[功能索引](../README.md#功能规格)进入。下面区分已实现、已集成和已验证；既往本机验收只覆盖当时的版本、输入与环境，新候选按影响范围补验。

## 工作现场与授权

本机用户体验直接运行 `TeacherWorkspace-preview` 源码，入口与维护方式见[SETUP](../SETUP.md#已有本机实例)。新环境按[隔离环境](../SETUP.md#新的隔离环境)启动；当前分支、HEAD 及未提交文件以 Git 为准。原 `TeacherWorkspace` 的 main 不在本轮开发范围。

总控负责专属 session 的收发消息、公共文件唯一写者、集成与冲突。新任务按本节阶段授权及[开发约定](../agents/module-development.md#git-与运行现场)确认分支起点和工作现场。本机旧 session 仅供查阅，不作为新环境前置。AI/Agent 扩展开发仍暂停；已接入的首批能力与后续设计边界见下表。

当前处于已授权的 preview 集成过渡阶段：新任务以 `TeacherWorkspace-preview` 工作树中经总控核对的集成提交为基线，创建短期分支。这是根 AGENTS 中“从 main 创建分支”的阶段例外；合并 main 仍须用户明确批准。已验收成果合入 main 并完成集成验证后，结束此例外并更新本节，后续任务从 main 创建分支。preview 目录和体验服务可以继续保留。

当前源码集成了日程、导航、材料修复、OCR 内容疑点处理、全站中英切换与账户删除；这些范围曾在本机完成独立验收，新环境须按[核查入口](#核查入口)对所需结论重新验证。数据处理协议继续占位。用户授权总控自主安排专属 session、工作树及技术决策；已集成代码以当前 Git 为准。

合 main、push、公开部署、费用和模型窗口按对应授权执行。测试业务数据可丢弃，不以旧库、草稿保留或历史迁移作为开发前置；代码、未提交成果、固定输入、有效证据和私有配置须保留。

## 开发基线

当前代码可继续开发：共享静态目录驱动 Web 的页面、导航及辅助栏；六模块通过同步只读端口提供资料包业务值；文件模块统一拥有固定预览来源读取。代码入口及职责见[SETUP](../SETUP.md#代码结构)，用户体验沿 preview 源码更新。

当前独立 clone 已验证依赖与浏览器安装、shared/API/Web 构建及开发启动，完整 API 400 通过、0 失败，4 项可选检查因外部 E 原稿与 P/M 验收库缺省跳过。固定旧版升级输入随仓库提供，不需要旧 Git 引用或 checkout；浏览器回归及实际输出范围见[核查入口](#核查入口)。语言曾覆盖六模块及支持页、跨浏览器读回、未知保存核实和教师原文保持。账户删除曾覆盖身份撤销、文件及业务清理、另一账户/实例隔离和 OCR 任务停止。OCR 曾覆盖固定 F 和真实缺字对照的局部提示，以及题库、备课、资源库的定位、校对、保存与刷新。固定 raw 回放只证明消费者，不证明再次进行模型推理。

当前可重现的代码、样本与测试入口见[核查入口](#核查入口)。上述本机结果不替代下表的能力边界、完整工作日和目标环境验收。

### 可选增强与明确暂缓

以下属于能力边界或待选增强，不自动进入核心待办：任意裸 TeX 纠错、教学环节自动划分、所有极端版式无损转换、精确单元格框选、OCR 生成 PDF 文字层、跨页/语义搜索、通用几何约束求解、复杂三维和多参数动画。现有原页/区域定位若不足以完成实际校对，或常用材料必须大量重录，则按具体失败纳入核心缺陷。

受管文件物理回收继续暂缓；业务条目永久删除与磁盘回收不同。已由用户移除的设置入口、自动整套 PPT 及其他范围外能力不因旧文档或测试重新恢复，范围以[PRODUCT_SCOPE](../PRODUCT_SCOPE.md)为准。

## 接续顺序与完成条件

日程、导航、材料、设置及 OCR 内容疑点已集成。先用当前源码、仓库固定样本和对应测试入口核查需要接续的结论；新出现的可复现失败由 agent 诊断。通用能力边界不自动成为无限扩展待办。

1. 先处理表中可复现的核心问题或明确选择的缺项；当前资料足够时 agent 自行验证，不把技术回归全部交给用户。
2. 资源原件→题库→含数学作品的备课→班级记录曾完成真实认证保存、重读和五模块浏览器切片；在当前候选上按[完整矩阵](../acceptance/mvp-matrix.md)补完整工作日缺项。目标设备单列，认证恢复专项可独立验证。
3. 全模块 Agent 保持暂停；恢复后再补其业务与数据/现场组合。手动模块的正常开发不等待 Agent。
4. 完整工作日汇合材料、数学、教学、身份和数据的当前候选结果，按矩阵独立验收；选定实际部署环境并取得对应动作许可后，验证同一交付版本，再由用户验收。

每个事项只有满足其具名结果才改变状态；保留问题归属、证据及下一动作。缺材料/环境标待验证，用户选择标待决定，代码已合入但未验证不写验收完成。

## 核查入口

本页的集成状态来自当前源码和已记录的验证范围。选择受影响功能，先按[验证指南](../acceptance/README.md)建立隔离候选，再从仓库内的测试与固定样本重建结果。记录 Git 版本、输入、实际环境、通过和未验项；外部原件、真实模型、目标 Office 或设备缺失时保留未验证边界。

当前可移植性验证候选为 `3b5c930d`，在同一 Linux 主机创建独立 Git clone、空业务库与新浏览器缓存，不复制旧运行现场或 Git 归档引用。`npm ci`、shared/API/Web 构建、`npm run dev` 的健康及登录页通过；完整 API 为 400 通过、0 失败、4 跳过，跳过的是外部 E 原稿两项与 P/M 验收库两项。补充的偏好 HTTP 保护与服务关闭重开读回也已在 clone 通过。A11/T53、两份 R31 及 B16 升级使用入库原版源码包，缺少对应旧 Git 对象时仍可执行。

本轮按改动范围完成认证 10、开发服务 2、日程能力 12、帮助 3、设置 6、题干/答案定位 1、数学组合 6、跨模块恢复 11、资料包与备份恢复 2 项浏览器回归。数学覆盖真实 Word/PDF、公式结构、私密备注隔离，以及停服禁网后的新浏览器冷启动；日程冲突草稿重开保留原版本，继续输入不覆盖远端内容，另有 17 项日程与共享保存回归。恢复与原稿定位在最终 clone 构建复验，网络故障测试先等待页面恢复再撤销拦截，具名不稳定场景连续三次通过。
