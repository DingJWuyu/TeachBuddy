## B11 冻结第一条流程、共享边界与反馈标准

写入边界：`first-flow` 批次文档、工作台契约入口和后续任务的逐文件清单。

- 产物/完成：定义“自建/粘贴题目 -> 编辑/复制改编 -> 新建备课和自定环节 -> 引用 -> 返回 -> 刷新”。冻结数学内容的首版可扩展结构、对象稳定 ID、账户归属、来源/副本、引用更新和删除、版本冲突、重复写入与未知结果、保存失败、草稿/现场层次、软删除与恢复基础。只为本轮消费者定义端口，保留后续资产和数学内容演进方式。
- 产物还包括：B12-B15 的逐文件边界、前后端相同 OpenAPI/schema 及错误例、可复现数据与关键 .feature、同源 HTTPS 测试方案、用户看见“已保存”的依据；提前列出提取/Office/数学/pi/部署/认证风险及 C20 的验证问题。

本节点补充边界：身份来源不能由浏览器传 accountId 自证；认证未完成只允许测试 runner 注入可信身份，不代表完整认证。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="b12"></a>
## B12 实现最小公共底座与可复现反馈设施

写入边界：冻结的公共服务接缝、静态模块目录、迁移入口、共享 schema 使用代码、Playwright 配置、测试启动/数据脚本、隔离日志及必要根配置。

- 产物/完成：一条命令能启动真实 Web/API、独立 SQLite 和文件目录，建立两个测试账户场景并重置；保留指定数据库可重启复测。提供同源 HTTPS 浏览器入口、生产构建、失败 trace/截图/网络/服务日志索引。开发身份仅在独立测试启动路径可用，生产启动拒绝该模式。
- 完成还要求：验证启动失败会失败退出；空库/升级库分别能启动；普通保存故障能被重现；迁移、构建不写用户数据库。这里只补现有 runner，不造平台；是否引入 lint 由具体问题决定，不要求先重写旧仓库。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#b16)，具体场景由任务包列明。
