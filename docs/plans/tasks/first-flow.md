# 首条流程与认证交接任务说明

本页保留 DAG 节点的职责、依赖和完成要求，不记录当前是否已实现，也不是本次派发授权。当前状态读 [run-state](../run-state.md)，实现入口读 [模块地图](../../README.md#模块入口)。执行者只读任务包点名的节点章节；已实现节点按实际缺口接续，不从零重做。

## 当前消费方式

首条流程和真实认证均已有实现。修复分别从[题库](../../modules/questions.md)、[备课](../../modules/lessons.md)或[认证](../../modules/identity.md)进入。下列 B10-B16 / A10-A12 保留职责与完整门槛，不把早期 test-principal 输入替换成真实身份，也不把原旧底座作为新开发基线。

新任务的工作树、实际候选、写者和验证范围由根固定；当前构建与运行方法见[运行指南](../../SETUP.md)。

<a id="b10"></a>
## B10 统一执行入口和仓库所有权

写入边界：入口核对与 Git 准备方案。审查后的文件及 Git 落地由单独的实现任务负责，最后独立复核。允许路径仍为 README、ROADMAP、ARCHITECTURE、SETUP、API 的入口说明及 DAG 状态；不写认证契约、AGENTS 或原型。

- 产物/完成：ROADMAP 只导航到交付 DAG；README 明确仍未交付 MVP；建立分支和逐文件所有权清单，记录未跟踪研究输入校验值。两份文档不再同时宣称拥有执行顺序。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="b11"></a>
## B11 冻结第一条流程、共享边界与反馈标准

写入边界：`first-flow` 批次文档、工作台契约入口和后续任务的逐文件清单。

- 产物/完成：定义“自建/粘贴题目 -> 编辑/复制改编 -> 新建备课和自定环节 -> 引用 -> 返回 -> 刷新”。冻结数学内容的首版可扩展结构、对象稳定 ID、账户归属、来源/副本、引用更新和删除、版本冲突、重复写入与未知结果、保存失败、草稿/现场层次、软删除与恢复基础。只为本轮消费者定义端口，保留后续资产和数学内容演进方式。
- 产物还包括：B12-B15 的逐文件边界、前后端相同 OpenAPI/schema 及错误例、可复现数据与关键 .feature、同源 HTTPS 测试方案、用户看见“已保存”的依据；提前列出提取/Office/数学/pi/部署/认证风险及 C20 的验证问题。

本节点补充边界：身份来源不能由浏览器传 accountId 自证；认证未完成只允许测试 runner 注入可信身份，不代表完整认证。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="b12"></a>
## B12 实现最小公共底座与可复现反馈设施

写入边界：冻结的公共服务接缝、静态模块目录、迁移入口、共享 schema 使用代码、Playwright 配置、测试启动/数据脚本、隔离日志及必要根配置。

- 产物/完成：一条命令能启动真实 Web/API、独立 SQLite 和文件目录，建立两个测试账户场景并重置；保留指定数据库可重启复测。提供同源 HTTPS 浏览器入口、生产构建、失败 trace/截图/网络/服务日志索引。开发身份仅在独立测试启动路径可用，生产启动拒绝该模式。
- 完成还要求：验证启动失败会失败退出；空库/升级库分别能启动；普通保存故障能被重现；迁移、构建不写用户数据库。这里只补现有 runner，不造平台；是否引入 lint 由具体问题决定，不要求先重写旧仓库。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#b16)，具体场景由任务包列明。

<a id="b13"></a>
## B13 首条题库与备课真实后端

写入边界：API 的 questions、lessons 模块、本模块迁移/仓储及对应 API 测试；共享文件只读。

- 产物/完成：自建、读取、编辑、复制改编、备课环节增删排序及题目引用真实落库；笔记与题目内容分开；跨账户拒绝、乐观冲突/重复请求和删除恢复按契约执行。服务端重启后数据与关联一致。

自验入口：[后端 CRUD 切片](../../acceptance/mvp-matrix.md#backend-self)，具体 API 场景由任务包列明。后续浏览器阶段验收另由 B16 负责。

<a id="b14"></a>
## B14 首条前端及可持续的工作台外壳

写入边界：Web 的题库、备课、共享右栏/外壳和本节点 E2E 文件，具体边界由设计包划定；认证表单只读。

- 产物/完成：真实编辑、复制对照、备课取题和返回；保留选中、筛选、滚动、草稿与面板状态。沿用紧凑视觉和既有侧顶栏，日程只预留顶部注册位置，首页不恢复旧统计看板。Agent 未接入前不得用固定回复宣称功能完成。
- 产物还包括：契约替身只供独立开发，等待/失败/未确认保存均可见；正文、列表各自滚动，右栏工具/AI 切换不丢现场。最终通过条件必须用 B13 真服务验证。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#b16)，具体场景由任务包列明。

<a id="b15"></a>
## B15 集成第一条真实链路并证明反馈能抓错

写入边界：本轮独占集成清单和 `first-flow` E2E。冻结规范只读。

- 产物/完成：真实浏览器创建题目、改编、加入备课，刷新及 API 重启后重找；录制现场恢复。主动停止 API、阻止一次实际写入或中断响应，验证不能误报保存成功、草稿仍可找回、重试不重复建对象。故障撤除后完整重跑，通过与失败证据分存。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#b16)，具体场景由任务包列明。

<a id="a10"></a>
## A10 核对独立认证交付

写入边界：`docs/arch/auth-handoff.md`、工作台侧接入场景及接缝清单；`auth.md`、`auth.openapi.yaml`、`auth-cases.md` 和认证实现只读。

- 产物/完成：逐项核对身份和昵称、登录/注册后进入、刷新/重开与记住我、会话失效、迟到结果、密码重置撤销、退出成功/失败/未知结果、来源防护、生产邮件链路及账户隔离；确认 G01-G06 旧缺口已被新契约正确吸收。固定可调用接口和认证所有权边界。A10-OPS-001 由认证后端原拥有者给出具体恢复操作、事务/失败停止条件和可验证结果，经 A10 接受交接后供 F60 冻结及 F62 实施；需改认证契约或代码时由原拥有者交新 revision。A10 不以 F62 产品恢复实测或 A12 完整 PASS 作为交接前置。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

## A11 工作台接入真实身份并实现设置退出

写入边界：引入已审查的认证负责人提交，不修改其中实现；工作台身份适配、路由门禁、账号展示、设置退出、相关 E2E 及指定集成文件。

- 产物/完成：真实认证后访问业务、过期后按约定保留草稿并重新登录；设置退出撤销真实会话，失败和结果未知时诚实呈现，不伪造已退出。切换账户不能显示另一账户的草稿、缓存、文件或对话。生产路径没有开发身份入口。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#a12)，具体场景由任务包列明。
