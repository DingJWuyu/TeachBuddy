# 全模块 Agent、保存与恢复任务说明

按任务包指定的节点章节读取；本文件不是整份必读材料。设计输入仅供设计者，实现者从冻结契约和本节点进入。以下均为计划要求，未来产物尚未生成。精确版本、逐文件写入权、验证命令和回执位置由派发给本 session 的任务包固定。产物齐全后按本角色协议自验或交审；下方链接仅定位本节点适用的验收要求，不要求实现者等待整个阶段验收。

## 设计输入

F60 从已采纳的[入口提案](../../arch/reliability-entry.md)固定来源表及[原后继包](reliability-entry.md)第 3 步进入，消费固定局部证据、C27 具名本地独立结果、冻结契约及逐项未决清单。原包的审查和采纳步骤已完成。完整 A12/T54 不阻断设计启动或冻结；认证恢复语义须由认证后端原拥有者提出具体操作，经 A10 接受后才能冻结对应契约。F60 通读[完整范围映射](../../acceptance/mvp-matrix.md#scope)，对照真实身份、早期 Agent 和各模块固定回执；同时读取 [PRODUCT_SCOPE](../../PRODUCT_SCOPE.md) 的跨模块与基础交付要求。F61-F64 只读各自被冻结的任务切片。

<a id="f60"></a>
## F60 冻结全范围补齐与可靠性验收

写入边界：`reliability` 批次包和全范围验收索引。

- 产物/完成：列出六模块每项手工能力对应的 Agent 服务/工具和页面结果，补足缺失操作；统一已保存内容、草稿、设备现场与账户偏好的恢复级别，明确双标签页/设备冲突和会话失效。设计整体个人资料导出、软删除恢复、含文件/源码/对话/关联的备份、版本兼容与失败还原，沿用早期模型而非最后重建数据层。区分个人资料包与部署级备份；干净环境恢复的身份映射及认证数据只能按 A10 接受的交接方式处理，不越界改认证表。
- 产物还包括：真实偏好、帮助、更新日志、外部 AI 复制上下文并打开网页/带回成果的可用路径，及完整桌面/Pad 验收矩阵。更新日志内容来源必须为实际发布记录，不手改 CHANGELOG 或造历史。
- 独立冻结还须给出 A10 恢复交接、场景与失败停止条件、F61-F64 可实现切分及共享唯一写者；环境实测缺项逐项留给最终验收。影响语义而无法决定的输入阻断对应契约冻结，未冻结切片不能派实施。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="f61"></a>
## F61 交付 Agent 全模块真实操作

写入边界：缺失的模块工具适配、Agent 操作呈现、跨模块恢复和 tests，必要集成文件独占。

启动须有 F60 独立冻结、C26 与各模块真实端口、本节点冻结接缝及独占写权；完成交固定合格候选与 self 证据。缺端口时停在适配边界，不以待补接口报完成。

- 产物/完成：Agent 能实际整理导入材料、检索/改编题、编排备课、制作/修改数学作品、管理资源、记录班级反馈、安排日程；六模块都存在真实读取和写入证据。所有手工操作适用的验证、归属、幂等、版本和恢复规则在同一业务服务执行。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#f65)，具体场景由任务包列明。

<a id="f62"></a>
## F62 实现个人数据导出、备份和误删恢复

写入边界：账户资料导出/备份恢复服务与入口、所有模块必要适配、迁移及恢复 tests。

启动消费 F61 固定合格候选/self、F60 冻结接缝、A10 接受的认证恢复操作交接及独占写权；交可运行固定恢复候选与 self 证据后，A12 可独立核验 OPS-001，不等 F65/D71/D72。

- 产物/完成：个人资料包包含可携带内容及关联说明，排除密码、会话凭据和服务密钥；误删题目/资源/备课/作品/记录/日程后按契约恢复关联。部署级一致备份按 A10 交接覆盖业务、账户、挑战、会话、撤销状态和迁移账本，必需配置另行受控保管。在全新数据目录真实还原并校验文件、公式/源码、对话与引用；恢复对外开放前使旧 Cookie 和页面绑定失效，包括备份后已撤销却被回滚的会话，重新登录保持 accountKey 与业务引用。处理失败不开放恢复库，损坏/不兼容备份不覆盖原数据；跨账户导入策略明确并验证。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#f65)，具体场景由任务包列明。

## F63 完善现场、真实设置、帮助和更新日志

写入边界：现场/草稿持久化适配、账户偏好和支持页面、真实帮助内容及 tests；认证本体只读。

启动消费 F62 固定合格候选/self、本节点冻结接缝及独占写权；完成交固定候选/self，必要偏好对象供 A12 完整隔离验收。

- 产物/完成：逐模块补齐筛选/选择/滚动/布局/工具与 AI 切换恢复，草稿在失败和重登后符合契约；账户偏好跨设备生效，设备视图不被误当账户偏好同步。设置中退出沿用 A11，帮助覆盖实际流程；支持页面采用合适布局和真实发布记录。外部 AI 便利入口不承诺嵌入、自动登录或会话互通。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#f65)，具体场景由任务包列明。

## F64 集成完整教师工作日

写入边界：独占集成清单、跨模块 E2E 与交付证据整理。

启动汇合 F63 和 F60 冻结范围内全部实施候选/回执，以及完整 A12、T54、R35/M43/M44、T51/T53 等原模块完成链。缺完整输入或授权则停在本节点，不用早期 OPS-001 专项或局部 PASS 替代。

- 产物/完成：真实身份下完成“导入试卷 -> 校对改编 -> 备课取材 -> 做数学演示 -> 导出讲义 -> 排课提醒 -> 课后记录 -> 调整下次备课”，其中一段由 pi+DeepSeek 真执行，再刷新/重登/第二设备重找。穿插保存失败、文件替换、误删和恢复，重跑此前仅开发身份通过的场景。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#f65)，具体场景由任务包列明。
