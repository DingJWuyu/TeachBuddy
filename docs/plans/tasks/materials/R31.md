# R31/v1 持久文件与公共内容底座

目标：为三个消费者提供同版、可持久恢复的 File/Preview/Document/Job，含真实Office页预览、受控裁图和公共文档编辑原语。前置及共同执行规则见[任务入口](README.md)。B16完整SHA和运行入口未给时不开始产品实现；可以核对本设计。

## 必要资料

- [契约](../../../contracts/workbench/materials.md)：共用规则、B11过渡、文件与定位、内容、短任务与恢复。
- [OpenAPI](../../../contracts/workbench/materials.openapi.yaml)：File/Preview/Location/Document/Job、upload/get/download/preview/crop、jobs各操作；[cases](../../../contracts/workbench/materials-cases.md) MC01、02、05、07、19、21、22。
- [架构](../../../arch/materials.md)：公共端口、文件持久性、迁移、文件所有权；[实验裁决](../../../arch/materials-evidence.md)C22和旧DOC。
- 公共编辑原语需要 [UX U-M2/U-M8](../../../ux/materials.md#u-m2-校对和局部失败)与[设计规则](../../../rules/design-and-verification.md)。

## 工作边界

独占架构表中R31目录与逐项共享文件，认证内部表/协议只读。模块迁移由消费者提供，R31不写resources/questions/lessons业务。公共schema适配、依赖/锁、文件/任务/内容原语及runner在本节点完成；交候选后停止共享文件写入，由R34继任。固定公共编辑原语的导出路径、静态目录文件路径和handler绑定位置写入integration.md，消费者不得猜路径。

## 完成条件

1. 原文件从真实HTTP上传、读取、受控下载并重启后保持；重复同键、不同键同字节、上传中断、rename/DB提交前后失败均无伪成功/悬空引用。跨账户包括页图/裁图/任务均404。
2. DOCX/PPTX/PPT/PDF/图片产生真实预览页；旧DOC已知公式丢失为limited，失败和重试保留原件。HTML/宏/外部关系不执行，转换超限有真实隔离证据。
3. Document v1/v2可以查看/编辑并保存源，含列表小问/选项、表格、图、公式及教师注记；公共Editor无模块保存逻辑。未知版本不有损写回。
4. Job受理、取消、部分结果、重启interrupted和未知Provider停止重试均可由同版fixture验证；未接真实Provider不签真实识别通过。迁移测试空库/B16旧库/重复启动，账户布局及旧记录不变。
5. 交给R32/R33/R34的成功/失败Adapter使用同版样本，提供一个可直接运行的隔离启动命令、reset和保留数据重启方法。安装本批必要docx.js、公式呈现与Office转换依赖，消费者新增共享需求转R34。

验证：[BDD](../../../acceptance/materials.feature)WB-M005、M008、M012、M014、M015、M023至M027中的底座断言；共同API测试/构建及公共文档fixture浏览器检查。不能以实验脚本成功替代正式HTTP原件流程。

回执：`docs/acceptance/evidence/R31/v1/author.md`及integration.md，verification_level=self。放行三个消费者并行所需证据为本版端口、隔离运行/迁移和失败样本齐全；B16身份接缝保持。最终真实材料流程归R34集成、R35独立。
