目标：自动完成主要录入，老师对照原稿局部修正并确认题目；分类、自建/直接修改/复制和PPT素材均真实可用。前置见[任务入口](README.md)。

## 必要资料

- [UX U-M1至U-M3、U-M6素材/U-M7/U-M8](../../../ux/materials.md)及设计规则。
- [契约](../../../contracts/workbench/materials.md)：内容、定位、自动收题与分类、短任务、B11过渡；[OpenAPI](../../../contracts/workbench/materials.openapi.yaml)questions/v2全部操作与File/Document/Job/Location、题引用公共读取。
- [cases](../../../contracts/workbench/materials-cases.md)MC03至11、20至22；[C21原件消费裁决](../../../arch/materials-evidence.md)完整读取；[架构](../../../arch/materials.md)公共端口/所有权。

## 工作边界

仅questions前后端模块、自己的迁移/tests/E2E/fixture/证据。共享依赖/公共编辑器/外壳/runner不双写，需求交R34。原实验文件只读，私有完整response与E保留，不复制reasoning、密钥或版权全文。真实模型请求必须取本次派发授权与注入入口；缺少时继续原生/契约/恢复实现，明确列出真实识别切片BLOCKED。

## 完成条件

1. T/W/P/I/PS全部从正式四入口自动拆题，每入口分别至少5/6正确边界、4/6主要内容无需整题重录；逐题核对公式/图/选项小问/已有答案/定位。不能以固定题号正则评分、图描述或空题壳冒充完整结果。
2. E只选7-8页仍保留完整原稿并按真实页定位，至少2/3题组完整；截断候选仅局部保留、教师活动不混题面。F遮挡和损坏文件、Provider空正文/未知结果能保存并继续，不补造数字或Q6答案。
3. 真实可编辑LaTeX和实际裁图绑定、原稿对照重框、拆分合并、忽略片段、部分入库及重试不重复/不覆盖；刷新重启后校对仍在。原生DOCX结构不可靠分页时显示段落位置。
4. 自定义题型/标签空集起步，增查改删和组合搜索/标记/笔记完整；直接修改与复制改编、原题互跳、使用位置、v1安全演进完整。
5. 输出题面透明PNG分片/配图与可复制文字公式源供手工PPT使用；不实现整套PPT生成。提供readForReferenceV2及operations端口供R34/Agent，不读lessons表。

先消费已有机器响应验证Adapter和失败分支，不机械重跑付费批次。真实产品端到端自动识别补验仍必须在获授权后执行，重放fixture不能签该项PASS。C21的T/W完整自动整理、B公式/裁图、E尾部都须按裁决补到真实可用。

验证：BDD WB-M001至M012、M024、M026至M028；`materials-questions` API/E2E、全API/构建；独立保存未校对输出与校对后结果。题库加入备课可用同版lessons Adapter先验self，最终真链归R34/R35。

回执：`docs/acceptance/evidence/R33/v1/author.md`和integration.md，逐入口分子/分母、实际模型ID/有限调用记录、未决项、固定SHA和self。真实能力不足不降低范围，交本节点与R30处理；候选固定后停止写入交R34。
