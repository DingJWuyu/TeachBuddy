# R34/v1 备课编辑、六输出与最终集成

目标：按自定义环节组织真实题目/资源，以固定采用版本生成三类DOCX/PDF，再独占整批集成。前置见[任务入口](README.md)；R31完成即可与R32/R33并行开发。

## 必要资料

- [UX U-M5至U-M8](../../../ux/materials.md#u-m5-备课编排与取材)及设计规则。
- [契约](../../../contracts/workbench/materials.md)：共用规则、B11过渡、内容、引用和输出、任务；[OpenAPI](../../../contracts/workbench/materials.openapi.yaml)lessons/v2全部操作、Question/ResourceReference、Document、Export、File/Job。
- [cases](../../../contracts/workbench/materials-cases.md)MC11、13至19、21、22及六种输出预期；[实验裁决](../../../arch/materials-evidence.md)C22全部，尤其学生正文泄漏、硬编码OMML和目标设备缺口。
- [架构公共端口/所有权/并行验收](../../../arch/materials.md#公共端口)。

## 工作边界与阶段

并行阶段仅lessons模块及自己的迁移/tests/E2E/fixture/证据；需要题目/资源输入时用同版ReferenceRead与HTTP样本Adapter，不等资源UI或自动收题完成。R31回交后本节点是共享文件唯一继任写者，依据其他模块各自integration.md装配依赖，不改其业务目录。

最终集成须外层交R31-R33完整候选SHA、各自self/缺口及停止写入记录。按架构接手共享入口/注册/runner/公共Editor与README，禁止覆盖认证候选或其他flow写入。模块缺陷退原节点，只有固定修复候选回交后再集成；公共语义回R30，不自行改schema。

## 完成条件

- 任意环节增删改名排序、文稿/教师注记、本课材料、批量取材、显式重复引用、本课备注和返回现场完整。来源更新提示与采用版本、删除恢复、使用位置符合统一契约。
- 六个Export_*组合真实生成，按照三类结构输出，两个开关的四种组合分别检查。先过滤内容树再生成，Q2配方只在答案开关开启时出现，teacher-note/本课note只在注记开启时出现；长期题库/资源笔记不输出。
- 一般LaTeX输入经编辑保存转换为可继续编辑OMML，覆盖分式/根式/上下标/对数/区间/分段函数。真实编辑器改中文、行内分式、独立公式后保存关闭重开并再导PDF，不以OOXML计数替代动作。
- 三类各一次实际打印预览，全部输出页检查分页/字体/图/公式。转换失败、缺文件、不支持公式、受理后源更新、丢响应、重启和磁盘失败都能恢复且旧成功输出在。
- 最终真实链：上传及预览/替换 → 四入口自动收题与校对保存 → 备课取题取资源 → 六输出 → 新浏览器/服务重启再读取；同时验证B11旧库与身份接缝。只有完成该链才能报告完整self PASS，Adapter先验不足。

验证：BDD WB-M016至M023、M025至M028，并在最终集成补全部WB-M001至M028；`materials-lessons`和`materials-integration`API/E2E、全API与生产构建。各视口真实截图及操作记录。Windows/WPS若设备未提供，准确标明目标切片未验并交外层/R35；Linux本机可编辑结果单独记录，不能代签目标兼容。

回执：`docs/acceptance/evidence/R34/v1/author.md`、integration.md及完整运行证据，包含R31-R34固定集成SHA、真实/替身覆盖、self、实际时钟、身份模式和缺口。交R35独立验收，不自行冻结/合main/push/部署。R35须能从回执一步启动隔离环境，复现原件到六输出及设备补验。
