# 班级反馈与日程任务说明

本页保留 DAG 节点的职责、依赖和完成要求，不记录当前是否已实现，也不是本次派发授权。当前状态读 [run-state](../run-state.md)，实现入口读 [模块地图](../../README.md#模块入口)。执行者只读任务包点名的节点章节；已实现节点按实际缺口接续，不从零重做。

## 设计输入

T50 读取 [PRODUCT_SCOPE](../../PRODUCT_SCOPE.md) 的班级教学、日程及现场要求，相关 [工作台行为](../../WORKBENCH_DESIGN.md)、C20 风险清单和首条流程公共端口。具体字段仍由本批设计冻结。

T50 取 B11 独立冻结端口，不等待 B16 或数学完整功能。冻结包必须给出 T51/T52 可分别实现的班级、教学记录关联端口、成功/失败样本和独占写者；T51/T52 在 T50 冻结且 B16 通过后并行。班级记录、普通日程与日期计算先做；T52 对班级端口的同版替身自验可交接给 T53，真实关联由 T53 汇合验证，不能据此宣称教学时间阶段通过。

作品公共端口尚未由 M40 冻结，T50 只能明确此项适配边界及待接条件，不发明提供方字段；不依赖作品的已冻结行为可先实现。T51 的作品适配实现须取得 M40 契约，如与本批语义冲突则回 T50/M40 修订受影响部分并独立冻结；T51 完整 self PASS 仍需 M44 真实作品。T52 到 T53 启动依赖保留，当前缺少重复实例、单次例外及提醒共享状态的冻结切分。T53 收齐 T51/T52 后独占教学时间集成，T54 仍验真实完整流程。

<a id="t50"></a>
## T50 冻结班级、日程和提醒行为

写入边界：`teaching-time` 批次包。

- 产物/完成：定义一句话记录、班级进度/共性问题/下次备注与备课/题目/作品关联；日程任意连续日期、拖选时段、全局优先级和段内顺序、未排期事项、每周重复/结束日/单次例外；区分计划授课与实际记录。确定账户时区和日期边界、提醒唯一性、时间修改/删除/重复实例的通知影响及关闭期间补呈现。

本节点补充边界：不引入任务完成状态、自动顺延或催办；缺公共端口须在实现前补设计，不能让实现者猜。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="t51"></a>
## T51 实现班级教学与备课反馈

写入边界：classes 模块、相关迁移、备课反馈及记录操作端口与 tests。

- 产物/完成：班级管理、快速一句话、教学位置/未讲内容/共性问题/下次备注保存可用；关联备课、题目、作品并双向回看。同一备课用于两班时记录独立，日程不自动标记授课完成。

本节点补充边界：非目标：个人学生管理。

启动与完成：先在 B16 基线上实现班级和一句话记录，按 T50 使用已冻结题目/备课端口；作品适配遵守上述输入条件。M44 到达后补齐真实作品关联和双向回看，提交完整候选与证据；之前保留未完成项，不把替身自验写作完整 PASS。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#t54)，具体场景由任务包列明。

<a id="t52"></a>
## T52 实现连续日期、安排和重复例外

写入边界：schedule 前后端、重复计算/迁移、班级备课关联、公共业务端口与 browser/逻辑 tests。

- 产物/完成：顶部唯一日程入口、连续天数与日期范围、真实拖选时间段和右栏编辑；同段多事项、全局优先级/段内排序、未排期记录；周重复、结束日期与仅改一次。更改日期范围不抢 AI，明确编辑才切工具，并保留对话草稿。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#t54)，具体场景由任务包列明。

<a id="t53"></a>
## T53 实现站内提醒和关闭期间补呈现

写入边界：提醒存储/计算、顶部通知接入、跳转、相关迁移与 tests。

输入与集成：T52 固定候选到达后可先做真实时段、重复例外、提醒与补呈现，不必等待 T51 的作品关联完成。完成另需 T51 固定候选，汇合班级/备课/教学记录关联及提醒返回，形成含 T51-T53 的真实集成候选、运行入口和证据交 T54；模块缺陷回原节点，时间或关联语义缺口回 T50。

- 产物/完成：用户设置结束前/后的间隔才触发；调整时段后按新时间计算；工作台关闭再进入仍看见原定提醒时间，不连续弹窗、不重复生成。点击标记已读并返回对应时段，不划完成线、不称任务逾期。服务重启、单次调课和重复进入结果一致。

本节点补充边界：复用简单持久记录与到期查询，不默认增加外部队列或推送服务。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#t54)，具体场景由任务包列明。
