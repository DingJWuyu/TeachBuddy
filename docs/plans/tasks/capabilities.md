# 能力实验与早期 Agent 任务说明

按任务包指定的节点章节读取；本文件不是整份必读材料。设计输入仅供设计者，实现者从冻结契约和本节点进入。以下均为计划要求，未来产物尚未生成。精确版本、逐文件写入权、验证命令和回执位置由派发给本 session 的任务包固定。产物齐全后按本角色协议自验或交审；下方链接仅定位本节点适用的验收要求，不要求实现者等待整个阶段验收。

## 设计输入

C20 读取首条流程的风险表、实际环境与已授权条件。C25 读取 C24 的实验材料和首条流程的业务服务契约。实验实现者只读取自己那一项的固定样本、最多两条候选路径与标准，不需要读取其他实验。

C20 在 B11 独立冻结后即可启动，不等待首流产品验收；其风险输入见 [B11 风险表](../../arch/first-flow.md#c20-需验证的问题与外部缺口)。C20 独立冻结后 C21-C23 可在隔离目录并行；C24 仍等待 B16 的真实服务与有效模型条件。环境或样本缺口只阻塞受影响实验，实验结果不能冒充产品能力。

<a id="c20"></a>
## C20 冻结有界实验、代表性材料和环境风险

写入边界：`docs/arch/capability-checks.md`、实验验收清单和所需材料索引。

- 产物/完成：给 C21-C24 每个实验最多两条候选路径、样本与量化/可观察通过标准，禁止试验后降低标准。提取样本覆盖四入口和中文高中数学；Office 覆盖现存格式、公式和多页；数学覆盖三类作品；pi 必须真模型真读写。记录授权可用的 DeepSeek/OCR 凭据、转换软件、字体、Office 查看编辑环境、课堂浏览器与部署主机条件。
- 产物还包括：单进程后端、SQLite、持久目录的候选交付路径及磁盘/重启/转换依赖限制。先查已有环境，不先采购或建服务。普通技术选择由 A 裁决；真实缺少凭据、设备或主机权限才列外部 BLOCKED，并给后续消费节点。

本节点补充边界：标准需能反驳不可行方案，不能不断加候选来掩盖失败。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="c21"></a>
## C21 验证图片/PDF/Word/文字自动拆题

写入边界：独立实验目录、脚本、原始输出及 `docs/arch/evidence/C21.md`，不接入产品。

- 产物/完成：四类入口均实际提取多题，记录拆题、公式、配图、选项/小问、已有答案解析、原稿位置映射的逐项正确/错误结果；保存失败材料可继续校对的路径。报告耗时、外部调用和失败恢复，输出可编辑结构候选，不能用手工逐题录入冒充自动提取。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#experiments)，具体场景由任务包列明。

<a id="c22"></a>
## C22 验证真实 Office 预览和可编辑输出

写入边界：独立实验目录、生成样本、对照截图和 `docs/arch/evidence/C22.md`。

- 产物/完成：真实 PPT/Word/PDF/图片逐页预览；明确 `.ppt/.pptx/.doc/.docx` 等实际支持与转换路径，不能静默把常见旧文件排除。生成含中文、公式、图、答案和教师注记的 Word/PDF；在可用 Office 编辑器中修改文字和公式再保存，并检查打印分页。只检查 DOCX XML 或把公式图片放进 Word 不足以 PASS。

本节点补充边界：报告转换组件、字体、体积/时间及候选部署环境可运行性。阻塞判定见该实验验收条目。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#experiments)，具体场景由任务包列明。

<a id="c23"></a>
## C23 验证数学制作、源码和离线演示

写入边界：独立实验、样例和 `docs/arch/evidence/C23.md`。

- 产物/完成：调查并实测候选工具/skill，用公式、函数图像、平面图、立体图和带参数/拖动/步骤的动态作品验证制作、二次修改、源码保存、透明 PNG、SVG、离线 HTML。导入一个外部 AI HTML，列出实际可编辑范围；断网冷启动验证全部必要资源本地可用。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#experiments)，具体场景由任务包列明。

<a id="c24"></a>
## C24 验证 pi 与 DeepSeek 的真实服务调用

写入边界：隔离适配实验和 `docs/arch/evidence/C24.md`，不自建 runtime。

- 产物/完成：核实 pi 的准确包、版本、许可证、扩展与持久会话接口、DeepSeek 适配；真模型调用题目查询和一次幂等写入已有业务服务，页面可重找结果。验证一次工具失败/中断与手动修改冲突，记录恢复语义和脱敏工具轨迹。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#experiments)，具体场景由任务包列明。

<a id="c25"></a>
## C25 冻结早期 Agent 与持久对话契约

写入边界：`agent` 故事、UX、契约、架构与 .feature。

- 产物/完成：首页完整 Agent、侧栏固定入口和业务右栏共用同一对话；冻结消息/引用/输入草稿持久化、流式中断与恢复、工具权限、重复执行和手动编辑冲突、实际费用/密钥配置的必要边界。先开放题库和备课，定义其余模块如何提供静态工具适配并调用同一业务服务。

本节点补充边界：工具调用同一业务服务并遵守权限，不为 Agent 另建脱离手工操作的数据，也不预设任意 shell 执行。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="c26"></a>
## C26 实现 pi 首页、共用右栏和首批操作

写入边界：API Agent 适配/对话存储、Web Agent 工作区与右栏、题目/备课工具适配、相应测试和独占集成清单。

- 产物/完成：DeepSeek 通过 pi 真读写题库/备课，对话跨刷新持久；工具/AI 切换与页面往返继续同一会话，失败不谎报操作完成。密钥留服务端；业务所有权来自已验证身份接缝。按 C25 暴露后续模块接入点，不搭通用插件市场。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#c27)，具体场景由任务包列明。
