# 节点职责参考

这里是完整 DAG 的节点边界与验收归属，不是活动任务列表。当前授权和状态读[台账](../run-state.md)；实际模块修复从[领域页](../../README.md#模块入口)进入。

- `first-flow*` / `auth-*`：首条保存链及认证接线。
- `materials*`：文件、资源、收题、备课输出与材料接缝。
- `math.md`：数学制作、源码、离线和往返。
- `teaching-time.md`：班级、日程、提醒。
- `capabilities.md`：有界实验的原判据，旧调用窗口不重开。
- `agent-implementation.md`：暂停的产品 Agent 范围。
- `reliability*` / `delivery.md`：完整可靠性、交付与用户门槛。

编排者给执行者的是按[短模板](../task-package.md)固定的新任务包，只引用这里实际需要的节点。原说明中的候选、阶段写者和实验样本属于对应固定设计输入，不能当成当前运行位置或重新从零实施的指令。
