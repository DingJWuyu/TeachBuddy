# M43 / 工坊备课往返与离线成果集成

背景与目标：把M42与真实材料备课接起来，教师从具体环节制作/复用作品、带回、更新、另存和离线使用，原稿与现场不丢。提供可供后续Agent消费的实际操作清单。

任务输入：固定 M42、M40、实际材料候选及公共文件唯一写权。本地切片启动与完整 M43 完成分别按[DAG](../../mvp-dag.md)，不能用本地或接缝 PASS 代签完整 R35。若接教学反馈，还要教学时间新版OpenAPI/固定T51候选；T50参考候选不能当已集成输入。

边界：[架构M43与公共文件清单](../../../arch/math.md#分阶段写权)。M43独占本批装配、lessons v3/MathReference适配、math返回/使用位置、跨模块E2E。与R34/T53的公共目录、入口、锁和lessons/math页面写入由外层串行交接，不抢写。模块自身缺陷回原实现固定新候选后再集成。

必读：[UX U-MA0、5、6、7](../../../ux/math.md)；契约“材料引用新版与备课返回”“目录、公共端口与教学反馈”；[MC05至12](../../../contracts/workbench/math/cases.md)；[WB-MA009至014、017至020](../../../acceptance/math.feature)。涉及教学记录才读[教学时间扩展](../../../contracts/workbench/math/teaching-time-extension.md)，涉及真实登录/失效只读现行认证交接，不重设计身份。

完成条件：

- 从实际备课草稿/指定课时环节进入，制作或复用、保存、带回，原选中/滚动/未提交文字/AI现场恢复。作品和备课两次保存的失败/未知结果可恢复，环节删除/冲突不自动改目标，取消返回不加入引用。
- 同源多课快照独立，显式采用更新/另存替换、普通去重/明确重复、源软删除恢复与使用位置真实工作。旧v2遇math拒绝有损操作；v3读取旧材料不迁移改写，保留已受理导出及未知请求。
- 静态素材实际用于外部PPT；含math的教案/讲义使用受控源/固定海报且教师备注过滤不泄漏。动态HTML不交Office执行、不宣称PPT交互嵌入。R35支持范围之外的目标环境仍分列。
- 最终M-D/M-X真实下载物：服务关闭、新配置冷缓存、禁网、file双击，检查数学结果、滑杆/键盘、拖点、步骤和重置；记录具体浏览器/OS。未到Windows/PPT/WPS环境则该目标片标待验并归外层，不能冒签。
- 目录version=3只注册实际模块，缺提供方/重复/环明确失败。教学时间如未接真，保留扩展待接说明，不用空数组或占位反馈签WB-MA018。
- Agent操作清单置本节点integration.md或operations.md，给实际operationId、参数schema入口、源读取/制作/修改/导出/带回序列、真实与未接项、身份/版本/未知结果。无需调用新模型，也不以直接HTTP回放替代后续真实Agent验收。
- `node --test apps/api/test/math-integration*.test.js`；`npx playwright test apps/web/e2e/math-integration*.spec.js`；共同API/build及受影响材料与math E2E。空库、R35旧库、已有math库迁移/重启验证；对照保存前后ID/版本/文件和旧快照。

回执：固定最终候选、实际README状态、全部运行/数据隔离入口、独占变更清单、逐场景self和目标环境未决项，交M44独立验收。本节点self不替代M44 independent，也不代替教学时间的完整反馈条件。WB-MA018由T51在M44作品候选到达后接真、T54独立验收；M43/M44只交可用提供方与装配位置，不为等待反馈形成反向依赖。
