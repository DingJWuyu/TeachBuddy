# 数学作品与课堂离线任务说明

按任务包指定的节点章节读取；本文件不是整份必读材料。设计输入仅供设计者，实现者从冻结契约和本节点进入。以下均为计划要求，未来产物尚未生成。精确版本、逐文件写入权、验证命令和回执位置由派发给本 session 的任务包固定。产物齐全后按本角色协议自验或交审；下方链接仅定位本节点适用的验收要求，不要求实现者等待整个阶段验收。

## 设计输入

M40 读取 [PRODUCT_SCOPE](../../PRODUCT_SCOPE.md) 的数学工坊及备课往返段落，相关 [工作台行为](../../WORKBENCH_DESIGN.md)，C23 实验，以及材料阶段冻结的内容、文件和引用契约。

M40 的材料输入是 R30 独立冻结包，不是 R35 完整产品；设计可与材料实现并行。M41 在 M40 冻结且 R31 文件底座完成后启动，独立制作、保存和导出不等待资源/收题/六种输出验收。备课返回适配按 R30/M40 冻结契约准备，最终 M43 必须等 R35 固定材料候选与 M42，接真后交 M44。M41 到 M42 的启动依赖保留：尚无 M40 对共用作品、源码存储和写入边界的冻结切分。

<a id="m40"></a>
## M40 冻结工坊制作和往返契约

写入边界：`math` 批次包和 M41-M43 文件清单。

- 产物/完成：选定经过验证的工具/skill；定义公式、函数/平面/立体静态图、动态作品的制作内容、修改能力、标注样式、预览/演示、适用导出和源码版本。定义导入外部 HTML 的隔离与编辑边界、离线依赖和支持浏览器，以及备课目标课时/环节的返回协议。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="m41"></a>
## M41 实现公式与静态数学素材

写入边界：math 的公式/静态制作前后端、源码持久化、导出、公共业务端口和 tests，独占集成清单。

- 产物/完成：公式可编辑且可出透明图；函数、常见平面与立体图能实际制作、改标注样式、保存重开修改并导出 PNG/SVG。检查数学结果与公式可读性，不以画布空壳和样例按钮通过。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#m44)，具体场景由任务包列明。

<a id="m42"></a>
## M42 实现动态作品和外部 HTML 导入

写入边界：动态制作/修改、源码/参数/步骤保存、导入与隔离预览、下载打包及 tests。

- 产物/完成：按教学意图建立可交互作品，修改后保存并恢复；参数、拖动、分步展示按作品适用能力真实工作。外部 HTML 原文件可保存、预览和再次取回，说明真实可修改范围；不能运行在可读取账户凭据和主应用数据的上下文中。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#m44)，具体场景由任务包列明。

<a id="m43"></a>
## M43 集成工坊、备课往返和离线成果

写入边界：工坊与备课公共端口适配、返回现场、跨模块 E2E 及集成清单，并交付可供 Agent 使用的操作清单。

输入与集成：接收 M42 和 R35 的固定候选；本节点独占本批装配，备课共享文件按根交接的唯一写者处理。开发替身或仅制作端通过不能替代真实往返、重启与离线验证。

- 产物/完成：从指定备课环节进入制作，完成带回且草稿/选中/滚动不丢；已有作品可复用，修改影响遵守版本规则。下载动态成果后，在全新浏览器环境断网打开，不靠工作台登录、CDN 缓存或本地服务；静态输出用于外部 PPT 的实际取用可验证。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#m44)，具体场景由任务包列明。
