# 材料、题库与备课输出任务说明

按任务包指定的节点章节读取；本文件不是整份必读材料。设计输入仅供设计者，实现者从冻结契约和本节点进入。以下均为计划要求，未来产物尚未生成。精确版本、逐文件写入权、验证命令和回执位置由派发给本 session 的任务包固定。产物齐全后按本角色协议自验或交审；下方链接仅定位本节点适用的验收要求，不要求实现者等待整个阶段验收。

## 设计输入

R30 读取 [PRODUCT_SCOPE](../../PRODUCT_SCOPE.md) 的题库、备课、资源库及基础交付段落，相关 [工作台行为](../../WORKBENCH_DESIGN.md)，首条流程冻结契约，以及 C21/C22 原材料和输出。实现者只读取任务包指定的契约操作和本节点说明。

R30 不等待 B16，可以先冻结材料设计；R31 实现仍取 B16 固定的运行/迁移基线。R30 独立冻结包必须提供 R32/R33/R34 共用的文件、内容、引用端口与成功/失败样本，并分配共享入口、依赖与迁移文件的唯一写者。R31 完成后这三个消费者并行，不以资源 UI 或自动收题全部完成作为备课输出启动条件。文件/内容基础接缝已取得下述限定冻结；完整 R31 到 R32/R33/R34 的启动边仍保留，M41 仅按另行冻结的限定隔离范围例外。

R32/R33/R34 各自修改 resources/questions/lessons；未到达的跨模块输入使用同版契约样本或测试 adapter，只记录对应 self 结果。R34 接收 R31-R33 的固定候选并独占本批集成，再报完整 self PASS；R35 的真实材料流程与独立验收要求不变。跨 flow 的备课适配和共享入口按根指定的单写者交接，不覆盖其他候选的变更。

R35 的具名本地材料消费切片取得 independent PASS 后，可作为 M43 本地实现的一项启动输入，但还必须同时固定 P/M/D 并交接共享唯一写权。此限定例外已经[独立核验](../../acceptance/evidence/R30-MATERIALS-CONTINUATION/v1/review.md)并纳入 DAG，详细范围只由[接续裁决](../../arch/materials-continuation.md#r35-m43-m44-gates)拥有。R35 当前仍在验收，不表示该切片已通过或 M43 已开始；完整 R35 仍是完整 M43 的完成门禁。

## R30 冻结材料、数学内容与导出行为

写入边界：`materials` 批次包及 R31-R34 的精确文件清单。

- 产物/完成：裁决真实文件归属、原稿页/区域定位、题目内容结构演进、自定义题型/标签增改删与检索、识别校对与部分失败、资源文件替换的引用版本、备课三类输出的结构和答案/注记选择。明确转换重试/进度和未确认结果，使用简单持久任务记录仅在长操作确实需要时引入，不设计队列平台。
- 产物还包括：Word 可编辑公式的证据门槛、六种输出组合、每格式样本、重复上传/磁盘失败/重启恢复、文件和软删除关联、Agent 公共端口；决定题目取用到手工 PPT 的可用素材路径，不承诺整套 PPT 生成。

本节点补充边界：实验失败要回设计处理，不能缩成上传后手工录入或 Office 仅下载。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

## R34 交付完整备课编辑和 Word/PDF 输出

写入边界：备课编辑、材料总览/环节取材、导出服务及界面、对应业务端口和 tests、冻结集成清单。

- 产物/完成：自定环节增删命名排序、未安排材料、重复引用和本课备注可保存；教案/提纲、导学案/讲义、练习三类均可导出 Word 和 PDF。文字/公式在 Word 可编辑，图按图形处理；输出可选答案与教师注记，学生材料不会泄漏未选内容。

- 集成完成：收齐 R32/R33 固定候选后，以真实文件预览/替换、自动收题/校对结果走到备课取材和六种输出；提交包含 R31-R34 的固定集成候选、运行入口和证据交 R35。消费者替身的先行自验不满足此条件，模块缺陷回原节点，公共语义缺口回 R30。
