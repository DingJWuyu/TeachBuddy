# 可运行交付任务说明

本页保留 DAG 节点的职责、依赖和完成要求，不记录当前是否已实现，也不是本次派发授权。当前状态读 [run-state](../run-state.md)，实现入口读 [模块地图](../../README.md#模块入口)。执行者只读任务包点名的节点章节；已实现节点按实际缺口接续，不从零重做。

## 设计输入

D70 读取全功能验收结果、C20 环境清单与实验依赖，以及 [PRODUCT_SCOPE](../../PRODUCT_SCOPE.md) 的基础交付要求。D71/D74 只读取获批动作清单、当前候选版本和本任务所需环境说明；授权是否齐全由派发表明确。

<a id="d70"></a>
## D70 固定交付环境与操作说明

写入边界：`delivery` 架构/验收包和具体交付动作清单。

- 产物/完成：在单用户需要下选一个简单可持续的运行路径，核对同源 HTTPS、SQLite/文件持久卷、转换字体/二进制、pi/DeepSeek、邮件、备份位置、重启和升级。区分已获授权的验收环境与尚需授权的公开部署动作；明确地址、桌面/Pad/离线浏览器支持范围和恢复步骤。

本节点补充边界：环境无持久盘、缺转换能力或外部权限不足则 BLOCKED；普通实现配置由本设计裁决，不让用户选择架构。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#design-review)，具体场景由任务包列明。

<a id="d71"></a>
## D71 制作并运行交付候选

写入边界：冻结的启动/部署配置、交付说明、README/SETUP/ARCHITECTURE/API 状态与集成修复，不扩建 CI/CD。

- 产物/完成：从干净 checkout 按说明构建启动，提供实际可访问的验收 URL、固定候选 SHA、环境变量名称、持久路径、备份/恢复步骤与支持限制。可用授权本机局域网环境验证，不为取得地址擅自公开发布。重启/替换应用版本后真实数据仍在，桌面与 Pad 可访问。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#d72)，具体场景由任务包列明。

<a id="d74"></a>
## D74 按许可完成集成和交付

写入边界：获批集成冲突修复和必要状态文档；在授权范围内操作 Git/运行环境。

- 产物/完成：main 未移动时按许可合入已审候选；main 已移动或冲突则产出新的合并候选，并由新 A 先复核受影响 diff/回归再落到 main，不能把冲突解决视为纯机械操作。正式版本按仓库 Release PR 流程，推送、Tag、发布仅在授权内进行，不手改 CHANGELOG。

本节点补充边界：记录最终 commit、部署制品及数据迁移前备份；冲突或构建失败保留候选，行为变化回对应设计拥有者。

验收入口：[本节点适用条目](../../acceptance/mvp-matrix.md#d75)，具体场景由任务包列明。
