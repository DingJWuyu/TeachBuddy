# 单次任务包

任务只带目标、固定输入、必要资料、写入和运行边界、完成条件及回执位置。例如：

```text
目标：老师修改题目后能确认保存，刷新仍能读取。
输入：preview 的固定 commit，保留所列未提交文件。
必读：features/questions.md；contracts/workbench.md 的写入与恢复节；相关 v2 操作。
边界：题库模块；公共编辑器由指定唯一写者修改；运行使用隔离数据。
完成：任务指定的正常保存及失败复现场景，通过后提交并返回具名证据。
回执：本次 .scratch 目录，含实际模型、版本、结果、未决和下一步。
```

只在目标涉及时补读文件、数学或教学接缝。固定输入缺失应给具体对象和解除条件，不用不存在的路径充当规格。派发身份、attempt、session、模型/effort、候选与权限记录放本次 `.scratch/<任务>/`，当前待办更新 [run-state](run-state.md)，不在长期文档积累回执。
