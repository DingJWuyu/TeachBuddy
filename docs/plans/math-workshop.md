# 数学工坊界面重构

接续数学体验反馈先读本页，再读[设计规则](../rules/design-and-verification.md)、[数学行为](../features/math.md)和[开发约定](../agents/module-development.md)。本页记录当前授权和交付条件；整体进度、未解决问题与下一步归[项目状态](run-state.md)。

## 目标与现场

桌面 Edge 与 Chrome 的网页 AI 首次接入、扩展安装及更新体验已完成本机实现和独立验证。用户指引只呈现当前所需的下一步，保留底部模型选择器浮层、已认可的布局与渐进式披露；数学制作、内容保护、输出和备课等功能保持不变。设计与文案要求统一读取[设计规则](../rules/design-and-verification.md)。

用户尚未准备开发者账号或商店条目。本机实现、两个浏览器的隔离验证与可提交的安装包已备齐；正式商店安装和自动更新须在实际发布后验证，不用模拟结果代替。Firefox 与其他浏览器不纳入本轮。扩展实现方案的后续深入优化与当前剩余项统一见[项目状态](run-state.md#剩余事项)。

本次由项目总控集成数学成果并清理独立工作树，授权与实际进度统一读取[项目状态](run-state.md#工作现场与授权)。后续任务从更新后的 trunk 创建新现场；全站 Agent 继续暂停。

## 体验目标

- 一个数学工坊入口、同一份作品，公式、二维/三维图形、参数与教学步骤按操作需要出现。自然语言是主要制作方式，直接手动制作也有清楚入口。
- 按 Don't Make Me Think 和亲密性、对齐、重复、对比组织界面。参考日程现有样式，不另立品牌或套用通用 AI 模板；参考优秀画布编辑器的排版、留白、工具组织与细节，并转化为本项目风格；具体排版由设计者在真实页面验证，不能以功能通过或组件拼接代替美观。
- 文案用日常说法，名称通常 2-4 字，提示短句不超过 20 字；信息足以判断操作和后果。辅助说明只出现在有助于决策的位置。
- 删除数学产品中的“草稿”话术、卡片与管理界面；自动保存、失败重试、未知结果确认、取消和冲突保护继续可靠工作。
- 顶部栏与左导航保持原有外壳。全站 AI 入口保留原星芒图标；数学侧栏使用自有视觉，不使用 Gemini 标识。
- 免费 DeepSeek 继续通过已授权浏览器扩展连接正常网页账号；老师日常操作留在工作台。连接状态对应当前浏览器，安装、登录与断连处理清楚可执行。保留用户私有登录配置。
- GGB 继续使用项目本地固定源码构建的运行时；不重写几何引擎，不重新引入官方远程程序。公式、图形、步骤的编辑源、历史、导出及备课版本语义保持。

## 执行边界

后续功能按独立数学模块设计，以自身制作、编辑、管理、导出和演示闭环为范围。备课与班级教学的现有联动保留，暂不设计或扩展这两类联动，也不将其完善列为数学新功能的完成条件。若改动确实影响既有联动，单独说明影响，避免无意破坏；这不授权拆分独立应用或重建公共支持能力。

数学工坊专属总控承担模块内方案讨论、任务编排与验收；其他模块及全局集成由项目总控负责。当前会话与工作树安排见[项目状态](run-state.md#工作现场与授权)。

后续派发使用 Codex，按[开发约定的模型映射](../agents/module-development.md#模型与固定派发)选择模型与 effort，不再使用 agy。设计者按设计规则独立判断视觉方向，现有审美与总控个人审美不作为答案；数学总控核对授权、功能保持和验证证据。

界面执行者负责布局、文案、交互、焦点和相关前端接线。遇到数学核心、后端、持久化或网页桥功能缺陷时，先用真实用户路径复现，向总控提供证据，由总控另行分派。共同文件由总控指定唯一写者；仍未解决的问题同步项目状态，已关闭问题的详细回执留任务产物。

## 完成条件

1. 日程已进入 preview，math 已同步；日程有效源码、固定回归、体验数据及有用证据均保留，旧工作树及分支按授权清理。
2. 实际完成新建、手动加入公式与图形、修改参数和教学步骤、试演、保存刷新、下载及备课往返。所改路径的真实结果正确，未改能力沿具名既有证据，不重复昂贵的无关重建。
3. 检查首页、完整作品、属性、助理连接状态、弹窗及课堂展示的实际画面；深浅主题、常用桌面、较窄桌面与窄屏无裁切/溢出。真实键盘、点击、拖动和动效符合设计规则，截图与机械断言不能相互替代。
4. 原顶部 AI 图标在首页、数学和备课均实际可见且可打开；无重复入口、无散落的小字或技术流程说明。保存和破坏性动作有准确反馈与保护。
5. 固定候选完成独立 Standards/Spec 审查及受影响行为验证；确认缺陷修复并复验，不把待验写成通过。
6. 同步当前行为和状态，清理无用临时产物；最终运行服务与交付候选一致。体验沿 preview 当前源码，已集成的临时现场按清理规则处理；真人满意度由用户验收。
