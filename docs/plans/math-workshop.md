# 数学工坊统一制作任务

接续本轮数学重做时先读本页，再读[本地设计规则](../rules/design-and-verification.md)、[数学规格](../features/math.md)与[开发约定](../agents/module-development.md)。本页保存当前授权、交付条件与验证边界；当前行为归数学规格，整体状态归[项目状态](run-state.md)。

## 目标与权限

- 用户授权总控自主组织长程设计、实现与验收。工作现场固定 `TeacherWorkspace-math` / `work/math-workshop`；起点 `3fcbbcf2`。最终成果留本工作树，不合 preview/main，不推送。日程、Agent 和 preview 不在修改范围。
- 仅把日程 worktree 当前 `docs/rules/design-and-verification.md` 原样同步到本工作树；后续读取本地文件。不等待或集成日程代码。
- 老师从一个数学工坊入口制作同一份可编辑作品，公式、平面、三维、动态及教学步骤按任务融入统一体验；不让用户选择技术引擎或四个独立制作入口。既能自然语言起稿，也能直接手动操作。
- GGB 复用数学、构造和绘图能力，界面由工作台设计；公式复用成熟编辑/渲染组件。不重写几何引擎，也不把原生 GGB 工具栏换色当作完成。
- GGB 运行代码及所需资源随项目自行提供，屏蔽官方域名后仍能加载、作图、保存和重开。优先按固定源码构建所需组件，核清实际资源与许可证；不得把官方完整非商用资源包伪称纯源码内核。全站离线与 DeepSeek 离线不在本轮目标中。
- 免费 DeepSeek 网页桥继续使用正常登录账号，老师日常操作留在工作台侧栏；一次安装浏览器扩展已获接受。保留已登录的私有浏览器，隔离实例不得覆盖用户日常资料。不用付费模型 API，不引入复制粘贴或桌面伴侣流程。
- 老数据为测试用途，不要求历史草稿迁移；实现过的有价值教学能力和新作品持久正确性须保留。全站 Agent 定位及扩展继续暂停。

## UI/UX 硬约束

- Don't make user think：常用操作可见，属性随对象选择出现，可选信息渐进展开，避免整屏表单、层层卡片与重复入口。
- 用户否定现有数学 UI。新设计遵守已同步规则的层级、字体、动效、浮层、对齐、焦点和真实手势验证。主内容易读；辅助小字仅在帮助决定或解释实际问题时出现。
- 删除数学产品中的“草稿”类话术、草稿卡片与管理界面；自动内容保护沿既有可靠持久化机制处理，不换名称复活同一管理流程。必要冲突与破坏性确认说明实际操作结果。
- Gemini 只作为协作体验参考，不使用其品牌图标或视觉标识。数学侧栏与相关入口使用一致的自有视觉，保持其他模块外壳稳定。
- 一个作品内自然容纳公式、图形、参数与讲解步骤；编辑、试演和课堂展示区分清楚，退出展示回到原编辑内容。AI 与手动操作读取同一当前状态。
- 用户自己的浏览器曾显示扩展未连接。首次连接须提供真实且可执行的引导、准确状态与恢复操作；不能把主控专用浏览器成功当作普遍开箱即用。

## 必须完成的验证

1. 全新进入，直接手动创建公式与图形，添加三维内容、参数变化及教学步骤；同一制作空间完成修改、撤销、保存、刷新重开。空作品退出不制造空记录。
2. 现有有价值成果得到承接：公式可编辑源、图片输出、备课取用与版本、教学步骤和可带走的课堂成果。对应实际文件需打开核对，不能以下载成功代替可用。
3. GGB 不访问官方域名：全新浏览器配置、无既有缓存，阻断官方网络后运行必要制作与文件流程。安装/构建可从独立检出重建，不依赖本机忽略目录或旧任务产物。
4. 未安装扩展、安装后、未登录、已连接和断连分别验证；真实 DeepSeek 从自然语言作图，经手动改图到 AI 继续修改，核对真实画布与保存读回。
5. 防丢失与竞态：取消执行、迟到响应、离开页面、刷新、冲突、历史恢复与保存未知状态沿实际用户路径验证。此前取消前即时手动修改丢失的保护必须保留。
6. 视觉与交互：深浅主题、桌面/较窄桌面/窄屏，真实点击输入拖动，检查画布与侧栏边界、字号、焦点、滚动及动效。完整制作流程的易用性和截图检查均为完成条件。
7. 固定候选进行独立 Standards/Spec 核验，修复后复验具名影响范围。作者自验、独立验收与用户体验分别记录。
