# 数学工坊界面重构

接续本轮任务先读本页，再读[设计规则](../rules/design-and-verification.md)、[数学行为](../features/math.md)和[开发约定](../agents/module-development.md)。本页记录授权和交付条件，整体进度归[项目状态](run-state.md)，当前功能问题归[问题缓冲区](math-ux-buffer.md)。

## 目标与现场

用户已否定现有数学工坊的 UI/UX。本轮重做首页、统一编辑器、数学助理侧栏、菜单弹窗与文案，以最新日程的真实页面和设计规则为视觉参考。保留已经实现的数学制作、网页 AI、内容保护、输出和备课能力。

总控自主决策并完成交付。最新日程成果先集成到 preview，再同步 math；核对成果及体验资料已保留后，删除日程工作树与已集成分支，将其独立 session 标记为 old。数学成果留在 `TeacherWorkspace-math` / `work/math-workshop`，不合 preview/main，不推送；数学工作树与体验服务保留。全站 Agent 继续暂停。

## 体验目标

- 一个数学工坊入口、同一份作品，公式、二维/三维图形、参数与教学步骤按操作需要出现。自然语言是主要制作方式，直接手动制作也有清楚入口。
- 按 Don't Make Me Think 和亲密性、对齐、重复、对比组织界面。参考日程现有样式，不另立品牌或套用通用 AI 模板；参考优秀画布编辑器的排版、留白、工具组织与细节，并转化为本项目风格；具体排版由设计者在真实页面验证，不能以功能通过或组件拼接代替美观。
- 文案用日常说法，名称通常 2-4 字，提示短句不超过 20 字；信息足以判断操作和后果。辅助说明只出现在有助于决策的位置。
- 删除数学产品中的“草稿”话术、卡片与管理界面；自动保存、失败重试、未知结果确认、取消和冲突保护继续可靠工作。
- 顶部栏与左导航保持原有外壳。全站 AI 入口保留原星芒图标；数学侧栏使用自有视觉，不使用 Gemini 标识。
- 免费 DeepSeek 继续通过已授权浏览器扩展连接正常网页账号；老师日常操作留在工作台。连接状态对应当前浏览器，安装、登录与断连处理清楚可执行。保留用户私有登录配置。
- GGB 继续使用项目本地固定源码构建的运行时；不重写几何引擎，不重新引入官方远程程序。公式、图形、步骤的编辑源、历史、导出及备课版本语义保持。

## 执行边界

UI/UX 设计和实现本轮临时使用 `gpt-6-astra / medium`，其余按开发约定派发。界面执行者先提交一条完整制作路径的实际页面，由总控检查视觉方向后展开；无需用户逐步确认。

界面执行者负责布局、文案、交互、焦点和相关前端接线。遇到数学核心、后端、持久化或网页桥功能缺陷时，先用真实用户路径复现，在问题缓冲区记录证据并通知总控，由总控另行分派。共同文件由总控指定唯一写者。

## 完成条件

1. 日程已进入 preview，math 已同步；日程有效源码、固定回归、体验数据及有用证据均保留，旧工作树及分支按授权清理。
2. 实际完成新建、手动加入公式与图形、修改参数和教学步骤、试演、保存刷新、下载及备课往返。所改路径的真实结果正确，未改能力沿具名既有证据，不重复昂贵的无关重建。
3. 检查首页、完整作品、属性、助理连接状态、弹窗及课堂展示的实际画面；深浅主题、常用桌面、较窄桌面与窄屏无裁切/溢出。真实键盘、点击、拖动和动效符合设计规则，截图与机械断言不能相互替代。
4. 原顶部 AI 图标在首页、数学和备课均实际可见且可打开；无重复入口、无散落的小字或技术流程说明。保存和破坏性动作有准确反馈与保护。
5. 固定候选完成独立 Standards/Spec 审查及受影响行为验证；缓冲区的确认缺陷修复并复验，不把待验写成通过。
6. 同步当前行为和状态，清理无用临时产物；最终运行服务与交付候选一致。保留 math 工作树供用户体验，真人满意度由用户验收。
