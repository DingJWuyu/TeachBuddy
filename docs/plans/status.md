# 当前状态与接续

实际开发以 `preview/usable-mvp` 为准。`main` 尚未合入当前产品，现有本机预览入口为 `https://localhost:50880`。本页只记录仍影响接续的状态；功能范围以 [产品范围](../product/scope.md)为准。

## 已可体验

六个业务模块的手动路径、设置中的资料导出与最近删除、帮助和更新日志页面已进入预览。题目收录、备课取材与 DOCX/PDF 输出、资源预览、数学作品、班级记录和日程都已有真实前后端路径。已有自验与限定独立检查只覆盖其受测范围，完整 MVP 仍未通过。

顶部栏、侧栏、首页、认证及共享 AI 入口保持当前实现。全站外壳后续改造和产品 Agent 扩展由用户暂停；接续需用户新指令。手动业务仍按原范围补齐，不能因线路暂停删减功能要求。UI 交互采用渐进的打开、关闭、展开与收起，保护已确认的界面。

## 工作边界

当前在唯一开发树继续处理用户反馈和已授权的手动业务，按实际影响做定向验证。原库 `main`、用户数据、`.scratch/preview`、配置和运行中的服务保持原状。`main` 合并、push、部署及发布分别需要用户授权。历史候选和回执可由 Git 或私有现场按需追溯，不在本页重建过程台账。
