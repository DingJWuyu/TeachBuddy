# 全站界面与交互清查

本页供本轮接手、派发和验收使用。总控覆盖更新检查范围、发现、证据及下一步；模块行为归现有规格，待产品决定的功能差异仍归根 [buffer](../../buffer.md)。完成集成后将结果收进运行台账并移除此临时任务记录。

## 目标与边界

用户在全站前端迁移后指出：首页“新建对话”图标挤在夹缝中，日程从任务切回日历时整页闪烁。要求先复现修复，再并行清查其余页面，避免只依赖既有 CI。

- 基线：`ed5004501b0f7a82f17ddd0bd428ad9851db5153`。现场：`TeachBuddy-ui-audit`，分支 `fix/ui-interaction-audit`。
- 检查实际布局、可点击区域、切换过程、弹层遮挡、滚动与焦点、保存后的界面反馈，覆盖真实常用操作及宽窄容器、中英文和深浅色。检查组合按实际触发选择，不机械展开所有排列。
- 保持既定视觉和产品结构；明确的前端缺陷用最小修改修复，包括原型中存在而本轮确认为缺陷的同类问题。设计输入只读，不增加功能或重新设计页面。
- 后端业务、协议、存储、真实外部模型、邮件、私人账户及用户数据不在本轮写入范围。业务能力差异仍按 buffer 处理，不能用此轮清查扩展功能。
- 使用现成隔离 fixture 和真实浏览器。先记录实际症状，再定位根因；仅为值得长期保护的真实缺口补既有 E2E。作者定点，完整候选集中审查，CI 承担完整回归，不重复本地全量。
- 总控管理 Git、公共源码、测试收集、台账及 buffer；各作者仅写下表独占文件。共享构建由总控生成，作者不互相覆盖构建或数据。

## 并行归属与覆盖

各作者使用 fresh context，`gpt-6.1-sol / medium`，职责是实际检查、常规前端修复与定点自验。固定候选的独立 Standards/Spec 按既有流程使用 `gpt-6.1-sol / xhigh`，集中执行一次；增量只补受影响范围。

| 工作线 | 源码与测试写入归属 | 必查路径 |
| --- | --- | --- |
| audit_home | `features/agent/`、`features/workbench/`，排除设置/帮助、demo；catalog/navigation/module-layout 与 c26/agent 相关用例 | 首页新建对话图标、会话展开收起、首页/辅助栏往返、导航折叠/拖排、顶栏各弹层、模块往返 |
| audit_schedule | `features/schedule/`、`e2e/schedule/` | 任务到日历的完整帧过程；日期/视图切换、编辑器开合、拖动、提醒与确认、辅助栏开闭 |
| audit_account | `features/auth/`、设置/帮助相关 workbench 文件、`features/reliability/`，对应 auth/settings/help 用例 | 登录/注册/找回切换、输入与角色动画、设置各页与主题语言、帮助阅读、确认层和焦点 |
| audit_materials | `features/questions/`、`features/resources/`，对应 questions/resources 页面用例 | 空/有数据、筛选与编辑、预览/详情、上传/保存/重开、菜单及宽窄工具栏 |
| audit_math | `features/math/`，对应 math 页面用例 | 作品列表/制作/网页、公式与画布、保存/历史/下载、辅助栏、弹层与退出 |
| audit_classroom | `features/classroom/`、`classroom.spec.js` | 名单/座位/学生/记录/考试/导入/统计、归档、标题与胶囊布局及页内切换 |
| 总控 | `components/`、`styles/`、App/公共装配及其必要回归，全局文档与 buffer | 共享浮层/焦点/层级、容器与页面动效、跨模块组合；复核用户两条原始路径 |

作者先实际探索本域，带着症状沿源码追查；只看源码、截图或跑现有套件不算完整检查。每条工作线提交实际访问的路径/状态、发现与未发现范围、修前修后证据、修改文件及尚未覆盖项。证据放 `.scratch/ui-audit/<工作线>/`，不提交截图和临时脚本。
