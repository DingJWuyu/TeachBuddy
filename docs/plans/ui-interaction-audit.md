# 全站界面与交互清查

本页供本轮接手、派发和验收使用。总控覆盖更新检查范围、发现、证据及下一步；模块行为归现有规格，待产品决定的功能差异仍归根 [buffer](../../buffer.md)。完成集成后将结果收进运行台账并移除此临时任务记录。

## 目标与边界

用户在全站前端迁移后指出：首页“新建对话”图标挤在夹缝中，日程从任务切回日历时整页闪烁。要求先复现修复，再并行清查其余页面，避免只依赖既有 CI。

- 基线：`ed5004501b0f7a82f17ddd0bd428ad9851db5153`。现场：`TeachBuddy-ui-audit`，分支 `fix/ui-interaction-audit`。
- 检查实际布局、可点击区域、切换过程、弹层遮挡、滚动与焦点、保存后的界面反馈，覆盖真实常用操作及宽窄容器、中英文和深浅色。检查组合按实际触发选择，不机械展开所有排列。
- 保持既定视觉和产品结构；明确的前端缺陷用最小修改修复，包括原型中存在而本轮确认为缺陷的同类问题。设计输入只读，不增加功能或重新设计页面。
- 后端业务、协议、存储、真实外部模型、邮件、私人账户及用户数据不在本轮写入范围。业务能力差异仍按 buffer 处理，不能用此轮清查扩展功能。
- 使用现成隔离 fixture 和真实浏览器。先记录实际症状，再定位根因；仅为值得长期保护的真实缺口补既有 E2E。作者定点，完整候选集中审查，CI 承担完整回归，不重复本地全量。
- 总控管理 Git、公共源码、测试收集、台账及 buffer；各作者仅写下表独占文件。共享构建由总控生成，作者不互相覆盖构建或数据。
