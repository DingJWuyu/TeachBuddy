# First-flow 交互

状态：B11/v1 候选。阅读 [页面共识](../WORKBENCH_DESIGN.md#3-题库) 和 [设计规则](../rules/design-and-verification.md#二美学原则用户反复强调) 后，以本页补齐状态分支。数据字段见 [唯一契约](../contracts/workbench.md)。

## 工作区域

```text
既有侧栏  | 找题：搜索 / 自建 / 收录文字 | 当前题目：正文 / 编辑 / 更多 | 工具或 AI
          | 列表，独立滚动             | 正文，独立滚动              | 同一辅助栏

改编对照  | 原题采用版本，只读         | 改编题，可编辑              | 工具或 AI
备课      | 课题与保存状态固定；环节文稿独立滚动                    | 我的备课 / 大纲
环节取题  | 返回「课题 · 环节」；找题列表 | 题目预览；底部确认所选顺序 | 原辅助栏
```

业务路径为 `/questions`、`/questions/:id`、`/lessons`、`/lessons/:id`，由静态目录声明；原型 `/modules/bank` 和 `/modules/prep` 不成为新契约。临时取题和对照由页面现场恢复，不将任意 return URL 作为导航目标。直接打开不存在/无权对象给出“未找到内容”和返回本模块列表，已删除对象可进入恢复状态。

桌面基准 1440×900：中央两区约 35:65，对照约 50:50，区域间露出背景；右栏展开占据布局空间。768×1024 平板：侧栏沿用窄轨/抽屉，列表与题目、原题与副本采用区域切换，保留各自滚动；右栏独占当前内容区域，关闭后回原位置。普通浏览不切走 AI。两尺寸均支持键盘与指针；平板验证触控基本操作。浮层焦点进入首个有效控件，Esc 关闭并回触发处，出现动效和 reduced-motion 沿用设计规则。

不增加跨区大标题、说明卡或铺满操作的按钮排。当前题目的“编辑”就近常驻；复制修改、出处、使用位置、删除收进更多菜单；“加入备课”在阅读题目或多选后可达。删除与恢复属于业务内容入口，不使用侧栏隐藏模块垃圾桶。

## 状态与动作

| 状态 | 可见内容及动作 | 转移与返回 |
| --- | --- | --- |
| U0 空/浏览 | 空题库仅提供自建与收录文字；非空显示题干摘录、公式、标记。无标题用正文摘录认题，不强制命名。搜索和“已标记/已删除”过滤不清选择。 | 点击题目进 U1；无匹配保留搜索并允许清空。读取失败留现有内容并重试，空结果与失败分开。 |
| U1 阅读 | 正文、折叠的答案解析、独立教学笔记；有出处/副本/使用位置才露入口。 | 编辑进 U2；复制修改创建本地副本草稿进 U3；加入备课进 U5；回列表恢复位置。 |
| U2 编辑 | 正文可混排文字、行内/独立公式；答案和笔记按需展开。一个就近“保存”，Ctrl/Cmd+S 同义。 | 校验后保存；未通过定位字段、保留输入。保存成功回阅读。继续输入时旧响应不能覆盖新内容。离开不自动提交，草稿保留。 |
| U3 来源/改编对照 | 左侧原始粘贴文本或复制时的原题快照；右侧新内容。 | 首次保存才创建改编题。返回保留未保存草稿；明确“放弃草稿”才丢弃，需确认。来源已修改时可查看当前原题，原快照仍可回看；原题删除时对照仍可用。 |
| U4 备课编辑 | 新建时允许“未命名备课”和零环节；老师随时命名、加环节、改名、排序、写段落与备注。 | 新建空稿先留本地，首次保存才落库。进入取题前先保存当前备课，失败留在此处；删除环节默认将其中题目移入本课材料，确认后才保存。 |
| U5 取题/选目标 | 备课发起：显示目标课题和环节，搜索、预览、多选按选择顺序编号；题库发起：选已有或新建备课，再选环节或本课材料。 | 备课发起确认成功回原环节；取消不添加。题库发起成功留题库，以短反馈提供“前往备课”；新建目标成功但添加失败时保留该目标重试，不再次新建。 |
| U6 引用阅读 | 本课已采用的题面，答案可展开，本课备注独立。可看原题、移位、移出；有新版本时才显示“查看更新”。 | 查看更新并排比较旧/新，确认“采用更新”仅更新这一引用；取消保留旧版。原题已删除显示“原题已删除”，本课内容仍在。 |
| U7 已删除 | 模块过滤中的已删除条目可打开只读内容及恢复动作。 | 删除确认说明引用保留，恢复后原 ID、来源和引用关系继续。已删除备课不出现在取题目标；恢复备课带回全部环节和材料。 |

U2/U3 中无内容的新空草稿可以直接退出；有输入的草稿在模块入口可继续找到，草稿标识不冒充服务器题目。正文没有有效文字或公式不能创建题目；题型、标签、答案、笔记均不是必填。粘贴文字先完整保留原稿，再在右侧编辑为一道题，不自动拆题。公式编辑保留 LaTeX 源，预览失败在该公式旁提示并显示源内容，仍允许保存和后续修正。

同题可以在不同环节使用。一个目标位置已有同题时，普通“加入”跳过并提示“已在此处”；选择中已加入项可辨认。老师确实要在同一环节重复讲题时，从该引用更多菜单“再放一次”创建独立引用。引用排序按老师选择顺序；移出引用不删除题库题目。删除环节如选择连同题目移出，确认后从当前备课移除；保存之前仍可通过放弃当前草稿回到已保存版本。

## 保存与恢复反馈

| 状态 | 老师看到什么 | 可做什么 |
| --- | --- | --- |
| 未保存 | 内容旁“未保存”；本地恢复记录成功时可标“草稿在此设备” | 继续输入、保存、离开后继续；这不代表跨设备保存 |
| 保存中 | “保存中…”；当前提交动作防重复 | 可继续输入；新输入属于下一次提交，不并发覆盖当前请求 |
| 已保存 | 服务端确认当前提交且编辑器没有更新输入后，显示“已保存” | 刷新/其他设备可读同一服务器内容 |
| 保存失败 | 明确失败原因，保留草稿 | 修正字段/重试；服务器已明确拒绝的提交可以换请求键 |
| 结果未确认 | “暂时无法确认是否保存”，保留提交副本和后续输入 | “重试确认”发送原请求；确认前不生成另一个创建/引用操作 |
| 版本冲突 | “内容已在别处修改”，保留当前草稿并提供查看服务器版本 | 选择采用服务器版需确认丢弃本地输入；或对照整理后，以最新版本重新保存，不自动覆盖/合并 |
| 身份失效 | 隐藏业务内容并保留该账户本地草稿，提示重新登录 | 同账户重新验证后继续；异账户不能看到旧草稿；实际登录恢复由 A11 接入 |
| 本地存储失败 | “草稿无法保留，请先保存”，不得显示已保留 | 在线保存或复制输入；离开/关闭前提示未保护输入，不能承诺强制关闭后的恢复 |

本地草稿、提交中的原始请求、浏览现场按可信账户与当前浏览器分别保存；现场包括当前对象、搜索/过滤、多选顺序、每区滚动、展开项、对照、取材目标与返回点、面板模式/开合和宽度。刷新先核对身份，再取服务器内容、恢复本地草稿与现场；基线版本不一致进入冲突。数据未加载完成前不错误清除选中和滚动锚点。

本地草稿不跨设备同步，换设备读取服务器已保存内容并采用当地现场；显式说明只在确有未保存草稿时出现，不常驻页面介绍。退出不主动抹除未保存草稿，重新验证同账户后可恢复；清理该设备数据会丢失本地草稿。API 停止期间刷新会保留本地记录，但身份无法核实时暂不展示，服务恢复并确认同账户后继续。身份切换或失效后到达的旧响应被丢弃，不进入新账户状态。

取题后刷新恢复目标与已选题，重新检查目标/版本；目标环节已删除时不静默插到别处，允许选本课材料或取消。用户在题库查原题再返回时，备课的版本快照和文稿位置保持。已删除/消失的选中项恢复为可理解的状态，不悄悄改选另一题。

首页与右栏保持同一 AI 工作区的容器和输入现场，B14 不发送固定回复或展示虚构对话；真实消息、会话及服务端持久化由 C25/C26 接入。B14 只预留顶部日程注册位置，不出现无功能日程页面或多余侧栏入口。

## 验证入口

[BDD](../acceptance/first-flow.feature) 的所有 UI 场景在桌面验证；WB-004、006、010、011、014、015 还需 768×1024。B14/B15 应为 U0-U7、保存等待/失败/冲突、平板区域切换记录截图与真实事件；每组标明尺寸、候选 SHA、数据和场景 ID。检查区域边界、相等间距、长公式溢出、焦点、动画、右栏宽度和滚动隔离，截图不能替代交互结果。本轮是文档设计，没有新增可运行原型或截图证据。
