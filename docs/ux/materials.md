# Materials 行为与必要 UX

状态：R30/v1 候选。遵循 [工作台布局与现场](../WORKBENCH_DESIGN.md#1-整体结构)及[设计规则](../rules/design-and-verification.md)。这是行为设计，线框不是已运行页面或视觉验收证据。精确字段见[唯一契约](../contracts/workbench/materials.openapi.yaml)。

## U-M1 收录、等待与再次进入

题库找题面板内的“收录”提供图片（可多选并排序）、PDF、Word、粘贴文字四入口；自建仍是独立动作。收录不先要求题型或标签。先保存原始材料和可选出处，再自动开始拆题。上传字节进度与“原稿已保存”“正在整理”“已整理 3 页，还有 1 页待处理”分别呈现，不能把接收请求显示为已收录题目。

原始材料保存后进入中央对照区。右侧题目草稿逐批出现，每题默认待校对，机器的高置信度不代表老师确认。处理中的草稿可看；等当前运行结束或停止后编辑，避免后台替换正在修改的内容。工具栏显示已入库数量与待处理数量，题库列表有“待整理材料”入口，重新打开沿用同一材料和已保存校对结果。

```text
全局导航   原始材料                         题目草稿                      工具 / AI
           文件名  页码  缩放  选区         3/6 题  待校对  保存校对
           [原页，当前题相关框]             [题干、选项、小问、配图]
           [独立滚动]                       [答案解析] [定位疑点]
                                             拆开 / 合并 / 忽略 / 确认收录
```

一次收录多张图片按老师确认的顺序编号；原图字节不旋转重写，识别用的纠偏图映射回原图坐标。PDF 页码从 1 开始，以整份 PDF 为准。只选第 7-8 页时仍显示 7、8，不显示模型局部序号 1、2。Word 优先显示固定转换版本的页面，同时提供原始段落定位；没有可靠分页时明确显示“段落 N”，不把显式分页符数冒充真实页数。文字原稿逐字保留，用字符范围高亮。

关闭、切模块、AI 切换和刷新后，从待整理材料恢复原稿页、缩放、草稿选择和已保存结果；未上传的文件字节不会跨设备恢复，显示重新选择同一文件的动作。已保存材料跨设备可用。停止后显示“正在停止”，重开仍可见；它只停止后续处理，已保存原稿/成功单元保留；已运行请求可能稍后结束，停止后不得自动覆盖草稿。丢失创建响应时先确认原请求，避免建立第二份收录。

## U-M2 校对和局部失败

选题时定位该题的所有原稿位置，包括题面、分散的答案和跨页续题；点击疑点跳到对应块和原稿区域。左右阅读区各自滚动，不永久强制联动。老师可重框定位、裁图、调整配图与题的归属，在右边改文字与公式、移动段落、增删选项/小问。公式以可编辑源和即时排版同处呈现；渲染错误保留输入并标出位置。

拆分把一个草稿变成两个独立草稿，合并把选定草稿按选择顺序组成一题；均在同一校对保存中提交完整结果和定位，旧草稿被显式移除。已入库的草稿不能再次拆分或改变映射，转入题库编辑；其余草稿仍可继续。忽略可辨识的页眉、教师活动等片段不删除原稿；未分配片段有独立列表，可归入题干、答案、笔记或忽略。教师活动默认留在未分配内容，不自动混入题干。

缺字、遮挡、丢图、公式转换失败、截断响应分别定位。未看到答案时保持“未提供答案”；只读到部分答案为“答案待核对”，不能当成不存在或模型补做。只有题干可读、必需图已绑定、公式可编辑、所有阻断疑点已由老师解决，才能“确认收录”。允许一次收录已校对的部分题，其余继续保存；成功响应包含新题 ID，可直接查看或加入备课。手工补充是局部恢复动作，不能成为四入口自动整理的正常主流程。

请求空正文、非完整 JSON、页数遗漏或超时不会显示“全部完成”。有完整可独立验证的题片段时保留为待核对候选，外层截断使整批为部分失败。每次重试只覆盖选定失败单元，已校对或已入库内容不被替换；新增候选供显式选择。新照片作为补充原稿加入原材料，旧遮挡图仍保留。重试有新任务 ID，网络请求结果未知时先重放确认原任务。

## U-M3 题库与分类

找题与当前题目分区沿用约 35%/65% 可调布局；列表显示题干/公式/图的辨识片段。搜索标题、题干、公式源、长期笔记，自定义题型（单选）、标签（多选且全部匹配）、标记与删除状态可组合筛选。答案与原稿不混入默认搜索。

右侧分类工具初始没有预置题型或标签。“管理”内新建、改名、删除均就近完成；同类名称去首尾空白后不区分大小写唯一。改名保留关联；删除先显示影响题数，确认后移除关联，题目仍在，题型变为未分类。删除后以同名重建获得新身份，不自动恢复旧关联。自动整理只建议已有分类，老师确认后采用，不自动创建标签体系。

编辑直接改当前题；复制改编以当前采用版本初始化独立副本，长期笔记清空、标记关闭，分类初始沿用。原题与改编题双向可达，原题删除后仍能看采用时的内容及原始材料。校对定位可修正，但原文件和原始文字不可修改。引用方始终保留采用时快照。

## U-M4 资源浏览、预览与替换

资源中央面板显示当前文件夹路径、搜索、缩略图/列表切换及上传。右侧为自定义文件夹和标签，与 AI 共用。文件夹同时承担分类，不再增设并行分类树。文件夹可移动、改名、删除；删除只把直接子文件夹与资源移到父级，不递归删除资料。标签操作与题库的规则相同，但两个模块分别拥有标签。

先上传即收录，名称默认文件名，可稍后分类、改名、加标签或备注。搜索名称、原文件名、备注，结合文件夹（含后代）、标签与格式筛选。缩略图来自第一页或原图片。点击预览扩展为主工作区，提供真实逐页内容、页码、缩放、备注和使用位置；关闭返回原筛选、选择及滚动位置。PPT/PPTX 预览为静态幻灯片，Word 为固定转换版本页面，PDF/图片直接查看。上传 HTML 以安全文本查看或下载；交互展示归数学工坊，资源库不执行其中脚本。

无法完整转换时显示“预览需核对”并标出缺页/公式对象风险。损坏文件显示失败和重试，原件仍可下载。旧 DOC 必须提供实际转换页和可供对照的外部 PDF/图片补充入口，不能把空公式页标为完整，也不能只给下载按钮。补充预览绑定该次文件版本；新的原文件替换后不沿用旧补充。教师可上传由目标 Office 导出的 PDF 作为该版本的补充预览，核对页数后明确采用。

“更新文件”先上传新文件，成功后才替换条目的当前文件，保留名称、分类、标签、备注及关联，显示新旧文件名和引用数量。预览尚未完成不阻止原件安全收录，但状态持续可见。失败保留旧当前文件。备课已有引用仍看旧版，显示“来源有更新”，明确采用新版才改快照；资源软删除后已引用文件仍能打开，恢复不自动刷新引用。

## U-M5 备课编排与取材

文稿开头、任意命名环节、环节正文、引用材料和本课备注构成一份备课。右栏为我的备课/本课大纲或 AI，保留滚动。环节可增删改名和排序，删除时明确“材料移到本课材料”或“一并移除本课引用”。移动引用保持引用身份和备注；“再放一次”建立第二个独立引用。

从环节取题/资源时中央临时替换为选择界面，显示目标课题与环节。多选按选择顺序插入，成功后返回原段落；取消保持未提交选择与文稿草稿，目标已删或版本变化则对照后重选，不悄悄插到别处。从题库/资源主动加入备课后留在原模块，提供前往备课链接。

本课材料总览同时列出环节内材料及未安排材料；同一引用只存一次，总览是投影。未安排的备用内容默认不进入输出。资源引用显示原件版本、预览和打开来源；题引用就地显示题面，答案展开、本课备注独立编辑。资源整文件不能自动拆成可编辑题面；需要题目时从该文件发起收录。这里不新增数学作品类型字段；M40 使用现有文件/内容接缝后再设计作品引用。

## U-M6 六种成果与手工 PPT

输出前保存备课，选择“教案/提纲”“导学案/讲义”“练习”、Word/PDF、答案解析开关、教师注记开关、包含的环节和备用引用。两个开关独立；所有类型默认关闭，用户明确勾选才纳入。默认取全部环节、排除未安排材料，练习默认只取题目。选项只控制本次输出，不更改备课或题库。

| 成果 | 固定组成规则，顺序由备课决定 |
| --- | --- |
| 教案/提纲 | 课题、开头文稿、所选环节标题与文稿、环节内题目和资源目录；所选备用材料置文末。 |
| 导学案/讲义 | 同一可编辑文稿结构；题面后留可编辑作答空白；资源仅列标题与文件名，无私密 URL/原文件附件。 |
| 练习 | 课题，所选环节中的题目按顺序重新编号；保留选项、小问和配图，题后作答空间；排除开头和环节说明、非题文件目录。 |

答案解析放在全部题面之后的单独答案部分，保持输出题号；缺答案不补造。教师注记部分只在开关开启时收录本课备注及显式教师注记块，排除题库长期笔记与资源备注。自由文稿默认是正文，编辑器提供明确“教师注记”块；老师手动把答案写入正文时输出预览必须能检查，系统不承诺靠猜测清除自由文本。自动整理和输出器须守住结构角色，不把 solution 复制入 body。

预览显示将分发的最终结果、页数和选项，文件生成与校验成功才出现下载。公式不支持时定位到公式并回编辑，保留旧的成功输出；不能自动把 Word 的文字/公式栅格化冒充成功。转换中可离开；重回仍显示任务和已有结果，修改备课后原任务仍固定在原保存版本。停止、失败和未确认均按 U-M1 恢复。

题目面板另有“用于 PPT”：复制题面文字（公式用 LaTeX 源）、分别复制公式源、下载题面 PNG 或单幅配图 PNG。题面 PNG 默认排除答案/笔记，透明背景，长题按段落分片且不截公式或图；剪贴板受限时提供下载或可全选文字。该素材是辅助老师手工排版，公式编辑仍可回源。M40 负责进一步的公式透明素材、SVG 和作品能力。

## U-M7 保存、删除与显示状态

“原稿已保存”“校对已保存”“已收录 N 题”“备课已保存”“文件已生成”分别由对应成功响应确认。未知结果保留原键/原请求和新输入草稿，先重试确认再读取最新状态；冲突对照后新键提交，不自动覆盖。磁盘满、转换退出、Provider 不可用有具体可恢复动作，业务拒绝不抹掉现场。

所有对象软删除后可恢复；源删除不删既有引用、副本、原始材料或文件。删除材料只隐藏待整理入口，已入库题仍能回看原稿；恢复沿用 ID。跨账户文件、任务、缩略图、原稿和使用位置统一拒绝，身份失效暂停写入并沿用 B11 的账户分区和迟到响应规则。

## U-M8 布局与可验标准

1440×900 和 1280×800 桌面都检查右栏开/关，对照区均能看公式和原稿；1024×768 平板提供列表/当前题、原稿/结果切换，保留各自位置，基本上传、校对、取材和下载可用。窄宽度不让整页横滚，长公式只在所在阅读区横滚。键盘可切题、翻页、进入公式源、完成保存并返回触发点，错误摘要可聚焦对应内容。

控件密度、边框、动效和间隙沿用设计规则实测值；题文按阅读需要增加留白。原稿与编辑器均位于中央，不挤占业务/AI 共用右栏。R32/R33/R34 以实际截图和交互记录分别证明初始、进行中、部分失败、未知结果、冲突、删除来源及返回现场；本线框不替代这些检查。
