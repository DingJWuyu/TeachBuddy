# TeacherWorkspace · TeachBuddy

面向高中教师个人的教学工作台，把题目、数学作品、教学资源、班级记录与日程放在一起。

收录和改编题目，整理教学资料，制作数学图示或离线演示，安排课程，再记录各班实际进度与共性问题。资料真实保存，可在后续教学中继续使用。

数学工坊在同一作品中制作公式、二维/三维图形、参数和教学步骤，使用自己的编辑界面与本地 GeoGebra 引擎，自动保存。右侧免费 DeepSeek 网页助理首批支持桌面 Chrome/Edge，需要安装[浏览器扩展](extensions/math-web-ai/README.md)并登录自己的账号；扩展尚未上架，本机开发可按扩展说明连接。能力、输出及当前验证边界见[数学工坊](docs/features/math.md)。

## 功能

产品按八个分区组织，完整职责与目标见[产品范围](docs/PRODUCT_SCOPE.md#产品分区)。以下描述当前本地实现，未验与暂停范围见段末和[项目状态](docs/plans/run-state.md)。

- **账户与身份**：邮箱验证码注册、登录、找回密码、会话恢复和退出；确认邮箱后可永久删除账户及服务器内所属资料，网络中断时保留原请求核实。
- **工作台与设置**：导航分组、模块顺序与隐藏选择按账户保存，同账户在另一设备可恢复；侧栏开合和分组折叠保留各设备习惯。简体中文/English、主题、内容背景和头像按账户保存并同步全站；设置提供账户操作和个人资料导出入口，以及本地中英帮助和既定更新页。
- **题库**：手工录题、文字、Word 与常规双栏文字 PDF 整理、图片和扫描页识别后校对入库、原稿对照、复制改编、自定义题型与标签、笔记和检索；搜索可按需包含答案，来源删除后保留已入库题目与改编快照。题号或图文归属不明确时保留未分配内容，不自动补答案。旧 DOC 先转换后读取现有公式和配图，可对照固定转换稿段落，缺失对象仍需补充原件。
- **资源库**：批量收录、重复提醒、分类整理、正文检索、预览页内查找与高亮、文字复制与文件版本恢复；扫描页可手动识别，阅读公式和配图、复制识别文字并搜索定位。支持批量移动、加标签、归档和恢复，可彻底删除资料条目。
- **数学工坊**：统一制作公式、函数与几何、三维构造、参数播放和教学步骤；支持选中编辑、撤销重做、自动保存、历史版本恢复、源文件导入、图片与可编辑源输出和课堂演示 ZIP。作品可归档、恢复和彻底删除。
- **班级教学**：按班级写课堂记录，回顾进度、问题和下次教学想法，按关键词与日期找回记录，按需加入公式与课堂图片、跨班移动记录，关联已有资料；主页可对照各班进度，班级支持归档、恢复和彻底删除，单条记录支持删除、恢复和彻底删除。
- **日程**：日历支持日、周、月及自选日期段，拖选、拖动和拉伸安排，标签、备注、全天、自定义重复与单次独立任务；按需设置开始或结束前后提醒、关联班级与实际教学记录，管理待安排、多事项完成、排序与移动。日程自动跟随系统时区并保留当地日期和钟点，任务删除前确认无法恢复。保存结果未知时可确认原请求，冲突时保留草稿供核对。
- **AI 助理**：首页和业务侧栏共用对话、引用和操作记录，已接入首批题库工具；五模块扩展开发暂停。

共享技术底座提供文件、识别、保存和数据恢复。个人资料包包含保留的教学内容、历史与附件，可离线阅读并手工取回内容；误删内容在对应模块恢复，实例备份与还原使用维护命令。

当前是本地体验版。OCR 采用单路识别，题库可对照原页校对文字、公式和配图，资源库可读取与检索识别结果；机器结果仍可能漏读、误读或自行补全，复杂表格、跨栏和跨页教学语义仍可能无法自动整理。复杂旧 Word 与目标环境仍有验证边界，数据处理协议保留占位。AI 助理扩展开发暂停，现有助理界面不代表五模块操作全部完成；公共文件转换使用本机 Office/Pandoc，环境要求见[运行指南](docs/SETUP.md#文件转换工具)。

## 本地运行

需要 Node.js 22、npm、同源 HTTPS、SQLite 与持久文件目录；注册和找回还需邮件配置。Office 预览和成果输出另需 Pandoc、LibreOffice、Poppler、字体及隔离转换工具；数学图形保存与输出另需 Chromium，本地数学引擎首次准备见[数学运行依赖](docs/SETUP.md#数学运行依赖)。

题库文字 PDF 整理另需 Xpdf 4.06，安装和路径配置见[题库 PDF 运行依赖](docs/SETUP.md#题库文字-pdf)。

本地 OCR 使用 [MinerU](https://github.com/opendatalab/MinerU) 及固定的本地模型，配置 `MATERIALS_OCR_HOME` 后启用；运行时不联网下载或上传材料。未配置时仍可读取已保存的识别结果，准备方法见[本地页识别工具](docs/SETUP.md#本地页识别工具)。

```bash
npm ci
npm run math:geogebra:build
npx playwright install chromium
cp .env.example .env
# 按运行指南填写本机路径、HTTPS 证书、认证密钥和邮件配置。
npm run dev
```

按[运行指南](docs/SETUP.md#新的隔离环境)完成配置后，`npm run dev` 在同一个 HTTPS 地址提供前端热更新和 API 自动重启。新检出无需旧开发现场或旧数据库；首次启动自动创建空库并执行迁移。已有本机体验入口为 `https://localhost:50880`，直接运行 `TeacherWorkspace-preview` 当前源码；模块 worktree 使用各自的隔离实例。用户服务和固定构建的启动方式也见运行指南。
