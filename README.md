# TeacherWorkspace · TeachBuddy

面向高中教师个人的教学工作台，把题目、备课、数学作品、教学资源、班级记录与日程放在一起。

从一道题准备一节课：收录和改编题目，按自己的教学环节组织讲义，制作数学图示或离线演示，安排课程，再记录各班实际进度与共性问题。资料真实保存，可在后续备课中继续使用。

## 功能

- **题库**：手工录题、文字整理与拆分校对、原稿对照、复制改编、自定义题型与标签、笔记和检索；搜索可按需包含答案，来源删除后保留已入库题目与改编快照。
- **备课**：从示例了解用途，直接写讲课思路，按需组织环节、加入题目和资料；可阅读课稿、继续草稿，按用途生成 Word/PDF 教案、讲义和练习。
- **数学工坊**：从用途和示例开始制作公式、函数与几何示意、动态作品；支持常用公式填写、图形选中编辑、草稿继续、源码编辑和离线演示下载。
- **资源库**：保存文件、分类、预览、替换；支持归档、恢复与彻底删除资料条目，保留已有备课引用。
- **班级教学与日程**：按班级写课堂记录，按需补充进度、问题和下次教学想法，关联已有资料；班级可归档、恢复，归档后可彻底删除；日历支持日、周、月及自选日期段，拖选、拖动和拉伸安排，编辑标签、备注、全天与自定义重复任务，保留单次调整和站内提醒。
- **设置与个人数据**：主题、内容背景和头像按账户保存并同步全站；导出个人资料包，误删内容在对应模块恢复，实例备份与还原使用维护命令。

当前是本地体验版。手动主链已有局部验证，扫描材料自动提取、复杂旧 Word、部分设置及目标环境仍有缺口。产品 Agent 开发暂停，现有助理界面不代表六模块操作全部完成；当前本机 Office/Pandoc 配置还需维护后才能重新确认预览与输出可用。

## 本地运行

需要 Node.js 22、npm、同源 HTTPS、SQLite 与持久文件目录；注册和找回还需邮件配置。Office 预览和成果输出另需 Pandoc、LibreOffice、Poppler、字体及隔离转换工具。

```bash
npm ci
npm run build
node --env-file=/absolute/private/runtime.env apps/api/src/server.js
```

先按[运行指南](docs/SETUP.md)准备配置、证书和持久目录。已有本机体验入口为 `https://localhost:50880`，邮箱验证码注册后使用；不要用开发测试覆盖已有实例数据。
