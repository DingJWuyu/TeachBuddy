# TeachBuddy

TeachBuddy 是面向高中教师个人的教学工作台。它把题库、备课、数学作品、资源、班级教学和日程放在同一个账户中，让教学材料可以在模块之间复用。

当前可体验版本位于 `preview/usable-mvp` 分支。`apps/` 是实际产品，`prototype/` 仅供交互参考。产品仍在开发中，尚未完成全部 MVP 验收。

## 已有能力

- **题库与备课：** 自建和编辑题目，从文字、DOCX、文字层 PDF 等材料收录题目，保留原稿与人工校对；在备课环节取题、调整顺序，输出 DOCX 和 PDF。
- **资源与数学：** 上传、预览、整理和复用常见文档与图片；制作公式、平面图形、空间图形及交互演示，并导出相应文件。
- **班级与日程：** 记录班级教学情况并关联材料；安排课程与待办、设置重复和提醒，在重新进入后查找提醒。
- **账户与资料：** 邮箱注册登录、个人资料 ZIP 导出、最近删除恢复，以及供维护者使用的整体备份和恢复命令。
- **界面：** 六个业务模块、设置、帮助和更新日志页面已接入当前预览。首页与共享 AI 入口保留现有实现。

## 快速开始

需要 Node.js 22、npm，以及供本机 HTTPS 使用的证书。安装依赖并构建：

```bash
npm ci
npm run build
```

按 [.env.example](.env.example) 配置持久化数据库路径、HTTPS 证书、公开地址和邮件服务。把凭据保存在仓库外或本机未跟踪的 `.env`，然后启动同源服务：

```bash
node --env-file=.env apps/api/src/server.js
```

打开 `WORKBENCH_PUBLIC_ORIGIN` 指定的地址，通过界面注册或登录。已有本机预览入口是 `https://localhost:50880`，其账户和数据独立于新建的本地数据库；请保持正在运行的预览服务和配置原样。开发与验证命令见 [开发指南](docs/development/setup.md)。

## 当前限制

扫描图片和扫描 PDF 的自动视觉识别尚未配置。旧 DOC 转换可能丢失对象；复杂公式排版、多栏或跨页题目仍需核对原稿。部分 Office 输出与预览在目标 Word/WPS 上、课堂设备和 iPad 上尚未完成验证。设置中的头像、外观、周起点、语言、背景及删除账户等控件没有相应后端能力。

产品 Agent 的后续开发与全站外壳改造已暂停；已有入口并不代表完整 Agent 业务通过验收。完整手动业务范围仍需继续核对，当前预览不能视为正式交付。具体剩余工作见 [当前状态](docs/plans/status.md)，产品要求见 [范围](docs/product/scope.md)。
