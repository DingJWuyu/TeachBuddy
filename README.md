# TeacherWorkspace · TeachBuddy

面向高中教师个人的教学工作台，把题目、备课、数学作品、教学资源、班级记录与日程放在一起。

从一道题准备一节课：收录和改编题目，按自己的教学环节组织讲义，制作数学图示或离线演示，安排课程，再记录各班实际进度与共性问题。资料真实保存，可在后续备课中继续使用。

## 功能

- **题库**：手工录题、文字、Word 与常规双栏文字 PDF 整理、图片和扫描页识别后校对入库、原稿对照、复制改编、自定义题型与标签、笔记和检索；搜索可按需包含答案，来源删除后保留已入库题目与改编快照。题号或图文归属不明确时保留未分配内容，不自动补答案。旧 DOC 先转换后读取现有公式和配图，可对照固定转换稿段落，缺失对象仍需补充原件。
- **备课**：从示例了解用途，直接写讲课思路，按需组织环节、加入题目和资料；可将扫描页识别为正文，也可单独识别页内配图中的文字或表格，校对后保存为可编辑环节并保留原页和机器稿。按用途生成 Word/PDF 教案、讲义和练习；支持复制备课、跨课复用环节、正文与材料混排、撤销未保存编辑、恢复已保存版本、逐题输出与单题留白，将资源按原页插入讲义（页面为图片），以及归档、恢复与彻底删除备课。
- **数学工坊**：制作公式、函数与几何示意、动态作品；支持可视化公式输入、图形选中编辑、撤销重做、历史版本恢复、制作源导入和离线演示下载，支持自然函数输入、分段绘图、零点与交点近似查找、关联几何构造、凸多面体截面、参数播放和采样轨迹，平面图可另建动态副本；作品可归档、恢复和彻底删除，保留已有备课引用。
- **资源库**：批量收录、重复提醒、分类整理、正文检索、预览页内查找与高亮、文字复制与文件版本恢复；扫描页可手动识别，阅读公式和配图、复制识别文字并搜索定位。支持批量移动、加标签、归档和恢复，可彻底删除资料条目，保留已有备课引用。
- **班级教学与日程**：按班级写课堂记录，回顾进度、问题和下次教学想法，按关键词与日期找回记录，按需加入公式与课堂图片、跨班移动记录，关联已有资料；主页可对照各班进度，班级支持归档、恢复和彻底删除，单条记录支持删除、恢复和彻底删除。日历支持日、周、月及自选日期段，拖选、拖动和拉伸安排，标签、备注、全天、自定义重复与单次独立任务；按需设置开始或结束前后提醒、关联班级与备课，管理待安排、多事项完成、排序与移动。日程自动跟随系统时区并保留当地日期和钟点，任务删除前确认无法恢复。保存结果未知时可确认原请求，冲突时保留草稿供核对。
- **设置与个人数据**：导航分组、模块顺序与隐藏选择按账户保存，同账户在另一设备可恢复；侧栏开合和分组折叠保留各设备习惯。简体中文/English、主题、内容背景和头像按账户保存并同步全站；确认邮箱后可永久删除账户及服务器内所属资料，网络中断时保留原请求核实；导出包含保留课稿历史的个人资料包，可离线阅读并手工取回内容；误删内容在对应模块恢复，实例备份与还原使用维护命令。

当前是本地体验版。OCR 采用单路识别，题库、资源与备课可对照原页校对文字、公式和配图；机器结果仍可能漏读、误读或自行补全，复杂表格、跨栏和跨页教学语义仍可能无法自动整理。复杂旧 Word 与目标环境仍有验证边界，数据处理协议保留占位。产品 Agent 开发暂停，现有助理界面不代表六模块操作全部完成；备课 Word/PDF 输出使用本机 Office/Pandoc，转换要求与验证边界见[备课规格](docs/features/lessons.md)。

## 本地运行

需要 Node.js 22、npm、同源 HTTPS、SQLite 与持久文件目录；注册和找回还需邮件配置。Office 预览和成果输出另需 Pandoc、LibreOffice、Poppler、字体及隔离转换工具。

题库文字 PDF 整理另需 Xpdf 4.06，安装和路径配置见[题库 PDF 运行依赖](docs/SETUP.md#题库文字-pdf)。

本地 OCR 使用 [MinerU](https://github.com/opendatalab/MinerU) 及固定的本地模型，配置 `MATERIALS_OCR_HOME` 后启用；运行时不联网下载或上传材料。未配置时仍可读取已保存的识别结果，准备方法见[本地页识别工具](docs/SETUP.md#本地页识别工具)。

```bash
npm ci
cp .env.example .env
# 按运行指南填写本机路径、HTTPS 证书、认证密钥和邮件配置。
npm run dev
```

按[运行指南](docs/SETUP.md#新的隔离环境)完成配置后，`npm run dev` 在同一个 HTTPS 地址提供前端热更新和 API 自动重启。新检出无需旧开发现场或旧数据库；首次启动自动创建空库并执行迁移。已有本机体验入口为 `https://localhost:50880`，直接运行 `TeacherWorkspace-preview` 当前源码；模块 worktree 使用各自的隔离实例。用户服务和固定构建的启动方式也见运行指南。
