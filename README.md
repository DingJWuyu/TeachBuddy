# TeachBuddy

教师个人工作台，把题目、备课、教学资源、数学作品、班级记录和日程放在一起。

面向一位教师的日常工作：从一道题开始准备一节课，将材料组织成教案或讲义，再记录课堂反馈。

## 可以做什么

| 工作 | 能力 |
| --- | --- |
| 题库 | 手工录题、修改和复制改编，管理题型、标签、笔记和原稿 |
| 备课 | 自定义教学环节，引用题目、资源和数学作品，生成 Word 与 PDF |
| 数学工坊 | 制作公式、静态图形和动态演示，编辑源码、导入 HTML、下载离线作品 |
| 资源库 | 保存和整理文件，预览、替换文件，回看备课中的使用位置 |
| 班级教学 | 记录各班进度、共性问题和下一步，关联备课与材料 |
| 日程 | 安排课程和事项，处理重复与单次调整，接收站内提醒 |
| 个人数据 | 导出个人资料，恢复最近删除的内容；维护工具提供备份与还原 |

## 当前状态

这是持续打磨中的本地体验版。手动业务已经汇入同一开发分支，UI/UX 仍在改进；不宣称完整产品范围已全部通过验收。

- 产品 Agent 开发暂停，现有助理界面不代表所有跨模块能力已完成。
- 扫描材料自动提取、复杂旧 Word 文档和部分设置能力仍有缺口。
- 当前机器的 Office/Pandoc 工具路径失效，相关预览、Word/PDF 输出需要恢复运行依赖。
- 目标 Word/WPS、课堂设备、iPad、大陆网络和正式部署尚未完成整体验证。

具体可用范围及下一步见[当前状态](docs/plans/run-state.md)，各项验证来源见[能力与证据](docs/plans/run-inputs.md)。

## 本地使用与开发

现有本机体验入口：**https://localhost:50880**。新用户通过邮箱验证码注册，已有账户直接登录。已有实例的数据与配置应保留。

长期开发位置为 `TeacherWorkspace-preview`，分支为 `preview/usable-mvp`；原 `TeacherWorkspace` 的 `main` 单独保留。

新环境安装与启动请按[运行指南](docs/SETUP.md)准备 Node.js、HTTPS、SQLite 持久目录和邮件配置。前后端由同一 HTTPS 服务提供；Office 输出另需外部转换工具。

## 项目结构

