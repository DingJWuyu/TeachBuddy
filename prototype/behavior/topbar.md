# 顶部栏入口

Status: Accepted

运行入口见 [manifest](manifest.md)，共用关闭、焦点与渐进出现规则见 [外壳](shell.md)，导航与搜索见 [导航](navigation.md)。本文件拥有 J5、J6、J8-J10、J14、J15 与 S3、S3a、S4、S7、S10-S12、S25。

## Journeys and states

| 旅程 | 状态 | 当前行为与复现 |
| --- | --- | --- |
| J5 处理通知 | S3 通知面板、S3a 全部已读 | 打开通知显示 3 条固定样例（今天与明天各 1 条未读、周三 1 条已读）。面板只有标题行、消息列表和底部垃圾桶三部分，没有说明文字。未读数为 0 时入口右上角的红色感叹号消失，有未读时重新出现 |
| J6 发送反馈 | S4 致谢 | 选择类型、填写非空内容后可发送，空白内容禁用发送；点击后进入本地致谢，只有橙色对勾圆盘、「已收到，谢谢你的反馈！」与「知道了」。关闭再打开重置输入 |
| J8 首次引导 | S7 聚光引导 | 未关闭引导的标签页进入外壳展示遮罩、教程入口高亮和气泡；点击遮罩、「知道了」、教程入口或搜索快捷键后结束。同一标签页内跳页不再出现，新标签页重新出现 |
| J14 标记与撤销已读 | S3、S3a | 点击一条消息切换已读：变已读时文字变浅、删除线从左向右画出；再点一次变回未读，删除线反向收回。点击「全部已读」所有消息逐一画出删除线，该操作入口随之消失 |
| J15 删除通知 | S25 通知拖拽删除 | 把一条已读消息拖到列表底部的「删除消息」上：指针带着拖拽图，整行与垃圾桶图标变红、图标放大，松手后该条从列表消失。未读消息不可拖拽。拖动中途松手在别处或按 `Esc` 不删除任何消息，红色状态清除 |
| J9 教程进度 | S10 教程面板、S11 庆祝 | 点击教程入口显示列表，点击条目切换完成状态；全部完成时显示庆祝，关闭庆祝后可继续操作。关闭面板保留完成状态，刷新重置 |
| J10 隐私信息 | S12 隐私面板 | 点击隐私入口打开只读盾牌图标与隐私标题，沿用共享关闭规则 |

## Visible information

- 通知的今天、明天、周三是固定样例标签，与真实日期不联动。通知为单向删除加可逆已读，没有"全部删除"。
- 教程条目对应模块列表；进度表示完成比例，琥珀色角标表示剩余数，全部完成时角标消失。进度条与角标同色，附可访问的完成数量。
- 反馈类型为建议、错误报告、问题、赞扬，选中态分别使用紫、红、琥珀、绿的语义色，未选中为灰色。面板不连接真实反馈服务，截图快捷键仅为提示。
- 界面内不出现任何"这是一条原型／演示／不会真的发送"类说明文案。

## Experience rules

- 顶栏右侧保留搜索、通知、反馈、教程、隐私五个独立入口，每个都有悬停提示与无障碍名；通知的无障碍名带出未读数（`通知，N 条未读`）。通知与反馈分开，窄屏仍保留全部入口。
- 普通弹层在宽屏按触发器右侧对齐，手机遵循[外壳的视口约束](shell.md#experience-rules)；搜索为居中模态，支持菜单从顶部中心生长。隐私面板按图标和标题收窄，不保留证书、正文及行动按钮的空位。
- 引导遮罩拦截其他区域的指针操作，教程入口保持点亮。遮罩从 0s 开始淡入，入口从 0.06s 开始放大点亮，气泡从 0.3s 开始上浮淡入；减少动态效果偏好下直接显示稳态。
- 全部教程完成时显示祝贺卡片和循环烟花，可关闭；减少动态效果偏好下关闭烟花动画。
- 通知面板底部的垃圾桶整行常驻，不随列表内容出现或消失；列表为空时显示空状态。
- 当前尺寸、排版和对齐约束见 [样式](../src/sidebarEditingPrototype.css) 与 [顶部栏验证](../verification/verify-topbar.mjs)。
