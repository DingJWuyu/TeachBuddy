# 顶部栏入口

Status: Accepted

运行入口见 [manifest](manifest.md)，共用关闭与焦点规则见 [外壳](shell.md)，搜索和支持菜单行为见 [导航](navigation.md)。

## Journeys and states

| 旅程 | 状态 | 当前行为与复现 |
| --- | --- | --- |
| J5 处理通知 | S3 通知面板、S3a 全部已读 | 打开通知显示 3 条固定样例，初始 2 条未读；点击一条设为已读，点击全部已读进入 S3a 并隐藏该操作。关闭再打开重置样例，入口红色感叹号固定 |
| J6 发送反馈 | S4 致谢 | 选择类型、填写非空内容后可发送，空白内容禁用发送；点击后仅进入本地致谢。关闭再打开重置输入；致谢显示原型说明文案，通过面板外部或 Escape 关闭 |
| J8 首次引导 | S7 聚光引导 | 每次加载展示遮罩、教程入口高亮和气泡；点击遮罩、知道了、教程入口或搜索快捷键后结束。刷新重新出现 |
| J9 教程进度 | S10 教程面板、S11 庆祝 | 点击教程入口显示列表，点击条目切换完成状态；全部完成时显示庆祝，关闭庆祝后可继续操作。关闭面板保留完成状态，刷新重置 |
| J10 隐私信息 | S12 隐私面板 | 点击隐私入口打开只读盾牌图标与隐私标题，沿用共享关闭规则 |

## Visible information

- 通知的今天、明天、周三是固定样例标签；通知为单向标已读，没有删除操作。
- 教程条目对应模块列表；进度表示完成比例，琥珀色角标表示剩余数，全部完成时角标消失。进度条与角标同色，附可访问的完成数量。
- 反馈类型为建议、错误报告、问题、赞扬，选中态分别使用紫、红、琥珀、绿的语义色，未选中为灰色。面板不连接真实反馈服务，截图快捷键仅为提示。

## Experience rules

- 顶栏右侧保留搜索、通知、反馈、教程、隐私五个独立入口，每个都有悬停提示与无障碍名。通知与反馈分开，窄屏仍保留全部入口。
- 普通弹层按触发器右侧对齐，搜索为居中模态。隐私面板按图标和标题收窄，不保留证书、正文及行动按钮的空位。
- 引导遮罩拦截其他区域的指针操作，教程入口保持点亮。遮罩从 0s 开始淡入，入口从 0.06s 开始放大点亮，气泡从 0.3s 开始上浮淡入；减少动态效果偏好下直接显示稳态。
- 全部教程完成时显示祝贺卡片和循环烟花，可关闭；减少动态效果偏好下关闭烟花动画。
- 当前尺寸、排版和对齐约束见 [样式](../src/sidebarEditingPrototype.css) 与 [顶部栏验证](../verification/verify-topbar.mjs)。
