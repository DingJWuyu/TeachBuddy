# 账户入口行为

Status: Accepted

本文只维护原型的体验参考和适用边界；认可范围见 [manifest](manifest.md)。现行产品从[文档入口](../../docs/README.md)读取，原型样例、存储与旧场景结果不定义产品能力。

## Scope

本文定义 TeachBuddy 账户入口的当前可观察行为：登录、注册、找回与重置密码、验证码生命周期、失败与恢复、请求并发、会话恢复与会话交接。账户入口面向未登录教师，登录或注册成功后交接到现有工作台。

支持 PC 1440x900、平板 768x1024、手机 390x844，以及鼠标、触摸点击和键盘输入。工作台的布局、导航、学期、语言、首页和其他交互仍由工作台行为拥有；账户入口只向账号行提供已保存的昵称。长昵称在账号行省略显示，完整名称可通过无障碍名称访问，头像显示一个完整的 Unicode 字符。

注册默认开放。产品关闭注册后，只禁止创建新账户；登录、找回密码和已存在账户的重置继续可用。设置页退出入口 CA53 暂缺，服务条款链接不跳转。真实认证、邮件投递、服务端会话和真实跨设备网络事件不在本原型实现范围内，但它们造成的等待、失败、未知结果、过期和撤销状态必须可观察地模拟。

## 行为拥有与场景入口

本文拥有 J11-J13、J25 及账户状态 S14-S21、S36-S47。运行入口、前置条件和运行方式见 [manifest](manifest.md)。[账户场景目录](auth-scenarios.md)唯一维护 CA 编号与复现入口，具体步骤和断言归其链接的场景源码；本文维护体验意图和状态，不积累执行结果。产品输入传输与后端独立校验见[认证契约](../../docs/contracts/auth.md)。

浏览器中的账户、密码、昵称、验证码和会话是服务行为的本地模拟。模拟账户服务可以报告持久数据不可读、损坏或不可写，模拟发送和业务请求可以报告网络、服务、超时或响应丢失。产品账户、邮件与会话语义以当前账户规格和认证契约为准；这里的模拟分支只保留已确认体验意图，不规定产品交换或存储实现。

## Journeys

### J11 登录

1. 从 S14 填写邮箱和密码并提交。邮箱先 trim 后转小写作为提交值，密码原样提交；本地错误停留在 S19，不进入业务请求。
2. 提交中进入 S38，按钮显示“登录中”并禁用，重复提交不产生第二次业务操作。提交快照包含规范化邮箱、原始密码和记住我选择。
3. 凭据正确且会话交接成功时进入 S21。账号行使用账户保存的昵称。
4. 不存在的邮箱和错误密码使用同一凭据拒绝文案，进入 S36；邮箱保留，密码清空。错误横幅可关闭。
5. 已知请求未执行的网络、服务、超时或登录结果缺失/畸形失败进入 S36，保留可重试输入。登录不进入 S44；S44 的“结果暂未确认”只用于注册或重置业务可能已经成功但响应丢失的分支。
6. 请求中编辑字段或切换到其他账户表单时，迟到登录结果不得清空新输入、改变当前表单或自动进入工作台。注册或重置的已提交业务副作用若已经完成仍然保留，用户可用已提交凭据从登录恢复，不能声称已经撤销。
7. 点“忘记密码？”进入 J13 的 S17，已填写邮箱可沿用。

### J12 注册

1. 从 S14 点“创建账户”进入 S15。注册字段为昵称、邮箱、密码、确认密码和条款；验证码在成功发码后才出现。
2. 本地校验通过后申请验证码。成功发送进入 S16，显示发送目标、10 分钟有效期和重发控件；发码等待使用 S38，失败保留原表单且不出现验证码字段。
3. 注册邮箱已占用时停留在 S20，给出邮箱字段错误，不发送验证码。改为可用邮箱后可重新发码。
4. 发码后改邮箱会清除当前注册挑战、发送目标和验证码输入；旧地址的迟到结果被丢弃，只有新地址重新发码后才能继续。
5. 提交时再次执行本地校验。有效挑战、有效验证码、条款已同意且业务成功时进入 S21，昵称以 trim 后的值保存。注册关闭或注册业务失败时不创建账户，不消费验证码。
6. 注册关闭事件覆盖正在填写、已发码和待提交的注册状态，显示 S43 的关闭说明并提供“返回登录”。已经成功创建的账户不因随后关闭注册而失效；登录和找回仍可用。
7. 注册业务响应丢失但创建可能已完成时进入 S44，保留填写内容并提示结果暂未确认。返回登录后可用刚提交的邮箱和密码恢复；这条路径不把业务回滚说成已发生。
8. 账户或密码持久数据写入失败时显示可重试失败，账户不视为创建成功，验证码保持可用。恢复后可以使用同一有效码重试，不因失败重复消费。

### J13 找回与重置密码

1. 从 S14 进入 S17，第一步只有邮箱。未知邮箱在本地或模拟账户服务拒绝，不发送验证码。
2. 对已存在邮箱执行真实的模拟发码操作。只有发码成功才进入确认卡 S18，并同时具有 S41 的只读绑定邮箱和活动验证码；当前行为不产生原 S42 的“第二步待发码”状态。
3. 确认卡只读显示第一步成功发码的邮箱，并提供“更换邮箱”。更换邮箱返回 S17，重新校验并重新发码；不会沿用旧挑战。
4. 确认提交进入 S38，快照包含绑定邮箱、challenge、验证码和新密码。确认卡本地校验顺序是验证码形状、新密码长度、两次新密码一致性、是否已经成功发码；验证码值错误、过期、已消费或耗尽进入 S40。
5. 重置成功后旧密码立即失效，已有该账户会话全部撤销，回到 S14 并显示 S37 的“密码已重置，请用新密码登录。”提示；用新密码登录可以进入 S21。
6. 重置持久写入失败时不改变账户密码、不撤销会话、不消费验证码，留在当前确认卡并可重试。
7. 重置响应丢失但密码可能已经改变时进入 S44，保留新密码并提示结果暂未确认。返回登录后用新密码尝试恢复；若恢复失败，沿正常登录或重新发码找回路径处理，不能伪装成已知网络失败。

### J25 会话与交接

1. 登录或注册成功后，默认入口进入 S21。已有站内会话门禁上下文保持其现有工作台路径，不新增一套返回地址规则。
2. 记住我会话的绝对有效期为 7 天。只有存在待恢复的记住我身份时，刷新或浏览器重开才先显示 S46，再在有效期内恢复到 S21；没有待恢复身份时直接显示 S14。不记住我只在当前页面内存中有效，刷新或重开回到 S14。
3. 恢复期间只显示 S46 等待卡，不闪现登录表单或工作台。恢复失败显示 S47，提供“重试”和“返回登录”。恢复期间会话被移除、过期、撤销或账户持久数据损坏时，迟到结果不得进入工作台；回到 S14 并显示过期或恢复失败提示。
4. 记住我会话持久化失败时进入 S45。业务登录或注册已经完成，但页面明确说明登录状态未保存，用户可继续当前会话、重试保存或返回登录。继续当前会话转为只在当前页面有效的会话；不应要求用户重复提交已完成的登录或注册业务。离开 S45 切换到任意表单都会放弃待恢复身份并清理它；之后来自旧待恢复身份的重置事件不得清空或改写新表单。
5. 待处理会话在继续或重试保存前重新核验账户、重置时间和会话有效性。核验发现该账户被重置、撤销或过期时回到 S14 并提示过期；不能迟到进入工作台或写回无效会话。
6. 密码重置撤销同一账户的所有已有会话。重置账户 A 不得退出账户 B 的工作台；不记住我会话也不得因无关的持久会话事件掉线。
7. 原型暂不提供设置页退出入口，CA53 保留为明确暂缺项。真实跨设备撤销由可见的外部事件替身呈现，不能宣称已经实现服务端全设备撤销。

## G01-G06 输入与结果口径

### G01 请求失败、并发与未知结果

输入先经过本地校验，再以一次提交快照执行登录、注册发码、注册、找回发码或重置。提交快照锁定规范化邮箱、trim 后昵称、原始密码、挑战标识、验证码、条款同意值和记住我选择；确认密码只用于本地一致性校验。条款先在本地校验，正式传输及后端独立校验由系统契约定义，本文不重述交换字段。

本地错误停留在对应字段，不发送本次业务请求。凭据拒绝统一显示，不透露邮箱是否存在；只清除被拒绝的密码，保留邮箱。已知未执行的网络、服务和超时失败保留输入并允许重试。登录的缺失、畸形或未分类结果进入 S36 的普通可重试错误，不进入 S44。注册或重置业务可能已经完成而响应丢失时，才使用 S44 的“结果暂未确认”分支；该分支不声称撤销或安全重复。

请求中允许编辑字段、改邮箱和切换表单。迟到结果只在原提交上下文仍然有效时更新当前界面；否则丢弃其界面结果，不清除新输入、不切换表单、不进入工作台。已完成的账户创建或密码重置仍然有效，用户通过登录恢复。提交和发码按钮在等待时锁定，重复触发不产生第二个业务操作。

关联旅程与场景：J11-J13、J25；CA41-CA48、CA65-CA73、CA77、CA79-CA81、CA82-CA91、CA96-CA109、CA120。完整步骤见[账户场景目录](auth-scenarios.md)指向的场景源码。

### G02 验证码、投递和挑战绑定

验证码为 6 位 ASCII 数字字符串，保留前导零，单个挑战有效 10 分钟，值错误最多 5 次；第五次错误后当前挑战作废并进入耗尽语义。成功发码后冷却 30 秒；重发成功才替换旧码并开始新冷却，发送失败不抹掉仍有效的旧码，也不启动新冷却。

注册和找回各自拥有挑战，挑战同时绑定用途和规范化邮箱。注册发码必须先确认邮箱未占用；找回第一步必须确认账户存在并真正发码成功，才进入只读邮箱的确认卡。改邮箱或切换用途清除当前挑战，旧挑战不能验证新地址或新用途。

验证码形状错误是本地错误，不消耗尝试次数。若验证码形状合法但值错误，且注册条款未勾选，先显示条款错误，不进入验证码业务判断，也不消耗次数。只有同一模拟业务操作完成注册或重置时才消费验证码；业务失败、网络失败、服务失败、注册关闭、邮箱冲突、持久写入失败和已知未执行的请求都不消费。

关联旅程与场景：J12-J13；CA55-CA64、CA69-CA70、CA74、CA78、CA82、CA84-CA85、CA92-CA94、CA101、CA105、CA110-CA119。

### G03 会话、恢复、过期和撤销

会话成功建立后，记住我为 7 天绝对有效期，未记住只在当前页面内有效。只有存在待恢复的记住我身份时，刷新和浏览器重开才进入 S46，再按账户、会话签发时间、有效期和重置状态核验；没有待恢复身份时直接显示登录卡。恢复等待期间不显示登录表单或工作台，所有迟到恢复结果都必须经过当前尝试和当前保存会话核对；已过期或畸形的保存身份直接进入相应过期或恢复失败结果，不伪装成成功恢复。

密码重置使该账户的旧会话失效，并在恢复、继续和重试保存前重新核验。账户 A 的重置只影响 A；账户 B 的工作台和会话保持可见。不记住我会话不因无关的持久会话变化掉线。存储损坏或账户服务不可读时显示可恢复失败，不静默回种子账户或旧密码。

记住我写入失败不否定已经完成的登录或注册业务，进入 S45；继续当前会话形成不持久的当前页会话，重试保存只重试会话持久化。离开 S45 切换到任意表单会放弃待恢复身份；旧待恢复身份的重置事件不得清空新表单。两个动作都不能绕过账户重置或过期核验。

关联旅程与场景：J25；CA49-CA54、CA71-CA73、CA79-CA81、CA95-CA99、CA106、CA108-CA109、CA120。

### G04 注册能力与关闭范围

默认允许新账户注册。关闭事件只禁止新的注册业务和新的注册验证码，不删除已创建账户，不阻止登录、找回或重置。已经打开的注册页在填写、已发码或提交等待中收到关闭事件时显示 S43，并提供回登录；待处理提交在业务裁决时发现关闭，不创建账户、不消费验证码。已经成功创建的账户不因随后关闭而失效。

注册入口可以保留为可见路径，但关闭时必须得到明确的关闭结果，不能进入工作台或把关闭伪装成网络失败。现有账户的登录和找回入口继续可用。

关联旅程与场景：J12；CA65-CA66、CA104。

### G05 账户身份与昵称交接

注册提交的昵称先 trim，再按 Unicode code point 计数 1-40，并以规范值保存。登录、注册恢复和密码重置后的身份交接都使用账户保存的昵称，不再从邮箱派生名称。账号行只接收 auth 提供的昵称数据；账号行布局、截断样式、完整名称可访问性和头像绘制由工作台拥有。

浏览器模拟账户的密码和昵称持久化后，刷新或重新打开可恢复；持久数据损坏时走恢复失败规则，不回到示例旧密码。密码重置只更新目标账户，且旧密码和目标账户的旧会话失效。

关联旅程与场景：J11-J12、J25；CA67、CA68、CA75-CA76、CA95、CA99、CA108。

### G06 精确输入边界与本地校验

- 邮箱：输入期间保留用户原文；提交或只读展示使用 trim 后转小写的规范值。规范值必须为 ASCII、长度不超过 254、恰好一个 `@`。本地部分长度 1-64，只允许英文字母、数字及 `._%+-`，不能以点开头或结尾，也不能有连续点。域名至少两个非空标签，每个标签 1-63，只允许英文字母、数字和中间连字符，不能以连字符开头或结尾。不做 DNS 查询，不宣称覆盖完整 RFC 邮箱语法。
- 昵称：trim 后为 1-40 个 Unicode code points；不把 UTF-16 length 当作字符数。输入显示不在键入时自动改写，提交保存 trim 后的值。
- 密码和确认密码：密码为 8-128 个 Unicode code points，不能 trim、大小写转换或 Unicode normalization。确认密码只用于本地一致性校验，不作为独立业务值提交。密码显隐是前端呈现状态。
- 验证码：必须是 6 位 ASCII 数字字符串，保留前导零；形状错误优先在本地提示，不消耗次数。
- 条款：注册默认不勾选；注册提交必须勾选。未勾选时先在本地阻止注册提交；正式传输及后端独立校验由系统契约定义。链接不跳转。有效形状的错误验证码与未勾选条款同时出现时先提示条款，不尝试验证码。

本地校验失败不发送业务请求，字段规则错误和业务字段错误落在引起它的字段下；非字段业务结果和持久化失败使用卡片顶部可关闭横幅。输入长度、规范化和字符规则在注册、登录、找回和重置的相应入口保持一致。

各入口的校验与业务判定顺序固定如下：

格式、长度、确认密码一致性和条款同意是本地校验。注册关闭、账户存在或占用、验证码真实性和持久化结果由模拟权威服务返回；正式应用由对应服务负责。以下顺序区分页面先做的本地校验和随后发生的业务判定。

- 登录：本地先检查邮箱为空或形状/长度错误，随后本地检查密码长度错误；均停留在字段，不发送登录请求。
- 注册发码：本地先检查邮箱错误，随后由模拟权威服务判定注册是否关闭、账户存储是否可用、邮箱是否已占用，之后才发送验证码。
- 注册提交：本地先检查邮箱错误；随后由模拟权威服务判定注册是否关闭；本地检查昵称为空、昵称超过 40 个 Unicode code points、密码长度、确认密码一致性、未发码、验证码形状和条款未同意；之后由模拟权威服务判定验证码真实性、账户占用、注册及持久化结果。有效形状的错误验证码不会在条款未同意时消耗次数。
- 找回第一步：本地先检查邮箱错误，随后由模拟权威服务判定账户存储是否可用、账户是否存在，之后才发送验证码；只有发送成功才进入确认卡。
- 找回确认：本地依次检查验证码形状、新密码长度、确认新密码一致性和是否已经成功发码；之后由模拟权威服务判定验证码真实性、生命周期、重置及持久化结果；没有注册条款校验。

本地或业务错误的呈现映射也固定：验证码值错误、缺失、已消费、过期和耗尽落验证码字段；注册邮箱占用和找回未知邮箱落邮箱字段；凭据拒绝、注册关闭、存储失败、响应未执行或普通未知错误落卡片顶部横幅。值错误显示剩余次数并可继续同一挑战，只有过期、已消费或耗尽要求重新发码。

关联旅程与场景：J11-J13；CA01-CA40、CA74-CA75、CA82-CA94、CA100-CA105、CA110-CA119。

## 持久化、服务替身与可见限制

初始浏览器模拟可提供示例账户 `example@example.com`、密码 `teachbuddy` 和昵称“林老师”。之后创建的账户、密码和昵称由浏览器内模拟账户服务保存；记住我会话由浏览器内模拟会话服务保存。上述保存位置只是原型替身，不是正式产品的技术要求。

首次没有账户记录可以使用示例账户。已有账户数据如果损坏、版本不识别、重复、字段非法或服务不可读，必须报告可恢复失败，不能静默重建示例账户或恢复旧密码。账户写入或重置写入失败时，业务结果保持未成功，恢复后可重试；会话持久化失败单独进入 S45。

真实邮件、真实网络、服务端全设备撤销和正式认证不由原型提供。验证场景可以用可控替身呈现发码等待、网络失败、响应丢失、存储损坏、到期和外部撤销，但界面不显示故障注入控件，也不把替身的浏览器事件描述为正式服务能力。

## Experience rules

- 入口卡片在三种支持视口内完整可见，不以页面滚动隐藏按钮或错误；卡片、文案和控件不横向溢出。
- 字段错误使用字段红边和字段下方说明；整条请求的结果使用卡片顶部横幅。横幅可关闭，关闭不会清除字段输入或撤销业务结果。
- 等待按钮使用“登录中”“注册中”“发送中”“提交中”等中文案并禁用，不重复触发操作。
- 找回第二步邮箱为只读但“更换邮箱”路径可用；只读状态不阻止返回第一步重新输入。
- 密码拒绝只清密码；网络、服务、超时、存储和未知结果保留可以恢复所需的输入。重置成功回登录并显示成功提示。
- 凭据拒绝、未知结果和持久化失败不显示内部异常、堆栈或实现细节。
- 账户入口与工作台交接后，工作台仍拥有原有布局和行为；auth 只提供已确认的账户昵称。
- 超长发码地址在发送目标说明中保持单行省略，不撑开卡片或挤压控件；完整规范地址通过可访问文本、`aria-label` 或 `title` 提供，原邮箱输入仍可查看。普通地址保持现有布局。

入口视觉、响应式、间距、焦点和控件可操作性遵循[项目设计与验证规则](../../docs/rules/design-and-verification.md)。

## Decisions and limitations

已确定：默认开放注册；关闭只影响新注册；登录和找回保留；验证码为 6 位 ASCII、10 分钟、错误 5 次作废、成功重发 30 秒冷却；昵称和密码边界及邮箱形状按 G06；请求快照、迟到结果丢弃、未知结果不撤销副作用；记住我 7 天，未记住只当前页面；账户密码昵称持久模拟；恢复等待、失败、重试、到期、撤销、重置旧会话和多账户隔离均可观察。

明确排除：CA53 设置页退出入口、服务条款页面跳转、真实邮件投递、真实后端认证、真实跨设备网络服务和管理后台。排除的是基础设施或尚未提供的入口，不得用它们排除对应的可见等待、失败、恢复、过期、撤销和重置行为。
