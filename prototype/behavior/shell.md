# 外壳与共享交互

Status: Accepted

运行入口见 [manifest](manifest.md)。本文件拥有跨导航与弹层共用的规则；具体入口行为见 [导航](navigation.md)、[侧栏](sidebar.md) 和 [顶部栏](topbar.md)。

## Scope

独立教师使用同一套顶部栏与侧边栏。桌面、平板和手机均可进入原型；外壳在会话之后，打开原型先看到[账户入口](auth.md)，登录或注册成功后才是本文件描述的界面。首页正文只是样例，不构成业务模块设计承诺。

## States and scenarios

| ID | 状态 | 进入与退出 |
| --- | --- | --- |
| S8 | 桌面侧栏窄轨 | 悬停顶栏后点击收起键；再次点击展开。宽度由 256px 过渡到 72px，顶栏品牌和导航锚点保持不动 |
| S9 | 手机抽屉 | 390px 视口点击汉堡入口；点击遮罩、关闭按钮或按 Escape 退出。抽屉内包含首页、日历、支持及模块列表 |
| S29 | 跳转中 | 点击任意入口后，顶栏与侧栏静止不动，只有正文以 160ms 淡入替换。整屏不出现白闪 |

展开态保留账户区、分组标签和垃圾桶；窄轨隐藏这些区域，模块保留图标与名称提示，鼠标悬停或键盘聚焦时完整显示于滚动容器外，分组间保留细分隔线。首次引导可能覆盖页面，体验其他状态前先关闭引导。

## Experience rules

- **顶栏入口与支持菜单共用一个打开状态**，同一时刻只显示一个面板。Escape 关闭当前面板并把焦点交还触发按钮；点击面板及其触发按钮之外关闭面板。切换入口直接切换面板。`Ctrl/Cmd + K` 切换搜索。
- **渐进出现**：所有浮层从透明度 0、缩放 0.96、上移 4px 展开到终态，180ms，`--tb-ease`。锚定右侧的浮层从右上角生长，居中的支持菜单从顶部中心生长。只出现不消失。`prefers-reduced-motion: reduce` 时取消动画直接落终态。
- **跳页即收起**：地址变化后任何打开的浮层都会关闭，新页面不会被旧浮层盖住，滚动位置同时复位到顶部。
- **外壳不重建**：跳转走历史 API，只替换正文。品牌、顶栏导航、支持菜单、搜索、侧栏模块行与抽屉条目都走这条路，漏掉任意一个都会让外壳整页重建。
- **真实链接**：每一个可跳转的入口都保留真实 `href`，中键、新标签页、复制链接和浏览器前进后退照常可用；只有普通左键点击被路由接管。
- **侧栏收起采用 0.2s 列宽动画**，顶栏固定，无翻页遮罩。
- **焦点**：键盘可聚焦的入口都有可见的 3px 焦点环；面板内的动作完成后焦点回到触发它的按钮。
- **状态分层**：布局等账户级偏好写入 `localStorage`，跨刷新保留；首次引导的"已看过"是标签页级（`sessionStorage`）；会话本身、通知已读、面板开合与侧栏收起都是设备内的临时状态，刷新即重置。
- **响应式**：桌面三栏首页网格；880px 以下收为单列；700px 及以下侧边栏变为抽屉加遮罩，顶栏只显示汉堡入口与五个独立动作，不显示桌面收起键。弹层限制在视口内，手机顶栏弹层固定在顶栏下方，宽度不超出两侧 12px 留白；侧栏菜单的定位见[侧栏](sidebar.md#experience-rules)。
- **动作反馈**共用一个可访问播报区域，内容随最后一次动作更新。
