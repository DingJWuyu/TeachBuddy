# 账户入口失败与恢复场景覆盖

Status: Accepted

本文拥有 CA41-CA109、CA120 的失败、恢复、验证码生命周期、请求并发和会话交接场景；CA53 是设置页退出入口的明确暂缺。行为定义由[账户入口](auth.md)拥有，本文只记录场景前提、复现入口、当前结果和证据链接。

完整运行包含 69 个可执行场景（CA41-CA109 中除 CA53 外的 68 个，加 CA120），在 PC、平板和手机三个视口生成 207 条通过记录。CA66、CA76、CA95 另有三端共 9 条补跑记录，均通过；完整结果中的对应三端条目是当前复核指针。

## 场景前提与复现

从 [manifest](manifest.md) 启动原型。每个场景使用独立浏览器上下文，从空登录卡开始；需要第二设备或另一标签页的场景由脚本创建额外上下文。示例账户为 `example@example.com` / `teachbuddy`，场景脚本通过既有模拟服务提供注册和找回验证码。

完整操作与逐步断言见 [auth-behavior-scenarios.mjs](../verification/auth-behavior-scenarios.mjs)，采集入口见 [capture-auth-behavior.mjs](../verification/capture-auth-behavior.mjs)：

```bash
node prototype/verification/capture-auth-behavior.mjs
```

默认地址为 `http://127.0.0.1:4174/`，可用 `PROTOTYPE_URL` 覆盖；`SCENARIO_IDS=CA66,CA76,CA95` 运行指定场景，`VIEWPORT_NAMES=PC` 运行指定视口。`dev-code`、`dev-cooldown` 和 `dev-no-cooldown` 只为脚本提供确定性的模拟验证码和冷却接缝，不在产品界面显示故障控件。

输入边界 CA110-CA119 由[输入边界场景索引](auth-input-scenarios.md)单独拥有，不在本表重复定义。
