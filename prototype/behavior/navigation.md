# 导航与搜索

Status: Accepted

运行入口见 [manifest](manifest.md)，面板互斥、关闭、焦点与跳转共用的规则见 [外壳](shell.md)。目的页面的正文只有首页有设计，其余统一为空占位，不属于导航本身的交付内容。

## Journeys

| ID | 目标 | 当前行为 |
| --- | --- | --- |
| J1 | 使用品牌与顶栏导航 | 品牌与「首页」到 `/`，「日历」到 `/calendar`；当前地址对应的顶栏项为选中态（深色药丸加 `aria-current="page"`），其余为未选中态。浏览器后退与前进让外壳跟着地址走，正文与选中态一起切换 |
| J2 | 使用模块入口 | 点击侧栏模块行进入 `/modules/<模块 ID>`，该行变为选中态；手机断点下先关闭抽屉再跳转。拖动换位、`Alt` 加方向键移动、`Delete` 隐藏这三个布局手势不受影响，`Enter` 交给链接本身 |
| J3 | 使用支持菜单 | 鼠标进入「支持」展开菜单，离开关闭，点击只负责打开；选择设置、帮助或更新日志后跳到对应地址并关闭菜单。手机断点下这三个入口内联展开在抽屉里，选择后关闭抽屉 |
| J4 | 搜索 | 点击搜索或按 `Ctrl/Cmd + K` 打开居中面板；输入按名称和提示过滤，方向键循环高亮，`Enter` 或点击进入结果对应的目的地并关闭面板。无匹配时保留输入与空状态提示 |

分组标题在展开时本身就是链接，指向组内第一个模块；折叠后降级为普通标题，只有右侧箭头可点，因为没有可见内容的组不该把用户带走。

## States and scenarios

| ID | 状态 | 复现 |
| --- | --- | --- |
| S1 | 首页 | 打开原型根地址；正文是与其余目的页面相同的空占位，只有图标与标题 |
| S2 | 空页面 | 进入除首页外的任一目的地址；圆形图标与页面标题，外壳完整可用。首页正文与此相同 |
| S2b | 不存在页面 | 手动输入未知路径；标题为「页面不存在」，正文带出该地址 |
| S24 | 支持菜单 | 顶栏悬停或手机抽屉点击「支持」；选择目的地后关闭 |
| S13 | 搜索面板 | 关闭首次引导，按 `Ctrl/Cmd + K`；输入已知样例或无匹配文本，体验结果与空状态 |

搜索为居中模态，打开后自动聚焦输入框，关闭后再次打开清空查询。支持菜单的悬停间隙连续可达；触摸以点击打开为入口。支持箭头展开时左旋 180°，关闭后复位。

## Visible information

模块、班级与课程名称是固定样例。搜索提示中的人数、时间同样来自样例，不表示真实账户资料。完整样例位于 [外壳源码](../src/SidebarEditingPrototype.jsx) 与 [搜索面板源码](../src/TopbarSurfaces.jsx)。

原型无需查询参数即可运行；已有查询参数在站内跳转时保留。页面标题同步为「TeachBuddy 工作台外壳原型 · <页面名>」。
