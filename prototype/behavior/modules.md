# 功能模块交互稿

Status: Draft，待用户视觉与交互评审。

产品要求见 [PRODUCT_SCOPE.md](../../docs/PRODUCT_SCOPE.md)，页面共识见[工作台共同交互](../../docs/features/workbench.md)。本文件只说明本轮源码原型已经覆盖到哪里，不缩减完整产品范围。

## 入口与布局

- 首页 `/` 是完整 Agent 工作区；底部固定 AI 入口在业务页面打开同一个助理的右栏形态。两种形态沿用同一段对话和输入草稿。
- 五个业务入口为 `/modules/bank`、`prep`、`studio`、`resources`、`classes`。日程从顶部 `/calendar` 进入，手机从导航抽屉进入。
- 桌面主工作区与右栏并排。题库标签、备课目录与大纲、资源分类、班级选择、工坊作品、日程工具各自与 AI 共用右栏。
- 页面固定在视口内，列表、文稿、预览、时间网格、安排编辑和 AI 对话分别滚动。业务页面和辅助页保持挂载，跨模块切换保留当前草稿与滚动位置。
- 当前窄屏交互稿在 1050px 及以下将主区和右栏切换显示；关闭右栏返回主区，不挤压成不可阅读的并列区域。题库在手机宽度下改为上下两块。该尺寸策略待实际使用评审。
- 普通浏览、筛选和修改可见日期范围不替换 AI；拖出时间段或明确编辑安排时打开日程工具，保留 AI 内容。

## 首轮可操作内容

| 区域 | 已接入的交互 |
| --- | --- |
| Agent | 输入、固定回复、同一对话在首页与右栏切换、返回原工作页面、当前对象提示 |
| 题库 | 搜索、自定义标签增改删、直接编辑、复制改编及原题关联、左右对照和宽度调整、自建题目、文本收录、图片/PDF 原始材料预览、教学笔记、单题或多题加入备课 |
| 备课 | 新建备课、编辑课题/目标/环节内容、增删及拖动教学环节、右侧目录与大纲定位、环节内选择题目/资源/作品、进入工坊并携带返回目标、关联课堂反馈 |
| 数学工坊 | 作品切换、可交互函数示例、导入与隔离预览 HTML、全屏、将当前作品带回备课 |
| 资源库 | 缩略图/列表、搜索、分类增改删、展开预览与返回、导入文件、替换文件并保留备注/关联、加入备课 |
| 班级教学 | 切换班级、实际教学位置、按日期阅读记录、保存一句随记、可选关联备课、跨模块保留未保存文字 |
| 日程 | 选择连续日期与天数、网格内横向/纵向浏览、按住指针拖出时间段、编辑已有安排、多个事项与优先级/段内排序、未安排时间的随手记、结束前后提醒、通知返回安排 |

标签、目录及教学材料都是可修改的个人样例，不构成预设题型体系。日程没有完成状态、逾期、进度或自动顺延。通知已读不加完成划线。

## 实现边界

- 数据与业务草稿只保存在当前页面会话的内存中；刷新、重新打开会重置。原有账户和侧栏布局存储边界继续各自维护。跨重启恢复、离线、跨设备、提醒补记尚未实现。
- AI 回复是本地固定文字，不调用模型，也不执行模块操作。未接 API Key、免费 AI 网站衔接或真实 Agent。
- 收录页已能展示原始材料并手工输入内容，尚未接 OCR、自动拆题、原稿位置对应、复杂公式编辑和导出。多来源自动整理仍是产品目标。
- 文稿当前为文字与引用块；不是完整 Word 编辑器。本课材料总览当前主要列资源，完整的备用材料与文书输出仍待细化。
- PPT/Word 样例封面由代码绘制，不表示已解析文件；实际导入文件可保留、替换和下载，图片与 PDF 可预览。尚未接 Office 文档渲染、缩略图提取、本地文件自动同步或正式引用版本规则。
- 数学工坊的函数示例自身提供参数控件，不能推定任意导入 HTML 都有统一编辑器。导入 HTML 在仅允许脚本的 sandbox iframe 中运行；skill 选择、制作流程、课堂设备兼容与 PPT 衔接待验证。
- 尚未实现重复排课、复杂时间重叠排布或服务端计时。当前提醒在页面存续期间轮询产生，最多约 15 秒延迟。
- 全局搜索仅覆盖固定入口样例，未搜索全部业务数据。设置、帮助与更新日志等目的页面仍保持原占位。

## 首轮检查

2026-09-21，在独立设计 worktree 使用实际浏览器走查：

- 首页与侧栏的同一 AI 对话、输入草稿和返回；题目复制、编辑、自建标签与筛选。
- 备课文稿和滚动位置跨模块保留；主区选题不替换右侧 AI，所选题目加入目标环节。
- 资源预览与返回、课堂随记保留与保存、数学示例参数跨模块保留。
- 11 天日程、真实指针拖选、右栏编辑、事项优先级与排序、到期提醒及通知返回。
- 1440×900、768×1024、390×844 的区域布局与滚动检查；生产构建通过。

走查结果用于排除当前交互错误，不能代替用户视觉验收，也不覆盖上述未实现能力。既有验证中针对旧九模块、空首页、固定三条通知的断言属于历史基线，不再适用于本轮模块交互稿；对应截图继续保留历史身份，未重新标记为本版通过。
