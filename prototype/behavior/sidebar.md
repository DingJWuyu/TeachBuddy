# 侧栏编辑

Status: Accepted

运行入口见 [manifest](manifest.md)，共享响应式规则见 [外壳](shell.md)。本文件拥有 J7、S6。

## Journeys

J7：教师在展开的侧栏中调整模块布局。

| 操作 | 结果与恢复 |
| --- | --- |
| 点击分组头 | 折叠或展开组内模块 |
| 右键或长按分组头 | 打开分组菜单，可重命名或移到未分组 |
| 重命名、新建分组 | 名称去除首尾空白，非空才提交；Escape 放弃输入 |
| 将分组移到未分组 | 移除分组，其模块保留并移入未分组 |
| 拖动模块或分组 | 插入线指示落点，松手后更新顺序；无效落点保持原位 |
| 拖入垃圾桶 | 隐藏模块或整个分组，更新隐藏计数 |
| 从垃圾桶点击或拖出 | 点击模块恢复到未分组，点击分组恢复其结构；拖出可指定落点 |
| 模块行按 `Alt` 加方向键、`Delete` | 移动模块或隐藏模块 |

分组头长按 480ms 打开菜单。`未分组` 是固定分组，保留为恢复模块的落点；布局数据的生命周期见 [外壳](shell.md)。

## States and scenarios

S6：点击垃圾桶打开隐藏项面板。隐藏模块或分组可复现非空状态，逐项恢复后回到空状态。计数为隐藏分组与隐藏模块的总数，零时隐藏计数。

## Experience rules

- 垃圾桶面板右侧展开，与垃圾桶行同宽；空状态占一个模块行，非空时每个条目等宽等高。细线不挤占内容尺寸。
- 新建分组在触发器右侧紧凑浮层内输入，不占用侧栏整行。
- 拖拽插入线不挤动列表，任一时刻只显示一条有效落点线。分组交界处的线与落点保持一致。
- 工作台标题、新建分组入口和窄轨分组线表达可编辑的分组结构；创建学期按钮使用 10px 圆角，避免宽按钮过于方正。
- 焦点与拖放落点使用清晰可见的 3px 环。具体视觉值见 [样式](../src/sidebarEditingPrototype.css) 与 [几何验证](../verification/verify-visual.mjs)。

## Accepted limits

真实指针拖拽在特定轨迹下仍可能出现插入线跳动，触发条件未确定，用户已同意暂缓处理。[拖拽验证](../verification/verify-drag.mjs) 的合成事件未复现该问题；这些断言不表示真实指针问题已解决。
