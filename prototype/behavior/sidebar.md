# 侧栏编辑

Status: Accepted

运行入口见 [manifest](manifest.md)，共享响应式与跳转规则见 [外壳](shell.md)，模块行的跳转行为见 [导航](navigation.md)，
头部区（账号行、语言切换、学期选择）见[侧栏头部](sidebar-head.md)。本文件拥有 J7、J16、J17 与 S5、S6、S22、S23、S26-S28。

## Journeys

J7：教师在展开的侧栏中调整模块布局。

| 操作 | 结果与恢复 |
| --- | --- |
| 点击分组箭头 | 折叠或展开组内模块，内容高度插值过渡；展开时点击名称进入首个模块 |
| 右键或长按分组头 | 打开分组菜单，可重命名或移到未分组 |
| 重命名、新建分组 | 名称去除首尾空白，非空才提交；Escape 放弃输入 |
| 将分组移到未分组 | 移除分组，其模块保留并移入未分组 |
| 拖动模块或分组 | 插入线指示落点，松手后更新顺序；无效落点保持原位 |
| 拖入垃圾桶 | 隐藏模块；拖入分组会删除分组并隐藏其成员，计数只统计模块 |
| 从垃圾桶点击或拖出 | 点击模块恢复到未分组；拖出可指定落点，不重建已删除分组 |
| 模块行按 `Alt` 加方向键、`Delete` | 移动模块或隐藏模块 |

分组头长按 480ms 打开菜单。`未分组` 是固定分组，保留为恢复模块的落点。

J16：教师删除正在浏览的页面所对应的模块。

删除方式可以是模块行按 `Delete`、把模块行拖进垃圾桶，或把包含它的整个分组拖进垃圾桶。三种方式都会把用户带回首页，因为当前地址已经没有任何内容可显示。删除别的模块时停留在当前页。

J17：教师把模块放进一个已经空了的分组。

分组里的模块全部移走后，分组标题仍然保留；空分组整块成为落点，模块可以落进去。分组标题及其上方的空白属于该组顶部，模块因此可以放到任意分组的第一位。组与组之间的缝隙按中点归属。

## States and scenarios

| ID | 状态 | 进入与退出 |
| --- | --- | --- |
| S5 | 侧栏垃圾桶识别 | 拖动模块或分组到垃圾桶上；垃圾桶行与图标变红，图标放大，计数徽标变红。离开或松手即还原 |
| S6 | 垃圾桶面板 | 点击垃圾桶打开，列出被隐藏的模块；点击恢复，也可拖出。计数为隐藏模块总数，零时不显示计数 |
| S26 | 拖拽图 | 拖动任意模块行，指针旁出现一枚 32px 白色圆，正中是模块自己的图标；拖分组头时同一枚白圆里换成文件夹图标 |
| S27 | 布局恢复 | 刷新、换页或直接深链打开后，模块顺序、分组、折叠状态与垃圾桶内容与刷新前一致 |
| S28 | 分组折叠中 | 点分组箭头，在 220ms 内观察内容高度收缩、行被裁切；折叠开始即退出可达树 |
| S22 | 空分组落点 | 把一个分组的模块全部移走，再把别的模块拖到该分组标题下方的区域；整块高亮，松手后模块成为该组第一项 |
| S23 | 删掉当前页面 | 在 `/modules/<ID>` 上按 `Delete`、拖该行入垃圾桶，或把它的分组拖入垃圾桶；页面回到首页 |

## Experience rules

- 垃圾桶面板右侧展开，与垃圾桶行同宽；空状态占一个模块行，非空时每个条目等宽等高。细线不挤占内容尺寸。
- 新建分组在触发器右侧紧凑浮层内输入，不占用侧栏整行。
- 手机分组菜单固定在抽屉底部。Escape 只关闭当前菜单或放弃分组输入，不同时关闭抽屉。
- 拖拽插入线不挤动列表，任一时刻只显示一条有效落点线。**插入线即落点**：落点在插入线出现时确定并保存，松手不再按几何重新解析，因为拖动开始后源行已经离开文档流。
- 分组内容用 `grid-template-rows` 从 `1fr` 过渡到 `0fr`，时长 220ms；折叠中的内容立即 `inert`，不可聚焦也不可拖拽。
- 拖拽图是一枚 32px 白圆，圆内是深色图标，圆心精确落在指针上，圆外留 4px 透明边距；系统图用 1x1 透明画布压掉，因此指针旁边只有这一枚圆。圆用细描边和投影保证在白底上可见。拖拽结束（含取消）即从文档移除，拖拽期间光标按抓取手势请求。
- 拖拽图在拖拽过程中若源行被自己的拖放删除、拖拽中途关闭面板或离开页面，都不留下残留。
- 工作台标题、新建分组入口和窄轨分组线表达可编辑的分组结构。
- 焦点与拖放落点使用清晰可见的 3px 环。具体视觉值见 [样式](../src/sidebarEditingPrototype.css) 与 [几何验证](../verification/verify-visual.mjs)。
- 布局写入 `localStorage`，版本号为 1；全部模块恰好出现一次，分组 ID 唯一，未分组区域必须存在。结构不符、缺项、重复或数据损坏时整份回落默认，不半读。存储内的隐藏分组只提取成员进入垃圾桶，不恢复分组结构。清除原型的站点存储后重新进入可恢复默认布局。
