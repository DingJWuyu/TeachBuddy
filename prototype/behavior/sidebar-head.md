# 侧栏头部

Status: Accepted

本文件拥有 J18-J24、S30-S35。运行入口见 [manifest](manifest.md)，场景 CW48-CW51 的复现和证据见[头部场景覆盖](sidebar-head-scenarios.md)。共享规则由[外壳](shell.md)拥有。

## Scope

独立教师在展开态侧栏使用账号行、语言菜单与学期选择器。支持 PC 1440×900、平板 768×1024、手机 390×844，以及鼠标、键盘和触摸点击。窄轨隐藏头部；手机抽屉显示头部。

学期使用会话内的样例列表，刷新恢复两个初始学期。语言选择只改变语言按钮、国旗与当前项，不模拟全站翻译。创建、编辑、删除不连接服务；复制只模拟分类选择和反馈，不创建真实班级、学生或课程数据。

## Journeys

| ID | 目标 | 行为 |
| --- | --- | --- |
| J18 | 进入账户设置 | 账号行保留 `/settings` 的真实链接；普通左键客户端跳转，关闭浮层与手机抽屉，外壳不重建 |
| J19 | 选择语言 | 展开 S30，选择后更新按钮无障碍名、国旗和对勾，播报选择结果并关闭；取消不改变选择 |
| J20 | 切换学期 | 展开 S31，选择后更新选择器名称和列表对勾，播报结果并关闭；取消保持当前学期 |
| J21 | 创建学期 | S31 点「新学期」进入 S32；必填校验通过后加入列表、成为当前学期并关闭；取消不产生学期 |
| J22 | 编辑学期 | 学期行右侧编辑按钮进入 S33，名称与日期预填；保存只更新该学期，不切换当前学期；取消保持原值 |
| J23 | 删除学期 | S33 的「更多」菜单点「删除」立即移除，无二次确认；删除当前项时选择剩余第一项；最后一项禁用删除（S35） |
| J24 | 选择复制内容 | 创建时选「从已有学期复制」，或直接在编辑对话框使用复制区；选择来源显示 S34，勾选分类后随提交播报复制结果 |

鼠标点击与聚焦后按 Enter、Space 都能操作编辑按钮，不触发行本身的学期切换。

创建或编辑的子菜单先于父对话框关闭：Escape 收起当前「更多」或来源菜单，保留全部表单输入；即便 Tab 或 Shift+Tab 已将焦点移出子菜单，也先收起仍打开的子菜单并归还焦点。再按 Escape 才取消对话框。关闭按钮、取消按钮、对话框外部点击也取消表单。重新打开重新读取当前学期，不恢复取消的草稿。

切换复制来源清除分类勾选。切回「从头开始」时，提交不携带复制选择；只选来源但没有勾选分类，也不播报复制成功。创建和编辑都只在存在来源及至少一个勾选分类时播报复制结果。

## States

| ID | 状态 | 可见内容与退出 |
| --- | --- | --- |
| S30 | 语言菜单 | 20 种语言、国旗、当前项对勾；可滚动至末项；选择、Escape 或外部点击关闭 |
| S31 | 学期弹层 | 当前全部学期、完整日期范围、编辑按钮与新建入口；选择、Escape 或外部点击关闭 |
| S32 | 创建对话框 | 名称、起止日期、两种起始方式、预览或复制区、创建与取消 |
| S33 | 编辑对话框 | 预填字段、更多菜单、复制区、保存与取消；没有起始方式卡片 |
| S34 | 复制分类 | 班级、学生、单元、课程、课程标准、课堂主题及样例数量；零数量分类禁用 |
| S35 | 最后一个学期 | 更多菜单的删除项禁用；仍可编辑、取消或创建新学期；无其他来源时来源列表为空 |

## Visible information

- 账号行使用字母头像和单行截断的名字。账户显示名的规则及原型接线范围见[账户入口](auth.md#g05-账户身份与昵称交接)。
- 语言项显示母语名与英文名；English 不重复第二个名字。语言按钮无障碍名就是当前语言的母语名。
- 日期使用浏览器原生日期字段，三个表单字段必填。列表日期始终包含完整年月日，以 ` – ` 连接起止日期，不省略年份。
- 分类数量为固定样例，课堂主题数量为 0，用于呈现禁用态。
- 选择、创建、保存与删除通过外壳的可访问播报区反馈。刷新清空本次语言、学期与表单状态。

## Experience rules

- 语言、学期、学期对话框与顶部栏共享打开状态。切换入口互斥，`Ctrl/Cmd+K` 切换搜索并收起手机抽屉；普通导航、后退或前进都关闭浮层。隐藏头部时关闭其浮层。
- 语言菜单与实际侧栏同宽，最多高 321px；学期弹层宽 280px，并受视口宽高限制。菜单滚动不改变页面布局。
- 语言按钮 32×32；徽标 14×14，右下溢出 2px，带 2px 白环。学期选择器高 36px，侧边留白 12px。悬停时出现「切换学期」提示，弹层打开时隐藏。
- 编辑按钮 28×28，桌面悬停或键盘聚焦时显形并带 2px 描边；手机始终显示，支持直接触摸点击。
- PC 对话框 1000×601，表单列 380px；平板保持双栏并缩小预览列。关闭图标与标题左边缘对齐；起始方式卡片高 82px，提交入口与卡片间距约 24px。
- 手机对话框距视口四边至少 16px，依次呈现标题、字段、复制或预览内容、底部动作。内容纵向滚动，底部提交和取消保持可达，不产生横向滚动。
- 对话框使用原生模态层，背景不可操作，打开时聚焦名称。Tab、Shift+Tab 在可用控件间循环；子菜单关闭回到自己的触发按钮，对话框关闭回到学期选择器。外部点击关闭非模态菜单时不抢走目标焦点。
- 桌面选中复制来源不改变对话框和两栏的位置，分类在栏内滚动；手机由整个对话框滚动，完整访问分类、提示和提交入口。
- 编辑态未选来源时显示琥珀提示，选定来源后显示蓝色说明。浮层的圆角、阴影、渐进出现与减弱动效规则沿用外壳。

## Decisions

- 日期始终显示完整年月日，删除无需二次确认，最后一个学期不可删除，创建后切换为新学期。
- 分类样例包含可选值与一个零数量禁用项；这是可观察交互模拟，不代表真实数据复制。
- 手机沿用现有控件和视觉令牌，通过纵向布局、滚动和固定可达的底部动作适配，不另设一套视觉样式。

## Verification boundaries

鼠标、键盘、三端浏览器视口与模拟触摸点击均有检查；未把模拟点击当作真机手势验证。账户样例与服务范围见 Scope 及账户入口，不计为产品故障或已验证的真实服务行为。
