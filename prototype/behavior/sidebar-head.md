# 侧栏头部

Status: Accepted

运行入口见 [manifest](manifest.md)，浮层共用的关闭、焦点与渐进出现规则见[外壳](shell.md)。
本文件拥有 J18-J24、S30-S35，并索引场景 CW48-CW51。

侧栏展开态顶部的账号行、语言切换与学期选择三块内容。三者的视觉与交互一比一复刻真实登录态的
EMStudio；项目记录里不再保留实测过程，取值直接写在本文件。

## Scope

演员是使用个人工作台的独立教师，只有一个登录账号，不涉及学校或组织层级。

入口是侧栏展开态顶部的头部区：账号行、同一行右端的语言按钮、下方独立的学期选择器，以及它们打开的
语言菜单、学期弹层和学期对话框。窄轨与手机抽屉下这三块的可见性由[外壳](shell.md)拥有。

支持视口：PC 1440×900、平板 768×1024、手机 390×844。

学期是样例数据，创建、编辑、删除与复制只改本次会话内的列表，刷新回到初始的两个学期；不做数据层与服务。
账号显示名的取值属于[账户入口](auth.md)的接缝，侧栏只负责呈现。

## Journeys

| ID | 目标 | 行为 |
| --- | --- | --- |
| J18 | 进入账户设置 | 账号行本身是指向 `/settings` 的链接，保留真实 `href`，普通左键走客户端跳转 |
| J19 | 切换界面语言 | 点地球按钮展开语言菜单，选中一种语言后按钮的无障碍名、国旗徽标与菜单里的对勾一起更新，菜单关闭 |
| J20 | 切换当前学期 | 点学期选择器展开弹层，选中一个学期后选择器文字、账号行下方的当前学期与列表里的对勾一起更新 |
| J21 | 创建学期 | 在弹层里点「新学期」打开创建对话框，填名称与起止日期后提交，新学期进入列表并成为当前学期 |
| J22 | 编辑学期 | 点学期行右侧的编辑按钮打开编辑对话框，字段预填该学期现值，保存后就地更新 |
| J23 | 删除学期 | 在编辑对话框标题行的「更多」菜单里点「删除」，该学期从列表移除；删的是当前学期时切到剩余的第一个 |
| J24 | 从已有学期复制 | 在对话框右侧选一个来源学期，列出可复制的分类并逐项勾选，随创建或保存一起生效 |

创建与编辑都以对话框形式进行，两者共用同一个对话框组件：创建态有「起始方式」两张卡片，编辑态没有；
编辑态的标题行右侧多一个「更多」菜单。

## Visible information

- 账号行显示登录账号的显示名，超长截断；头像取显示名首字。参照用的是一张真实头像图，这里用字母头像，
  属于样例数据的替换，几何一致。
- 语言菜单每项是一面圆形国旗、该语言的母语名，以及英文名；英文项没有第二个名字。当前语言的项在右侧带对勾。
- 学期行显示学期名与日期范围，日期**始终是完整年月日**，两个日期之间用 ` – `（en dash）。
- 复制内容的六个分类依次是班级、学生、单元、课程、课程标准、课堂主题，各带数量胶囊。
  数量是样例值，最后一项保持为 0 以呈现禁用态。
- 创建与编辑成功后内容随最后一次动作更新到外壳的播报区。

## Experience rules

- 语言按钮的无障碍名是语言名本身，不是「语言：…」；国旗徽标悬在地球图标的右下角并向外溢出 2px，
  带 2px 白色描边环。
- 语言菜单横跨侧栏整宽；学期弹层比侧栏更宽，向右溢出。两者互斥，与其他浮层共用一个打开状态。
- 学期选择器悬停时在其正上方显示 `切换学期` 提示，带向下的小箭头；弹层展开时不显示。
- 学期行的编辑按钮默认 `opacity: 0`，所在行悬停或按钮获得键盘焦点时显形，并带 `2px` 描边环。
- 两个对话框都是 1000×601，左侧表单栏 380、右侧 619。关闭按钮比内容左边线左移 4px，
  让图标而非点击区与标题左边缘对齐。
- 名称、开始日期、结束日期三个字段都是必填，用浏览器原生校验拦截空表单，不自绘错误提示。
- 日期字段是原生日期输入，年月日分段与日历选择器由浏览器提供。
- 复制面板的提示条随状态换语气：编辑态未选来源时是琥珀警示，已选来源时是蓝色说明。
- 对话框正文高度固定，固定高度之外的余量把底部按钮压到对话框底部。
- 浮层沿用外壳的渐进出现规则；`prefers-reduced-motion: reduce` 下直接落终态。
- 窄轨隐藏整个头部区；手机抽屉里头部区照常显示。

## Decisions

- 账号名称来自注册时填写的昵称，不由邮箱推导。取值属于[账户入口](auth.md)的接缝，侧栏按
  「会话提供昵称、侧栏原样呈现」实现，不在这里重新推导。
- 日期范围必须显示完整年月日。参照会省略与当前年份相同的起始年份，这里不省略。
- 删除没有二次确认，点即删。
- 只剩一个学期时删除项禁用，避免列表变空、选择器无内容可选。
- 创建出的学期直接成为当前学期。
- 复制内容的分类数量用样例值，且保留一项为 0 以呈现禁用态。
- 浮层动效时长沿用[外壳](shell.md)已定的 180ms，而非参照的 150ms。
- 复制面板提示条文案里的连接符用普通连字符，参照原文用的是 em dash。

## 覆盖缺口

- **账号名未接线**：账号行仍显示样例名字。等[账户入口](auth.md)提供昵称后由会话传入。
- **响应式未取证**：三个断点下的头部布局、以及窄轨与手机抽屉下新浮层的表现尚未逐视口截图断言。
- **「更多」菜单只有删除一项**，与参照一致；参照里没有其他项。
- **复制结果不可见**：勾选只影响播报文案，原型里没有班级、学生等数据能让它产生真实结果。
- **对话框未提交到任何服务**：创建、编辑与删除只改本次会话内的样例列表。
