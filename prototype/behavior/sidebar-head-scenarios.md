# 头部场景覆盖

Status: Accepted

本文件拥有 CW48-CW51 的复现与证据索引。行为定义见[侧栏头部](sidebar-head.md)，运行与输出配置见 [manifest](manifest.md)。

## 复现

每个场景使用独立浏览器上下文，示例账户登录后关闭首次引导；手机先打开工作台抽屉。浏览器上下文重建可重置语言、学期列表和布局。除专门的刷新检查外，场景中的导航使用客户端路由。

| 场景 | 初始条件、操作与预期 |
| --- | --- |
| CW48 | 默认两个学期与简体中文；检查头部与菜单，滚动语言列表至末尾，选择 English，再取消一次选择；切换春季学期并取消菜单；快捷键切到搜索，账号行进入设置，后退关闭浮层；宽屏收起侧栏后隐藏头部 |
| CW49 | 从空创建表单输入“待取消的学期”与 2027 年日期，取消、重开验证草稿不保留；键盘编辑春季学期，改名后分别打开更多与来源菜单，直接 Escape 或用 Tab/Shift+Tab 移出焦点后 Escape，都只关闭子菜单且保留输入；再次 Escape 取消，重开仍为原值；外部点击取消 |
| CW50 | 顺次提交缺少名称、开始日期和结束日期的表单，浏览器拒绝后补齐；创建“2027春季学期”，再改名保存；复制模式选择来源、勾选学生、查看零数量禁用项；换来源清除勾选，切回从头开始提交不复制；独立创建一次带复制选择的学期，最后刷新恢复两个样例学期 |
| CW51 | 编辑非当前春季学期，选复制来源前后宽屏两栏位置不变；删除非当前项保持秋季为当前；最后一项禁用删除；重置场景后删除当前秋季学期，自动选择剩余春季学期 |

手机使用触摸点击，无悬停或桌面窄轨入口；这些入口仅在 PC、平板检查，不作为手机缺陷或待办。原生日期字段和必填提示的语言跟随浏览器；它们不由界面语言选项翻译。

## 当前验证

- [交互回归](../verification/verify-sidebar-head.mjs)：三端键盘编辑、嵌套 Escape、焦点循环与归还、互斥、导航、复制模式、资源加载、布局和减弱动效。[结果](../evidence/verification/sidebar-head.json)
- [几何检查](../verification/verify-sidebar-head-geometry.mjs)：PC 控件与对话框尺寸、日期输入和客户端跳转。[结果](../evidence/verification/sidebar-head-geometry.json)
- [学期布局](../verification/verify-semester-layout.mjs)：复制区稳定、删除与编辑按钮。[结果](../evidence/verification/semester-layout.json)
- [学期动作](../verification/verify-semester-actions.mjs)：必填校验、创建、保存、来源与分类选择、禁用状态和反馈。[结果](../evidence/verification/semester-actions.json)
- [状态采集](../verification/capture-sidebar-head.mjs)：12 个场景与视口组合全部通过，共 134 张当前截图；采集前断言状态，同时记录实际几何。[结果](../evidence/verification/sidebar-head-capture.json)

静态图不证明焦点、时序或数据变化，交互断言负责这些结果。构建后的页面也运行交互回归，逐项确认 20 面国旗能够解码。鼠标、键盘与模拟触摸点击不等于真机手势验证。
