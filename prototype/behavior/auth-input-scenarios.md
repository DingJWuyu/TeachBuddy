# 账户输入边界场景索引

Status: Accepted

本文拥有 CA110-CA119 的 G06 输入边界场景索引。边界规则和用户可观察行为由[账户入口](auth.md#g06-精确输入边界与本地校验)拥有，本文只记录复现入口、当前结果和证据链接，不重复行为定义。

## 场景前提与复现

从 [manifest](manifest.md) 启动原型。每个场景在 PC 1440×900、平板 768×1024、手机 390×844 运行；截图在断言目标状态后生成，并检查入口卡片完整、无横向溢出和无开发浮层。

完整操作与逐步断言见 [verify-input-boundaries.mjs](../verification/verify-input-boundaries.mjs)：

```bash
PROTOTYPE_URL=http://127.0.0.1:4174/ node prototype/verification/verify-input-boundaries.mjs
```

`SCENARIO_IDS=CA110,CA111` 或 `VIEWPORT_NAMES=PC` 可运行子集；子集报告不会覆盖完整报告。脚本使用现有模拟服务和检查接缝，不增加产品界面控件。

## 当前结果

结果指针：[JSON 报告](../evidence/verification/input-boundary-report.json) · [Markdown 报告](../evidence/verification/input-boundary-report.md)。完整运行包含 10 个场景、30 条三端记录，63 张截图，全部通过。

截图统一位于 `evidence/screenshots/input-boundary/CA110/` 至 `CA119/`，下表直接链接每个视口的当前截图。
